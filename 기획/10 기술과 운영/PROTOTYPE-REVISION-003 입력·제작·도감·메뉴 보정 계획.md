## 1. 확정 보정

1. 슬롯 `0/-106`만 서버 권위 장비 슬롯으로 유지하고 핫바 `1~8`은 바닐라 자유 슬롯으로 되돌린다.
2. 무기 전투 라우터는 현재 슬롯 `0`에서만 실행하고 `0`을 유지한다. 웅크린 채 `2~5`는 C1~C4, `6~9`는 Q1~Q4이며 어느 슬롯에서 호출해도 실행 뒤 원래 슬롯으로 복원한다.
3. 일반 `2~9` 선택과 슬롯 `1~8`의 채굴·설치·섭취는 가로채지 않는다. `Shift+F`는 어느 슬롯에서든 메뉴를 열고 원래 슬롯을 유지하며, 일반 F는 슬롯 `0`에서만 W3이고 그 밖에서는 바닐라 교환이다.
4. 채집·적 드롭은 개인 PDC 자원 아이템으로 지급한다. 공용 보급 저장소 제작 전 공용 원장은 접근할 수 없다.
5. Craft는 회차 시작 시 잠금 상태이며 아무 원목 4개로 파티 해금한다. 커스텀 제작은 빈 3×3 GUI만 사용한다. 장비·도구는 고정 배치, 배급·붕대·중화제·보급 저장소는 위치 무관 조합이고 요구 단위마다 서로 다른 칸을 차지한다.
6. 아이템 도감은 자원·장비·소모품·시설의 고정 ID 순서를 사용한다. 미발견 항목은 검은 염료 `???`, 첫 획득 뒤 상세·조합법·사용처를 공개한다.
7. 플레이어 메뉴는 Craft·도감·스탯·장비·증강·공용 원장·설정을 통합한다.
8. 피해량은 대상 근처 TextDisplay로 표시하고 동시 48개·20틱 상한 및 개인 표시 설정을 적용한다.
9. 전투 장비는 제작 시 실제 인벤토리 아이템으로 지급하고 장비 GUI가 실제 보유 장비만 장착·해제·직접 교체한다. 비장착 가능 위치는 장벽으로 표시한다.
10. 공용 보급 저장소는 실물 시설 아이템으로 제작·배치한 뒤 원장을 해금한다. 회차 시작 생존 시계는 Day 진행을 표시한다.
11. 증강 메뉴는 보유 개인·파티 증강과 미선택 드로우를 연결한다. 설명 기본값은 간단 모드이며 설정에서 도감·증강·스킬 수치 상세를 함께 전환한다.
12. 액션바 알림에 우선순위와 유지 시간을 부여하여 상시 HUD가 EXP·레벨 상승·빈사·구조를 덮어쓰지 못하게 한다.

## 5. BLOCKER

`BLOCKER-INPUT-PLACE-001`: 현재 자동·콘솔 중심 빌드에서는 실제 플레이어의 블록 설치 패킷과 웅크림+숫자 조합을 재현할 수 없다. `/setblock`은 입력 라우터와 `PlayerInteractEvent`를 통과하지 않으므로 통과 증거로 인정하지 않는다. 실제 Minecraft Java 클라이언트로 슬롯 `0` 전투 곡괭이 채굴, 슬롯 `1~8` 각각의 블록·횃불 설치, 음식·물약 사용, 모든 시작 슬롯에서 웅크림+2~9, Shift+F, 휠 전환을 수행해야 해제한다.

`BLOCKER-HOTKEY-SAME-SLOT-002`: Bukkit `PlayerItemHeldEvent`는 클라이언트가 현재 선택 중인 번호를 다시 누를 때 패킷/이벤트가 발생하지 않을 수 있다. 예를 들어 이미 slot `1`을 선택한 상태의 `Shift+2`도 반드시 C1으로 잡혀야 한다면 폐쇄 테스트로 이벤트 발생 여부를 먼저 확정하고, 미발생 시 모드가 아닌 서버 플러그인형 패킷 어댑터(PacketEvents/ProtocolLib 계층)를 선택해 입력 라우터 앞에 추가한다. 단순 웅크림 이벤트 추정은 블록 설치와 잠입을 오발시키므로 사용하지 않는다.

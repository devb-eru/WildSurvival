## 1. 확정 보정

1. 슬롯 `0/-106`만 서버 권위 장비 슬롯으로 유지하고 핫바 `1~8`은 바닐라 자유 슬롯으로 되돌린다.
2. 전투 라우터는 현재 슬롯 `0`에서만 실행한다. 웅크린 채 `2~5`는 C1~C4, `6~9`는 Q1~Q4이며 실행 뒤 `0`으로 복원한다.
3. 일반 `2~9` 선택과 슬롯 `1~8`의 채굴·설치·섭취는 가로채지 않는다. `Shift+F`는 메뉴, 일반 F는 무기 입력이다.
4. 채집·적 드롭은 개인 PDC 자원 아이템으로 지급한다. 공용 보급 저장소 제작 전 공용 원장은 접근할 수 없다.
5. Craft는 회차 시작 시 잠금 상태이며 아무 원목 4개로 파티 해금한다. 커스텀 제작은 3×3 GUI의 정확한 고정 배치만 허용한다.
6. 아이템 도감은 자원·장비·소모품·시설의 고정 ID 순서를 사용한다. 미발견 항목은 검은 염료 `???`, 첫 획득 뒤 상세·조합법·사용처를 공개한다.
7. 플레이어 메뉴는 Craft·도감·스탯·장비·증강·공용 원장·설정을 통합한다.
8. 피해량은 대상 근처 TextDisplay로 표시하고 동시 48개·20틱 상한 및 개인 표시 설정을 적용한다.

## 4. BLOCKER

`BLOCKER-INPUT-PLACE-001`: 현재 자동·콘솔 중심 빌드에서는 실제 플레이어의 블록 설치 패킷과 웅크림+숫자 조합을 재현할 수 없다. `/setblock`은 입력 라우터와 `PlayerInteractEvent`를 통과하지 않으므로 통과 증거로 인정하지 않는다. 실제 Minecraft Java 클라이언트로 슬롯 `1~8` 각각의 블록·횃불 설치, 음식·물약 사용, 웅크림+2~9, 휠 전환을 수행해야 해제한다.

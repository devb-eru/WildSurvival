## 1. 확정 보정

1. 슬롯 `0/-106`만 서버 권위 장비 슬롯으로 유지하고 핫바 `1~8`은 바닐라 자유 슬롯으로 되돌린다.
2. 무기 전투 라우터와 `Shift+2~9`는 입력 직전 슬롯 `0`에서만 실행한다. 공용·소모품 숫자 조합 뒤에는 슬롯 `0`으로 복귀한다.
3. 일반 `2~9` 선택과 슬롯 `1~8`의 채굴·설치·섭취는 가로채지 않는다. `Shift+F`는 어느 슬롯에서든 메뉴를 열고 원래 슬롯을 유지하며, 일반 F는 슬롯 `0`에서만 보조무기 행동이고 그 밖에서는 바닐라 교환이다.
4. 채집·적 드롭은 개인 PDC 자원 아이템으로 지급한다. 공용 보급 저장소 제작 전 공용 원장은 접근할 수 없다.
5. Craft는 회차 시작 시 잠금 상태이며 아무 원목 4개로 파티 해금한다. 커스텀 제작은 빈 3×3 GUI만 사용한다. 장비·도구는 고정 배치, 배급·붕대·중화제·보급 저장소는 위치 무관 조합이고 요구 단위마다 서로 다른 칸을 차지한다.
6. 아이템 도감은 자원·장비·소모품·시설의 고정 ID 순서를 사용한다. 미발견 항목은 검은 염료 `???`, 첫 획득 뒤 상세·조합법·사용처를 공개한다.
7. 플레이어 메뉴는 Craft·도감·스탯·장비·증강·공용 원장·설정을 통합한다.
8. 피해량은 대상 근처 TextDisplay로 표시한다. 생산값은 `ENTITY-LIST-001`의 다단 4틱 합산·14틱 수명·전역/대상/시청자 상한을 따른다.
9. 전투 장비는 제작 시 실제 인벤토리 아이템으로 지급하고 장비 GUI가 실제 보유 장비만 장착·해제·직접 교체한다. 비장착 가능 위치는 장벽으로 표시한다.
10. 공용 보급 저장소는 실물 시설 아이템으로 제작·배치한 뒤 원장을 해금한다. 회차 시작 생존 시계는 Day 진행을 표시한다.
11. 증강 메뉴는 보유 개인·파티 증강과 미선택 드로우를 연결한다. 설명 기본값은 간단 모드이며 설정에서 도감·증강·스킬 수치 상세를 함께 전환한다.
12. 액션바 알림에 우선순위와 유지 시간을 부여하여 상시 HUD가 EXP·레벨 상승·빈사·구조를 덮어쓰지 못하게 한다.
13. 도감의 간단 보기에서도 조합법·사용처 존재 여부와 대표 ID를 공개한다. 상세 보기에서는 3×3 칸·수량·태그 가치·비소비 증명을 추가한다.
14. 공용 원장 접근 조건은 GUI를 열 때뿐 아니라 입출고를 확정하는 클릭 시점에도 다시 검사한다. 시설이 비활성화되면 열린 GUI를 닫고 거래를 거부한다.

### 4.1 2026-08-24 회귀 보정

- Shift+숫자 판정을 순수 정책으로 분리하고 `이전 슬롯=0 + 웅크림`에서만 C/Q를 실행하며, 나머지는 바닐라로 남기는 테스트를 추가했다.
- 도감 획득 판정은 픽업 이벤트 직후가 아니라 다음 틱의 실제 인벤토리 소유를 기준으로 재조정했다.
- 도감 간단 보기에도 대표 조합법과 사용처를 표시하고, 열린 공용 원장도 거래 직전에 `sharedLedgerUnlocked + 활성 FAC-S16/프로토타입 저장소`를 재검사한다.
- 격리 Gradle `check`는 34 suite·109 test, 실패·건너뜀 0으로 통과했다. 후보 JAR은 별도 `build/candidate-smoke`, 포트 `25567`, 새 월드에서 Paper `26.1.2-74` 기동·70파일/334 도감/21 상태 로드·정상 종료를 통과했다.

## 5. BLOCKER

`BLOCKER-INPUT-PLACE-001`: 현재 자동·콘솔 중심 빌드에서는 실제 플레이어의 블록 설치 패킷과 웅크림+숫자 조합을 재현할 수 없다. `/setblock`은 입력 라우터와 `PlayerInteractEvent`를 통과하지 않으므로 통과 증거로 인정하지 않는다. 실제 Minecraft Java 클라이언트로 슬롯 `0` 전투 곡괭이 채굴, 슬롯 `1~8` 각각의 블록·횃불 설치, 음식·물약 사용, 모든 시작 슬롯에서 웅크림+2~9, Shift+F, 휠 전환을 수행해야 해제한다.

`CLOSED-HOTKEY-SAME-SLOT-002`: C/Q는 입력 직전 슬롯이 `0`일 때만 실행한다는 사용자 확정으로 닫혔다. 슬롯 `1~8`을 선택한 상태의 Shift+숫자와 동일 슬롯 재입력은 전부 바닐라 입력이며, 패킷 어댑터를 추가하지 않는다.

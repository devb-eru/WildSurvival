# WildSurvival EVENT 동적 사건 목록 기획서

## 문서 정보

| 항목 | 내용 |
|---|---|
| 문서 ID | EVENT-LIST-001 |
| 상위 기준 | `CONTENT-MASTER-001`, `BASE-002`, `ACT-001`, `RES-001`, `DISC-LIST`, `TECH` |
| 목적 | 고정 임무 구역을 대체할 자연 발생·플레이어 유발 동적 사건 목록 정의 |
| 구현 | 서버가 선택한 임시 문맥, 바닐라 개체·블록·표시·GUI |

## 1. 동적 사건 원칙

- 사건은 미리 배치한 임무 구역이 아니라 파티의 위치, 행동, 시설, 오염, Day와 발견 상태를 바탕으로 생성한다.
- 정확한 좌표를 퀘스트처럼 지시하지 않고 방향·거리 범주·소리·입자·환경 변화를 단서로 제공한다.
- 사건 참여는 선택적일 수 있지만 야간 압박 자체는 시설 건설 여부와 무관하게 발생한다.
- 핵심 진행 사건은 실패·지형·시설 파괴 후 다시 시도하거나 대체 경로로 진행할 수 있다.
- 사건 보상은 `encounterId`별 한 번만 확정한다.
- 같은 사건이 반복돼도 첫 발견·고급 보상은 재지급하지 않는다.
- 전조 없는 즉사, 장시간 강제 CC와 블록 대규모 파괴를 사용하지 않는다.
- 표의 Day 상한 50은 핵심 설계 구간을 뜻한다. Day 51+에는 `DAY-001`의 순환 프로필이 호환 사건을 `POST_50_REUSABLE`로 다시 선택한다.
- Day 51+ 재사용은 시작 Day 조건을 유지하고 새 필수 발견·부품을 추가하지 않으며 복구 재료와 최종 준비 보상으로 풀을 조정한다.

## 2. 사건 공통 데이터

| 필드 | 설명 |
|---|---|
| `eventId` | 사건 템플릿 ID |
| `encounterId` | 실제 사건 인스턴스 ID |
| `dayRange` | 후보가 될 Day 범위 |
| `contextTags` | 지형·오염·시설·행동 조건 |
| `spawnPolicy` | 파티 주변 후보·시설망·이동 경로 등 |
| `telegraph` | 방향, 소리, 메시지, 표시 |
| `objectives` | 순서 없는 목표 또는 단계 목표 |
| `threatBudget` | 개체·패턴·환경 위험 예산 |
| `rewardPool` | 재료·발견 증거·기여 보상 |
| `failurePolicy` | 시간 초과·이탈·전멸·재시도 |
| `cooldown` | 같은 템플릿 반복 제한 |

## 3. 사건 선택

```text
사건 가중치 =
기본 가중치
× Day·오염 적합도
× 최근 미등장 보정
× 파티 필요 자원 보정
× 발견 진행 보정
× 공간 유효성
```

- 보정은 부족 자원을 직접 지급하지 않고 관련 사건이 나타날 확률을 올린다.
- 같은 유형이 두 번 연속 선택되면 가중치 0.35를 적용한다.
- 핵심 발견에 필요한 사건은 보스 Day 2일 전까지 한 번도 유효 후보가 없었다면 대체 사건을 보장한다.
- 사건별 난수 스트림은 다른 증강·보상 난수와 분리한다.

### 탐험 사건 구현 메모

- 후보 중심은 플레이어가 최근 방문하지 않은 2~6청크 범위에서 찾는다.
- 건축물·시설·보호 블록과 겹치면 다른 후보를 선택한다.
- 표시용 블록을 놓았으면 사건 종료 후 원래 블록 스냅샷을 복원한다.
- 청크가 언로드되면 사건 시간을 정지하거나 저장 상태로 전환하고 개체를 중복 생성하지 않는다.

### 야간 압박 공통 안전선

- 시설을 짓지 않았다고 적 예산이 사라지지 않는다.
- 시설을 지었다고 매일 같은 시설만 파괴 대상으로 삼지 않는다.
- 이탈한 등록 플레이어 때문에 현재 공세 스케일 인원을 낮추지 않는다.
- 적 수, HP, 엘리트, 스킬과 상태 강도를 한 번에 모두 올리지 않는다.
- 시설 파괴가 핵심 고유 부품 영구 소실로 이어지지 않는다.

# 10. 보스 전장 변형

보스 본체와 스킬은 후속 보스 문서에서 다루고, 여기서는 동적 전장의 공간 변형만 정의한다.

| ID | 이름 | 공간 변화 | 금지 조합 |
|---|---|---|---|
| ARENA-01 | 원형 붕괴 | 바깥쪽부터 짧은 위험 구간 순환 | 지속 장판 과밀 |
| ARENA-02 | 삼중 신호 | 세 상호작용 지점 중 순서 선택 | 1인 수행 불가 동시 입력 |
| ARENA-03 | 이동 안전대 | 느리게 이동하는 안전 영역 | 고속 추적 보스와 과도 중첩 |
| ARENA-04 | 엄폐 파동 | 임시 엄폐 후보 생성·소멸 | 지형에 후보가 없으면 제외 |
| ARENA-05 | 균열 연결 | 두 균열 중 하나를 닫아 패턴 변화 | 특정 무기 필수 |
| ARENA-06 | 시설 보호 | 재건 시설과 보스 사이 방어 선택 | 시설 즉사 피해 |

동적 전장은 자연 블록을 영구 변경하지 않고 임시 보호·표시 상태만 적용한다. 종료 후 표시 엔티티와 임시 블록 스냅샷을 정리한다.

## 11. 보상 원칙

- 일반 사건: 자원·활동 EXP·발견 증거
- 위험 사건: 희귀 자원·변이 표본·높은 기여 가중치
- 야간 압박: 공용 재료·개인 기여 보상·잔존 압박 감소
- 핵심 발견 사건: 해금과 증거가 주 보상이며 반복 아이템 보상은 낮음
- 보스: 후보 3개 고유 장비 투표, 최초 완제품 1개, 제작식 공유, 재건 부품

막타만으로 보상을 결정하지 않는다. 피해, 브레이크, 상태, 구조, 회복, 방어, 시설 수리와 목표 상호작용을 기여로 기록한다.

## 13. 성능 규칙

- 사건 후보 공간 검사는 여러 틱에 분할한다.
- 활성 사건은 파티당 기본 1개, 보조 환경 사건 1개로 제한한다.
- 일반 개체 수 상한을 넘으면 남은 위협 예산을 정예도·패턴 슬롯으로 전환한다.
- 표시 엔티티와 파티클은 TPS 저하 시 먼저 축소한다.
- 동적 노드·임시 블록은 원래 블록 스냅샷과 사건 ID를 저장한다.
- 사건 종료 후 청크 티켓을 해제한다.

## 14. 테스트 항목

- 시설 없음·소규모 야영·대형 정착지에서 각 압박 모드 선택
- 사막·바다·동굴·산악 등 지형 후보 실패와 대체 사건
- 같은 사건 연속 등장 감쇠와 결정론적 재시작
- 사건 중 청크 언로드·서버 종료·파티 재접속
- 보정 사건이 아이템 직접 지급이나 보상 복제를 만들지 않음
- 적 수 상한에서 위협 예산 재분배
- 특정 무기·역할 없이 사건 목표 완료
- 동적 전장 종료 후 자연 블록·표시 엔티티 정리
- Day 잠금 전 보스 사건 생성 차단
- 미등록 플레이어 기여·보상·증거 제외

## 15. 완료 기준

- 탐험·생존·오염·야간 압박·특수 Day·복구 사건 풀이 존재한다.
- 사건이 고정 임무 구역 대신 파티 행동과 환경에서 생성된다.
- 유목과 정착 플레이 모두 야간 압박과 선택 사건을 경험한다.
- 핵심 사건 실패와 공간 후보 실패에 재시도·대체 경로가 있다.
- 모든 사건이 바닐라 클라이언트와 서버 플러그인으로 구현 가능하다.

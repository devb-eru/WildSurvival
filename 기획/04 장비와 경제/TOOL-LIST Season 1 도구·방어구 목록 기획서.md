## 1. 권위와 분류

- 이 문서는 장비·도구의 영구 ID, 인벤토리 템플릿 여부, 슬롯, 대표 Material, codexIndex를 소유한다.
- 기존 장비 문서는 수치·효과 설명의 상위 원장이다. 서로 충돌하면 본 문서의 ID·슬롯·Material과 각 원장에 적힌 효과 수치를 함께 적용하고 충돌을 검증 실패로 처리한다.
- `EQL-W10`은 권투 가상 프로필이며 아이템·도감 칸을 만들지 않는다.
- `EQD20-AUG-R01/R02`는 기존 장비에 붙는 개조 규칙이며 아이템이 아니다.
- 세트 정의 `EQD20-SET-*`, `EQD50-SET-*`는 효과 묶음이고 실제 아이템은 아래 4부위 ID다.
- `현재 주무기군`으로 적힌 D10·D20·D30·D40 보상은 저장 시 무기군이 빠지지 않도록 9개 실제 ID로 전개한다.
- 등록 장비는 커스텀 장비 GUI에서만 장착한다. 주무기는 slot 0, 보조무기는 slot -106에 미러링한다.
- 유틸리티 도구는 장비 GUI 주무기에 넣을 수 없으며 slot 1~8에서 바닐라 채집 행동만 수행한다.

필수 필드는 `id`, `textKey`, `codexIndex`, `inventoryTemplate`, `equipmentSlot`, `weaponClass/toolTier`, `displayMaterial`, `rarity`, `itemLevel`, `durability`, `stats/effects`, `source/recipe`, `enabled`다.

### 1.1 장비 시너지 태그 허용 목록

`tags`는 장비 효과표의 마지막 열을 임의로 정제하지 않고 아래 값만 허용한다. 희귀도·아이템 레벨·AP 비용·해금 표기와 같은 값은 별도 필드이며 태그가 아니다.

```text
SWORD, AXE, BOW, CROSSBOW, DAGGER, MACE, STAFF, PICKAXE, TRIDENT, UNARMED,
COMBO, GUARD, HEAVY, EXECUTE, RANGED, AIM, MAGAZINE, BREACH, AGILE, BLEED,
IMPACT, BREAK, MAGIC, AREA, PENETRATE, THROW, RECALL, REACTION, CONTROL,
COOLING, SUPPRESS, STATUS_EXTEND, COUNTER, MUTATION, STATUS, INTERRUPT,
BACKSTAB, CORRUPTION, NO_RETRIGGER
```

- 무기군 9종의 실제 장비에는 해당 무기군 태그를 정확히 하나 포함한다.
- `RARE`, `AP5`, `AB41`, `LG25`, `SPD3`, `UNBREAKABLE6`처럼 다른 열의 값을 합친 문자열은 거부한다.
- 새 태그는 이 목록과 증강 태그 권위를 함께 개정한 뒤에만 생산 데이터에 들어갈 수 있다.

## 2. 전투·채집 입력 경계

```text
slot 0 + 전투 장비
  공격 가능한 대상 있음 → 커스텀 기본 공격
  대상 없음 + 전투 곡괭이 + 허용 블록 → 바닐라 채굴 폴백
  그 외 블록 → 블록 손상 취소

slot 1~8 + 바닐라/WS 유틸리티 도구
  → 바닐라 채굴·벌목·경작·상호작용
  → WS 자원 지급 여부만 도구 등급과 노드 규칙으로 후처리
```

- 유틸리티 도구의 좌클릭은 스킬로 변환하지 않는다. 전투 장비로 등록되지 않았기 때문이다.
- slot 0의 검·도끼·활·석궁·단검·둔기·지팡이·삼지창은 블록 파괴를 허용하지 않는다.
- slot 0 전투 곡괭이는 유효 전투 대상이 없을 때만 블록 파괴를 허용한다.
- 권투는 slot 0과 MAIN_WEAPON이 모두 비었을 때 자동 활성화하며 별도 아이템이 없다.

## 5. 전개된 세트 부위

- `SCOUT`: HEAD/CHEST/LEGS/FEET 모두 수색자 세트. 기본 방어 수치는 같은 부위 `EQL-AR-C01~04`를 계승한다.
- `VANGUARD`: HEAD/CHEST/LEGS/FEET 모두 선봉대 세트. 부위별 DEF 보정은 4/8/6/4다.
- `OBSERVER`: HEAD/CHEST/LEGS/FEET 모두 오염 관측자 세트. 부위별 RES 보정은 4/8/6/4다.
- `EQD20-AR-MED/CTRL/GUARD-*`: 각 D20 세트 정의의 1부위 효과와 제작 재료를 부위 계수 `0.7/1.4/1.1/0.6`으로 적용해 올림한다.
- `EQD50-AR-PURIFIER/INTERRUPT/REBUILD-*`: 각 D50 세트 정의를 실제 4부위에 연결하며 세트 페널티도 장착 부위 수 조건에서만 발동한다.
- 세트 효과 계산은 템플릿 접두 추론이 아니라 각 아이템의 명시적 `setId`를 사용한다.

## 7. 서버 권위 내구도와 BROKEN

| 희귀도/등급 | 무기 기본 최대 내구 | 방어구 계수 | 유틸리티 |
|---|---:|---:|---:|
| COMMON | 320 | ×1.25 | 바닐라 T0~T2 |
| UNCOMMON | 450 | ×1.25 | 해당 없음 |
| RARE | 600 | ×1.25 | REINFORCED_IRON 720 |
| EPIC | 800 | ×1.25 | RESONANT 1100 |
| LEGENDARY | 1100 | ×1.25 | HARDENED 1550 |
| ABYSSAL | 1500 | ×1.25 | RECONSTRUCTION 2100 |

- `currentDurability/maxDurability`는 서버 원장이 권위다. 실제 ItemStack은 `Unbreakable=false`로 두어 채굴 손상 이벤트를 받을 수 있게 한다.
- `PlayerItemDamageEvent`는 관찰 가능하게 두되 적용 damage를 0으로 중화한 뒤 서버 원장을 정확히 한 번 차감하고, 바닐라 damage 표시는 원장 비율로 직접 갱신한다.
- 표시 damage는 항상 `maxVanillaDamage-1` 이하로 제한한다. 바닐라 삭제를 발생시키지 않고 0에 도달하면 `BROKEN`으로 전환한다.
- 커스텀 기본 공격은 성공한 실행당 1, 일반 액티브는 1, 강공·투척·영역 핵심기는 실행 데이터의 2~3을 차감한다. 빗나감 비용은 각 스킬 데이터가 명시한다.
- 방어구는 최종 피해가 1 이상인 피격에서 1을 차감하되 초당 부위별 1회 상한을 둔다. 방패는 가드 피해 흡수·패링 시 실행 데이터 비용을 쓴다.
- `BROKEN`은 아이템 인스턴스를 보존하고 장비 스탯·공격·세트 효과를 비활성화한다. 장착 미러 클릭 시 수리 GUI로 이동한다.
- `ACTIVE → BROKEN` 전이마다 권위 `EquipmentBrokenEvent`, 감사 `EQUIPMENT_BROKEN`, Bukkit 호환용 합성 `PlayerItemBreakEvent`를 각각 한 번 발행한다. 합성 이벤트는 전이 직전 ItemStack 복사본을 전달하며 실제 삭제 권위가 아니다.
- slot 0 파손은 `MAIN_HAND` 슬롯 정보와 `equipment-broken:{instanceUuid}:{breakOrdinal}` 멱등 키를 사용한다. 차수는 인스턴스별 파손 성공 횟수+1이며, 복사본 생성 실패 시 파손 전이를 중단하고 성공 시 차수를 증가시킨 뒤 주손 파손 효과·사운드와 다음 틱 권위 미러 복원을 수행한다.
- 이미 `BROKEN`인 인스턴스에는 파손 이벤트를 재발행하지 않고, slot 1~8 바닐라 도구에는 합성 이벤트를 발행하지 않는다.
- 수리·강화·재련·분해는 `instanceUuid` 잠금을 공유하여 동시 실행과 복제를 막는다.

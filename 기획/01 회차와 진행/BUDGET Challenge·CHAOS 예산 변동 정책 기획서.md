# WildSurvival Challenge·CHAOS 예산 변동 정책 기획서

## 문서 정보

| 항목 | 내용 |
|---|---|
| 문서 ID | `BUDGET-001` |
| 상태 | `BASELINE_LOCKED` |
| 역할 | Challenge 야생 활동 EXP 변동 범위와 CHAOS 전 예산 1000% 상한의 단일 계산 계약 |
| 상위 기준 | `DIFFICULTY-001`, `PROG-001`, `GAME-003` |
| 연계 | `REWARD-001`, `EVENT-DATA-001`, `CONTENT-DATA-D50-001`, `TECH-001` |
| 기준값 | 각 DATA·BALANCE 문서의 Easy STANDARD 예산 = 100% |
| 적용 시점 | 새 회차 생성 및 Day 예산 스냅샷 확정 시 |
| 최종 수정일 | 2026-08-21 |

## 1. 핵심 결정

- Challenge STANDARD의 야생 활동 EXP 예산은 난이도별 허용 범위 안에서 설계·선택할 수 있다.
- Normal은 기준 대비 `±50%`, Hard는 `±100%`, `???`는 `±200%`까지 허용한다.
- 예산은 음수가 될 수 없으므로 수학적 하한이 0% 아래로 내려가면 0%에서 제한한다.
- Challenge Easy STANDARD는 별도 변동 요청이 없으므로 기준 예산 100%를 유지한다.
- CHAOS는 모든 수치형 예산의 상한을 기준 예산 1000%, 즉 `×10.00`까지 확장한다.
- “1000%까지”는 기준의 최대 10배이며 `+1000%`, 즉 11배를 뜻하지 않는다.
- 예산 배율은 회차·Day 스냅샷에 먼저 고정한다. 보상 발생 순간마다 무작위로 다시 뽑지 않는다.
- 안전 상한, 고유 보상 1회성, Day 50 잠금과 원자 트랜잭션은 예산이 아니므로 배율로 우회하지 않는다.

## 2. 용어와 기준값

| 용어 | 정의 |
|---|---|
| 기준 예산 `baseBudget` | Easy STANDARD DATA·BALANCE 문서에 기록된 100% 값 |
| 허용 범위 `allowedRange` | 콘텐츠 분류·난이도·규칙 모드가 허용하는 최소·최대 배율 |
| 선택 배율 `selectedMultiplier` | 허용 범위 안에서 리비전·프로필·결정론적 시드가 확정한 실제 배율 |
| 확정 예산 `lockedBudget` | 기준 예산에 선택 배율을 적용하고 정수 분배한 회차·Day 값 |
| 실제 지급 `actualPaid` | 유효 참여·개인 보너스·반복 감쇠까지 적용해 실제 원장에 기록된 값 |

```text
lockedBudget = floor(baseBudget × selectedMultiplier)
```

- `lockedBudget`은 공급 가능한 원천 기본값의 합이고 반드시 모두 획득하는 보장량은 아니다.
- 참여 실패, 선택 활동 미수행과 반복 처치 감쇠로 `actualPaid`가 확정 예산보다 낮아질 수 있다.
- EXP 스탯·장비·증강 보너스는 예산을 늘리지 않고 개인별 실제 지급 단계에서 적용한다.

## 3. Challenge STANDARD 야생 활동 EXP 범위

`contentCategory == CHALLENGE_CONTENT && gameMode == STANDARD`일 때 다음 표를 사용한다.

| 표시 난이도 | 내부 ID | 변동 허용 | 선택 배율 범위 | 기준 100의 허용 예산 |
|---|---|---:|---:|---:|
| Easy | `EASY` | 고정 | `1.00` | 100 |
| Normal | `NORMAL` | `±50%` | `0.50~1.50` | 50~150 |
| Hard | `HARD` | `±100%` | `0.00~2.00` | 0~200 |
| ??? | `UNKNOWN` | `±200%` | `0.00~3.00` | 0~300 |

- Hard와 `???`의 음수 수학 범위는 0에서 제한한다. 음수 EXP나 EXP 회수는 만들지 않는다.
- `???`의 실제 선택 배율은 서버·완료 원장에는 저장하지만 시작 UI와 일반 진행 UI에는 공개하지 않는다.
- Challenge라는 콘텐츠 분류 자체의 추가 배율은 없다. 표의 난이도 범위만 사용한다.
- Story 콘텐츠의 Story STANDARD 활동 EXP 예산은 100% 고정이며 이 표를 사용하지 않는다.

### 3.1 야생 활동 EXP에 포함되는 원천

- 야생 일반·특수 적 유효 참여 보상
- 야생 엘리트 유효 참여 보상
- 위험 지역 탐험 목표
- 제한된 선택 활동·사건
- 특수 자원 지점 최초 발견

### 3.2 제외되는 EXP

- Day·필수 발견·공세·보스의 진행 EXP
- 운영 복구용 보정 EXP
- 공세 적·보스 소환체·분열체 개별 처치
- 아군 공격, 반복 회복·수리·제작

제외 항목은 Challenge STANDARD 야생 활동 EXP 배율을 받지 않는다. CHAOS에서 진행 EXP 예산까지 확대하는 경우에는 §5의 별도 도메인 배율을 사용한다.

## 4. EXP 예산 분배

Day 또는 세션의 확정 야생 활동 EXP 예산을 기존 원천 가중치에 따라 정수로 분배한다.

```text
sourceRaw[i] = lockedBudget × sourceWeight[i]
sourceBase[i] = floor(sourceRaw[i])
remainder = lockedBudget - sum(sourceBase)
→ 소수 나머지가 큰 원천부터 1씩 배정
→ 동률은 runSeed + day + sourceId 순서로 결정
```

- 원천 가중치 합은 정확히 1.00이어야 한다.
- 원천 하나의 기본 EXP를 배율 적용한 뒤 다시 Day 총예산 배율을 곱하지 않는다.
- 배율 0.00이면 해당 Day의 야생 활동 EXP 원천은 0이지만 전투·드롭·발견·Story는 정상 동작한다.
- 배율이 높아도 동일 개체 반복 처치 감쇠와 생성 원인 차단은 유지한다.

### 4.1 기준 원장 예시

| 세션 | Easy 기준 활동 EXP | Normal STANDARD 허용 | Hard STANDARD 허용 | ??? STANDARD 허용 | CHAOS 최대 |
|---|---:|---:|---:|---:|---:|
| Day 1~10 | 846 | 423~1,269 | 0~1,692 | 0~2,538 | 8,460 |
| Day 11~20 | 4,170 | 2,085~6,255 | 0~8,340 | 0~12,510 | 41,700 |
| Day 21~30 | 10,470 | 5,235~15,705 | 0~20,940 | 0~31,410 | 104,700 |
| Day 31~40 | 19,770 | 9,885~29,655 | 0~39,540 | 0~59,310 | 197,700 |
| Day 41~50 | 32,070 | 16,035~48,105 | 0~64,140 | 0~96,210 | 320,700 |

이 표는 허용 범위를 보여 주는 산술 예시다. 모든 Challenge·CHAOS 회차가 상한을 사용한다는 뜻이 아니다.

## 5. CHAOS 전 예산 1000% 상한

`gameMode == CHAOS`이면 각 수치형 예산 도메인의 최대 배율을 `10.00`으로 확장한다.

```text
chaosAllowedMin[domain] = standardAllowedMin[domain]
chaosAllowedMax[domain] = 10.00
```

- CHAOS는 상한 확장 규칙이다. 각 도메인의 기존 최소값을 자동으로 0으로 만들지 않는다.
- Challenge 야생 활동 EXP는 난이도별 하한을 유지하고 상한만 10.00으로 바꾼다.
- Story CHAOS 또는 Easy CHAOS처럼 STANDARD 하한이 1.00인 도메인은 `1.00~10.00`을 사용한다.
- 도메인별 선택 배율은 서로 다를 수 있으며 하나의 전역 10배를 무조건 곱하지 않는다.

### 5.1 CHAOS 적용 예산 도메인

| 도메인 ID | 기준 예산 | CHAOS 최대 해석 |
|---|---|---|
| `PROGRESS_EXP` | Day·발견·공세·보스 진행 EXP 합 | 기준 합계의 10배까지, Day·발견 게이트는 미완료 상태 유지 |
| `WILD_ACTIVITY_EXP` | 야생 전투·탐험 활동 EXP | 기준 공급 예산의 10배까지 |
| `COMMON_RESOURCE` | 일반 공용 자원 가치 | 기준 원장 가치의 10배까지 |
| `PERSONAL_SUPPLY_VALUE` | 개인 기여품 총 동가치 | 후보 희귀도 상승 없이 총 가치 10배까지 |
| `ENCOUNTER_THREAT` | 공세·사건 적 비용 합 | 동시 개체 상한을 지키며 웨이브·단계로 10배까지 |
| `ELITE_MUTATION` | 정예·변이·적 증강 비용 합 | 조합 금지표와 슬롯 상한 안에서 사건 수·단계로 10배까지 |
| `ENVIRONMENT_PRESSURE` | 오염·환경 위험 발생 예산 | 상태 강도 하드캡을 지키며 구역·주기·단계로 10배까지 |
| `FACILITY_PRESSURE` | 시설 표적·공성 비용 합 | 시설 영구 손실 금지와 동시 공성 상한 유지 |
| `BOSS_PATTERN` | 패턴 선택·소환·지역 위험 예산 | 즉사 금지·전조·활성 소환체 상한을 지키며 10배까지 |

### 5.2 1000%를 적용하지 않는 값

| 값 | 이유 |
|---|---|
| 재건 부품 A~D, C01~C30, 보스 처치 플래그 | 불리언·고유 진행 결과이며 예산이 아님 |
| 최초 고유 장비 1개, 파티 증강 선택 횟수 | 회차 고유 횟수 계약 |
| 개인 증강 마일스톤·등급 잠금 | 성장 상태 전이 |
| Day 번호·Day 50 최종 잠금 | 시간·진행 게이트 |
| 활성 일반 적·정예·공성·소환체 상한 | TPS·판독 안전 상한 |
| 강한 전조·지속 영역·투사체 상한 | 성능·공정성 상한 |
| 상태 중첩·CC 보호·즉사 방지 | 전투 안전 규칙 |
| 보상 멱등키·트랜잭션 횟수 | 중복 방지 계약 |

예산이 안전 상한보다 크면 값을 삭제하거나 한 번에 생성하지 않고 추가 웨이브, 사건 단계, 시간 구간과 정산 묶음으로 분할한다.

## 6. 선택·잠금 정책

| 시점 | 처리 |
|---|---|
| 회차 생성 | `budgetPolicyRevision`, 허용 범위와 회차 공통 프로필 저장 |
| Day 시작 | Day·도메인별 선택 배율, 확정 예산, 분배 시드 저장 |
| 사건 생성 | 저장된 확정 예산 일부를 예약하고 중복 소비 차단 |
| 정산 | 예약·소비·잔여·실제 지급을 원장에 기록 |
| 재접속·재시작 | 저장된 배율·예산 재사용, 재추첨 금지 |
| 콘텐츠 리로드 | 활성 회차의 정책·배율 불변, 새 회차만 새 리비전 사용 |

선택 배율의 출처는 다음 중 하나다.

- `AUTHORED`: 콘텐츠 데이터가 정확한 배율을 지정
- `SEEDED`: 허용 범위 안에서 결정론적 시드로 선택
- `SEASONAL`: 시즌 규칙이 범위 안의 프로필을 지정
- `ADMIN_QA`: 개발·QA 회차에서만 명시값 지정, 감사 로그 필수

라이브 일반 회차에서 운영자가 진행 중 배율을 즉석 변경할 수 없다.

## 7. 저장 계약

```yaml
budget-profile:
  policy-revision: "budget-r1"
  content-category: "CHALLENGE_CONTENT"
  difficulty: "HARD"
  game-mode: "STANDARD"
  day: 18
  source: "SEEDED"
  seed: "run-01:day-18:budget"
  domains:
    WILD_ACTIVITY_EXP:
      base: 480
      allowed-min: 0.00
      allowed-max: 2.00
      selected-multiplier: 1.65
      locked: 792
      reserved: 610
      consumed: 540
      actual-paid: 496
```

- 배율은 소수점 네 자리, 예산·지급량은 0 이상의 정수로 저장한다.
- `selectedMultiplier`가 허용 범위를 벗어나거나 `locked != floor(base × selectedMultiplier)`이면 회차 시작·Day 전환을 거부한다.
- `UNKNOWN`도 서버 원장에는 실제 값을 저장하며 일반 UI 직렬화에서만 숨긴다.
- BigNumber가 필요한 CHAOS 전투량과 달리 현재 EXP·자원 예산은 정수 오버플로 검사를 먼저 통과해야 한다.

- `???` 정보 제한은 실제 지급 원장과 관리자 감사 로그를 숨긴다는 뜻이 아니다.

## 9. 악용·소프트락 방지

- 높은 활동 EXP 예산을 선택해도 보스·발견·시설·Day 잠금을 건너뛰지 못한다.
- 낮은 활동 EXP 예산으로 증강 레벨 도달이 늦어질 수 있지만 Challenge의 허용된 성장 변동으로 취급한다.
- 활동 EXP 0%에서도 일반 공격·드롭·발견 증거와 필수 진행 EXP는 STANDARD에서 유지된다.
- CHAOS에서 진행 EXP가 빨라 Lv50에 일찍 도달해도 Day 50 전 최종 목표를 시작할 수 없다.
- 자원 예산이 호출·시설의 필수 경로를 0으로 만드는 프로필은 대체 경로 또는 시작 전 소프트락 검사 없이 승인하지 않는다.
- 배율을 확인한 뒤 재접속·서버 재시작으로 다시 뽑는 행위를 막기 위해 Day 스냅샷을 먼저 커밋한다.
- 실제 지급을 예산에 맞추려고 가짜 적·가짜 활동을 자동 생성하지 않는다.

## 10. 검증 항목

- Normal `0.50~1.50`, Hard `0.00~2.00`, UNKNOWN `0.00~3.00` 경계값
- 음수 입력, NaN, Infinity, 네 자리 초과 배율 거부
- Easy·Story STANDARD 1.00 고정
- CHAOS 모든 등록 예산 도메인 최대 10.00과 미등록 도메인 거부
- `1000% == ×10.00`, `+1000% == ×11.00` 오해 차단
- 기준 846·4,170·10,470·19,770·32,070 산술 범위
- Day 원천 정수 분배 합이 확정 예산과 정확히 일치
- EXP 개인 보너스·반복 감쇠와 예산 배율 중복 적용 없음
- UNKNOWN 값의 서버 저장·UI 비공개 동시 성립
- 재접속·재시작·리로드 뒤 배율과 잔여 예산 불변
- 10배 위협 예산의 웨이브 분할과 활성 개체·전조 상한 준수
- 고유 보상·증강 횟수·Day 50 게이트 무배율

## 11. 완료 기준

- Challenge STANDARD 야생 활동 EXP의 난이도별 허용 범위가 정확히 정의된다.
- CHAOS의 모든 수치형 예산 최대 1000%와 예산이 아닌 불변식의 경계가 분리된다.

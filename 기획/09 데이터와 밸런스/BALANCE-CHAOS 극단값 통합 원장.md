# WildSurvival CHAOS 극단값 통합 원장

## 문서 정보

| 항목 | 내용 |
|---|---|
| 문서 ID | `BALANCE-CHAOS-001` |
| 상태 | `VALIDATED_STATIC` |
| 권위 | `BUDGET-001`, `BUDGET-PROFILE-001` 극단값의 산술·전달·안전 검증 원장 |
| 기준 | 3인 Easy, 각 DATA 문서의 Day 기준 예산 |
| 수치 엔진 | 전투 `BigDecimal`, 원장 `long`, 배율 `BigDecimal(scale=4)` |
| 최종 수정일 | 2026-08-21 |

## 1. 고정 경계

| 항목 | 값 |
|---|---:|
| 등록 배율 | `0.0000~10.0000` |
| 원장 단일 필드 | `0~9,000,000,000,000,000` |
| 전투 중간값 | 절댓값 `10^24` 미만 |
| 한 틱 신규 일반 적 | `4` |
| 한 틱 신규 정예·보스 소환체 | `1` |
| 한 패턴 강한 전조 | `3` |
| 한 플레이어 동시 추적 강패턴 | `1` |
| 추가 웨이브 간 최소 전조 | `40틱` |
| CHAOS 잔류 공세 최대 | Day 종료 뒤 `180초` |

- 범위를 넘는 입력, NaN, Infinity, 음수 예산은 스냅샷 전에 거부한다.
- 전투 값은 연산마다 반올림하지 않고 최종 표시·피해 적용 경계에서만 반올림한다.
- 잔류 공세가 180초 안에 소비되지 않으면 적 비용을 삭제하지 않는다. 남은 비용을 동가치 정예 패턴 토큰으로 압축하되 HP·피해·상태 하드캡은 유지한다.

## 2. 위협 전달 공식

```text
lockedThreat = floor(baseThreat × threatMultiplier)
waveCapacity = min(DATA wave cap, GAME-003 active cost room)
waveCount = ceil(lockedThreat / waveCapacity)
wave[i] = min(waveCapacity, remainingThreat)
```

동시 개체 상한 때문에 남은 비용이 있을 때 다음 순서로 전달한다.

1. 같은 사건의 추가 웨이브
2. 엘리트·변이 비용 토큰으로 치환하되 슬롯 상한 유지
3. Day 종료 후 최대 180초 잔류 공세
4. 남은 비용 20당 `TACTIC_TOKEN` 1개로 압축해 기존 적의 다음 패턴 주기에 사용

`TACTIC_TOKEN`은 패턴 하나를 동시에 추가하지 않는다. 기존 패턴 종료 뒤 최소 30틱 후 다음 승인 패턴을 앞당긴다. 토큰은 보상·EXP를 만들지 않는다.

### 3.1 CX-02 상세

Day 37 기준 비용 550, 웨이브 용량 46으로 잠근다.

| 웨이브 | 비용 | 누적 | 비고 |
|---:|---:|---:|---|
| 1~11 | 각 46 | 506 | 동시량이 아니라 순차 소비 |
| 12 | 44 | 550 | 마지막 웨이브 |

첫 4웨이브는 Day 압박 구간, 다음 5웨이브는 잔류 공세, 마지막 3웨이브는 비용 138을 `TACTIC_TOKEN` 7개와 정예 비용  - `7×20=140`이므로 초과 2를 허용하지 않고 토큰 6개·잔여 18 적 구성으로 소비한다. 합계는 항상 550이다.

### 3.2 CX-05 상세

`BOSS_PATTERN ×10`은 HP·직접 피해·브레이크 게이지를 10배로 만들지 않는다.

| 항목 | 기준 | 극단 적용 |
|---|---:|---:|
| 패턴 선택 토큰 | 18 | 180 |
| 페이즈당 동시 패턴 | 1 | 1 |
| 강한 전조 동시 수 | 3 | 3 |
| 소환체 활성 상한 | 6 | 6 |
| 동일 패턴 연속 | 최대 2 | 최대 2 |
| 전투 시간 안전 목표 | 9~13분 | 18~35분 |

보스가 35분을 넘기면 남은 토큰은 `OVERDRIVE_CYCLE`로 바꾼다. 한 사이클은 세 패턴을 순차 실행하고 사이클 종료 시 토큰 9를 소비한다. 이 변환은 보스 피해나 HP를 올리지 않는다.

## 4. 자원·인벤토리 과잉 방지

- `COMMON_RESOURCE ×10`은 단일 ItemStack 수량을 10배로 넣지 않는다. `ResourceLedger` 가치로 적립하고 GUI에서 묶음 단위로 인출한다.
- 한 정산의 실물 아이템 생성은 플레이어당 27스택, 파티 보관함 54스택까지다. 초과는 원장 잔액으로 남는다.
- 개인 기여품은 희귀도 확률을 올리지 않고 후보 수와 가치 정산 횟수만 늘린다. 고유 장비는 여전히 1회다.
- 자원 원장 총합이 `9e15`의 90%를 넘으면 새 회차 생성·Day 전환을 거부하고 운영 경고를 남긴다.

## 1. 콘텐츠 정의

WildSurvival은 바닐라 야생 생존의 자유도를 유지하면서 커스텀 전투, 장비 제작·강화·재련, 개인·파티 증강, 상태이상, 브레이크, 오염, 협동 보스, Day 기반 세계 변화를 결합한 협동형 하드코어 야생 생존 콘텐츠다.

플레이어는 미리 준비된 고정 기지나 정해진 임무 구역에서 출발하지 않는다. 임의의 야생에서 생존을 시작하고, 자연환경과 발견한 단서를 이용해 다음에 필요한 물건·설비·대응책을 추론하며, 원하는 위치에 임시 야영지와 장기 거점을 구축한다.

최종 목표는 단순한 최종 보스 처치가 아니라 세계 붕괴 핵을 정화하고 인류 재건에 필요한 첫 기반을 완성하는 것이다.

## 2. 최상위 설계 기둥

### 2.1 자유 야생 생존

- 고정 기지, 고정 임무 구역, 선형 퀘스트 동선을 기본 전제로 사용하지 않는다.
- 바닐라 지형, 자원, 구조물과 플레이어가 만든 건축물을 실제 플레이 공간으로 사용한다.
- 특정 좌표를 방문해야만 진행되는 핵심 목표는 만들지 않는다.
- 핵심 자원과 진행 조건에는 두 개 이상의 획득·해결 경로를 제공한다.
- 월드 시드 차이로 핵심 진행이 막히면 탐지 장치, 대체 제작식 또는 보정 드롭이 작동한다.

### 2.2 발견형 목표망

- 일반 퀘스트처럼 정답, 좌표, 완성 제작식을 처음부터 모두 표시하지 않는다.
- 플레이어가 관찰, 제작, 전투, 분석, 실패 결과를 통해 다음 가능성을 발견하게 한다.
- 핵심 진행은 `단서 → 가설 → 실험 → 발견 → 활용` 흐름을 사용한다.
- 플레이어가 이미 조건을 우연히 만족했다면 해당 발견을 소급 인정한다.
- 장시간 정체될 경우 정답 대신 범주형 힌트를 단계적으로 제공한다.
- 핵심 진행 상태는 파티 공유이며, 각 플레이어의 도감·기록 UI에도 동기화한다.

### 2.3 자발적 거점 성장

- 거점은 시작부터 제공되는 고정 기지가 아니라 플레이어가 선택한 위치에 구축하는 시설망이다.
- 초반에는 휴대 설비와 임시 야영만으로 생존할 수 있다.
- 고급 제작, 정화, 증강 재조정, 최종 재건 준비에는 설치형 시설이 필요하다.
- 하나의 영구 중심지만 강제하지 않으며 전초 야영지, 이동 거점, 복수 시설군을 허용한다.
- 공세와 오염은 고정 좌표가 아니라 플레이어, 활성 시설, 축적된 위협도와 소음·열·오염 신호를 기준으로 발생한다.

### 2.4 빌드형 협동 성장

- 모든 플레이어는 같은 팀이지만 장비, 무기, 개인 증강과 스탯으로 서로 다른 빌드를 만든다.
- 필수 직업이나 특정 무기 강제를 사용하지 않는다.
- 모든 무기군은 단독 생존 수단과 최소 하나의 파티 기여 수단을 가진다.
- 파티 증강은 팀 전체의 운영 방향을 바꾸되 특정 플레이어의 빌드를 무효화하지 않는다.
- 피해, 브레이크, 상태, 회복, 구조, 방어, 시설 운용을 모두 유효 기여로 인정한다.

### 2.5 Day 기반 질적 난이도 상승

- Day 상승은 HP·ATK 증가만으로 표현하지 않는다.
- 새 적 역할, 새 스킬, 패턴 조합, 상태이상, 오염 변이, 추적 방식, 자원 압박을 함께 추가한다.
- 각 신규 위협에는 관찰 가능한 전조와 최소 하나의 대응 수단이 존재해야 한다.
- Day 10·20·30·40은 중간 보스와 세션 경계로 사용하고 Day 50은 최종 목표의 최초 해금 경계로 사용한다.
- Day 50 이전에는 어떤 수단으로도 최종 재건 목표를 완료할 수 없다.
- Day 50이 끝나도 회차를 자동 종료하지 않으며, 최종 목표를 달성할 때까지 Day 51 이상으로 세계 압박이 계속된다.

### 2.6 하드코어와 복구 가능성의 균형

- 전원 완전 사망은 회차 실패이며 일반적인 방법으로 되돌릴 수 없다.
- 한 번의 대응 실패만으로 즉시 완전 사망시키는 패턴은 기본적으로 사용하지 않는다.
- 시설 손상과 오염은 압박을 만들지만 복구 수단이 완전히 사라지는 소프트락은 허용하지 않는다.
- 핵심 진행 아이템과 최초 고유 장비는 서버 권위 저장과 중복 방지 규칙을 사용한다.

### 2.7 Story와 Challenge 콘텐츠 분리

- 구 Easy 규칙은 Story 난이도로 이동하며 Story + STANDARD의 클리어 실패율 목표는 10%다.
- Challenge는 난이도명이 아니라 Easy, Normal, Hard, ???를 묶는 콘텐츠 분류다.
- 구 Normal은 Easy, 구 Hard는 Normal, 구 Challenge는 Hard로 이동하고 ???는 유지한다.
- Season 1 실제 서사, 챕터, 오브젝트와 인물은 `STORY-001`이 담당한다.
- Story 상태 저장과 도메인 이벤트 접점은 실제 Story와 `EMPTY` 폴백을 모두 지원하며 내용이 없어도 회차를 정상 완주할 수 있어야 한다.
- Challenge STANDARD 야생 활동 EXP 예산은 Normal `±50%`, Hard `±100%`, ??? `±200%`까지 허용하고 음수 하한은 0으로 제한한다.
- CHAOS는 모든 수치형 예산의 상한을 기준 1000%, 즉 10배까지 허용하되 안전 상한·고유 보상·진행 게이트는 배율 대상이 아니다.
- 정확한 분류, 수치 계승, 통계와 레거시 마이그레이션은 `DIFFICULTY-001`을 따른다.

### 2.8 시즌 확장과 플레이어 연대기

- Season 1은 첫 재건 신호와 한 지역 안정화로 자체 완결된다.
- 완료 뒤 중앙 승인·민간 교환·출처 불명 신호를 복선으로 남겨 Season 2의 재건 경쟁으로 연결한다.
- Season 2에서도 플레이어들은 하나의 협동 파티이며, 중심 기관·다른 생존권역·비밀 프로젝트와의 경쟁 속에서 실제 행동으로 자기 연대기를 만든다.
- 후속 시즌은 Season 1이 가상 실험이었다는 반전이나 소급 무효화를 사용하지 않는다.
- 시즌 간에는 장비·레벨·자원을 직접 복사하지 않고 완료·생명·시설 방식·구조·정보 공개 같은 역사만 읽기 전용 스냅샷으로 이관한다.
- Season 2의 권력·경쟁·다른 지역·가능성 기반은 `STORY-S2-001`을 따른다.

## 3. 한 회차의 핵심 루프

```text
야생 관찰·탐험
→ 자원·단서·위협 발견
→ 휴대 설비 또는 거점에서 제작·분석
→ 장비·시설·증강·대응책 성장
→ Day 위협·정예·공세·보스 대응
→ 새로운 세계 규칙과 제작 단계 발견
→ 인류 재건 준비
```

### 루프 검증 기준

- 탐험 결과가 전투력, 생존력, 시설 또는 정보 중 하나 이상으로 연결된다.
- 제작 결과가 다음 탐험과 전투의 선택지를 확장한다.
- 전투 결과가 단순 아이템 드롭 외에 연구 단서와 세계 진행을 제공한다.
- 거점에 머무는 것과 이동을 계속하는 것 모두 명확한 이익과 위험을 가진다.
- 어느 한 활동만 무한 반복해서 모든 진행을 대체할 수 없다.

## 4. 거점과 시설의 역할

### 시설 계층

| 계층 | 형태 | 역할 |
|---|---|---|
| 휴대 설비 | 인벤토리 도구 또는 짧은 설치물 | 기본 제작, 현장 수리, 단서 기록 |
| 야영 설비 | 빠르게 설치·회수 가능 | 보관, 휴식, 저등급 정화, 임시 분석 |
| 거점 시설 | 설치 후 성장·손상·수리 | 강화, 재련, 정화, 고급 연구, 증강 재조정 |
| 재건 시설 | 후반 핵심 설비 | 세계 붕괴 핵 분석, 최종 부품 조립, Day 50 이후 정화 |

- 시설은 플레이어가 배치한 시설 ID와 실제 블록·표시 개체를 연결한다.
- 시설군마다 중심 좌표를 강제하지 않고 연결 거리와 동력·정화 네트워크로 묶는다.
- 시설 철거와 이전은 가능하지만 진행 중 작업, 저장 물품, 손상도와 이전 비용을 보존한다.
- 공세 중 즉시 철거하여 공격을 무효화할 수 없다.

## 5. 협동 원칙

- 회차 시작 시 등록한 2~4명만 참여하며 신규 중도 참여는 허용하지 않는다.
- 접속 종료와 동일 플레이어의 재접속은 허용한다.
- 기획상 회차는 등록 플레이어 전원이 함께 있을 때 진행하는 것을 기준으로 한다.
- 파티 규모가 줄어도 필수 기믹은 남은 생존 인원으로 수행 가능해야 한다.
- 기본 아군 공격은 차단한다.
- 선택 규칙으로 아군 공격을 허용하더라도 비치명 규칙, 보상 미발동과 악용 방지를 적용한다.
- 완전 사망자는 파티 증강 투표권을 유지하되 동률 해결에서는 생존자 표를 우선한다.

## 6. 전투와 장비 원칙

### 무기군

- 검
- 도끼
- 활
- 석궁
- 단검
- 둔기
- 지팡이
- 곡괭이
- 삼지창
- 권투

방패는 10개 주 무기군에 포함하지 않고 보조무기 방어 장비로 분류한다.

### 장착 기준

- 모든 콘텐츠 장비는 커스텀 장비 GUI를 통해 장착한다.
- 주무기는 바닐라 장비 슬롯 ID `0`에 동기화한다.
- 보조무기는 바닐라 오프핸드 슬롯 ID `-106`에 동기화한다.
- 권투는 주무기 슬롯이 비어 있고 유효한 주무기 데이터가 없을 때 자동 활성화한다.
- 곡괭이는 전투 입력을 블록 파괴보다 우선한다.
- 삼지창은 바닐라 투척·급류·충성 실행을 사용하지 않고 커스텀 스킬로 전환한다.
- 단검은 초기에는 검 계열 바닐라 아이템, 둔기는 철퇴를 사용하고 이후 서버 리소스팩으로 외형을 확장한다.

## 7. UI와 클라이언트 제약

- 기본 설계는 서버 리소스팩이 없는 바닐라 클라이언트에서 완전히 플레이 가능해야 한다.
- 인벤토리 GUI, 보스바, 액션바, 스코어보드, 타이틀, 채팅, 사운드를 사용한다.
- 임의의 신규 키 입력이나 완전 자유형 화면 UI를 전제로 하지 않는다.
- 리소스팩은 단검·둔기 등 외형과 선택적 가독성 향상에 사용하며 핵심 정보 전달을 리소스팩에 의존시키지 않는다.
- 동일 정보가 여러 HUD를 점유하면 중앙 UI 우선순위 정책을 따른다.

## 8. 최종 진행 잠금

최종 목표는 다음 조건을 모두 서버에서 검증해야 활성화된다.

1. 현재 Day가 50 이상이다.
2. Day 10·20·30·40 핵심 보스 진행 기록이 모두 존재한다.
3. 필수 재건 발견 노드와 최종 설비 연구가 완료됐다.
4. 최종 정화 설비와 필요 부품이 정상 등록됐다.
5. Day 49 준비 절차와 저장이 완료됐다.

클라이언트 표시, 아이템 보유 또는 GUI 상태만으로 최종 진행을 승인하지 않는다.

Day 50 도달은 최종 진행의 최소 Day 조건만 만족시킨다. 조건이 부족하면 Day 51 이상으로 계속 진행하며, 회차 성공은 최종 목표 완료 트랜잭션이 확정된 뒤에만 처리한다. Day 수명주기와 스킵은 `DAY-001`을 따른다.

## 9. 현재 제외 범위

- 클라이언트 모드 전용 키와 UI
- 고정 임무 맵과 고정 임무 구역
- 시작부터 완성된 고정 기지
- 신규 중도 참여 보정
- 현재 단계의 실행 프로토타입 제작
- 현재 `ws-content-r1`에 실제 Story 런타임 JSON 탑재
- Season 2의 실제 전투·경제·Day·세력 관계 구현
- 무기 하나가 없으면 진행할 수 없는 역할 고정 기믹

## 10. 하위 문서 우선순위

이 문서와 하위 문서가 충돌하면 이 문서를 우선한다. 기존 BASE·ACT·GAME 문서의 고정 기지, 고정 스폰 지점, 등록 임무 구역 전제는 자유 야생 거점 및 발견형 목표망 규칙으로 교체한다.

# WildSurvival RULES 바닐라 상호작용 정책 기획서

## 문서 정보

| 항목 | 내용 |
|---|---|
| 문서 역할 | 바닐라 기능이 커스텀 진행·경제·하드코어 규칙을 우회하지 않도록 허용 범위를 관리 |
| 기본 전제 | 바닐라 야생 자유도는 유지하되 핵심 전투·성장 결과는 서버 플러그인이 확정 |
| 기본 UI | 리소스팩 없는 바닐라 클라이언트 기준 |
| 최종 수정일 | 2026-08-16 |

## 1. 정책 상태

| 상태 | 의미 |
|---|---|
| `ALLOW` | 바닐라 기능을 그대로 허용 |
| `ALLOW_CONTROLLED` | 허용하되 보상·속도·저장·악용 방지 규칙 적용 |
| `REPLACE` | 입력·블록은 사용할 수 있으나 결과는 커스텀 시스템으로 교체 |
| `LOCKED_DISCOVERY` | 발견형 진행 조건을 만족하기 전까지 차단 |
| `DISABLE` | 회차 내부에서 사용하지 않음 |

| 바닐라 포션 전투 효과 | `REPLACE` | 시각 보조만 사용하고 실제 효과는 STATUS가 관리 |
| 불사의 토템 | `REPLACE` | 일반 부활을 차단하고 등록된 커스텀 부활 효과만 실행 |

## 4. 자원과 반복 생산

| 기능 | 기본 정책 | 처리 |
|---|---|---|

| 자동 농장 | `ALLOW_CONTROLLED` | 바닐라 산출물은 허용할 수 있으나 활동 EXP·핵심 재료·발견 진행을 반복 지급하지 않음 |
| 스포너·사육 개체 | `ALLOW_CONTROLLED` | 활동 EXP, 증강 발동 보상과 고유 드롭 차단 |
| 레드스톤 자동화 | `ALLOW_CONTROLLED` | 무인 서버 정지 중 콘텐츠 생산과 시설 작업은 진행하지 않음 |
| TNT 채굴 | `ALLOW_CONTROLLED` | 바닐라 블록 파괴는 월드 정책을 따르고 콘텐츠 자원 이벤트는 중복 지급하지 않음 |
| 어획·낚시 농장 | `ALLOW_CONTROLLED` | 반복 감쇠와 핵심 재료 획득 상한 적용 |

핵심 진행 재료는 생성 원인, 획득 이벤트 ID, 플레이어 또는 파티 수령 기록을 저장한다.

## 7. 월드 범위와 필수 자원 보장

- 핵심 진행은 특정 생물군계나 고정 구조물 하나에만 의존하지 않는다.
- 회차 월드는 운영 설정에 따라 사전 생성 범위와 월드 보더를 가질 수 있다.
- 보더 확장은 Day 또는 발견 진행과 연결할 수 있으나 임무 구역처럼 특정 좌표를 지시하지 않는다.
- 핵심 자원 탐색이 기준 시간을 넘으면 탐지 장치의 범주형 신호를 강화한다.
- 월드 시드에 필수 자원이 없거나 접근 불가능하면 대체 제작식 또는 보정 획득 경로를 활성화한다.
- 신규 청크 생성 자체가 무한 보상 전략이 되지 않도록 최초 발견 보상에 회차·플레이어별 상한을 둔다.

## 8. 커스텀 장비 입력 우선순위

### 좌클릭

```text
GUI·채팅·관전 여부 확인
→ 생명·제어 상태 확인
→ 커스텀 주무기 또는 권투 상태 확인
→ 유효 전투 입력이면 커스텀 일반 공격 실행
→ 전투 입력이 아니면 허용 블록 파괴 처리
```

- 곡괭이를 주무기로 장착한 상태에서는 전투 판정을 블록 파괴보다 우선한다.
- 곡괭이로 블록을 채굴하려면 공격 후보가 없고 전투 상태가 아니거나 별도 채굴 조건을 만족해야 한다.
- 주무기 슬롯이 비어 있으면 권투 상태를 활성화하므로 좌클릭은 권투 일반 공격을 우선한다.
- 권투 중 의도적인 블록 파괴는 웅크리기 유지 또는 별도 채굴 도구 사용 규칙으로 구분한다.

### 삼지창

- 바닐라 삼지창 투척, 충성, 급류, 찌르기 피해를 실제 전투 결과로 사용하지 않는다.
- 좌클릭 일반 공격과 지정 액티브 입력을 커스텀 스킬 실행으로 변환한다.
- 투사체 위치, 관통, 회수와 소유권은 서버 데이터로 관리한다.
- 바닐라 삼지창 엔티티를 연출에 사용하더라도 실제 피해는 CustomDamageService만 확정한다.

## 9. UI 정책

- 핵심 기능은 인벤토리 GUI, 액션바, 보스바, 스코어보드, 타이틀과 채팅만으로 사용 가능해야 한다.
- 리소스팩 전용 아이콘은 대체 텍스트와 바닐라 아이템 표현을 제공한다.
- 장비 GUI를 닫거나 접속 종료해도 서버에 확정되지 않은 장착 변경은 적용하지 않는다.
- 여러 시스템이 액션바를 동시에 요청하면 생명 위험, 보스 기믹, AP·상태, 발견 알림 순으로 표시한다.

## 10. 검증 매트릭스

- 바닐라 기능별 이벤트 차단·변환·허용 여부
- 회차 외부 아이템 반입·반출
- PDC 제거·복제·아이템 스택 병합
- 자동 농장과 스포너 보상 차단
- 네더·엔드 미해금 우회
- 호퍼와 컨테이너를 이용한 고유 보상 복제
- 곡괭이 전투·채굴 입력 충돌
- 권투 상태와 빈 주무기 슬롯 동기화
- 삼지창 바닐라 피해와 커스텀 피해 중복
- 리소스팩 미사용 상태의 모든 핵심 UI 접근성

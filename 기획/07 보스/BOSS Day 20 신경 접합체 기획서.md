## 11. 상태이상 계약

### 11.1 보스에게 적용

| 상태 | 처리 |
|---|---|
| BURN·POISON·BLEED | 지속·강도 50%, 합산 DPS는 최대 HP의 초당 0.8% 상한 |
| SLOW | 지속·강도 50%, 이동속도 감소 최대 20% |
| VULNERABLE | 지속·강도 50%, 전체 받는 피해 증가 상한 적용 |
| ARMOR_BREAK | 고정·비율 효과 50%, DEF 최소 30 |
| ROOT·STUN·AIRBORNE | BREAK_CONVERT |
| SILENCE·DISARM | 면역, 브레이크 변환 없음 |
| MARK | 조건용 정상 적용, 동일 출처 갱신 |

### 11.2 플레이어에게 적용

- 보스의 독·화상·출혈은 각각 최대 3중첩이며 같은 실행의 다중 히트가 중첩을 반복하지 않는다.
- SILENCE·DISARM은 실제 장착 아이템을 제거·이동·드롭하지 않는다.
- 강한 CC 종료 뒤 0.5초 면역과 3초 내 강한 CC 합계 상한을 보스 패턴보다 우선한다.
- 해독·냉각·지혈·신경 안정제는 각 허용 상태만 제거하고 접합 부하·신경 연결은 제거하지 않는다.
- 바닐라 우유는 커스텀 상태 전체 제거를 하지 않는다.

## 12. 패턴 선택기와 동시성

```text
현재 페이즈 후보
→ 직전 2개 패턴 제외
→ 활성 상태 영역·소환체·구조 상황 필터
→ 같은 상태 계열 2연속 금지
→ 같은 대응 태그 3연속 금지
→ 최근 표적 편향 보정

```

| 항목 | P1 | P2 | P3 |
|---|---:|---:|---:|
| 기본 패턴 간격 | 2.7초 | 2.45초 | 2.2초 |
| 상태 위험 영역 상한 | 1 | 2 | 2 |
| 소환체 상한 | 0 | 2 | 2 |
| 강한 전조 동시 상한 | 2 | 3 | 3 |

- 낮은 TPS에서는 장식 입자, 표시 엔티티 보간 빈도, 비핵심 투사체 수를 낮춘다.
- 전조 시간·판정 크기·안전 구역·서버 권위 히트 판정은 TPS 열화로 생략하지 않는다.
- 같은 플레이어를 주 표적으로 세 번 연속 선택하지 않는다.

## 13. 이탈·전투 시간

- 강제 시간 제한과 즉사형 광폭화는 없다.
- 13분 이후 2분마다 보스 이동속도 +3%, 최대 +9%만 적용하고 피해·상태 강도는 올리지 않는다.
- 모든 생존자가 중심 52블록 밖에 10초 있으면 마지막 표적을 추적하되 HP·브레이크·페이즈를 초기화하지 않는다.
- 유효 이동 영역을 벗어난 보스는 마지막 안전 위치로 복구하고 현재 패턴만 취소한다.
- 전원이 접속 종료해도 전투 스냅샷을 유지하고 접속 악용으로 상태·소환체·쿨다운을 초기화하지 않는다.

## 3. 동적 전장 생성

### 3.1 말뚝 배치

1. 파티가 후보 중심 주변에 신호 말뚝 3개를 배치한다.
2. 각 말뚝은 다른 말뚝과 20~42블록 떨어져야 한다.
3. 세 말뚝의 무게중심을 1차 전장 중심으로 사용한다.
4. 서버가 반경 32블록과 높이 차 14블록 범위를 스캔한다.
5. 유효하지 않으면 중심에서 8방향, 8·16블록 오프셋 후보를 순서대로 검사한다.
6. 유효 후보를 찾으면 `ArenaManifest`를 저장하고 호출 세트를 소비한다.

### 3.2 유효 조건

| 검사 | 조건 |
|---|---|
| 지면 | 중심 반경 6블록에 보스 발판 가능한 지면 60% 이상 |
| 이동 | 중심에서 말뚝 3개까지 적어도 한 개의 2블록 높이 경로 |
| 높이 | 핵심 패턴 경로의 순간 높이 차 4블록 이하 |
| 액체 | 전장 바닥의 물·용암 합계 35% 이하, 용암 10% 이하 |
| 보호 | 다른 보스·재건 시설·월드 보호구역과 겹치지 않음 |
| 공간 | 보스 몸체와 투사체가 통과할 최소 폭 4블록 구간 존재 |

- 작은 나무, 바위, 폐허와 플레이어 건축은 엄폐·경로 요소로 활용한다.
- 자연 지형을 평탄화하거나 광범위하게 파괴하지 않는다.
- 필요한 경계·위험 표식은 파티클, 표시 엔티티, 상호작용 엔티티와 임시 배리어를 사용한다.
- 임시 배리어는 공기 블록에만 놓고 원래 블록 스냅샷과 플러그인 소유 태그를 저장한다.

### 3.3 지형 적응

| 지형 특성 | 패턴 변환 |
|---|---|
| 엄폐 3개 이상 | 파편 일제사의 투사체 수 +1, 개별 피해 -15% |
| 엄폐 2개 이하 | 호출 시 임시 엄폐 2개 생성 |
| 물 비율 20% 이상 | 바닥 장판 대신 수면 링 사용, 익사 유도 금지 |
| 유효 고저차 6블록 이상 | 돌진은 같은 높이의 경로만 선택, 고저차 표적은 창 패턴 우선 |
| 좁은 통로 | 붕괴 고리 반경 -20%, 전조 +0.25초 |

지형 적응은 난도를 일방적으로 올리는 보정이 아니라 패턴을 성립시키기 위한 변환이다.

## 11. 패턴 선택기

```text

→ 직전 2개 패턴 제외
→ 지형·거리·대상 조건 필터
→ 같은 대응 태그 3연속 금지

```

- 기본 패턴 간격은 P1 2.8초, P2 2.5초, P3 2.2초다.

- 동시에 유지 가능한 보스 위험 영역은 2개, 4인에서는 3개다.
- 낮은 TPS에서는 파티클 수와 잔향 투사체 수를 줄이되 전조 시간과 판정 크기는 유지한다.

## 12. 이탈·추적·전투 시간

- 보스전에는 강제 시간 제한과 즉사형 광폭화가 없다.
- 12분 이후 2분마다 `추적 압력` 1중첩을 얻어 소환체가 아닌 보스 이동속도만 +3%, 최대 +9%가 된다.
- 모든 생존자가 전장 중심 48블록 밖에 10초 이상 있으면 보스가 가장 가까운 생존자를 추적한다.
- 보스가 유효 이동 영역을 벗어나면 마지막 안전 위치로 되돌리고 현재 패턴만 취소한다. HP·브레이크·내성은 초기화하지 않는다.
- 접속 종료로 전투를 리셋하거나 인원 배율을 낮출 수 없다.

### 13.2.1 개인 기여품

- 보스전에서 `REWARD-001`의 유효 참여와 기여 점수 20 이상을 만족한 플레이어는 상급 보급 1회를 받는다.
- 기여 등급은 보급의 양·희귀도가 아니라 동가치 후보 선택 폭만 변경한다.
- 완전 사망자는 EXP를 받지 않지만 사망 전에 고정된 개인 기여품은 개인 지급 대기함에 보존한다.
- 개인 기여품 예산은 Day 10 기존 자원 유입 안에서 배정하며 위 공용 보상에 무상으로 더하지 않는다.

### 13.3 파티 증강

- 보스·장비 정산 뒤 PAUG 후보 3개를 생성한다.
- Day 10 파티 증강 선택이 완료되기 전까지 다음 Day 시작을 보류한다.
- 이미 보유한 파티 증강과 현재 파티에 즉시 무효인 후보를 제외한다.
- 결과와 동률 시드를 저장해 재시작으로 후보나 결과가 바뀌지 않게 한다.

## 14. 실패와 복구

### 14.1 호출·전장 실패

| 실패 시점 | 처리 |
|---|---|
| 후보 검증 전 | 호출 세트 미소비, 말뚝 회수 가능 |
| 유효 후보 없음 | 이유·실패 지점을 표시하고 말뚝 1개 무료 재배치 허용 |
| ArenaManifest 저장 실패 | 호출 세트 미소비, 임시 오브젝트 전부 제거 |
| 호출 세트 소비 후 보스 생성 실패 | 같은 트랜잭션 롤백, 호출 세트 100% 복구 |

### 14.2 전투 실패

- 모든 등록 플레이어가 완전 사망하면 하드코어 회차 실패다.
- 전투 실패에는 호출 세트, 소모품, 장비 내구와 사망 결과를 환불하지 않는다.
- 일부 플레이어가 완전 사망해도 남은 생존자는 계속 싸울 수 있으며 보스 스케일은 낮아지지 않는다.
- 보스에게서 도망치거나 전원이 접속 종료해도 HP·브레이크·내성·페이즈를 초기화하지 않는다.

### 14.3 서버 종료·충돌

보스 전투는 다음 원자 스냅샷을 저장한다.

```yaml
boss-snapshot:
  encounter-id: "boss-uuid"
  arena-manifest-id: "arena-uuid"
  state: ACTIVE
  phase: P2
  hp-current: 0
  break-current: 0
  break-resistance-stacks: 0
  active-pattern: null
  pattern-rng-index: 0
  anchor-pressure: 0
  summon-instance-ids: []
  reward-state: NOT_GRANTED
  revision: 1
```

- 정상 종료는 현재 패턴 남은 시간까지 저장한다.
- 충돌 복구는 마지막 확정 스냅샷의 플레이어 HP·AP·상태·인벤토리와 보스 상태를 함께 복원한다.
- 재개 직후 3초는 보스와 플레이어 모두 피해·브레이크를 줄 수 없는 동기화 구간으로 사용한다.
- 전장 임시 블록·표시 엔티티가 사라졌으면 ArenaManifest로 재구성한다.
- 보스가 중복 생성되면 가장 높은 저장 순번 하나만 유지하고 나머지는 보상 없이 제거한다.
- 스냅샷이 복구 불가능하면 자동 보상을 지급하지 않고 회차를 `ADMIN_RECOVERY_REQUIRED`로 동결한다. 운영자는 전체 스냅샷 복원 또는 호출 전 트랜잭션 롤백 중 하나만 선택한다.

### 14.4 정산 실패

- 보스 사망, 진행 부품, EXP, 장비 후보, 최초 완제품, 제작식과 파티 증강 후보는 하나의 보상 ID 아래 단계별 멱등 처리한다.
- 보상 지급 중 서버가 종료돼도 완료된 단계는 반복하지 않고 미완료 단계만 재개한다.
- 인벤토리 부족 시 최초 완제품은 가상 파티 보상함에 보관한다.
- 정산이 완료되기 전 임시 전장을 먼저 철거하지 않는다.

## 15. 전장 철거

1. 보스 보상 상태를 `COMMITTED`로 확정한다.
2. 소환체와 보스 전용 투사체·장판을 제거한다.
3. 임시 배리어와 표시 엔티티를 ArenaManifest 역순으로 제거한다.
4. 플러그인 소유 태그가 없거나 원래 스냅샷과 다른 플레이어 블록은 건드리지 않는다.
5. 신호 말뚝을 회수 가능 상태로 바꾸고 전장 기록을 보관한다.

## 16. Story 확장 지점

아래 필드만 비워 둔다. 이 문서에서는 실제 값을 작성하지 않는다.

```yaml
story:
  chapter-id: null
  intro-sequence-id: null
  defeat-sequence-id: null
  completion-sequence-id: null
  character-hooks: []
```

Story 데이터가 없어도 호출, 전투, 보상과 회차 진행이 완전하게 동작해야 한다.

## 17. 검증 항목

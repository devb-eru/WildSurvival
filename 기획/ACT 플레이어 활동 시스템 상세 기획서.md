# ACT-001 플레이어 활동 루프와 Day 전략 선택

## 1. 목적

ACT-001은 7분 Day 안에서 전투 외 활동을 어떻게 선택하고, 그 결과를 밤 공세와 장기 성장에 연결하는지 정의한다.

- 탐사, 자원수집, 제작, 연구, 시설 정비를 동시에 열어 둔다.
- 2~4인이 한 활동에 집중하거나 여러 활동으로 나뉘는 전략을 모두 허용한다.
- 특정 Day마다 파티 활동 전략을 선택해 여러 Day의 운영 방향을 정한다.
- Hard 이상에서는 적군도 일반 전략을 사용해 반복되는 Day의 양상을 변화시킨다.
- 보스 Day에는 플레이어와 적군 모두 보스 전용 전략을 사용할 수 있다.
- 적군 전략은 연구를 통해 미리 파악하고 대응할 수 있다.
- 활동을 강제 역할이 아니라 시간, 위험, 자원, 정보 사이의 선택으로 만든다.

## 2. Day 활동 루프

기존 7분 Day 구조를 유지한다.

| 단계 | 남은 시간 | 활동 기준 |
|---|---:|---|
| 활동 단계 | 07:00~03:00 | 탐사, 자원수집, 제작, 연구, 시설 정비 |
| 경고 단계 | 03:00~01:30 | 모든 활동 유지, 귀환 판단, 선발대 대응 |
| 공세 단계 | 01:30~00:00 | 기지 방어 중심, 조건을 만족하면 다른 활동도 가능 |
| 일반 Day 전환 | 00:00 | 다음 Day 즉시 시작, 잔존 공세는 유지 |
| 보스 Day 전환 | 00:00 | 일반 공세 대신 보스전 시작, 처치까지 Day 정지 |

### 기본 원칙

- 활동은 동시에 개방하며 플레이어가 언제든 전환할 수 있다.
- 직업이나 고정 활동 역할을 요구하지 않는다.
- 같은 활동의 필수 인원수와 최대 참여 인원수를 두지 않는다.
- 일반 활동은 전투 AP를 소비하지 않는다.
- 활동 장소를 자동 안전 구역으로 만들지 않는다.
- 아군 공격은 모든 활동 단계에서 기존 전투 규칙대로 허용한다.
- 활동 전환에는 재사용 대기시간이 없지만 진행 중 채널링은 취소될 수 있다.
- Day가 넘어갔다는 이유만으로 허용 중인 채널링을 취소하지 않는다.

## 3. 활동 분류

| 활동 | 내부 ID | 핵심 산출물 | 주요 소비처 |
|---|---|---|---|
| 탐사 | `EXPLORATION` | 지도 정보, 발견 지점, 설계도, 연구 단서 | 신규 구역, 관측, 연구 |
| 자원수집 | `GATHERING` | 목재, 식물, 일반 재료 | 건설, 치료, 제작 |
| 광질 | `MINING` | 광석, 정화 원석, 희귀 광물 | 장비, 시설, 정화 |
| 제작 | `CRAFTING` | 아이템, 탄약, 부품, 수리 키트 | 전투, 기지 운영 |
| 연구 | `RESEARCH` | 해금, 정보, 효율 강화, 대응책 | 모든 성장 시스템 |
| 시설 정비 | `FORTIFICATION` | 수리, 건설, 보강, 배치 | 밤 공세 대비 |
| 정화 활동 | `PURIFICATION` | 정화 자원, 오염 감소, 정화탑 운용 | 오염 관리 |
| 회복 정비 | `RECOVERY` | HP 회복, 부상 관리, 전투 준비 | 생존 유지 |
| 잔존 공세 소탕 | `RESIDUAL_CLEAR` | 기지 안정화, 제한 보상 | 오염 압박 해소 |

- 세부 자원 노드와 산출량은 `RES-001`에서 정의한다.
- 제작식과 작업 시간은 `CRAFT-001`에서 정의한다.
- 연구 트리와 요구 샘플은 `RESEARCH-001`에서 정의한다.
- ACT는 활동 가능 시점, 전략 보정, 기여도, 저장과 UI 규칙을 담당한다.

## 4. 활동 실행 규칙

### 즉시 행동과 누적 작업

| 유형 | 예시 | 진행도 |
|---|---|---|
| 즉시 행동 | 일반 채집, 소형 광물 채굴, 발견 지점 조사 | 완료 즉시 정산 |
| 채널링 행동 | 표본 채취, 시설 수리, 수동 분석 | 완료 시 정산 |
| 누적 작업 | 대형 제작, 연구, 시설 강화 | 확정 진행도 저장 |
| 공용 대기열 | 제작 주문, 연구 분석, 시설 작업 | 시설 단위 저장 |

### 채널링 중단

일반 활동 채널링은 다음 조건에서 중단한다.

- 허용 범위를 벗어남
- 이동 제한을 초과함
- 피격
- 다른 행동 또는 GUI 실행
- 빈사 또는 완전 사망
- 접속 종료
- 시설 정지 또는 작업 조건 상실

- 자원은 기본적으로 완료 시 소비한다.
- 누적 작업은 체크포인트에 도달한 진행도만 저장한다.
- 작업별 체크포인트와 환불 규칙은 해당 세부 시스템이 덮어쓸 수 있다.

## 5. 단계별 활동 허용

| 활동 | 활동 단계 | 경고 단계 | 공세 단계 | 보스전 |
|---|---|---|---|---|
| 야생 탐사 | 가능 | 가능 | 가능, 높은 위험 | 불가 |
| 채집·광질 | 가능 | 가능 | 가능 | 불가 |
| 일반 제작 | 가능 | 가능 | 조건부 가능 | 불가 |
| 고급 제작·강화 | 가능 | 가능 | 조건부 가능 | 불가 |
| 연구 진행·확정 | 가능 | 가능 | 조건부 가능 | 불가 |
| 시설 업그레이드 | 가능 | 가능 | BASE/CORR 제한 적용 | 불가 |
| 일반 시설 수리 | 가능 | 가능 | 긴급 수리 규칙 | 긴급 수리 규칙 |
| 치료 시설 | 가능 | 가능 | 가능 | 가능 |
| 전략 목표 누적 | 가능 | 가능 | 출처 조건을 만족하면 가능 | 일반 목표 중지 |

`조건부 가능`은 다음을 의미한다.

1. 해당 시설이 현재 기능을 제공할 수 있다.
2. 시설 손상 상태가 해당 작업 등급을 허용한다.
3. 플레이어가 상호작용 가능한 상태다.
4. 실제 전투 상태 또는 적의 직접 방해가 작업을 제한하지 않는다.
5. 작업 자체에 공세·보스전 금지 태그가 없다.

- 일반 공세라는 이유만으로 고급 제작, 강화, 연구 확정을 일괄 금지하지 않는다.
- 보스가 실제로 등장한 뒤에는 보스 전투, 치료, 긴급 수리와 직접 연결된 작업만 허용한다.
- 기지 핵심부와 작업 시설이 중파라서 고급 기능이 제한되는 규칙은 유지한다.
- 정화탑 업그레이드처럼 개별 문서에서 공세 중 금지한 작업은 해당 규칙을 우선한다.
- 공세 중에도 야생에 남을 수 있으며 강제 귀환시키지 않는다.

## 6. 일반 파티 전략 선택 일정

### 선택 Day

일반 파티 전략은 Day 번호의 일의 자리가 `3`, `6`, `9`일 때 선택한다.

```text
일반 전략 선택 Day =
day % 10 ∈ {3, 6, 9}
```

| Day 구간 | 일반 전략 선택 Day |
|---|---|
| Day 1~10 | 3, 6, 9 |
| Day 11~20 | 13, 16, 19 |
| Day 21~30 | 23, 26, 29 |
| Day 31~40 | 33, 36, 39 |
| Day 41~50 | 43, 46, 49 |

- Day 1에는 전략을 선택하지 않는다.
- Day 1~2에는 `균형 운영`을 포함한 일반 전략 효과가 없다.
- 일반 전략은 선택한 Day부터 다음 일반 전략 선택 Day 직전까지 유지한다.
- 보스 Day에는 현재 일반 전략을 일시 중지하고 플레이어 보스 전략을 적용한다.
- 보스 처치 후 다음 일반 Day에는 이전 일반 전략을 다시 활성화한다.

### 투표

| 항목 | 규칙 |
|---|---|
| 투표 시간 | Day 시작 후 20초 |
| 투표 중 Day 진행 | 계속 진행 |
| 투표권 | 투표 종료 시 접속 중인 생존 플레이어 1인 1표 |
| 확정 | 최다 득표 |
| 동률 1차 | 직전 선택 주기에 사용하지 않은 전략 우선 |
| 완전 동률 | 서버 시드 기반 무작위 |
| 무투표 | `BALANCED_OPERATION` 자동 선택 |
| 중도 변경 | 불가 |

- 전략 보너스는 파티 전체에 적용하지만 관련 활동에만 효과를 준다.
- 투표 GUI에는 현재 해금된 일반 파티 전략을 모두 후보로 표시한다.
- 선택하지 않은 활동에 페널티를 주지 않는다.
- 기본 전략 슬롯은 하나다.
- 연구, 파티 증강, 특수 이벤트가 보조 전략 슬롯을 추가할 수 있도록 데이터 구조를 열어 둔다.

## 7. 일반 파티 전략 목록

| 전략 | 내부 ID | 기본 효과 |
|---|---|---|
| 균형 운영 | `BALANCED_OPERATION` | 모든 활동 산출량과 진행속도 +5% |
| 탐사 우선 | `EXPLORATION_PRIORITY` | 탐사 지점 발견 범위 +20%, 희귀 탐사 보상 가중치 +10% |
| 자원 확보 | `RESOURCE_ACQUISITION` | 채집·광질 공용 자원 산출량 +15% |
| 생산 집중 | `PRODUCTION_FOCUS` | 일반 제작 채널링 시간 -20% |
| 연구 집중 | `RESEARCH_FOCUS` | 연구 분석 진행량 +20%, 연구 단서 발견 가중치 +10% |
| 기지 보강 | `BASE_FORTIFICATION` | 건설·수리 속도 +20%, 공세 전 완전 수리 자원 효율 +10% |
| 정화 작전 | `PURIFICATION_OPERATION` | 정화 자원 획득량 +20%, 정화탑 오염 감소 출력 +10% |
| 회복 정비 | `RECOVERY_MAINTENANCE` | 치료 시간 -20%, 치료 자원 비용 -10% |
| 잔존 공세 소탕 | `RESIDUAL_EXTERMINATION` | 잔존 적에게 주는 피해 +15%, 잔존 공세 기지 오염 증가 -30% |

### 초기 해금

| 상태 | 전략 |
|---|---|
| 시작부터 해금 | 균형 운영, 탐사 우선, 자원 확보, 기지 보강 |
| 시설 또는 연구 필요 | 생산 집중, 연구 집중, 정화 작전, 회복 정비, 잔존 공세 소탕 |

- 전략 효과는 연구, 장비, 증강의 같은 활동 보정과 곱연산한다.
- 최종 수치는 각 활동 시스템의 상한을 따른다.
- 전략은 자원 비용 자체를 0 아래로 만들 수 없다.
- 잔존 공세 소탕은 기존 잔존 보상 제한을 해제하지 않는다.

## 8. 전략 활동 목표

일반 전략을 선택하면 해당 전략에 맞는 공용 활동 목표를 Day마다 하나 생성한다.

| 구분 | 규칙 |
|---|---|
| 기본 목표 | 현재 인원과 Day에 맞는 기준량 |
| 초과 목표 | 기본 목표의 150% |
| 필수 여부 | 선택 사항 |
| 실패 페널티 | 없음 |
| 기본 보상 | 관련 공용 재료 |
| 초과 보상 | 희귀 재료 또는 다음 Day 소규모 준비 보너스 |

```text
Day 활동 목표량 =
활동별 기본 목표량
× 활성 생존 인원 보정
× Day 구간 보정
× 특수 이벤트 보정
```

- 전략 보너스는 여러 Day 유지하지만 목표는 매 Day 새로 생성한다.
- 공세 중에도 올바른 출처의 행동이면 목표를 누적할 수 있다.
- 공세 적 반복 처치로 탐사, 제작, 연구 목표를 대신 채울 수 없다.
- 자원을 버린 뒤 다시 줍거나 보관함을 반복 이동해 중복 집계하지 않는다.
- 목표는 자원 고유 획득 이벤트와 작업 완료 이벤트를 기준으로 기록한다.

## 9. 플레이어 보스 전략

### 선택 규칙

- Day 10, 20, 30, 40, 50마다 보스 전용 전략을 선택한다.
- 보스 Day 시작 후 20초 동안 투표한다.
- 해금된 플레이어 보스 전략 중 시드 기반 무작위 3개를 후보로 제시한다.
- 파티는 후보 중 하나를 선택한다.
- 무투표 시 `COMBAT_READINESS`를 적용한다.
- 선택 전략은 보스 Day 준비 단계부터 보스 사망까지 유지한다.
- 보스 전략에는 일반 활동 목표를 생성하지 않는다.
- 패배 전 저장·재개가 발생하면 후보와 선택 결과를 유지한다.

### 플레이어 보스 전략 목록

| 전략 | 내부 ID | 효과 |
|---|---|---|
| 전투 준비 | `COMBAT_READINESS` | 주는 피해 +5%, 받는 피해 -5% |
| 선봉 돌격 | `VANGUARD_ASSAULT` | 주는 피해 +12%, 받는 피해 +5% |
| 붕괴 공략 | `BREAK_ASSAULT` | 주는 브레이크 피해 +25%, 그로기 대상 추가 피해 +10% |
| 요새 봉쇄 | `FORTRESS_LOCKDOWN` | 시설이 받는 피해 -25%, 긴급 수리 속도 +25% |
| 정화 쇄도 | `PURIFICATION_SURGE` | 플레이어 오염 축적 -30%, 정화탑 오염 감소 출력 +20% |
| 구조 프로토콜 | `RESCUE_PROTOCOL` | 구조 속도 +30%, 빈사 상태에서 받는 피해 -15% |
| 기동 사냥 | `MOBILE_HUNT` | 이동속도 +10%, 회피 AP 비용 -15% |
| 원거리 제압 | `RANGED_SUPPRESSION` | 투사체·원거리 피해 +15%, 투사체 유도 보정 +10% |
| 근접 압박 | `CLOSE_QUARTERS_PRESSURE` | 근접 피해 +15%, 패링 성공 후 다음 근접 공격 피해 +10% |
| 소환체 통제 | `ADD_CONTROL` | 보스가 아닌 적에게 주는 피해 +20%, 일반 CC 지속시간 +15% |

- 효과는 기존 STAT·COMBAT 하드캡을 따른다.
- `ADD_CONTROL`은 보스의 CC 면역과 TENACITY를 무시하지 않는다.
- `LAST_STAND`는 완전 사망과 접속 종료로 감소한 현재 생존 인원을 기준으로 한다.
- 전용 전략 해금 조건은 보스 연구와 파티 진행도로 확장할 수 있다.

## 10. 일반 적군 전략 등장 규칙

일반 적군 전략은 Hard 이상에서 Day 일정에 따라 등장한다.

| 난이도 | 최초 가능 Day | 주기 | 기본 개수 | 추가 전략 |
|---|---:|---:|---:|---|
| Easy | 없음 | 없음 | 0 | 없음 |
| Normal | 없음 | 없음 | 0 | 없음 |
| Hard | 6 | 3 Day | 1 | 없음 |
| Challenge | 6 | 2 Day | 1 | 20% 확률로 +1 |
| ??? | 6 | 1 Day | 1 | 50% 확률로 +1 |

```text
Hard 등장 Day:
day >= 6 AND day % 3 = 0

Challenge 등장 Day:
day >= 6 AND day % 2 = 0

??? 등장 Day:
day >= 6
```

- Day 1~5에는 난이도와 무관하게 일반 적군 전략이 등장하지 않는다.
- 같은 Day에 동일 전략을 중복 선택하지 않는다.
- 같은 일반 전략 풀 안에서 충돌 태그가 겹치면 재추첨한다.
- 전략은 회차 생성 시 Day별로 미리 추첨하고 숨김 상태로 저장한다.
- 접속 종료, 서버 재시작, 세션 재개로 추첨 결과가 바뀌지 않는다.

### 보스 Day 중첩

일반 적군 전략 등장 일정과 보스 Day가 겹치면 일반 전략을 제거하지 않는다.

- 해당 Day의 일반 적군 전략을 정상적으로 적용한다.
- 난이도별 보스 전용 적군 전략을 추가 적용한다.
- 일반 적군 전략과 보스 전용 적군 전략 사이에는 상호 배제 재추첨을 하지 않는다.
- 두 전략이 같은 능력치를 변경하면 서로 다른 출처로 함께 계산한다.
- 일반 전략의 대상 필터와 보스 전략의 대상 필터는 각각 독립적으로 적용한다.
- 보스 Day의 일반 적군 전략은 보스 사망까지 지속되어 보스 전용 전략과 실제로 중첩된다.

### 지속 범위

| 상황 | 처리 |
|---|---|
| 일반 Day | Day 시작부터 00:00까지 전역 효과 적용 |
| 일반 Day 잔존 적 | 개체에 부여된 효과만 사망까지 유지 |
| 보스 Day | Day 시작부터 보스 사망까지 유지 |
| 접속자 없음 | 지속시간과 관련 주기 정지 |
| 보스전 저장·재개 | 기존 일반·보스 전략 모두 복원 |

## 13. 전략 중첩과 계산 순서

### 출처

| 전략 출처 | 출처 ID |
|---|---|
| 일반 파티 전략 | `strategy.party.activity` |
| 플레이어 보스 전략 | `strategy.party.boss` |
| 일반 적군 전략 | `strategy.enemy.general` |
| 보스 전용 적군 전략 | `strategy.enemy.boss` |

### 적용 순서

1. 기본 활동·전투·시설 수치 계산
2. 일반 파티 전략 적용
3. 플레이어 보스 전략 적용
4. 일반 적군 전략 적용
5. 보스 전용 적군 전략 적용
6. 연구·장비·증강·상태 효과 적용
7. 시스템별 최종 하드캡 적용

- 보스 Day에는 일반 파티 전략을 중지하므로 2단계 효과가 발생하지 않는다.
- 일반 적군 전략과 보스 전용 적군 전략은 서로 독립 출처로 모두 적용한다.
- 같은 보조 능력치를 변경하면 해당 STAT의 출처 결합 규칙을 따른다.
- 독립 개체 속성은 개체별로 따로 계산한다.
- 전략에 명시되지 않은 고정·환경 피해에는 Damage Dealt·Taken 보정을 적용하지 않는다.

## 14. 적군 교리 분석 연구

적군 전략 정보는 `적군 교리 분석` 연구 계열로 해금한다. 연구는 전략을 변경하거나 재추첨하지 않고 정보만 제공한다.

### 일반 적군 전략 분석

| 연구 레벨 | 제공 정보 |
|---:|---|
| 0 | 경고 단계 시작 시 전략 이름과 효과 공개 |
| 1 | 다음 Day의 일반 적군 전략 등장 여부와 개수 |
| 2 | 다음 Day 전략 분류 |
| 3 | 다음 Day 전략 1개 정확히 공개 |
| 4 | 다음 Day의 모든 일반 전략 공개 |
| 5 | 정확한 수치, 충돌·시너지, 대응 추천 공개 |

### 보스 적군 전략 분석

| 연구 레벨 | 제공 정보 |
|---:|---|
| 0 | 보스 등장 시 이름과 효과 공개 |
| 1 | 다음 보스의 전략 개수 |
| 2 | 전략 분류 하나 공개 |
| 3 | 전략 하나 정확히 공개 |
| 4 | 전체 전략의 절반을 올림 처리하여 정확히 공개 |
| 5 | 모든 전략, 수치, 조합 시너지, 대응 추천 공개 |

### 연구와 관측 장치

- 연구 결과는 공세 관측 장치와 연구 단말에서 확인한다.
- 관측 장치가 정지하면 전략 투표는 가능하지만 관측 GUI의 전략 정보는 숨긴다.
- 연구 단말이 정상이라면 기지에서 분석 결과를 별도로 확인할 수 있다.
- 실제로 조우한 전략은 적군 교리 도감에 영구 등록한다.
- 미연구 전략도 조우 이후 이름과 기본 설명은 열람할 수 있다.
- 일반 적 샘플, 전략 행동 관측 기록, 보스 연구 샘플을 연구 재료로 사용한다.
- 구체적인 연구 비용과 해금 순서는 `RESEARCH-001`에서 확정한다.

## 15. 탐사 구역과 이동

- 고정 기지를 중심으로 탐사 구역, 광산, 자원 지점, 전초 지점을 배치한다.
- 연구와 탐사 성과로 신규 활동 지점을 해금할 수 있다.
- 무한 야생 탐사는 가능하지만 등록된 활동 지점이 주요 활동 보상에 더 효율적이다.
- 발견한 전초 지점과 기지 사이에 한해 빠른 이동을 허용한다.

### 빠른 이동

| 항목 | 규칙 |
|---|---|
| 사용 위치 | 기지 이동 시설 또는 발견한 전초 지점 |
| 채널링 | 5초 |
| 전투 상태 | 사용 불가 |
| 활동 단계 | 가능 |
| 경고 단계 | 가능 |
| 공세 단계 | 불가 |
| 피격·이동 | 취소 |

- 경고 단계의 빠른 귀환은 허용한다.
- 공세 단계가 시작되면 진행 중인 빠른 이동도 취소한다.
- 추후 제작 가능한 비상 귀환 소모품은 8초 채널링, 전투 중 사용 불가를 기본으로 한다.
- Day 전환 시 야생 플레이어를 강제로 귀환시키지 않는다.

## 16. 자원 소유권과 공용 작업

### 자원 소유권

- 획득 직후의 일반 자원은 플레이어 인벤토리에 들어간다.
- 플레이어 사이에서 제한 없이 공유할 수 있다.
- 공용 보관함이나 시설에 투입하면 공용 자원으로 전환한다.
- 전략 목표는 최초 유효 획득 이벤트에서 집계한다.
- 같은 자원의 버리기, 재획득, 보관함 이동은 중복 집계하지 않는다.

### 시설별 공용 대기열

| 항목 | 규칙 |
|---|---|
| 기본 동시 작업 | 시설당 1개 |
| 병렬 슬롯 | 시설 업그레이드로 확장 가능 |
| 작업 소유권 | 파티 공용 |
| 회수 권한 | 생존 플레이어 전체 |
| 서버 무인 상태 | 진행 정지 |
| 다른 생존자 접속 중 | 공용 자동 작업 계속 |
| 시설 정지 | 작업 일시 정지 |

- 작업 등록자 접속 종료로 공용 작업을 취소하지 않는다.
- 시설 파괴로 작업 결과물이나 투입 자원이 즉시 소실되지 않는다.
- 작업 취소 환불률은 제작·연구 세부 문서에서 정의한다.

## 17. 활동 기여도

### 인정 행동

| 활동 | 기여 행동 |
|---|---|
| 탐사 | 신규 지점 발견, 지도 정보 확보, 표본 조사 |
| 수집·광질 | 유효 자원 최초 획득, 희귀 노드 채굴 |
| 제작 | 공용 주문 완료, 탄약·부품·수리품 제작 |
| 연구 | 샘플 제출, 분석 진행, 연구 완료 |
| 시설 정비 | 건설, 수리, 보강, 함정 장전 |
| 정화 | 정화 자원 확보·투입, 정화 장치 유지 |
| 회복 | 치료 자원 제공, 구조·치료 지원 |
| 소탕 | 잔존 적 피해, 브레이크, 처치, 시설 방어 |

- 핵심 공용 자원은 파티에 지급한다.
- 개인 기여도에 따라 활동 EXP를 지급한다.
- 운반, 호위, 치료, 시설 작업, 정보 발견도 기여로 인정한다.
- 같은 저가 행동을 반복하면 기여도만 점감한다.
- 실제 자원 획득량 점감은 `RES-001` 규칙을 따른다.
- 같은 활동에 여러 명이 참여해도 별도 협동 배율은 주지 않는다.
- 인원 분산에도 페널티를 주지 않는다.

### 접속 상태

| 상태 | 처리 |
|---|---|
| 도중 참여 | 현재 전략 즉시 적용, 참여 이후 기여만 기록 |
| 접속 종료 | 기존 기여 보존, 오프라인 활동 EXP 없음 |
| 60초 이상 무활동 | 활동 기여도 누적 중지 |
| 빈사 | 활동과 투표 불가 |
| 완전 사망·관전 | 활동, 투표, 보상 기여 제외 |

- AFK 플레이어가 접속 중이어도 생존 플레이어로서 Day 타이머를 정지시키지는 않는다.
- 전략 효과를 받는 것만으로 기여도가 발생하지 않는다.

## 18. 특수 Day와 전략 변형

- 특수 Day 이벤트는 전략을 원칙적으로 금지하지 않는다.
- 이벤트는 활동 효율, 위험도, 목표량, 보상 가중치를 변경할 수 있다.
- 변경 수치는 전략 투표 GUI에 미리 표시한다.
- 이벤트와 전략의 효과는 서로 다른 출처로 계산한다.
- 보스 Day 이벤트는 플레이어 보스 전략 후보와 적군 전략 연구 정보를 함께 표시한다.

## 22. 플러그인 구현 기준

- Day와 단계 이벤트는 GAME 타이머 API를 구독한다.
- 전략은 데이터 기반 modifier와 event hook의 조합으로 구현한다.
- 단순 수치 전략은 STAT·COMBAT·BASE·CORR 보정 API를 사용한다.
- 행동형 전략은 웨이브, 시설 피해, 오염, 보스 패턴 이벤트를 구독한다.
- 전략 ID, 충돌 태그, 대상 태그, 공개 정보, 배율을 설정 파일로 관리한다.
- 모든 무작위 추첨은 회차 시드와 Day를 조합한 결정적 난수를 사용한다.
- 활동 지점은 좌표와 구역 ID로 등록하고 영구 청크 틱을 요구하지 않는다.
- 공용 작업은 서버 스케줄러로 처리하고 무인 상태에서는 정지한다.
- 인벤토리 GUI, 보스바, 액션바, 타이틀, 사운드만으로 구현 가능하다.
- 모드 전용 블록과 클라이언트 입력을 요구하지 않는다.

## 25. ACT-001 완료 기준

- 7분 Day의 활동·경고·공세 단계별 활동 허용 규칙이 정의되어 있다.
- 탐사, 수집, 광질, 제작, 연구, 정비, 정화, 회복, 소탕 활동이 분류되어 있다.
- 일반 파티 전략의 선택 Day, 투표, 지속, 중지·복귀 규칙이 정의되어 있다.
- 일반 파티 전략 9개와 플레이어 보스 전략 12개가 정의되어 있다.
- Hard 이상 일반 적군 전략의 주기와 추가 등장 확률이 정의되어 있다.
- 일반 적군 전략 48개가 고유 ID와 효과를 가진다.
- 난이도별 보스 적군 전략 개수와 보스 전용 전략 18개가 정의되어 있다.
- 보스 Day에 일반 적군 전략과 보스 전용 전략이 동시에 적용된다.
- 적군 교리 분석 연구의 정보 공개 단계가 정의되어 있다.
- 빠른 이동, 공용 작업, 기여도, UI, 저장, 예외, 테스트 기준이 정의되어 있다.
- 모든 핵심 기능이 바닐라와 서버 플러그인으로 구현 가능하다.

## 카테고리 공통 방향

- 기지는 WildSurvival의 협동 거점이자 밤 공세의 주 방어 목표다.
- 기지는 고정된 한 곳의 중심 기지를 사용한다.
- 기지 파괴 자체가 즉시 패배 조건이 되지는 않는다. 패배 조건은 기존처럼 전원 사망이다.
- 기지 시설은 생존, 성장, 저장, 정화, 방어 준비를 담당한다.
- 공세 생성은 `BASE-002`, 시설 피해·파괴·수리는 `BASE-003`에서 정의한다.

# BASE-001 기지 영역과 핵심 시설

## 1. 시스템 목적

`BASE-001`은 플레이어가 돌아오고, 정비하고, 방어해야 하는 고정 거점의 영역과 핵심 시설을 정의한다.

- 야생 탐험과 기지 방어의 리듬을 분리한다.
- 밤 공세가 명확한 방어 목표를 가지게 한다.
- 제작, 강화, 치료, 저장, 정화, 재분배 같은 비전투 기능을 한 곳에 모은다.
- 기지 기능 손상은 패배가 아니라 난이도 상승과 불편을 만드는 압박으로 사용한다.
- 이후 공세, 시설 피해, 오염, 장비, 인챈트 시스템이 참조할 기준점을 만든다.

## 2. 기지 기본 구조

| 항목 | 규칙 |
|---|---|
| 기지 형태 | 고정된 한 곳의 중심 기지 |
| 중심 오브젝트 | `기지 핵심부/Core` |
| 기본 기지 반경 | 중심 기준 48블록 |
| 영역 확장 | 불가능 |
| 영역 형태 | 원형 반경 기반 |
| 공세 목표 | 기지 영역 및 핵심 시설 |
| 정상 중단 가능 위치 | 기지 내부 |

기지는 월드마다 임의 위치로 바뀌지 않는다. 콘텐츠 시작 시 고정된 중심 좌표와 기지 핵심부가 생성되거나, 사전 제작된 맵의 지정 위치를 사용한다.

## 3. 기지 구역

기지 영역은 모두 전투 가능 구역이다. 단, 역할과 오염 영향 기준을 구분하기 위해 내부 구역을 나눈다.

| 구역 | 범위 | 역할 | 전투 가능 | 오염 영향 |
|---|---|---|---|---|
| 중심부 | 핵심부 주변 약 12블록 | 핵심 시설, 세션 관리, 주요 정비 | 가능 | 정화 장치가 작동하면 오염 영향 없음 |
| 내부 안전 구역 | 중심부 바깥 약 24블록 | 치료, 제작, 보관, 재분배 | 가능 | 정화 장치가 작동하면 오염 영향 없음 |
| 외곽 방어선 | 기지 반경 48블록까지 | 방어벽, 함정, 공세 교전 | 가능 | 기지 오염도 영향 가능 |
| 야생 경계 | 기지 밖 | 탐험, 채집, 적 접근로 | 가능 | 세계 오염과 기지 외부 오염 영향 |

- `안전 구역`은 전투 불가 구역을 뜻하지 않는다.
- 공세 중 적이 내부까지 들어오면 중심부와 내부 안전 구역에서도 정상적으로 전투가 발생한다.
- 정화 장치가 존재하고 작동 중이면 중심부와 내부 안전 구역은 오염 영향을 받지 않는다.
- 정화 장치가 정지하거나 파괴되면 내부 구역도 오염 영향 대상이 된다.

## 4. 기지 핵심부

기지 핵심부는 기지의 중심 오브젝트다.

| 항목 | 규칙 |
|---|---|
| 이동·재배치 | 불가능 |
| 플레이어 직접 파괴 | 불가능 |
| 보호 방식 | 블록 전체 보호가 아니라 플러그인 시설 HP와 상태로 보호 |
| 파괴 시 패배 여부 | 즉시 패배 아님 |
| HP·내구도 | `BASE-003` 규칙 적용 |
| 주요 역할 | 기지 기능 허브, 시설 연결, 세션 관리 기준점 |

기지 핵심부가 파괴되거나 기능 정지 상태가 되면 기지의 핵심 기능 일부가 마비된다. 단, 전원 사망 전까지 회차는 계속된다.

### 핵심부 기능 정지 불이익

| 기능 | 핵심부 정상 | 핵심부 정지 또는 파괴 |
|---|---|---|
| 제작·강화 | 정상 사용 | 일부 고급 제작과 강화 제한 |
| 정화 | 정상 연결 | 정화 효율 크게 감소 또는 정지 |
| 저장·중단 | 정상 중단 가능 | 정상 중단 제한 또는 경고 |
| 공세 준비 | 관측과 준비 UI 사용 | 다음 공세 정보 제한 |
| 시설 연결 | 모든 시설 정상 동기화 | 일부 시설 비활성화 |

정확한 피해, 파괴, 복구 비용은 `BASE-003` 규칙을 따른다.

## 5. 핵심 시설 목록

기지는 기본 핵심 시설과 확장 가능 시설 슬롯을 가진다.

| 시설 | 기본 해금 | 역할 |
|---|---|---|
| 기지 핵심부 | 시작 시 | 기지 중심, 시설 연결, 세션 기준점 |
| 공용 보관함 | 시작 시 | 아이템 자유 공유 |
| 제작·강화 작업대 | 시작 시 | 제작, 강화, 재련의 기본 상호작용 |
| 치료 시설 | 시작 시 | HP 회복, 부상 스택 관련 처리 |
| 유품 회수 시설 | 시작 시 | 완전 사망자의 유품 회수 |
| 정화탑 | 설치 상태로 시작, 초기 목표 후 가동 | 기지 내부 정화와 오염 억제 |
| 공세 관측 장치 | 시작 시 | 밤 공세 정보, 접근 방향, 위험도 확인 |
| 세션 관리 장치 | 시작 시 | 다음 Day 10 시작, 중단 투표, 회차 상태 확인 |
| 훈련 단말 | 시작 시 | 스탯 재분배, 추천 배분 확인 |
| 커스텀 인챈트 테이블 | 해금 필요 | 커스텀 인챈트 GUI 진입 |

추가 시설은 이후 BASE, ENCHANT, EQUIP, AUG, CORR 문서에서 추가할 수 있다. 모든 시설은 `facility-id`, 위치, 상태, 해금 조건, 사용 제한, 저장 데이터를 가진다.

## 6. 시설별 기본 역할

### 기지 핵심부

- 기지 좌표와 반경의 기준점이다.
- 시설 상태와 기지 오염도 요약을 제공한다.
- 세션 관리 장치와 연결된다.
- 공세 중 주요 방어 목표가 된다.

### 공용 보관함

- 아이템 공유 원칙에 따라 제한 없이 사용할 수 있다.
- 공용 핵심 재료, 보스 보상, 일반 재료를 보관할 수 있다.
- 접근 권한은 생존 플레이어 전체에게 열려 있다.
- 완전 사망 또는 관전 상태 플레이어는 아이템 이동을 할 수 없다.

### 제작·강화 작업대

- 일반 제작, 콘텐츠 제작, 장비 강화, 재련의 진입 시설이다.
- 공세 중에는 시설 상태, 플레이어 전투 상태, 작업별 태그에 따라 조건부로 사용할 수 있다.
- 일반 공세라는 이유만으로 고급 제작과 강화를 일괄 차단하지 않는다.
- 세부 제작식, 강화 비용, 재련 규칙은 EQUIP 및 관련 문서에서 확정한다.

### 치료 시설

- 기지 내 HP 회복은 자동 회복이 아니라 치료 시설 사용으로 처리한다.
- 빈사자 구조와 부활 후 회복 보조에 보너스를 줄 수 있다.
- 부상 스택 감소와 추가 치료 비용은 DEATH 문서 규칙을 따른다.

### 유품 회수 시설

- 완전 사망자의 유품을 기지에서 회수할 수 있게 한다.
- 유품의 보관, 회수 권한, 소실 예외는 DEATH 문서 규칙을 따른다.
- 공세 중에는 회수 상호작용을 제한할 수 있다.

### 정화탑

- 현재 정화 범위에 포함된 기지 구역의 오염 영향을 억제한다.
- 정화 수치, 오염 감소 공식, 정화 자원은 `CORR-003`을 따른다.
- 정화탑이 정지하거나 연료가 고갈되면 보호 중이던 구역도 오염 영향을 받는다.

### 공세 관측 장치

- 다음 밤 공세의 방향, 위험도, 주요 적 정보를 일부 표시한다.
- 공세 스폰 지점과 세부 생성 로직은 `BASE-002` 규칙을 따른다.
- 핵심부 기능 정지 시 관측 정보가 제한된다.

### 세션 관리 장치

- 다음 Day 10 진행 시작을 처리한다.
- 정상 중단 투표를 시작한다.
- 현재 Day, 세션 상태, 생존자, 기지 상태를 표시한다.
- 정상 중단은 기지 내부에서만 가능하다.

### 훈련 단말

- 스탯 재분배는 기지 내 훈련 단말을 통해서만 가능하다.
- 세션당 1회 무료 재분배와 이후 희귀 공용 자원 소비 규칙은 PROG 문서를 따른다.
- 공세 중에는 사용할 수 없다.

### 커스텀 인챈트 테이블

- 기지 핵심 시설 목록에 포함한다.
- 기능은 시작 시 열려 있지 않고 해금이 필요하다.
- 상호작용하면 바닐라 인챈트가 아니라 플러그인 커스텀 인챈트 GUI를 연다.
- 실제 인챈트 규칙은 ENCHANT 문서에서 확정한다.

## 7. 시설 사용 제한

| 상황 | 보관함 | 제작·강화 | 치료 | 유품 회수 | 정화탑 | 관측 장치 | 세션 관리 | 훈련 단말 | 인챈트 |
|---|---|---|---|---|---|---|---|---|---|
| 평상시 | 가능 | 가능 | 가능 | 가능 | 가능 | 가능 | 가능 | 가능 | 해금 후 가능 |
| 공세 중 | 제한 | 조건부 가능 | 가능 | 제한 | 가능 | 가능 | 중단 불가 | 불가 | 제한 |
| 보스전 중 | 제한 | 제한 | 가능 | 제한 | 가능 | 제한 | 중단 불가 | 불가 | 제한 |
| 핵심부 정지 | 제한 | 고급 기능 제한 | 가능 | 가능 | 효율 감소 | 정보 제한 | 제한 | 가능 | 제한 |
| 완전 사망자 | 불가 | 불가 | 불가 | 관전 확인만 | 불가 | 확인만 | 투표 불가 | 불가 | 불가 |

- 공세 중에도 치료, 수리, 방어와 직접 연결되는 시설은 사용할 수 있다.
- 보관함, 재분배, 인챈트처럼 정비 성격이 강한 기능은 공세 중 제한한다.
- 제작·강화·연구는 시설이 기능을 제공하고 플레이어와 작업 조건을 만족하면 일반 공세 중에도 완료할 수 있다.
- 보스 등장 후에는 전투, 치료, 긴급 수리와 직접 연결된 시설 기능만 허용한다.
- 전투 상태에서는 장비 해제 제한을 유지한다. 기지 내부라도 공세 중이면 전투 상태 규칙이 우선한다.

## 8. 기지 회복과 AP

| 항목 | 규칙 |
|---|---|
| 비전투 AP 회복 보너스 | 공세와 적 추적이 없을 때만 기지 안에서 적용 |
| 공세 중 AP 회복 | 전투 상태 회복 규칙 적용 |
| 보스전 중 기지 이동 | 강제 전투 상태 유지 |
| HP 자동 회복 | 제공하지 않음 |
| HP 회복 | 치료 시설 사용으로 처리 |
| 빈사자 구조 보너스 | 기지 안에서 적용 가능 |
| 부활 보너스 | 기지 안에서 적용 가능 |

기지 안에 있다는 이유만으로 항상 안전한 회복을 제공하지 않는다. 기지 역시 공세가 침입하면 전투 공간이 된다.

## 9. 건설과 블록 규칙

플레이어는 기지 안에서 자유롭게 블록을 설치하고 파괴할 수 있다. 단, 핵심 시설과 보호 구역은 플러그인이 보호한다.

| 항목 | 규칙 |
|---|---|
| 일반 블록 설치 | 가능 |
| 일반 블록 파괴 | 가능 |
| 핵심 시설 블록 | 파괴 불가 |
| 핵심부 주변 건축 제한 | 적용 |
| 방어벽, 문, 함정 | 바닐라 블록 기반 허용 |
| 몬스터의 블록 파괴 | 특정 공세 몬스터와 패턴만 가능 |
| 폭발·화재 환경 파괴 | 기본 차단 |
| 기믹성 폭발·화재 | 명시된 패턴이면 허용 |

### 건축 제한 구역

- 기지 핵심부와 핵심 시설 주변에는 건축 제한 구역을 둔다.
- 건축 제한 구역에서는 플레이어가 블록을 설치하거나 파괴할 수 없다.
- 제한 구역의 기본 반경은 시설별로 지정한다.
- 일반 방어벽과 함정은 외곽 방어선에 배치하는 것을 기본으로 한다.

## 10. 오염과 정화 연계

기지 오염도는 `CORR` 문서에서 상세화한다. `BASE-001`에서는 시설과 구역 연결만 정의한다.

- 기지 오염도는 시설 효율에 영향을 준다.
- 정화탑은 현재 정화 범위에 포함된 기지 구역의 오염 영향을 억제한다.
- 정화 수치와 정화 자원은 `CORR-003`을 따른다.
- 기지 오염도가 높아질수록 시설 효율이 떨어진다.

### 오염 영향 우선순위

| 우선순위 | 영향 대상 |
|---:|---|
| 1 | 정화 기능 |
| 2 | 치료 시설 |
| 3 | 제작·강화 기능 |
| 4 | 비전투 AP 회복 보너스 |

오염도 최대가 즉시 패배로 이어지지는 않는다. 다만 정화와 치료가 흔들리면서 방어 실패와 전원 사망 가능성이 높아진다.

## 11. 공세 연계

공세는 기지 영역을 목표로 몰려오는 디펜스 구조로 확정한다.

- 하루 일과 중 밤이 찾아오면 공세가 시작된다.
- 공세 스폰 지점은 기지 외곽 고정 포인트와 Day별 변형을 사용한다.
- 공세 적의 목표 우선순위는 `플레이어 > 핵심 시설 > 방어 시설 > 기타 시설`이다.
- 기지 밖으로 오래 도망치는 것에 별도 강제 패널티는 두지 않는다. 기지 밖은 오염 구역이므로 오래 머무르면 오염 자체의 페널티를 받는다.
- 공세 완료 후 시설은 자동 수리되지 않는다. 수리는 별도 자원을 사용한다.

공세 생성, 웨이브 구성, 스폰 지점, 밤 공세 진행 규칙은 `BASE-002` 규칙을 따른다.

# BASE-002 공세 생성 및 진행 시스템

## 1. 시스템 목적

`BASE-002`는 하루의 밤 구간에 발생하는 기지 방어 공세의 생성, 진행, 스폰, 목표, 완료와 잔존 처리를 정의한다.

- 공세는 기지 영역을 목표로 몰려오는 디펜스 전투다.
- 일반 Day는 공세 적이 남아 있어도 시간 흐름에 따라 다음 Day로 진행한다.
- 보스 Day는 일반 밤 공세를 생성하지 않고 보스전으로 대체한다.
- 공세 실패 조건은 전원 사망만 사용한다.
- 기지 시설 파괴와 수리는 `BASE-003` 규칙을 따른다.

## 2. Day 공세 시간 구조

기존 Day 내부 단계를 유지한다.

| 단계 | 남은 시간 | 공세 처리 |
|---|---:|---|
| 활동 단계 | 07:00~03:00 | 일반 탐험, 기지 정비, 공세 예고 없음 |
| 경고 단계 | 03:00~01:30 | 공세 접근 경고, 선발대 등장 |
| 공세 단계 | 01:30~00:00 | 본격 웨이브 생성 |
| Day 전환 | 00:00 | 보스 Day가 아니면 다음 Day로 진행 |

- 경고 단계부터 적 선발대가 등장한다.
- 공세 단계는 1분 30초 동안 진행된다.
- 일반 Day는 공세 적이 남아 있어도 다음 Day로 진행한다.
- 보스 Day는 일반 공세 대신 보스전으로 대체하며, 보스를 처치할 때까지 Day가 진행되지 않는다.
- 서버에 생존 플레이어가 없으면 기존 GAME 규칙대로 Day와 공세 진행을 정지하고 저장한다.

## 3. 공세 상태

| 상태 | 설명 |
|---|---|
| `SCHEDULED` | 해당 Day 공세 구성이 결정됨 |
| `WARNING` | 경고 단계, 선발대와 방향 안내 처리 |
| `ACTIVE` | 본 공세 웨이브 생성 중 |
| `RESIDUAL` | 공세 시간이 끝났지만 적이 남아 있음 |
| `CLEARED` | 해당 Day 공세 적이 정리됨 |
| `BOSS_REPLACED` | 보스 Day라 일반 공세 대신 보스전으로 대체됨 |

`RESIDUAL` 상태는 다음 Day 진행을 막지 않는다. 단, 잔존 공세 적이 남아 있는 동안 기지 오염도 증가와 전투 압박은 계속된다.

## 4. 웨이브 구조

일반 Day 공세는 기본 3웨이브로 나눈다.

| 웨이브 | 기본 시점 | 역할 |
|---:|---:|---|
| 선발대 | 03:00~01:30 | 경고, 귀환 압박, 소규모 교전 |
| 1웨이브 | 01:30 | 기본 공세 시작 |
| 2웨이브 | 01:00 | 역할 조합 강화 |
| 3웨이브 | 00:30 | 주요 적 또는 엘리트 등장 가능 |

웨이브는 기본 시간 간격을 사용하되, 남은 적 수가 적으면 다음 웨이브를 조기 생성할 수 있다.

```text
다음 웨이브 조기 생성 조건 =
현재 웨이브 주요 적 처치
또는 현재 웨이브 잔여 전투 예산 25% 이하
또는 다음 웨이브 예정 시각 도달
```

- 마지막 웨이브에는 주요 적 또는 엘리트가 등장할 수 있다.
- Day 10, 20, 30, 40, 50은 일반 공세를 생성하지 않고 보스전으로 대체한다.
- 특수 Day 이벤트는 웨이브 수, 등장 시각, 주요 적 종류를 변경할 수 있다.

## 5. 공세 예산

공세 구성은 예산 기반으로 생성한다.

```text
최종 공세 예산 =
기본 Day 공세 예산
× 전투 스케일 인원 배율
× Day Scaling
× 특수 Day 이벤트 배율
```

### 기본 Day 공세 예산

Day 1 기준 예산은 100이며, 구간별 증가폭을 다르게 적용한다.

| Day 구간 | 기본 증가폭 | 예시 |
|---|---:|---|
| Day 1~10 | Day당 +12 | Day 1: 100, Day 9: 196 |
| Day 11~20 | Day당 +16 | Day 11 이후 증가폭 상승 |
| Day 21~30 | Day당 +22 | 중반 이후 역할 적 증가 |
| Day 31~40 | Day당 +30 | 대규모 공세 압박 |
| Day 41~50 | Day당 +40 | 최종 구간 압박 |

보스 Day는 일반 공세 예산을 사용하지 않는다. 보스전 예산과 소환 적은 BOSS 문서에서 정의한다.

### 예산 소비 항목

공세 예산은 단순 몬스터 수만이 아니라 다음 요소에 소비된다.

| 항목 | 설명 |
|---|---|
| 몬스터 개체 수 | 기본 적 수 |
| 몬스터 등급 | normal, enhanced, corrupted 등 |
| 역할군 | 돌격, 방어, 원거리, 파괴, 지원 등 |
| 스폰 방향 수 | 동시에 열리는 접근 방향 |
| 특수 스폰 포인트 | 지하, 고지대, 오염 균열 등 |
| 주요 적 | 다음 Day 진행을 막지는 않지만 공세 압박의 핵심 |
| 엘리트 | 마지막 웨이브 또는 특수 이벤트로 등장 |

## 6. 전투 스케일 인원과 방향 수

공세 시작 시 활성 생존자 수를 기준으로 전투 스케일 인원을 확정한다. 접속 종료로 현재 공세 난이도를 낮추지 않는다.

| 전투 스케일 인원 | 기본 동시 스폰 방향 수 | 비고 |
|---:|---:|---|
| 1인 | 1 | 예외 진행용 |
| 2인 | 1 | 기본 협동 기준 |
| 3인 | 2 | 역할 분담 요구 |
| 4인 | 3 | 다방향 방어 요구 |

- 특수 이벤트나 후반 Day는 최대 4방향까지 사용할 수 있다.
- 동시 방향 수가 늘어나면 개별 방향의 개체 밀도는 과도하게 높이지 않는다.
- 인원수 증가는 단순 체력 증가보다 스폰 방향, 역할 조합, 주요 적 배치로 체감시킨다.

## 7. 스폰 지점

기본 스폰 지점은 기지 외곽의 고정 포인트 4개다.

| 기본 지점 | 용도 |
|---|---|
| 북쪽 스폰 | 기본 접근로 |
| 동쪽 스폰 | 기본 접근로 |
| 남쪽 스폰 | 기본 접근로 |
| 서쪽 스폰 | 기본 접근로 |

Day별 변형으로 특수 스폰 포인트를 추가할 수 있다.

| 특수 스폰 | 설명 |
|---|---|
| 대각선 스폰 | 기존 4방향 사이에서 접근 |
| 지하 스폰 | 지하 터널 또는 균열에서 등장 |
| 고지대 스폰 | 지형 위나 절벽 쪽에서 접근 |
| 오염 균열 | 오염도가 높은 지점에서 순간 등장 |
| 우회 스폰 | 방어벽을 우회하는 경로 사용 |

### 생성 보호

플레이어가 스폰 지점에 너무 가까이 있을 때는 생성 보호를 적용한다.

| 항목 | 기본값 |
|---|---:|
| 스폰 보호 반경 | 16블록 |
| 보호 판정 대상 | 생존 플레이어 |
| 처리 | 보호 반경 밖 보조 스폰 지점 사용 |
| 보조 지점도 막힘 | 짧은 경고 후 보호 파티클과 함께 강제 생성 |

- 생성 보호는 플레이어가 스폰 지점을 완전히 봉쇄하는 것을 막기 위한 장치다.
- 강제 생성 시 즉시 피해를 주지 않고 1초 전조를 제공한다.
- 스폰 직후 1초 동안 몬스터는 지형 끼임 방지 보정만 받고 피해 면역은 받지 않는다.

## 8. 공세 적 목표와 AI

공세 적의 기본 목표 우선순위는 다음과 같다.

```text
플레이어 > 핵심 시설 > 방어 시설 > 기타 시설
```

| 목표 | 처리 |
|---|---|
| 생존 플레이어 | 최우선 공격 대상 |
| 빈사 플레이어 | DEATH 규칙에 따라 우선순위 낮춤 |
| 기지 핵심부 | 생존 플레이어를 찾지 못하거나 역할군이 시설 공격형일 때 공격 |
| 방어 시설 | 방어벽, 문, 함정 등 |
| 기타 시설 | 보관함, 제작대 등 비핵심 시설 |

공세 적이 기지 밖으로 도망간 플레이어를 끝없이 추적하지 않게 한다.

| 조건 | 처리 |
|---|---|
| 목표 플레이어가 기지 중심에서 80블록 이상 이탈 | 추적 중단 후 기지 목표로 복귀 |
| 목표 플레이어와 30블록 이상 거리 유지가 10초 지속 | 기지 목표로 복귀 |
| 경로 탐색 실패 5초 이상 | 역할군별 대체 행동 수행 |

경로가 막힌 경우 특정 공세 몬스터와 패턴만 블록 파괴를 시도한다. 일반 공세 적은 무조건 블록을 파괴하지 않는다.

## 9. 블록 파괴와 경로 복구

블록 파괴는 공세 역할군 또는 패턴 권한이 있을 때만 허용한다.

| 역할군 | 블록 파괴 |
|---|---|
| 일반 돌격 | 불가 |
| 파괴자 | 가능 |
| 중장갑 파괴자 | 가능 |
| 굴착형 | 제한적 가능 |
| 원거리 | 불가 |
| 지원형 | 불가 |

- 블록 파괴 우선순위는 길막 블록, 문, 방어벽, 함정 순서다.
- 핵심 시설 블록과 건축 제한 구역 보호 블록은 직접 파괴할 수 없다.
- 폭발과 화재에 의한 지형 파괴는 기본 차단한다.
- 기믹으로 명시된 폭발, 화재, 균열은 패턴 데이터가 허용한 범위에서만 작동한다.

상세한 시설 피해, 파괴, 수리, 방어벽 내구도는 `BASE-003` 규칙을 따른다.

## 10. 잔존 공세

공세 단계가 끝났을 때 적이 남아 있으면 해당 적은 잔존 공세 상태로 전환된다.

- 잔존 공세는 다음 Day 진행을 막지 않는다.
- 잔존 주요 적은 사라지지 않는다.
- 일반 잡몹은 약화된다.
- 잔존 공세가 길어질수록 기지 오염도가 증가한다.
- 잔존 적 처치 보상은 제한된다.

### 일반 잡몹 약화

| 항목 | 처리 |
|---|---|
| 주는 피해 | -30% |
| 받는 피해 | +20% |
| 이동속도 | -15% |
| 공세 보상 | 50% |
| 기여도 | 정상 기록, 반복 파밍 보정 적용 |

### 잔존 주요 적 표시

잔존 주요 적 위치는 10초마다 표시한다.

- 표시 대상은 생존 플레이어 전원이다.
- 기지 관측 장치가 정상 작동하면 방향과 거리까지 표시한다.
- 관측 장치가 정지하면 대략적인 방향 또는 경고음만 제공할 수 있다.

### 잔존 공세 오염 증가

잔존 공세가 지속되면 기지 오염도가 증가한다. 정확한 수치와 단계별 효과는 CORR 문서에서 확정하되, BASE에서는 다음 연결만 가진다.

```text
잔존 공세 오염 증가 =
잔존 주요 적 수
× 잔존 지속 시간
× Day 구간 보정
```

## 11. 공세 완료

공세 완료는 해당 Day 공세에서 생성된 주요 적과 일반 적이 모두 제거되거나, 잔존 적이 시스템에 의해 소멸 처리되었을 때 발생한다.

단, 공세 완료는 일반 Day 진행 조건이 아니다. 일반 Day는 시간 흐름으로 다음 Day로 넘어간다.

| 완료 시점 | 처리 |
|---|---|
| 공세 단계 중 모두 처치 | 즉시 완료 보상 정산 |
| 다음 Day로 넘어간 뒤 잔존 적 처치 | 잔존 보정 보상 정산 |
| 모든 적이 시스템 소멸 | 제한 보상 또는 보상 없음 |

공세 완료 후 시설은 자동 수리되지 않는다. 수리는 별도 자원을 사용한다.

## 12. 보상

공세 보상은 공용 재료 중심으로 구성한다.

| 보상 | 지급 방식 |
|---|---|
| 공용 재료 | 파티 공용 보상 |
| 개인 기여 보상 | 개인별 기여도 기준 |
| 희귀 재료 | 주요 적, 엘리트, 특수 이벤트에서 제한 지급 |
| 시설 수리 재료 | 공용 재료 풀에 포함 가능 |

- 도중 참여자는 실제 기여한 공세에 대해서만 보상을 받는다.
- 아군 공격, 아군 브레이크, 자기 피해 유도는 기여도에 반영하지 않는다.
- 공세 실패 개념은 전원 사망 외에는 두지 않는다.
- 기지 시설 파괴는 보상 감소 또는 기능 마비로 이어질 수 있지만 즉시 패배는 아니다.

## 13. 공세 관측 장치

공세 관측 장치는 다음 공세 정보를 표시한다.

| 정보 | 표시 |
|---|---|
| 접근 방향 | 표시 |
| 위험도 | 표시 |
| 주요 적 유형 | 표시 |
| 특수 스폰 여부 | 레벨에 따라 표시 |
| 예상 웨이브 수 | 레벨에 따라 표시 |
| 엘리트 출현 가능성 | 레벨에 따라 표시 |

관측 정보의 실제 생성값은 정확하다. 다만 관측 장치 레벨에 따라 플레이어에게 보이는 표현은 일부 숨겨지거나 어림값으로 표시될 수 있다.

| 관측 장치 상태 | 표시 품질 |
|---|---|
| 정상 Lv.1 | 주요 방향과 대략 위험도 |
| 정상 Lv.2 | 방향, 위험도, 주요 적 유형 |
| 정상 Lv.3 | 특수 스폰, 엘리트 가능성, 웨이브 정보 |
| 핵심부 정지 | 정보 일부 제한 |
| 관측 장치 정지 | 공세 방향 경고 없음 |

관측 장치가 정지하면 공세 방향 경고가 뜨지 않는다. 기본 공세 시작 사운드와 화면 경고는 유지할 수 있지만, 어느 방향에서 오는지는 표시하지 않는다.

## 14. 전투 상태와 정상 중단

- 공세 시작만으로 모든 플레이어에게 `FORCED_COMBAT`를 적용하지 않는다.
- 플레이어가 공세 적과 실제로 전투하거나, 공세 적에게 추적되거나, 공세 적이 기지 내부에 진입해 교전 범위에 들어오면 전투 상태를 적용한다.
- 공세 중 정상 중단은 불가능하다.
- 공세 중 모든 생존 플레이어가 접속 종료하면 진행을 정지하고 저장한다.
- 재접속 시 저장된 공세 상태와 잔존 적 상태를 복원한다.

COMBAT 문서의 전투 상태 판정은 `BASE-002`의 공세 교전 조건을 따른다.

# BASE-003 시설 피해, 파괴, 수리

## 1. 시스템 목적

`BASE-003`은 공세와 기믹으로 기지 시설이 손상되고, 플레이어가 제한된 자원을 사용해 복구하는 규칙을 정의한다.

- 기지 피해를 즉시 패배가 아니라 장기 압박과 전략 선택으로 사용한다.
- 플레이어가 공용 자원을 수리, 제작, 연구, 장비 성장 중 어디에 쓸지 판단하게 한다.
- 공세 중 긴급 수리와 공세 후 완전 복구를 구분한다.
- 핵심 시설은 실제 블록 파괴보다 플러그인 시설 HP와 상태로 관리한다.
- 방어벽, 문, 함정, 바리케이드는 실제 블록 파괴와 연결될 수 있는 방어 구조물로 관리한다.

## 2. 적용 대상

기지 피해 대상은 크게 `핵심 시설`과 `방어 구조물`로 나눈다.

| 구분 | 예시 | 피해 모델 | 실제 블록 파괴 |
|---|---|---|---|
| 핵심 시설 | 기지 핵심부, 정화탑, 치료 시설, 관측 장치 | `facilityHp` | 기본 불가 |
| 정비 시설 | 제작·강화 작업대, 보관함, 훈련 단말, 인챈트 테이블 | `facilityHp` | 기본 불가 |
| 방어 구조물 | 방어벽, 문, 함정, 바리케이드 | `structureHp` | 0 도달 시 가능 |
| 일반 건축 블록 | 플레이어가 설치한 일반 블록 | 바닐라 또는 보호 규칙 | 역할군·패턴 허용 시 가능 |

핵심 시설은 블록 자체를 부수는 방식이 아니라, 해당 시설 엔티티 또는 보호 영역에 연결된 `facilityHp`를 감소시키는 방식으로 구현한다.

## 3. 시설 상태 단계

시설은 현재 HP 비율에 따라 상태가 바뀐다.

| 상태 | HP 비율 | 내부 ID | 의미 |
|---|---:|---|---|
| 정상 | 70% 초과 | `NORMAL` | 모든 기능 정상 |
| 손상 | 40% 초과~70% 이하 | `DAMAGED` | 경미한 효율 저하 |
| 중파 | 1% 초과~40% 이하 | `HEAVY_DAMAGED` | 주요 기능 제한 |
| 정지 | 0% | `DISABLED` | 기능 정지, 복구 필요 |
| 파괴 또는 복구대기 | 특수 시설만 | `REPAIR_PENDING` | 구조물 제거 또는 재설치 필요 |

- 기지 핵심부는 0%가 되어도 월드에서 사라지지 않고 `DISABLED` 상태가 된다.
- 공용 보관함은 0%가 되어도 내부 아이템이 소실되지 않는다.
- 방어 구조물은 0%가 되면 실제 블록이 파괴되거나 비활성화될 수 있다.
- `REPAIR_PENDING`은 방어 구조물 또는 별도 배치형 시설에만 사용한다.

## 4. 기본 시설 HP

시설 HP는 참여 인원수에 따라 자동 변경하지 않는다. 후반 공세가 강해질수록 플레이어는 수집, 제작, 연구, 보강을 통해 시설을 강화해야 한다.

| 시설 | 기본 HP | 0% 상태 | 핵심 기능 |
|---|---:|---|---|
| 기지 핵심부 | 10000 | 정지 | 기지 기능 허브, 세션 기준점 |
| 정화탑 | 6000 | 정지 | 현재 정화 범위의 오염 보호 |
| 공세 관측 장치 | 4000 | 정지 | 공세 방향, 위험도, 주요 적 정보 |
| 치료 시설 | 3500 | 정지 | HP 회복, 부상 회복 보조 |
| 제작·강화 작업대 | 3500 | 정지 | 제작, 강화, 재련 |
| 공용 보관함 | 3000 | 접근 정지 | 공용 아이템 보관 |
| 세션 관리 장치 | 3000 | 정지 | 중단, 회차 상태 확인 |
| 훈련 단말 | 2500 | 정지 | 스탯 재분배 |
| 커스텀 인챈트 테이블 | 2500 | 정지 | 커스텀 인챈트 GUI |

### 시설 HP 성장

시설 HP는 Day 자동 스케일링으로 증가하지 않는다. 강화는 시설 업그레이드, 연구, 보강 부품으로만 적용한다.

```text
최대 시설 HP =
기본 시설 HP
× 시설 강화 배율
+ 보강 부품 고정 HP
+ 연구 보너스 HP
```

- 시설 강화 배율과 연구 보너스는 이후 `CRAFT`, `RESEARCH`, `CONTENT` 문서에서 상세화한다.
- 시설 HP와 수리 비용은 참여 인원수에 따라 증가하지 않는다.
- 공세 난이도는 BASE-002의 공세 예산과 방향 수로 조정한다.

## 5. 방어 구조물 기본 규칙

방어 구조물은 플레이어가 디펜스 전략을 위해 설치하고, 공세 중 직접 손상될 수 있는 구조물이다.

| 구조물 | 역할 | 기본 처리 |
|---|---|---|
| 방어벽 | 접근 지연, 길막 | `structureHp` 0 도달 시 블록 파괴 |
| 문 | 출입 통제 | `structureHp` 0 도달 시 열림 또는 파괴 |
| 함정 | 적 피해, 둔화, 제어 | 내구 0 도달 시 비활성화 |
| 바리케이드 | 임시 방어선 | 낮은 HP, 빠른 설치·수리 |

방어 구조물 상세 목록과 제작식은 별도 방어 건축물 문서에서 확장할 수 있다. `BASE-003`에서는 피해, 파괴, 수리 공통 규칙만 확정한다.

### 방어 구조물 HP 기준

| 구조물 | 기본 HP | 공세 중 긴급 수리 | 0% 처리 |
|---|---:|---|---|
| 바리케이드 | 600 | 가능 | 블록 제거 |
| 일반 방어벽 | 1000 | 가능 | 블록 제거 또는 금 간 블록으로 교체 |
| 강화 방어벽 | 1800 | 가능 | 블록 제거 또는 잔해 생성 |
| 방어문 | 1200 | 가능 | 강제 개방 또는 파괴 |
| 기본 함정 | 800 | 가능 | 비활성화 |

## 6. 시설 피해 타입

시설 피해는 일반 전투 피해와 분리된 `structureDamage` 값을 사용한다.

| 피해 타입 | 적용 대상 | 설명 |
|---|---|---|
| `STRUCTURE_HIT` | 시설, 방어 구조물 | 몬스터의 직접 구조물 공격 |
| `BREAKER_ACTION` | 방어 구조물, 일반 블록 | 파괴자 계열의 길막 제거 |
| `SIEGE` | 시설, 방어 구조물 | 공성형 패턴 피해 |
| `CORRUPTION_DECAY` | 시설 | 오염으로 인한 지속 손상 |
| `GIMMICK_EXPLOSION` | 명시 대상 | 기믹으로 허용된 폭발 피해 |
| `GIMMICK_FIRE` | 명시 대상 | 기믹으로 허용된 화재 피해 |

- 몬스터의 플레이어 피해량이 곧 시설 피해량이 되지 않는다.
- 스킬 데이터에 `structure-damage` 또는 `structure-damage-multiplier`를 별도 필드로 둔다.
- 고정 피해 스킬도 시설에 적용하려면 `can-hit-structure: true`가 필요하다.
- 기믹으로 명시되지 않은 바닐라 폭발과 화재는 지형 파괴를 일으키지 않는다.

## 7. 피해 계산

시설 피해는 간단하고 예측 가능해야 한다.

```text
최종 시설 피해 =
기본 structureDamage
× 공격자 역할 보정
× 대상 구조물 취약도
× 공세 단계 보정
× 기믹 보정
```

| 보정 | 기본값 | 설명 |
|---|---:|---|
| 일반 몬스터 역할 보정 | 1.0 | 시설 공격형이 아니면 낮은 빈도로만 사용 |
| 파괴자 역할 보정 | 1.5 | 방어 시설과 길막 구조물에 강함 |
| 중장갑 파괴자 보정 | 2.0 | 느리지만 구조물 피해가 큼 |
| 굴착형 보정 | 1.2 | 일반 블록과 우회 경로에 강함 |
| 잔존 공세 보정 | 0.7 | 공세 시간 종료 후 시설 피해 감소 |
| 핵심 시설 취약도 | 1.0 | 별도 취약·저항은 시설 데이터에서 설정 |
| 방어 구조물 취약도 | 1.0 | 재질과 등급에 따라 변경 가능 |

### 플레이어 피해

플레이어의 일반 공격과 전투 스킬은 기본적으로 시설에 피해를 주지 않는다.

허용되는 예외:

- 철거 모드로 방어 구조물을 회수한다.
- 방어 구조물 수리 UI에서 철거를 선택한다.
- 특정 보스 기믹 또는 퀘스트 기믹이 시설 피해를 명시한다.
- 운영자 또는 테스트 명령으로 시설 피해를 적용한다.

| 항목 | 규칙 |

## 12. 공세 중 긴급 수리

공세 중에는 모든 시설을 완전히 복구할 수 없다.

| 대상 | 공세 중 수리 | 공세 중 수리 상한 |
|---|---|---:|
| 방어벽 | 가능 | 100% |
| 문 | 가능 | 100% |
| 함정 | 가능 | 100% |
| 바리케이드 | 가능 | 100% |
| 핵심 시설 | 임시 수리 | 50% |
| 정비 시설 | 임시 수리 | 50% |
| 기지 핵심부 | 임시 응급 수리 | 50% |

- 공세 중 핵심 시설 수리는 `임시 수리`로 기록된다.
- 임시 수리된 HP는 공세 종료 후에도 즉시 사라지지 않는다.
- 임시 수리 상태의 시설은 공세 종료 후 `안정화 수리`를 받아야 100% 완전 복구가 가능하다.
- 임시 수리 중 다시 0%가 되면 같은 Day 반복 정지 횟수가 증가한다.

## 13. 공세 후 완전 복구

공세 종료 후에는 시설을 100%까지 완전 복구할 수 있다.

```text
수리 비용 =
기본 시설 수리 비용
× 손실 HP 비율
× 시설 등급 배율
× 반복 정지 임시 비용 배율
```

| 요소 | 기본값 |
|---|---:|
| 손실 HP 비율 | `(최대 HP - 현재 HP) / 최대 HP` |
| 시설 등급 배율 | 1.0부터 시작 |
| 반복 정지 임시 비용 | 같은 Day 정지 1회당 +25% |
| 반복 비용 증가 상한 | +100% |

- 반복 정지 비용 증가는 같은 Day의 임시 수리 비용에만 적용한다.
- 영구 누적 패널티는 사용하지 않는다.
- Day가 넘어가면 반복 정지 임시 비용은 초기화한다.
- 시설 강화 등급이 높을수록 완전 복구 비용은 증가할 수 있다.

## 14. 철거와 회수

플레이어는 일반 공격으로 시설을 부술 수 없지만, 명시된 철거 상호작용은 사용할 수 있다.

| 대상 | 철거 가능 여부 | 처리 |
|---|---|---|
| 핵심 시설 | 불가 | 위치 고정 |
| 정비 시설 | 기본 불가 | 특수 재배치 시스템이 있으면 별도 문서 |
| 방어벽 | 가능 | 일부 재료 회수 |
| 문 | 가능 | 일부 재료 회수 |
| 함정 | 가능 | 일부 재료 회수, 장전 자원은 별도 처리 |
| 바리케이드 | 가능 | 낮은 비율 회수 |

공세 중 철거는 악용 가능성이 높으므로 기본적으로 제한한다. 단, 전투 상태가 아니고 해당 구조물이 적에게 공격받고 있지 않다면 예외적으로 허용할 수 있다.

## 15. UI와 표시

| UI | 표시 내용 |

| 홀로그램 | 시설 위 상태 아이콘, 정지 경고 |
| 사운드 | 시설 손상, 중파, 정지, 수리 완료 알림 |

| 플레이어 일반 공격으로 시설 타격 | 피해 0, 필요 시 보호 메시지 |

## 19. 플레이어 활동 시스템과의 연결

시설 수리와 보강은 향후 플레이어 활동 시스템과 직접 연결된다.

| 활동 | BASE-003 연결 |
|---|---|
| 자원수집 | 목재, 석재, 금속, 정화 재료, 희귀 부품 확보 |
| 탐사 | 특수 수리 부품, 연구 샘플, 시설 보강 설계도 발견 |
| 광질 | 금속 부품, 강화 벽 재료, 기계 부품 제작 재료 확보 |
| 제작 | 수리 키트, 방어 구조물, 시설 보강 부품 제작 |
| 연구 | 시설 HP 증가, 수리 효율 증가, 몬스터별 구조물 피해 대응 해금 |

이 활동들은 별도 문서에서 상세 기획한다. BASE 문서는 수리 자원과 시설 상태가 해당 시스템을 소비처로 사용한다는 기준만 가진다.

## 20. 테스트 항목

| 테스트 | 확인 목적 |
|---|---|
| 시설 HP 감소 | `facilityHp`가 정상적으로 감소하는지 검증 |
| 상태 전환 | 70%, 40%, 0% 기준 상태 변경 검증 |
| 핵심부 0% | 즉시 패배 없이 정지 상태 전환 검증 |
| 보관함 0% | 아이템 소실 없이 접근 제한 검증 |
| 정화탑 정지 | 현재 활성 정화 범위의 오염 보호 해제 검증 |
| 관측 장치 정지 | 방향 경고 미표시 검증 |
| 방어벽 파괴 | `structureHp` 0 도달 시 블록 처리 검증 |
| 플레이어 시설 공격 | 기본 피해 0 검증 |
| 공세 중 긴급 수리 | 핵심 시설 50% 상한 검증 |
| 공세 후 완전 복구 | 100% 복구와 자원 소비 검증 |
| 채널링 중단 | 피격, 이동, 행동 시 중단 검증 |
| 반복 정지 비용 | 같은 Day 임시 비용 증가 검증 |
| 저장·재개 | 시설 HP, 상태, 임시 수리, 진행도 복원 검증 |

## 21. BASE-003 완료 기준

- 핵심 시설과 방어 구조물의 피해 모델이 분리되어 있다.
- 시설 상태 단계와 HP 기준이 정의되어 있다.
- 기본 시설 HP와 0% 상태의 기능 불이익이 정의되어 있다.
- 몬스터 시설 피해가 일반 피해와 별도인 `structureDamage`로 정의되어 있다.
- 플레이어의 일반 시설 피해가 기본 차단되어 있다.
- 방어벽, 문, 함정, 바리케이드의 공통 피해·수리 규칙이 정의되어 있다.
- 공세 중 긴급 수리와 공세 후 완전 복구가 구분되어 있다.
- 수리 자원, 채널링, 중단, 반복 정지 비용 규칙이 정의되어 있다.
- 시설 피해 UI와 저장 데이터가 정의되어 있다.
- 자원수집, 제작, 연구 시스템과 연결될 수 있는 기준이 정의되어 있다.

| 항목 | 내용 |
|---|---|
| 프로젝트 | WildSurvival |
| 카테고리 | BASE 기지 시스템 |
| 콘텐츠 형태 | 2~4인 협동 하드코어 디펜스 RPG |

## 카테고리 공통 방향

- 기지는 WildSurvival의 협동 거점이자 밤 공세의 주 방어 목표다.
- 기지는 고정된 한 곳의 중심 기지를 사용한다.
- 기지 파괴 자체가 즉시 패배 조건이 되지는 않는다. 패배 조건은 기존처럼 전원 사망이다.
- 기지 시설은 생존, 성장, 저장, 정화, 방어 준비를 담당한다.
- 공세 생성은 `BASE-002`, 시설 피해·파괴·수리는 `BASE-003`에서 상세화한다.

# BASE-001 기지 영역과 핵심 시설

## 1. 시스템 목적

`BASE-001`은 플레이어가 돌아오고, 정비하고, 방어해야 하는 고정 거점의 영역과 핵심 시설을 정의한다.

- 야생 탐험과 기지 방어의 리듬을 분리한다.
- 밤 공세가 명확한 방어 목표를 가지게 한다.
- 제작, 강화, 치료, 저장, 정화, 재분배 같은 비전투 기능을 한 곳에 모은다.
- 기지 기능 손상은 패배가 아니라 난이도 상승과 불편을 만드는 압박으로 사용한다.
- 이후 공세, 시설 피해, 오염, 장비, 인챈트 시스템이 참조할 기준점을 만든다.

## 2. 기지 기본 구조

| 항목 | 규칙 |
|---|---|
| 기지 형태 | 고정된 한 곳의 중심 기지 |
| 중심 오브젝트 | `기지 핵심부/Core` |
| 기본 기지 반경 | 중심 기준 48블록 |
| 영역 확장 | 불가능 |
| 영역 형태 | 원형 반경 기반 |
| 공세 목표 | 기지 영역 및 핵심 시설 |
| 정상 중단 가능 위치 | 기지 내부 |

기지는 월드마다 임의 위치로 바뀌지 않는다. 콘텐츠 시작 시 고정된 중심 좌표와 기지 핵심부가 생성되거나, 사전 제작된 맵의 지정 위치를 사용한다.

## 3. 기지 구역

기지 영역은 모두 전투 가능 구역이다. 단, 역할과 오염 영향 기준을 구분하기 위해 내부 구역을 나눈다.

| 구역 | 범위 | 역할 | 전투 가능 | 오염 영향 |
|---|---|---|---|---|
| 중심부 | 핵심부 주변 약 12블록 | 핵심 시설, 세션 관리, 주요 정비 | 가능 | 정화 장치가 작동하면 오염 영향 없음 |
| 내부 안전 구역 | 중심부 바깥 약 24블록 | 치료, 제작, 보관, 재분배 | 가능 | 정화 장치가 작동하면 오염 영향 없음 |
| 외곽 방어선 | 기지 반경 48블록까지 | 방어벽, 함정, 공세 교전 | 가능 | 기지 오염도 영향 가능 |
| 야생 경계 | 기지 밖 | 탐험, 채집, 적 접근로 | 가능 | 세계 오염과 기지 외부 오염 영향 |

- `안전 구역`은 전투 불가 구역을 뜻하지 않는다.
- 공세 중 적이 내부까지 들어오면 중심부와 내부 안전 구역에서도 정상적으로 전투가 발생한다.
- 정화 장치가 존재하고 작동 중이면 중심부와 내부 안전 구역은 오염 영향을 받지 않는다.
- 정화 장치가 정지하거나 파괴되면 내부 구역도 오염 영향 대상이 된다.

## 4. 기지 핵심부

기지 핵심부는 기지의 중심 오브젝트다.

| 항목 | 규칙 |
|---|---|
| 이동·재배치 | 불가능 |
| 플레이어 직접 파괴 | 불가능 |
| 보호 방식 | 블록 전체 보호가 아니라 플러그인 시설 HP와 상태로 보호 |
| 파괴 시 패배 여부 | 즉시 패배 아님 |
| HP·내구도 | `BASE-003`에서 확정 |
| 주요 역할 | 기지 기능 허브, 시설 연결, 세션 관리 기준점 |

기지 핵심부가 파괴되거나 기능 정지 상태가 되면 기지의 핵심 기능 일부가 마비된다. 단, 전원 사망 전까지 회차는 계속된다.

### 핵심부 기능 정지 불이익

| 기능 | 핵심부 정상 | 핵심부 정지 또는 파괴 |
|---|---|---|
| 제작·강화 | 정상 사용 | 일부 고급 제작과 강화 제한 |
| 정화 | 정상 연결 | 정화 효율 크게 감소 또는 정지 |
| 저장·중단 | 정상 중단 가능 | 정상 중단 제한 또는 경고 |
| 공세 준비 | 관측과 준비 UI 사용 | 다음 공세 정보 제한 |
| 시설 연결 | 모든 시설 정상 동기화 | 일부 시설 비활성화 |

정확한 피해, 파괴, 복구 비용은 `BASE-003`에서 확정한다.

## 5. 핵심 시설 목록

기지는 기본 핵심 시설과 확장 가능 시설 슬롯을 가진다.

| 시설 | 기본 해금 | 역할 |
|---|---|---|
| 기지 핵심부 | 시작 시 | 기지 중심, 시설 연결, 세션 기준점 |
| 공용 보관함 | 시작 시 | 아이템 자유 공유 |
| 제작·강화 작업대 | 시작 시 | 제작, 강화, 재련의 기본 상호작용 |
| 치료 시설 | 시작 시 | HP 회복, 부상 스택 관련 처리 |
| 유품 회수 시설 | 시작 시 | 완전 사망자의 유품 회수 |
| 정화탑 | 시작 시 또는 초기 목표 | 기지 내부 정화와 오염 억제 |
| 공세 관측 장치 | 시작 시 | 밤 공세 정보, 접근 방향, 위험도 확인 |
| 세션 관리 장치 | 시작 시 | 다음 Day 10 시작, 중단 투표, 회차 상태 확인 |
| 훈련 단말 | 시작 시 | 스탯 재분배, 추천 배분 확인 |
| 커스텀 인챈트 테이블 | 해금 필요 | 커스텀 인챈트 GUI 진입 |

추가 시설은 이후 BASE, ENCHANT, EQUIP, AUG, CORR 문서에서 추가할 수 있다. 모든 시설은 `facility-id`, 위치, 상태, 해금 조건, 사용 제한, 저장 데이터를 가진다.

## 6. 시설별 기본 역할

### 기지 핵심부

- 기지 좌표와 반경의 기준점이다.
- 시설 상태와 기지 오염도 요약을 제공한다.
- 세션 관리 장치와 연결된다.
- 공세 중 주요 방어 목표가 된다.

### 공용 보관함

- 아이템 공유 원칙에 따라 제한 없이 사용할 수 있다.
- 공용 핵심 재료, 보스 보상, 일반 재료를 보관할 수 있다.
- 접근 권한은 생존 플레이어 전체에게 열려 있다.
- 완전 사망 또는 관전 상태 플레이어는 아이템 이동을 할 수 없다.

### 제작·강화 작업대

- 일반 제작, 콘텐츠 제작, 장비 강화, 재련의 진입 시설이다.
- 공세 중에는 기본적으로 사용 제한된다.
- 세부 제작식, 강화 비용, 재련 규칙은 EQUIP 및 관련 문서에서 확정한다.

### 치료 시설

- 기지 내 HP 회복은 자동 회복이 아니라 치료 시설 사용으로 처리한다.
- 빈사자 구조와 부활 후 회복 보조에 보너스를 줄 수 있다.
- 부상 스택 감소와 추가 치료 비용은 DEATH 문서 규칙을 따른다.

### 유품 회수 시설

- 완전 사망자의 유품을 기지에서 회수할 수 있게 한다.
- 유품의 보관, 회수 권한, 소실 예외는 DEATH 문서 규칙을 따른다.
- 공세 중에는 회수 상호작용을 제한할 수 있다.

### 정화탑

- 기지 내부 안전 구역의 오염 영향을 억제한다.
- 정화 수치, 오염 감소 공식, 정화 자원은 `CORR-003`에서 확정한다.
- 정화탑이 정지하면 내부 안전 구역도 오염 영향을 받을 수 있다.

### 공세 관측 장치

- 다음 밤 공세의 방향, 위험도, 주요 적 정보를 일부 표시한다.
- 공세 스폰 지점과 세부 생성 로직은 `BASE-002`에서 확정한다.
- 핵심부 기능 정지 시 관측 정보가 제한된다.

### 세션 관리 장치

- 다음 Day 10 진행 시작을 처리한다.
- 정상 중단 투표를 시작한다.
- 현재 Day, 세션 상태, 생존자, 기지 상태를 표시한다.
- 정상 중단은 기지 내부에서만 가능하다.

### 훈련 단말

- 스탯 재분배는 기지 내 훈련 단말을 통해서만 가능하다.
- 세션당 1회 무료 재분배와 이후 희귀 공용 자원 소비 규칙은 PROG 문서를 따른다.
- 공세 중에는 사용할 수 없다.

### 커스텀 인챈트 테이블

- 기지 핵심 시설 목록에 포함한다.
- 기능은 시작 시 열려 있지 않고 해금이 필요하다.
- 상호작용하면 바닐라 인챈트가 아니라 플러그인 커스텀 인챈트 GUI를 연다.
- 실제 인챈트 규칙은 ENCHANT 문서에서 확정한다.

## 7. 시설 사용 제한

| 상황 | 보관함 | 제작·강화 | 치료 | 유품 회수 | 정화탑 | 관측 장치 | 세션 관리 | 훈련 단말 | 인챈트 |
|---|---|---|---|---|---|---|---|---|---|
| 평상시 | 가능 | 가능 | 가능 | 가능 | 가능 | 가능 | 가능 | 가능 | 해금 후 가능 |
| 공세 중 | 제한 | 제한 | 가능 | 제한 | 가능 | 가능 | 중단 불가 | 불가 | 제한 |
| 보스전 중 | 제한 | 제한 | 가능 | 제한 | 가능 | 제한 | 중단 불가 | 불가 | 제한 |
| 핵심부 정지 | 제한 | 고급 기능 제한 | 가능 | 가능 | 효율 감소 | 정보 제한 | 제한 | 가능 | 제한 |
| 완전 사망자 | 불가 | 불가 | 불가 | 관전 확인만 | 불가 | 확인만 | 투표 불가 | 불가 | 불가 |

- 공세 중에도 치료, 수리, 방어와 직접 연결되는 시설은 사용할 수 있다.
- 보관함, 제작, 재분배, 인챈트처럼 정비 성격이 강한 기능은 공세 중 제한한다.
- 전투 상태에서는 장비 해제 제한을 유지한다. 기지 내부라도 공세 중이면 전투 상태 규칙이 우선한다.

## 8. 기지 회복과 AP

| 항목 | 규칙 |
|---|---|
| 비전투 AP 회복 보너스 | 공세와 적 추적이 없을 때만 기지 안에서 적용 |
| 공세 중 AP 회복 | 전투 상태 회복 규칙 적용 |
| 보스전 중 기지 이동 | 강제 전투 상태 유지 |
| HP 자동 회복 | 제공하지 않음 |
| HP 회복 | 치료 시설 사용으로 처리 |
| 빈사자 구조 보너스 | 기지 안에서 적용 가능 |
| 부활 보너스 | 기지 안에서 적용 가능 |

기지 안에 있다는 이유만으로 항상 안전한 회복을 제공하지 않는다. 기지 역시 공세가 침입하면 전투 공간이 된다.

## 9. 건설과 블록 규칙

플레이어는 기지 안에서 자유롭게 블록을 설치하고 파괴할 수 있다. 단, 핵심 시설과 보호 구역은 플러그인이 보호한다.

| 항목 | 규칙 |
|---|---|
| 일반 블록 설치 | 가능 |
| 일반 블록 파괴 | 가능 |
| 핵심 시설 블록 | 파괴 불가 |
| 핵심부 주변 건축 제한 | 적용 |
| 방어벽, 문, 함정 | 바닐라 블록 기반 허용 |
| 몬스터의 블록 파괴 | 특정 공세 몬스터와 패턴만 가능 |
| 폭발·화재 환경 파괴 | 기본 차단 |
| 기믹성 폭발·화재 | 명시된 패턴이면 허용 |

### 건축 제한 구역

- 기지 핵심부와 핵심 시설 주변에는 건축 제한 구역을 둔다.
- 건축 제한 구역에서는 플레이어가 블록을 설치하거나 파괴할 수 없다.
- 제한 구역의 기본 반경은 시설별로 지정한다.
- 일반 방어벽과 함정은 외곽 방어선에 배치하는 것을 기본으로 한다.

## 10. 오염과 정화 연계

기지 오염도는 `CORR` 문서에서 상세화한다. `BASE-001`에서는 시설과 구역 연결만 정의한다.

- 기지 오염도는 시설 효율에 영향을 준다.
- 정화탑은 기지 내부 안전 구역의 오염 영향을 억제한다.
- 정화 수치와 정화 자원은 `CORR-003`에서 확정한다.
- 기지 오염도가 높아질수록 시설 효율이 떨어진다.

### 오염 영향 우선순위

| 우선순위 | 영향 대상 |
|---:|---|
| 1 | 정화 기능 |
| 2 | 치료 시설 |
| 3 | 제작·강화 기능 |
| 4 | 비전투 AP 회복 보너스 |

오염도 최대가 즉시 패배로 이어지지는 않는다. 다만 정화와 치료가 흔들리면서 방어 실패와 전원 사망 가능성이 높아진다.

## 11. 공세 연계

공세는 기지 영역을 목표로 몰려오는 디펜스 구조로 확정한다.

- 하루 일과 중 밤이 찾아오면 공세가 시작된다.
- 공세 스폰 지점은 기지 외곽 고정 포인트와 Day별 변형을 사용한다.
- 공세 적의 목표 우선순위는 `플레이어 > 핵심 시설 > 방어 시설 > 기타 시설`이다.
- 기지 밖으로 오래 도망치는 것에 별도 강제 패널티는 두지 않는다. 기지 밖은 오염 구역이므로 오래 머무르면 오염 자체의 페널티를 받는다.
- 공세 완료 후 시설은 자동 수리되지 않는다. 수리는 별도 자원을 사용한다.

공세 생성, 웨이브 구성, 스폰 지점, 밤 공세 진행 규칙은 `BASE-002`에서 확정한다.

## 12. 정상 중단과 세션 관리

정상 중단은 기지 내부에서만 가능하다.

| 기능 | 처리 |
|---|---|
| 다음 Day 10 진행 시작 | 세션 관리 장치에서 처리 |
| 중단 투표 | 세션 관리 장치에서 시작 |
| 회차 상태 확인 | 세션 관리 장치 또는 기지 GUI에서 확인 |
| 공세 중 중단 | 불가능 |
| 보스전 중 중단 | 불가능 |

정상 중단은 안전한 재개 지점을 만드는 기능이다. 위험 상황에서 즉시 저장하고 빠지는 수단으로 사용하지 못한다.

## 19. BASE-001 완료 기준

- 기지가 고정된 한 곳의 중심 기지로 정의되어 있다.
- 기지 반경 48블록과 중심부, 내부 안전 구역, 외곽 방어선이 정의되어 있다.
- 모든 기지 구역이 전투 가능 구역임이 명시되어 있다.
- 기지 핵심부의 역할과 파괴 시 즉시 패배가 아님이 정의되어 있다.
- 기본 핵심 시설 목록과 각 시설의 역할이 정의되어 있다.
- 공세 중 시설 사용 제한과 기지 내 전투 상태 규칙이 정의되어 있다.
- 자유 건축과 핵심 시설 보호, 건축 제한 구역이 정의되어 있다.
- 오염, 정화탑, 밤 공세, 정상 중단, 저장 대상과의 연결이 정의되어 있다.
- 공세 생성은 `BASE-002`, 시설 피해·파괴·수리는 `BASE-003`으로 분리되어 있다.

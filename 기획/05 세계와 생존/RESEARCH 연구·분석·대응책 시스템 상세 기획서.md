## 1. 시스템 목표와 책임

- 연구는 전투력의 별도 레벨이 아니라 관찰→비교→해석→대응책의 진행 장치다.
- 연구 결과 중 핵심 제작식·시설·적 대응 정보는 회차·파티 공유다.
- 개인은 최초 채집자, 관측 종류와 도감 열람 기록만 소유하며 공용 해금을 독점하지 않는다.
- 연구가 특정 생물군계, 고정 연구소, 특정 무기·증강이나 무작위 희귀 드롭을 요구하지 않게 한다.
- `RESEARCH-001`은 노드·표본·분석 상태·대기열·비용·해금·복구를 소유한다. 발견의 가시성과 소급 판정은 `DISC-001`, 실제 재료 생성은 `RES`, 제작 소비는 `CRAFT`, 시설 표현은 `FACILITY`가 소유한다.

## 4. 연구 상태 전이

```text
HIDDEN
→ OBSERVABLE
→ HYPOTHESIZED
→ READY
→ QUEUED
→ PROCESSING ↔ PAUSED
→ ANALYZED
→ UNLOCKED
→ MASTERED(선택)
```

| 상태 | 진입 조건 | 허용 행동 |
|---|---|---|
| `HIDDEN` | 선행 발견·최소 Day 미충족 | 서버가 소급 관측 카운터만 보존 |
| `OBSERVABLE` | 단서 1개 이상 | 범주·현상만 표시, 표본 제출 가능 |
| `HYPOTHESIZED` | 가설 조건 충족 | 필요한 비교 축과 최대 힌트 단계 표시 |
| `READY` | 입력·관측·자원 예약 가능 | 분석기 선택, 비용 미소비 |
| `QUEUED` | 작업 생성·입력 예약 | 취소 가능, 100% 환불 |
| `PROCESSING` | 첫 처리 틱 원자 커밋 | 일시정지·복구 가능, 일반 취소 제한 |
| `PAUSED` | 시설 손상·전력·오염·네트워크 정지 | 진행도 보존, 다른 호환 시설로 이전 가능 |
| `ANALYZED` | 처리 시간 완료·출력 커밋 | 결과 검토·해금 트랜잭션 재시도 |
| `UNLOCKED` | 해금 액션 전부 멱등 적용 | 도감·제작·시설·대응책 사용 |
| `MASTERED` | 선택 숙련 조건 완료 | 정보·처리 효율만 개선, 핵심 진행 불필요 |

`DISCOVERED`와 `UNLOCKED`가 같은 틱에 발생하면 연구 결과를 먼저 공용 원장에 커밋하고 발견 해금 이벤트를 발행한다. 이벤트 소비 실패는 다음 틱에 재시도하며 비용을 다시 소비하지 않는다.

## 5. 제출·비교·분석 절차

1. GUI가 노드, 시설, 후보 입력과 예상 결과를 읽기 전용으로 표시한다.
2. 서버가 노드 리비전·최소 Day·선행·입력 소유권·시설 상태를 재검사한다.
3. `analysisJobId = hash(runId, nodeId, attemptSequence)`를 만든다.
4. 표본에는 `consumedByJob`, 공용 자원에는 예약 원장을 기록하고 한 트랜잭션으로 `QUEUED`를 커밋한다.
5. 작업 슬롯이 열리면 표본·촉매를 소비 확정하고 `PROCESSING`으로 전환한다.
6. 실제 서버 경과 시간만 누적한다. Day 스킵·서버 중단 시간·관리자 시간 변경으로 진행도를 늘리지 않는다.
7. 완료 시 결과를 가상 출력함과 노드 원장에 먼저 저장한 뒤 해금 액션을 적용한다.
8. 파티 알림·Story·통계 소비자가 실패해도 연구 결과는 유지한다.

### 5.1 비교 인정 규칙

- `DISTINCT_SOURCE`: 서로 다른 `sourceId` 수
- `DISTINCT_CONTEXT`: 서로 다른 생물군계 범주·사건·환경 처리 태그 수
- `BEFORE_AFTER`: 정화·가열·브레이크 전후 한 쌍
- `SUCCESS_FAILURE`: 같은 패턴의 유효 대응과 실패 기록 한 쌍
- `ROLE_COVERAGE`: 서로 다른 적 역할 또는 자원 범주 수

하나의 표본이 여러 축에 부합해도 같은 비교 세트 안에서는 한 칸만 채운다. 이미 완료한 핵심 관측은 `DISC-001` 소급 카운터에서 가져온다.

## 6. 분석 장치와 처리량

| 장치 | 동시 작업 | 입력 상한 | 시간 배율 | 허용 범위 | 정지 조건 |
|---|---:|---:|---:|---|---|
| `FAC-P04` 휴대 분석기 | 1 | 표본 2 | 1.50 | `PORTABLE`, 핵심 노드 복구 분석 | 이동·피격 채널 취소, 장기 작업은 PAUSED |
| `FAC-S06` 연구 단말 Lv1 | 2 | 표본 4 | 1.00 | 모든 기본 노드 | 전력·HP 25% 미만·오염 단계 5 |
| `FAC-S06` Lv2 | 2 | 표본 5 | 0.90 | 기본+숙련 | 동일 |
| `FAC-S06` Lv3 | 3 | 표본 6 | 0.85 | 전문·재건 하위 분석 | 동일 |
| `FAC-S06` Lv4 | 3 | 표본 6 | 0.80 | 원격 관측 기록 연결 | 네트워크 단절 시 로컬만 |
| `FAC-S06` Lv5 | 4 | 표본 8 | 0.75 | 최종 효율, 새 해금 없음 | 동일 |

- 시간은 `ceil(baseSeconds × timeMultiplier)`로 계산하고 최소 20초다.
- 작업 등록자가 접속 종료해도 진행한다. 회차가 `PAUSED` 또는 서버가 중단되면 경과 시간도 정지한다.
- 시설 파괴 시 작업은 `RECOVERY_LEDGER`로 이동한다. 호환 시설에서 무료 재개하거나 휴대 분석기로 150% 시간에 재개한다.
- 다른 시설로 이전하면 소비된 입력은 유지하고 진행도는 90%만 유지한다. 파괴 복구 이전은 100% 유지한다.

## 7. 취소·환불·파괴·재접속

| 상황 | 처리 |
|---|---|
| `QUEUED` 취소 | 표본·자원 예약 100% 해제 |
| `PROCESSING` 25% 미만 자진 취소 | 일반 촉매 75%, 미소비 고유 기록 100% 반환 |
| `PROCESSING` 25% 이상 자진 취소 | 일반 촉매 50%, 표본은 분석 잔재로 전환; 핵심 진행은 다시 획득 가능한 복구 표본 보장 |
| 시설 정지 | `PAUSED`, 손실 없음 |
| 시설 파괴 | 복구 원장 이전, 진행·고유 입력 보존 |
| 출력함 가득 참 | `ANALYZED` 유지, 바닥 드롭 금지 |
| 서버 재시작 | 마지막 누적 틱과 상태 복원, 오프라인 시간 미가산 |
| 중복 완료 콜백 | `analysisJobId`가 이미 완료면 무시 |
| 리비전에서 노드 삭제 | 활성 회차는 잠긴 구버전 유지, 신규 회차에서만 제거 |

| `RS-D47-SYNTHESIS` | D47, A~D 연구 | 네 하위 결과+대체 경로 1 | 18/28/32/36, 210초 | C28 완료·R01~R04 결합 검사 |
| `RS-D49-CALIBRATION` | D49, C29 | 세 방향 오차+실패 축 기록 | 20/30/36/42, 240초 | 최종 신호 키 제작·교정 상세 UI |

- 핵심 노드의 고유 부품은 존재 증명만 검사하고 소각하지 않는다.
- Day 하한 전 입력을 모아도 `READY_LOCKED`로 표시하며 작업을 시작하지 않는다.
- `RS-D49-CALIBRATION` 완료만으로 회차를 끝낼 수 없고 `FINAL-001`의 `currentDay >= 50` 검사를 반드시 통과한다.

## 9. 적군 교리 연구 레벨

교리 레벨은 별도 EXP가 아니라 위 원장 노드와 선택 숙련으로 오른다.

| 레벨 | 조건 | 공개 범위 |
|---:|---|---|
| 0 | 기본 | 등장 시 이름·효과 |
| 1 | `RS-D05-DOCTRINE-I` | 다음 Day 전략 여부·개수 |
| 2 | 일반 전략 4종 도감 | 전략 분류 |
| 3 | `RS-D15-DOCTRINE-II` | 일반 전략 1개, 보스 분류 1개 |
| 4 | 일반 전략 10종+보스 2회 | 일반 전체, 보스 절반 올림 |
| 5 | 선택 숙련: 대응 성공 20회 | 수치·충돌·시너지·대응 추천 |

연구는 전략을 변경·삭제·재추첨하지 않는다. 관측 배열이 정지하면 미래 정보만 숨기고 이미 조우한 도감은 유지한다.

## 10. 도감과 Story 경계

- 도감은 연구 사실, 출처, 대응 정보와 발견자 기록을 저장한다. 인물 대사·장면 순서·감정 해석은 `STORY-001`이 소유한다.
- Story가 `EMPTY`여도 모든 연구 노드와 해금은 정상 동작한다.
- Story 장면은 `RESEARCH_UNLOCKED(nodeId)`를 소비할 수 있지만 소비 실패가 연구를 롤백하지 않는다.
- `REDUCED` 표현에서는 생체 표본 이름·아이콘을 `오염 조직`·붉은색 염료 대신 회색 가루/종이 아이콘으로 대체한다. 수치·태그·판정은 동일하다.

## 11. GUI·저장·권한

연구 GUI는 `UX-001`의 공통 54칸 셸을 사용하고 `최근 관측 / 가설 / 대기열 / 완료 / 교리 / 재건` 탭을 제공한다. 전투 중 제출·취소·수령은 막고 읽기 전용 도감만 허용한다.

저장 최소 단위:

```yaml
research-run:
  revision: research-r1
  nodes:
    RS-D27-RIFT-STABILITY:
      state: PROCESSING
      job-id: "analysis:run-01:42"
      progress-ticks: 1280
      facility-id: "facility-uuid"
      reserved-samples: ["sample:run-01:184", "sample:run-01:201"]
      unlock-actions-applied: []
  doctrine-level: 3
  codex-entries: ["enemy:EN-D21-01", "pattern:CORRUPTION_TRAIL"]
```

- 변경 권한은 서버 메인 스레드의 `ResearchService`만 가진다.
- 다른 시스템은 명령 객체를 제출하거나 `RESEARCH_*` 도메인 이벤트를 소비한다.
- 출력 수령, 해금 액션과 알림에는 각각 멱등키를 둔다.

## 12. 소프트락·악용 방지

| 검사 | 처리 |
|---|---|
| 핵심 비교 출처가 현재 월드에서 0개 | 해금된 대체 사건·가공 경로를 같은 Day 후보 풀에 주입 |
| 표본 75% 이상 모았으나 2 Day 정체 | 필요한 범주와 획득 문맥 힌트 한 단계 상승 |
| 핵심 시설 없음·파괴 | FAC-P04 복구 분석과 복구 표본 후보 제공 |
| 고유 표본 분실 | 고유 원장으로 재발급, 중복 사용 차단 |
| 동일 적 반복 파밍 | sourceInstance 제한과 동일 sourceId 3회 이후 품질 상승 중지 |
| 관리자 복구 | 원인·이전 상태·복구 ID 감사 로그 필수, 결과 아이템 직접 생성 금지 |
| CHAOS 자원 배율 0 | 필수 연구 입력은 `BUDGET-PROFILE-001`의 진행 보장 바닥 적용 |

## 13. 이벤트와 테스트 ID

| 이벤트 | 발행 시점 |
|---|---|
| `RESEARCH_SAMPLE_REGISTERED` | 유효 표본을 파티 원장에 등록 |
| `RESEARCH_JOB_QUEUED` | 예약 트랜잭션 커밋 |
| `RESEARCH_JOB_STARTED` | 입력 소비 확정 |
| `RESEARCH_JOB_PAUSED` | 시설·전력·오염으로 정지 |
| `RESEARCH_ANALYZED` | 출력 원장 커밋 |
| `RESEARCH_UNLOCKED` | 모든 해금 액션 적용 |
| `RESEARCH_MASTERED` | 선택 숙련 완료 |

필수 테스트:

- `T-RES-001` 같은 표본 이중 예약 차단
- `T-RES-002` 서버 재시작 뒤 시간·입력·출력 불변
- `T-RES-003` 시설 파괴→복구 원장→휴대 분석 재개
- `T-RES-004` Day 스킵·오프라인 시간 무가산
- `T-RES-005` 2·3·4인 비용 반올림과 고유 입력 고정
- `T-RES-006` Day 1~49에 최종 신호 키 사용 불가
- `T-RES-007` `EMPTY` Story와 `REDUCED` 표현에서 기능 동일
- `T-RES-008` 핵심 자원 경로 0일 때 대체 후보 생성

## 14. 완료 기준

- 표본 제출부터 파티 공용 해금까지 상태·비용·대기열·복구가 구현 판단 없이 정의된다.
- Day 1~50 핵심 연구 노드가 실제 ID, 입력, 시간과 결과를 가진다.
- 시설이 없거나 파괴돼도 휴대 분석기와 대체 표본 경로로 핵심 진행을 복구할 수 있다.
- 연구가 고정 좌표·특정 무기·개인 빌드·클라이언트 모드를 요구하지 않는다.
- Day 50 잠금, 고유 부품 비소각, Story 독립성과 활성 회차 리비전 잠금을 우회하지 않는다.

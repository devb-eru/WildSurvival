# WildSurvival RES 야생 자원 및 채집 시스템 상세 기획서

## 문서 정보

| 항목 | 내용 |
|---|---|
| 문서 ID | RES-001 |
| 상위 기준 | `VISION`, `RULES`, `DISC`, `ECONOMY`, `CONTENT`, `TECH` |
| 목적 | 고정 자원 구역 없이 탐험·채집·광질·사냥을 성장과 발견으로 연결 |
| 구현 | 바닐라 블록·아이템·개체와 서버 플러그인 |
| 리소스 팩 | 불필요 |

## 1. 시스템 목표

- 어떤 월드 시드에서도 핵심 자원을 획득할 수 있다.
- 특정 좌표, 생물군계 하나, 구조물 하나에 핵심 진행을 묶지 않는다.
- 바닐라 채집의 직관성을 유지하면서 커스텀 제작·오염·발견 자원을 추가한다.
- 탐험과 위험 감수가 더 높은 효율을 주되, 운이 나쁘다고 회차가 막히지 않게 한다.
- 자동 농장, 설치·파괴 반복, 실크 터치와 외부 반입으로 자원 경제를 우회하지 못하게 한다.
- 플레이어가 시설을 짓지 않아도 현장 가공으로 최소 진행을 유지할 수 있게 한다.

## 2. 자원 계층

| 계층 | 역할 | 대표 자원 |
|---|---|---|
| `BASIC` | 생존·기본 도구·야영 | 목재, 돌, 섬유, 가죽, 식량, 석탄 |
| `INDUSTRIAL` | 장비 제작·시설·강화 | 철, 구리, 금, 레드스톤, 정제 합금 |
| `SPECIALIZED` | 무기 특화·연구·재련 | 탄성 섬유, 정밀 부품, 마력 결정, 경화 골재 |
| `CORRUPTED` | 오염 연구·증강·정화 | 오염 조직, 변이 골편, 균열 가루, 정화 촉매 |
| `BOSS` | 세션 핵심 해금 | 보스 핵, 패턴 잔재, 재건 부품 A~D |
| `RECONSTRUCTION` | Day 41~50 최종 준비 | 안정화 프레임, 동력 핵, 신호 렌즈, 정화 매질 |

상위 계층 자원도 하위 자원을 대량 대체하지 않는다. 후반 장비가 목재·철을 요구할 수 있지만, 후반 위험 자원을 얻기 위해 초반 채집만 반복하게 만들지 않는다.

## 3. 자원 형태

| 형태 | 내부 유형 | 예시 | 서버 판정 |
|---|---|---|---|
| 바닐라 원물 | `VANILLA_MATERIAL` | 원목, 철 원석, 가죽 | Material + 획득 원인 |
| 커스텀 재료 | `CUSTOM_ITEM` | 오염 조직, 정밀 부품 | PDC 템플릿·회차 ID |
| 동적 노드 | `DYNAMIC_NODE` | 풍부한 광맥, 변이 군락 | 좌표·노드 ID·고갈 상태 |
| 적 드롭 | `ENTITY_DROP` | 골편, 독샘, 핵 조각 | 적 템플릿·보상 원장 |
| 사건 보상 | `ENCOUNTER_REWARD` | 구조물 잔해, 균열 가루 | 사건 ID·기여 판정 |
| 가공 결과 | `PROCESSED_RESOURCE` | 합금, 촉매, 정화 매질 | 제작 트랜잭션 |

바닐라 아이템과 같은 Material을 쓰는 커스텀 재료는 표시명, 로어와 PDC로 구분한다. PDC가 사라진 재료는 커스텀 제작에 사용할 수 없다.

## 4. 획득 경로 원칙

### 4.1 핵심 자원 이중 경로

모든 핵심 자원은 최소 두 경로를 가진다.

| 핵심 자원군 | 주 경로 | 대체 경로 |
|---|---|---|
| 기본 철·구리 | 자연 광질 | 폐허·적 장비 분해 |
| 탄성 섬유 | 거미·식생 채집 | 가죽·실 가공 |
| 마력 결정 | 자수정·위험 동굴 | 오염 적 결정핵 정제 |
| 정화 촉매 | 자연 정화 현상 | 오염 조직과 금속 촉매 제작 |
| 변이 골편 | 변이 적 | 오염 군락 표본 분석 |
| 재건용 정밀 부품 | 고급 시설 제작 | 보스 잔재 분해 |
| 최종 정화 매질 | 세 종류 표본 합성 | Day 41 이후 대체 발견 조합 |

- 한 경로가 특정 생물군계를 요구하면 다른 경로는 범용 재료나 적 드롭을 사용한다.
- 대체 경로는 보통 시간·재료 효율이 낮지만 진행을 보장한다.
- 보스 핵과 재건 부품처럼 서사적으로 유일한 자원은 복제 경로 대신 복구 원장과 재지급 검증을 제공한다.

### 4.2 획득 경로 공개

- 미발견 상태에서는 이름 대신 형태, 환경 반응과 용도 단서만 공개한다.
- 표본을 획득하면 관련 자원 범주와 분석법을 연다.
- 반복 실패 또는 Day 지연 시 대체 경로의 범주형 힌트를 공개한다.
- 정확한 좌표를 표시하지 않고 나침반 방향, 고도 범위, 생물군계 범주와 현상 소리를 활용한다.

## 5. Day 구간별 자원 역할

| 구간 | 주요 자원 목표 | 새 위험·가공 |
|---|---|---|
| Day 1~5 | 식량, 목재, 돌, 철, 섬유 | 휴대 제작과 기본 장비 |
| Day 6~10 | 구리, 금, 레드스톤, 첫 오염 표본 | 분석 도구, 첫 신호 장치 |
| Day 11~15 | 의약 재료, 탄성 섬유, 상태 표본 | 해독·구조·상태 대응 |
| Day 16~20 | 정밀 부품, 강화 합금 | 치료·관측 시설 |
| Day 21~25 | 오염 조직, 균열 가루, 정화 촉매 | 정화기·변이 연구 |
| Day 26~30 | 변이 골편, 마력 결정 | 고급 재련·오염 개조 |
| Day 31~35 | 경화 골재, 패턴 잔재 | 브레이크 대응 장비 |
| Day 36~40 | 고밀도 합금, 안정화 코어 | 고급 시설·파티 준비 |
| Day 41~45 | 재건 부품 가공재 | 재건 프레임·동력 계통 |
| Day 46~50 | 정화 매질, 신호 렌즈, 보정 자원 | 최종 조립·교정·충전 |

구간은 자원 존재를 갑자기 생성하는 절대 잠금이 아니라, 발견·위험 사건·가공식과 효율을 해금하는 기준이다. 미리 얻은 표본은 저장하고 나중에 소급 인정한다.

Day 51+에는 Day 41~50의 `RECONSTRUCTION` 자원군과 대체 획득 경로를 계속 사용한다. 새 필수 자원 등급을 추가하지 않고 파괴·소모된 최종 준비물의 복구 공급을 보장하며, Day 스킵한 남은 시간은 자원 노드 재생이나 시설 가공 시간에 소급하지 않는다.

## 6. 바닐라 채집 정책

`RULES`의 바닐라 상호작용 매트릭스를 따른다.

| 행동 | 처리 |
|---|---|
| 일반 원목·돌·흙 채집 | 바닐라 허용, 회차 보더 안에서만 사용 |
| 광석 채굴 | 원물 획득 허용, 커스텀 보너스는 서버 판정 |
| 동물 사냥 | 바닐라 원물 허용, 반복 사육 감쇠 가능 |
| 낚시 | 기본 식량·선택 재료 경로로 허용 |
| 농사 | 기본 식량 공급 허용, 고급 재료 자동 생산 차단 |
| 실크 터치 | 바닐라 블록 회수만 허용, 동적 노드 복제 불가 |
| 행운 | 바닐라 원물에만 적용, 커스텀 노드 보상은 별도 공식 |
| 폭발 채굴 | 바닐라 결과는 허용 가능, 커스텀 노드 보상 제외 |
| 피스톤 이동 | 동적 노드·시설 블록 이동 차단 |

바닐라 자원을 지나치게 차단해 Minecraft의 야생성을 잃지 않도록 한다. 통제가 필요한 것은 핵심 진행 재료, 자동화 악용과 커스텀 보상 부분이다.

## 7. 동적 자원 노드

### 7.1 생성

동적 노드는 고정 맵에 배치하지 않고 활성 파티의 탐험 과정에서 적합한 자연 후보를 선택한다.

1. 현재 Day·발견 상태가 허용하는 노드 풀을 조회한다.
2. 최근 탐험하지 않은 청크 후보를 고른다.
3. 생물군계 범주, 높이, 주변 블록과 안전성을 검사한다.
4. 기존 플레이어 건축·시설·다른 노드와 충돌하면 제외한다.
5. 바닐라 블록 조합, 표시 엔티티, 파티클과 소리로 노드를 표현한다.
6. `resourceNodeId`, 좌표, 용량, 리비전과 만료 정책을 저장한다.

동적 노드는 광맥·군락·잔해·자연 현상으로 보이게 하며, 모드 전용 블록을 요구하지 않는다.

### 7.2 용량과 고갈

```text
최종 채집량 =
노드 기본량
× 도구 적합도
× 위험 보정
× 참여 보정
× 감쇠 보정
```

- 행운·실크 터치는 커스텀 채집량에 직접 적용하지 않는다.
- 노드의 남은 용량은 서버 원장에 저장한다.
- 마지막 채집과 보상 지급은 하나의 트랜잭션으로 처리한다.
- 고갈 시 자연 블록을 안전한 원래 상태로 복원하거나 잔해 상태로 바꾼다.
- 서버 종료 중 노드 용량이 되돌아가지 않게 마지막 채집 트랜잭션을 먼저 확정한다.

### 7.3 재생과 대체 생성

- 같은 좌표의 즉시 재생은 사용하지 않는다.
- 자원 종류별 `재탐사 쿨다운` 후 다른 적합 후보에 새 노드를 생성한다.
- 월드 보더와 미탐험 공간이 부족하면 기존 청크에 `재활성화 사건`을 생성할 수 있다.
- 핵심 자원 공급이 세션 최소치 아래면 대체 사건 또는 저효율 가공식을 보정 후보로 연다.

## 8. 채집 도구와 행동

| 행동 | 입력 | 요구 | 중단 조건 |
|---|---|---|---|
| 일반 채굴 | 좌클릭 블록 파괴 | 적합 도구 | 바닐라 기준 |
| 표본 채취 | 우클릭 또는 GUI | 채취 도구 | 피격·이동·도구 변경 |
| 잔해 회수 | 짧은 채널링 | 회수 도구 | 피격·전투 상태 |
| 위험 추출 | 다단 상호작용 | 보호 장비·용기 | 실패 패턴·오염 과다 |
| 현장 가공 | 휴대 도구 GUI | 레시피·연료 | 전투·GUI 종료 |

곡괭이는 공격 가능한 개체를 조준하면 전투가 우선한다. 채굴 대상 블록을 조준하고 유효 적이 없을 때만 일반 채굴을 실행한다.

## 9. 도구 적합도

| 등급 | 처리 |
|---|---|
| 부적합 | 노드 손상 없이 거부, 필요한 도구 범주 단서 제공 |
| 기본 | 100% 시간, 100% 수율 |
| 전문 | 80% 시간, 110% 수율 또는 안전성 증가 |
| 특수 | 특정 위험 추출·표본 무손상 회수 가능 |

전문 도구가 없다고 핵심 원물을 영구 파괴하지 않는다. 부적합 도구 사용은 자원 손실보다 시간 손실과 위험 증가를 우선 사용한다.

## 10. 위험과 보상

| 위험 원인 | 가능한 결과 |
|---|---|
| 높은 지역 오염 | 개인 오염 증가, 변이 적 출현 |
| 소음·열 | 야간 추적 위협도 증가 |
| 불안정 노드 | 채집 중 회피 가능한 파동·낙석 |
| 희귀 잔해 | 회수 완료까지 적 증원 |
| 과도한 체류 | 수율 감소와 위치 노출 |

- 위험은 즉사나 장시간 행동 불능보다 전조가 있는 패턴, 상태이상과 위치 압박으로 표현한다.
- 채집 중 강한 CC도 `STATUS-002`의 3초 체인 규칙을 따른다.
- 위험 노드는 일반 노드보다 평균 수율과 희귀 부산물 확률이 높다.

## 11. 자원 소유권

- 일반 원물은 획득한 플레이어 인벤토리에 들어간다.
- 커스텀 핵심 재료는 획득 즉시 회차 ID를 기록한다.
- 공용 시설·보관함에 투입하면 파티 원장 자원으로 전환한다.
- 보스 핵과 재건 부품은 바닥에 드롭하지 않고 파티 가상 원장으로 직접 지급한다.
- 완전 사망자의 개인 원물은 `DEATH` 유품 규칙을 따르며 공용 원장은 유지한다.

## 12. 현장 가공과 시설 가공

| 방식 | 장점 | 제한 |
|---|---|---|
| 인벤토리 기본 제작 | 즉시, 어디서나 | 바닐라·기초 조합만 |
| 휴대 가공 도구 | 유목 가능 | 느림, 높은 손실, 낮은 등급 |
| 야영 시설 | 중간 효율 | 소규모 대기열 |
| 정착 시설 | 높은 효율 | 설치·방어·연료 필요 |
| 재건 시설 | 최종 재료 | Day·발견·부품 잠금 |

- 휴대 경로는 시설 파괴 후 복구 부품을 만들 수 있어야 한다.
- 시설 효율이 높더라도 같은 자원을 무한 복제하지 않는다.
- 가공 결과와 부산물은 `ECONOMY`의 공급·소모 원장에 기록한다.

## 13. 반복 파밍 감쇠

### 13.1 감쇠 대상

- 같은 플레이어가 같은 템플릿 적을 짧은 시간에 반복 처치
- 사육·증식한 동물에서 얻는 고급 커스텀 부산물
- 같은 자동 농장 좌표에서 발생한 반복 아이템
- 설치한 블록을 파괴해 자원 획득 이벤트 재발생
- 동적 노드 주변 청크 재접속 반복

### 13.2 감쇠 방식

- 바닐라 기본 식량·건축 자원은 강하게 감쇠하지 않는다.
- 고급 커스텀 재료와 활동 EXP만 출처별 점감한다.
- 감쇠는 계정이 아니라 `runId + sourceGroup + timeWindow`로 관리한다.
- 파티원이 번갈아 획득해도 같은 자동화 출처면 감쇠를 공유한다.
- 감쇠된 이유와 회복 조건을 GUI 또는 로어에서 확인할 수 있게 한다.

## 14. 외부 반입과 복제 방지

- 회차 시작 시 허용되지 않은 커스텀 PDC와 다른 `ownerRunId` 아이템을 격리한다.
- 호퍼·드로퍼·상자·엔더 상자·아이템 액자·갑옷 거치대를 통한 인스턴스 이동을 추적한다.
- 크리에이티브 복제와 관리자 `give` 결과는 운영 승인 원장 없이는 커스텀 재료로 인정하지 않는다.
- 같은 재료 instance ID가 중복되면 사용을 잠그고 감사 대상으로 전환한다.
- 바닐라 스택 재료는 instance ID 대신 획득 원장과 회차 태그 묶음을 사용할 수 있다.
- 제작 소비량과 결과 생성은 하나의 DB 트랜잭션으로 확정한다.

## 15. 발견 시스템 연결

자원 행동은 다음 증거를 발생시킬 수 있다.

```text
ACQUIRE_MATERIAL
MINE_BLOCK_FAMILY
OBSERVE_NODE
SAMPLE_PHENOMENON
PROCESS_RESOURCE
COMBINE_MATERIALS
SURVIVE_EXTRACTION
```

- 숨겨진 발견 노드도 증거를 먼저 저장한다.
- 최초 획득만 필요한 발견과 누적 가공량이 필요한 숙련을 구분한다.
- 버리기·재획득과 공용 보관함 이동은 최초 획득을 다시 발생시키지 않는다.
- 파티 공유 발견은 유효 획득자가 한 명이면 전체에 적용한다.

## 16. 자원 공급 안전장치

### 16.1 세션 최소 공급량

각 10-Day 세션은 필수 제작 요구량에 다음 여유를 더한 공급 기회를 제공한다.

```text
권장 공급 기회 = 필수 소비량 × 1.5 + 복구 예비량
```

- 모든 공급 기회를 반드시 획득하게 보장하지는 않는다.
- 월드 생성 운으로 주 경로 공급이 80% 미만이면 대체 경로 사건 가중치를 높인다.
- 파티가 이미 충분히 보유했다면 보정 사건은 일반 풀로 돌아간다.
- 보정은 아이템 직접 지급보다 단서, 사건, 가공식과 노드 후보를 제공한다.

### 16.2 회차 소프트락 검사

Day 시작과 핵심 시설 파괴 후 다음을 검사한다.

- 필수 다음 제작식의 남은 재료
- 월드·인벤토리·공용 원장의 가용량
- 현재 해금된 획득 경로 수
- 접근 가능한 가공 수단
- 유일 부품의 원장 존재 여부

유일 부품이 데이터 손상 없이 소실된 경우 복구 원장으로 재생성한다. 일반 재료 부족은 대체 획득 경로를 열어 해결한다.

## 18. UI와 피드백

- 채집 가능 노드: 이름 대신 관찰된 특성·권장 도구·위험 범주 표시
- 고갈 노드: 남은 자원 없음과 재탐사 필요 안내
- 부적합 도구: 필요한 도구 태그와 손실 없음 표시
- 희귀 획득: 파티 알림과 관련 발견 단서 표시
- 공용 전환: 투입량, 파티 원장 총량과 취소 불가 여부 확인
- 감쇠: 현재 수율과 감쇠 원인 표시

보스바는 장시간 위험 추출 진행도에만 사용하고, 일반 채굴마다 표시하지 않는다.

## 21. 완료 기준

- 핵심 자원마다 두 개 이상의 획득 또는 복구 경로가 있다.
- 고정 자원 구역과 특정 좌표 없이 동작한다.
- 바닐라 채집의 직관성을 유지하면서 커스텀 경제를 보호한다.
- 시설이 없거나 파괴되어도 저효율 현장 경로로 진행 가능하다.
- 자원 고갈·서버 종료·복제 시도에서 공급 원장이 일관된다.
- 발견 시스템과 Day 1~50 핵심 제작 및 Day 51+ 복구 진행을 데이터로 연결할 수 있다.

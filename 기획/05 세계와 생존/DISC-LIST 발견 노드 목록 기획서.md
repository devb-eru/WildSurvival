# WildSurvival DISC-LIST 발견 노드 목록 기획서

## 문서 정보

| 항목 | 내용 |
|---|---|
| 문서 ID | DISC-LIST-001 |
| 상태 | `DATA_LOCKED` |
| 최종 수정일 | 2026-08-21 |
| 상위 기준 | `DISC-001`, `CONTENT-MASTER-001`, `RES-001`, `BASE`, `CORR` |
| 목적 | Day 1~50 핵심 숨김 진행과 Day 50+ 최종 실행을 실제 발견 노드와 대체 경로로 정의 |
| 노드 범위 | 핵심 30개, 선택 15개 |
| 구현 | 서버 증거 이벤트, 소급 판정, 인벤토리 GUI |

## 1. 목록 사용 규칙

- 노드는 좌표 방문이 아니라 관찰, 획득, 제작, 전투 행동과 환경 실험으로 진행한다.
- `Day 창`은 힌트와 효율이 열리는 권장 구간이며, 증거 자체를 무조건 무효화하는 절대 제한이 아니다.
- 핵심 진행은 `주 경로`와 `대체 경로` 중 하나를 완성하면 된다.
- 미발견 상태에서도 유효 증거를 기록하고 노드가 활성화될 때 소급 판정한다.
- 핵심 노드 완료와 제작식·시설·보스 신호 해금은 파티 공유다.
- 무기 숙련, 개인 도감과 실험 기록은 플레이어별로 둘 수 있다.
- Day 50부터 가능한 최종 실행만 서버 Day 잠금을 가지며, 재료를 미리 관찰한 사실은 보존한다.

## 2. 상태와 공개 단계

| 상태 | GUI 표시 |
|---|---|
| `HIDDEN` | 표시하지 않음. 관련 증거는 저장 |
| `CLUE` | 현상·용도·환경 범주만 표시 |
| `HYPOTHESIS` | 필요한 행동 종류와 대체 경로 수 표시 |
| `EXPERIMENT` | 현재 충족 증거와 남은 범주 표시 |
| `DISCOVERED` | 이름, 원리, 제작·시설 해금 표시 |
| `MASTERED` | 선택 숙련 보상 또는 효율 해금 |

정확한 재료 ID는 `HYPOTHESIS` 이전에 공개하지 않는다. 진행 지연 힌트도 좌표 대신 `동굴 계열`, `수중 생물`, `변이 적`, `금속 가공` 같은 범주를 제공한다.

## 3. 핵심 진행망 개요

```text
야생 생존 기반
→ 장비·현장 분석
→ 첫 이상 신호·Day 10 보스
→ 상태 대응·Day 20 보스
→ 오염 정화·Day 30 보스
→ 구조 약점·Day 40 보스
→ 재건 장치 조립·Day 49 교정
→ Day 50+ 최종 신호·세계 붕괴 핵
```

보스는 고정 위치에 존재하지 않는다. 각 장의 마지막 신호 노드를 완료한 뒤 파티 주변 안전 공간에서 동적 전장을 생성한다.

## 10. 힌트 단계 공통안

| 지연 기준 | 공개 내용 |

- 힌트를 늦게 봐도 이미 수행한 증거는 즉시 반영한다.

- 핵심 경로가 월드 상태로 불가능하다고 서버가 판정하면 대체 사건을 강제로 후보에 넣는다.

## 13. 소프트락 검사

서버는 매 Day 시작과 보스 Day 진입 시 다음을 검사한다.

- 현재 핵심 노드의 활성 경로 수
- 경로에 필요한 자원의 파티·월드 가용성
- 필요한 시설이 파괴됐을 때 휴대 대체 경로 존재 여부
- 미처리 보스 보상·재건 부품 원장
- 이미 충족됐지만 소급 처리되지 않은 증거
- Day 50 게이트의 각 미충족 원인

활성 경로가 0이면 오류로 기록하고 대체 사건·휴대 제작식·복구 원장 중 하나를 활성화한다. 단순히 핵심 아이템을 플레이어 발밑에 지급하지 않는다.

## 15. 완료 기준

- Day 1~50 핵심 준비와 Day 50+ 최종 실행이 30개 노드로 연결된다.
- 각 핵심 노드가 좌표가 아닌 서버 증거로 판정된다.
- 특정 생물군계·시설·무기군이 없어도 대체 경로가 있다.
- 숨김과 발견의 재미를 유지하면서 지연 힌트와 소급 판정으로 막힘을 방지한다.
- Day 10·20·30·40 중간 보스와 Day 50+ 최종 목표가 동적 신호와 전장으로 연결된다.
- Day 50 이전 최종 완료가 서버 게이트로 차단된다.
- Day 50 종료만으로 C30이나 회차 완료가 자동 확정되지 않는다.

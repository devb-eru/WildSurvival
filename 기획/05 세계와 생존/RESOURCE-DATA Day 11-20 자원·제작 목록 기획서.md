## 12. 복구·소프트락 방지

| 검사 | 발동 | 처리 |
|---|---|---|
| 상태 표본 종류 부족 | Day 17에 서로 다른 표본 2종 미만 | 미보유 상태 노드 1개 강제 후보 |
| 생체 조직 부족 | Day 19에 호출 계획량 80% 미만 | 표본 3종 합성 경로와 정예 흔적 사건 동시 안내 |
| 연구 시설 전멸 | C11 완료·유효 시설 0 | 휴대 분석기 150% 처리 경로 활성 |
| 소모품 예비 부족 | Day 19 생존·생체 충족률 115% 미만 | 보존된 약제 흔적 사건을 기존 예산 안에서 강제 |
| 호출 세트 손상 | 소비 원장 없음·아이템 서명 손상 | 재료 반환이 아니라 관리자 감사 후 원장 상태 복원 |

- 복구 사건은 미획득 보스 부품과 완료하지 않은 발견을 생성하지 않는다.
- 플레이 실패로 소비한 일반 소모품은 자동 환불하지 않는다.
- 월드 지형으로 획득 경로가 0인 경우에만 범용 지형 대체 노드를 보장한다.

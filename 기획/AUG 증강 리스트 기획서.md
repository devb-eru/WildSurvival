# WildSurvival AUG 증강 리스트 기획서

## 문서 정보

| 항목 | 내용 |
|---|---|
| 프로젝트 | WildSurvival |
| 카테고리 | AUG 실제 증강 목록 |
| 문서 역할 | 개인 및 파티 증강의 실제 이름, 효과, 수치, 태그 관리 |
| 시스템 규칙 문서 | AUG 증강 시스템 상세 기획서 |
| 문서 상태 | 목록 설계 대기 |
| 최종 수정일 | 2026-06-13 |

## 작성 원칙

- 증강 선택, 드로우, 리롤, 티어, 중복 규칙은 `AUG 증강 시스템 상세 기획서`에서 관리한다.
- 이 문서는 실제 플레이에 등장하는 개별 증강 목록만 관리한다.
- 모든 증강은 구현 가능한 플러그인 효과로 설계한다.
- 모든 수치는 통합 밸런스 테스트 전 기준안으로 기록하고 변경 이력을 관리한다.

## 개별 증강 필수 데이터

| 필드 | 설명 |
|---|---|
| 증강 ID | 저장 및 구현에 사용하는 고유 ID |
| 이름 | 플레이어에게 표시하는 이름 |
| 구분 | 개인 또는 파티 |
| 티어 | 실버, 골드, 프리즘 |
| 태그 | 무기, AP, 회피, 패링, 상태이상, 브레이크, 기지 등 |
| 등장 조건 | 무기, 선행 증강, Day, 파티 상태 등 |
| 선택 가중치 | 드로우 출현 확률 계산값 |
| 효과 설명 | 플레이어 표시용 설명 |
| 정확한 수치 | 내부 계산에 사용하는 수치 |
| 발동 조건 | 효과가 발동하는 사건 |
| 내부 재사용 대기시간 | 반복 발동 제한 |
| 중첩 규칙 | 중복 선택 및 효과 중첩 방식 |
| 배타 조건 | 동시에 등장하거나 선택할 수 없는 증강 |
| 진화 관계 | 선행 또는 진화 증강 |
| 구현 메모 | 필요한 이벤트, 데이터, 연출 |

# STAT-001 HP·AP·ATK·DEF·HIT·EVA·SPD·EXP 정의

## 1. 시스템 목적

커스텀 스탯 시스템은 플레이어의 성장 선택과 모든 독자 전투 계산의 공통 기반이다.

- 스탯 포인트 투자로 플레이어가 원하는 역할을 강화하게 한다.
- 무기, 스킬, 장비, 증강이 동일한 능력치 규격을 사용하게 한다.
- 난이도와 Day Scaling이 플레이어 및 몬스터 능력치에 일관되게 적용되게 한다.
- 바닐라 체력, 방어력, 공격 피해에 의존하지 않는 독자 전투를 지원한다.
- 스탯별 투자 가치와 최종 효과를 플레이어가 명확하게 확인하게 한다.

## 2. 스탯 구조

### 플레이어 주 스탯

플레이어가 스탯 포인트로 투자할 수 있는 능력치다.

| 스탯 | 한글 표시명 | 기본값 | 포인트당 증가 | 투자 상한 |
|---|---|---:|---:|---:|
| `HP` | 체력 | 난이도별 설정 | +10 최대 HP | 없음 |
| `AP` | 행동력 | 100 | +1 최대 AP | 25포인트 |
| `ATK` | 공격력 | 100 | +2 ATK | 없음 |
| `DEF` | 방어력 | 50 | +1 DEF | 없음 |
| `HIT` | 명중 | 0 | +2 HIT | 50포인트 |
| `EVA` | 회피 | 0 | +2 EVA | 30포인트 |
| `SPD` | 이동속도 | 100 | +0.5 SPD | 15포인트 |
| `EXP` | 경험 성장 | 0 | 활동 EXP +0.6%p | 30포인트 |

- `HP`, `ATK`, `DEF`는 총 보유 스탯 포인트가 허용하는 범위에서 투자 상한이 없다.
- 투자 상한은 포인트 투자에만 적용한다.
- 장비, 증강, 아이템, 상태 효과의 고정 보너스는 투자 상한과 관계없이 적용할 수 있다.
- 모든 출처를 계산한 최종값에는 스탯별 최종 하드캡을 적용한다.

### 공통 보조 스탯

플레이어와 몬스터가 보유하지만 플레이어가 스탯 포인트로 직접 투자할 수 없는 능력치다.

| 스탯 | 한글 표시명 | 플레이어 기본값 | 역할 |
|---|---|---:|---|
| `CRIT` | 치명타 확률 | 0% | 치명타 허용 공격의 치명타 발생 확률 |
| `CRIT_DMG` | 치명타 피해 | 175% | 치명타 발생 시 최종 피해 배율 |
| `PEN` | 방어 관통 | 0 | 대상 DEF를 감소시켜 피해 감소율 완화 |
| `RES` | 상태이상 저항 | 0 | 저항 가능한 상태이상의 적용 확률 감소 |
| `TENACITY` | 강한 CC 저항 | 0 | 제어 효과 지속시간 감소 |
| `STAGGER_RES` | 경직 저항 | 0 | 받는 경직 및 브레이크 피해 감소 |

- 플레이어는 장비, 증강, 아이템, 파티 효과 등을 통해 보조 스탯을 얻을 수 있다.
- 몬스터는 개체 템플릿, Day Scaling, 등급, 특성으로 보조 스탯을 얻는다.
- 보조 스탯의 포인트 투자 기능은 제공하지 않는다.

## 3. 포인트 투자와 최종값의 구분

모든 주 스탯은 다음 값을 구분하여 관리한다.

| 값 | 설명 |
|---|---|
| 기본값 | 플레이어 또는 개체 템플릿이 가지는 시작값 |
| 투자 포인트 | 플레이어가 스탯 포인트로 투자한 수량 |
| 투자 증가값 | 투자 포인트 × 포인트당 증가량 |
| 고정 보너스 | 장비, 증강, 아이템 등의 고정 수치 |
| 퍼센트 보너스 | 계산 전 합산되는 비율 증가·감소 |
| 상태 배율 | 상태이상, 오염, 기믹 등 일시적 배율 |
| 최종값 | 모든 계산과 하드캡을 적용한 실제 사용값 |

### 공통 최종 스탯 계산 순서

```text
1. 기본값
+ 투자 증가값
+ 장비·증강·아이템 고정값
→ 고정 합계

2. 고정 합계 × (1 + 퍼센트 증가 합계 - 퍼센트 감소 합계)
→ 보정값

3. 보정값 × 상태이상·오염·기믹 배율
→ 임시 최종값

4. 최소값과 최종 하드캡 적용
→ 최종 스탯
```

- 스탯별 고유 공식이 있으면 공통 계산 이후 효과 환산 단계에서 적용한다.
- 퍼센트 증가와 감소는 각각 합산한 뒤 하나의 배율로 계산한다.
- 상태 배율은 효과별 우선순위에 따라 곱연산할 수 있다.
- `ATK`는 특수 효과에 의해 음수가 될 수 있다.
- `SPD`는 최소 1, `ATK`를 제외한 나머지 스탯은 최소 0을 적용한다.

## 4. 최종 하드캡

| 스탯 | 최종 하드캡 또는 효과 상한 |
|---|---|
| `HP` | 없음 |
| `AP` | STANDARD 200, CHAOS 999 |
| `ATK` | 없음 |
| `DEF` | 수치 상한 없음, DEF 피해 감소 최대 99% |
| `HIT` | 200 |
| `EVA` | 효과 적용 상한 100 |
| `SPD` | 최대 300, 최소 1 |
| `EXP` | 전체 활동 EXP 획득 보너스 최대 +75% |
| `CRIT` | 100% |
| `CRIT_DMG` | 300% |
| `PEN` | STANDARD 90%, CHAOS 98%까지 대상 DEF 관통 |
| `RES` | 90 |
| `TENACITY` | 80 |
| `STAGGER_RES` | 80 |

- 하드캡을 초과한 원본 보너스는 데이터에 유지할 수 있지만 최종 효과에는 적용하지 않는다.
- 프리즘 증강이나 보스 기믹도 별도 명시가 없다면 최종 하드캡을 따른다.
- `TRUE_PEN` 태그가 있는 특수 공격만 일반 PEN 제한을 넘어 대상 DEF를 0까지 감소시킬 수 있다.

## 5. HP 체력

`HP`는 플레이어와 몬스터가 피해를 견딜 수 있는 커스텀 최대 체력이다.

### 플레이어 난이도별 기본 HP

난이도는 회차 생성 시 선택하며 회차 진행 중 변경할 수 없다.

| 표시 난이도 | 내부 ID | 기본 최대 HP | Normal 대비 |
|---|---|---:|---:|
| Easy | `EASY` | 1,800 | +80% |
| Normal | `NORMAL` | 1,000 | 기준 |
| Hard | `HARD` | 800 | -20% |
| Challenge | `CHALLENGE` | 500 | -50% |
| ??? | `UNKNOWN` | 100 | -90% |

- 난이도별 기본 HP는 플레이어에게만 적용한다.
- 몬스터는 난이도 배율, Day Scaling, 등급 배율을 별도로 적용한다.
- 난이도 선택은 회차 데이터에 저장하고 진행 중 변경을 차단한다.
- 추천 스탯 분배안은 현재 난이도에 따라 HP 권장량을 다르게 표시한다.

### HP 투자

```text
투자 HP 증가량 = HP 투자 포인트 × 10
```

- HP 투자에는 포인트 상한이 없다.
- HP 투자 증가량은 난이도 배율의 영향을 받지 않는다.
- 장비·증강을 포함한 최종 HP에도 하드캡을 두지 않는다.

예시:

```text
Challenge 기본 HP 500
+ HP 투자 100포인트 × 10
= 1,500 HP
```

### HP 효과 범위

- HP는 커스텀 최대 체력과 빈사 최대 체력에 영향을 준다.
- HP는 기본 회복량과 회복 효율을 직접 증가시키지 않는다.
- 최대 HP 변경 시 현재 HP는 비율을 유지하지 않고 새 최대치를 넘는 경우에만 감소한다.
- 실제 피해 및 빈사 전환 처리는 `CORE-001`과 `DEATH` 시스템을 따른다.

### 빈사 최대 체력 연계

```text
부상 스택 1 빈사 최대 체력 = 최종 최대 HP × 70%
부상 스택 2 빈사 최대 체력 = 최종 최대 HP × 52.5%
부상 스택 3 빈사 최대 체력 = 최종 최대 HP × 35%
```

- 부상 스택별 배율은 기본 70%에 기존 100%·75%·50% 부상 배율을 적용한 값이다.
- 빈사 상태에서 한 번에 받을 수 있는 최대 빈사 피해는 현재 빈사 최대 체력의 50%다.

## 6. AP 행동력

`AP`는 회피, 패링, 스킬, 구조 등 전략 행동에 사용하는 커스텀 자원이다.

### AP 투자 및 최종 상한

| 항목 | 값 |
|---|---:|
| 기본 최대 AP | 100 |
| 포인트당 증가 | +1 AP |
| 투자 상한 | 25포인트 |
| 투자만 적용한 최대 AP | 125 |
| 장비·증강 포함 권장 범위 | 100~150 |
| 모든 효과 포함 최종 하드캡 | STANDARD 200, CHAOS 999 |

```text
투자 AP 증가량 = min(AP 투자 포인트, 25) × 1
최종 최대 AP =
min(
  규칙 모드별 AP 상한,
  모든 AP 출처 계산 결과
)
```

- AP 기본값과 투자 효율은 난이도의 영향을 받지 않는다.
- AP 투자는 최대 AP만 증가시키고 자연 회복량을 증가시키지 않는다.
- 최대 AP 변경 시 현재 AP는 비율을 유지하지 않고 새 최대치를 넘는 경우에만 감소한다.
- AP 회복, 비용, 탈진 규칙은 `COMBAT-001`과 `COMBAT-002`를 따른다.

## 7. ATK 공격력

`ATK`는 커스텀 공격 및 스킬이 참조하는 기본 공격 계수 스탯이다.

### 기본값과 투자

| 항목 | 값 |
|---|---:|
| 기본 ATK | 100 |
| 포인트당 증가 | +2 ATK |
| 투자 상한 | 없음 |
| 최종 하드캡 | 없음 |

```text
투자 ATK 증가량 = ATK 투자 포인트 × 2
```

- ATK 기본값은 난이도의 영향을 받지 않는다.
- 대부분의 일반 공격 스킬과 공격 스킬은 ATK 계수를 참조한다.
- 지원, 회복, 방어, 고정 피해 스킬은 ATK를 참조하지 않거나 다른 스탯을 참조할 수 있다.
- 모든 스킬은 참조 스탯과 계수를 개별 데이터로 가진다.
- ATK가 높아도 고정 피해와 환경 피해는 증가하지 않는다.

## 8. DEF 방어력

`DEF`는 고정 피해와 환경 피해를 제외한 피해를 감소시키는 방어 스탯이다.

### 기본값과 투자

| 항목 | 값 |
|---|---:|
| 기본 DEF | 50 |
| 포인트당 증가 | +1 DEF |
| 투자 상한 | 없음 |
| 최종 DEF 수치 상한 | 없음 |
| DEF 피해 감소 상한 | 99% |

```text
투자 DEF 증가량 = DEF 투자 포인트 × 1
```

### PEN 적용 후 유효 DEF

일반 PEN은 STANDARD에서 대상 DEF의 최대 90%, CHAOS에서 최대 98%까지만 감소시킬 수 있다.

```text
일반 관통 상한 =
대상 DEF × 규칙 모드별 관통 상한
적용 PEN = min(공격자 PEN, 일반 관통 상한)
유효 DEF = max(0, 대상 DEF - 적용 PEN)
```

`TRUE_PEN` 공격은 별도 설정에 따라 DEF를 0까지 낮출 수 있다.

### DEF 피해 감소 공식

```text
DEF 피해 감소율 =
min(
  99%,
  유효 DEF / (100 + 유효 DEF)
)
```

예시:

| 유효 DEF | 피해 감소율 |
|---:|---:|
| 50 | 33.33% |
| 100 | 50.00% |
| 200 | 66.67% |
| 500 | 83.33% |
| 1,000 | 90.91% |

- DEF는 물리, 마법, 오염 등 고정·환경 피해가 아닌 모든 피해에 정상 적용한다.
- 고정 피해와 환경 피해에는 DEF를 적용하지 않는다.
- 방패 일반 방어는 DEF 계산 이후에 별도 피해 감소를 적용한다.

### 난이도별 오염 피해 DEF 효율

오염 피해를 받을 때 플레이어의 DEF 효율은 난이도에 따라 달라진다.

```text
오염 피해용 DEF =
최종 DEF × 난이도별 오염 DEF 효율
```

| 난이도 | 오염 피해용 DEF 효율 |
|---|---:|
| Easy | 100% |
| Normal | 100% |
| Hard | 100% |
| Challenge | 80% |
| ??? | 50% |

- 이 효율은 플레이어에게만 적용한다.
- 몬스터의 오염 피해 방어는 개체 템플릿과 등급 정책을 따른다.

## 9. HIT 명중

`HIT`은 확률 기반 기본 공격 명중률이 아니라 상태이상 적중과 특정 유도 투사체 성능을 강화한다.

### 기본값과 투자

| 항목 | 값 |
|---|---:|
| 기본 HIT | 0 |
| 포인트당 증가 | +2 HIT |
| 투자 상한 | 50포인트 |
| 투자만 적용한 최대 HIT | 100 |
| 최종 하드캡 | 200 |

```text
투자 HIT 증가량 = min(HIT 투자 포인트, 50) × 2
```

### 상태 적중 보정

```text
HIT 기반 상태 적중 보정 =
min(20%p, floor(HIT / 5) × 1%p)
```

- HIT 5당 상태 적중 보정 +1%p를 얻는다.
- HIT 100에서 상태 적중 보정 +20%p에 도달한다.
- HIT 100을 초과해도 상태 적중 보정은 더 증가하지 않는다.
- 최종 상태이상 적용 공식은 `STATUS-001`을 따른다.

### 유도 투사체

- HIT는 `HOMING` 태그가 있는 스킬의 투사체 유도 성능만 강화한다.
- HIT가 높을수록 유도 회전 속도 또는 추적 허용 각도를 높일 수 있다.
- 정확한 유도 환산식은 `SKILL-002`에서 확정한다.
- HIT는 일반 공격 범위, 일반 공격 명중 확률, 은신 적 탐지를 증가시키지 않는다.

## 10. EVA 회피

`EVA`는 확률 기반 완전 회피를 제공하지 않고 능동 회피 행동을 강화한다.

### 기본값과 투자

| 항목 | 값 |
|---|---:|
| 기본 EVA | 0 |
| 포인트당 증가 | +2 EVA |
| 투자 상한 | 30포인트 |
| 투자만 적용한 최대 EVA | 60 |
| 효과 적용 하드캡 | 100 |

```text
투자 EVA 증가량 = min(EVA 투자 포인트, 30) × 2
효과 계산 EVA = min(최종 EVA, 100)
```

### EVA 효과

| 효과 계산 EVA | 회피 AP 비용 감소 | 부분 회피 피해 감소 | 회피 이동 거리 증가 |
|---:|---:|---:|---:|
| 0 | 0% | 0% | 0% |
| 25 | 5% | 8% | 4% |
| 50 | 10% | 15% | 8% |
| 75 | 15% | 23% | 12% |
| 100 | 20% | 30% | 15% |

- EVA 100 초과값은 일반 효과를 제공하지 않는다.
- EVA에 의한 회피 AP 감소는 전체 회피 비용 감소 상한을 따른다.
- EVA는 무적 확률, 상시 피해 감소, 기본 무적 시간 증가를 제공하지 않는다.
- 상세 회피 규칙은 `COMBAT-003`을 따른다.

## 11. SPD 이동속도

`SPD`는 플레이어와 몬스터의 기본 이동속도 배율을 나타낸다.

### 기본값과 투자

| 항목 | 값 |
|---|---:|
| 기본 SPD | 100 |
| 포인트당 증가 | +0.5 SPD |
| 투자 상한 | 15포인트 |
| 투자만 적용한 최대 SPD | 107.5 |
| 최종 최소값 | 1 |
| 최종 하드캡 | 300 |

```text
투자 SPD 증가량 = min(SPD 투자 포인트, 15) × 0.5
이동속도 배율 = 최종 SPD / 100
```

- SPD 100은 기준 이동속도 100%를 의미한다.
- SPD 107.5는 기준 이동속도 107.5%를 의미한다.
- 장비, 증강, 상태이상 등을 포함한 최종 이동속도 범위는 1%~300%다.
- SPD는 걷기와 질주 이동속도에만 영향을 준다.
- SPD는 회피 거리, 공격속도, 스킬 시전속도, 구조속도에 영향을 주지 않는다.
- 몬스터의 이동 AI가 비정상적으로 동작하지 않도록 개체별 실질 이동속도 제한을 추가할 수 있다.

## 12. EXP 경험 성장

`EXP`는 선택 활동으로 획득하는 활동 EXP 보너스를 증가시킨다.

### 기본값과 투자

| 항목 | 값 |
|---|---:|
| 기본 EXP 스탯 | 0 |
| 포인트당 효과 | 활동 EXP +0.6%p |
| 투자 상한 | 30포인트 |
| 투자 최대 보너스 | 활동 EXP +18% |
| EXP 스탯 자체 효과 상한 | 활동 EXP +50% |
| 모든 출처 포함 최종 상한 | 활동 EXP +75% |

```text
투자 EXP 보너스 =
min(EXP 투자 포인트, 30) × 0.6%p
```

- EXP는 진행 EXP와 보정 EXP에 영향을 주지 않는다.
- EXP 스탯 자체 효과는 투자와 고정 EXP 스탯 보너스를 포함해 +50%를 넘지 않는다.
- 장비·증강의 별도 활동 EXP 보너스를 포함한 최종 상한은 +75%다.
- 몬스터는 EXP 스탯을 보유하지 않는다.

### EXP 재분배 악용 방지

- EXP 투자 포인트를 회수하면 다음 Day가 시작될 때까지 EXP 투자 효과를 비활성화한다.
- 비활성 중 EXP에 다시 투자해도 잠금 종료 전까지 투자 효과가 적용되지 않는다.
- 다른 출처의 EXP 보너스는 해당 효과 설명에 별도 제한이 없다면 유지한다.
- 잠금 상태와 해제 예정 Day를 저장한다.

### 최대 레벨 무료 회수

- 레벨 50 도달 후 기지 내부 안전 상태에서 EXP 투자 포인트만 무료로 회수할 수 있다.
- 이 회수는 세션 무료 재분배 횟수와 희귀 공용 자원을 소비하지 않는다.
- 회차당 한 번만 사용할 수 있다.
- 회수 후 EXP 투자 효과 비활성 잠금은 적용하지 않는다.
- 회수한 포인트는 다른 스탯에 투자할 수 있다.

## 13. CRIT 치명타 확률

`CRIT`는 치명타 허용 공격의 치명타 발생 확률이다.

```text
최종 치명타 확률 = min(100%, 최종 CRIT)
```

- CRIT 25는 치명타 확률 25%를 의미한다.
- 플레이어 기본 CRIT는 0%다.
- 스탯 포인트로 투자할 수 없다.
- 일반 공격 스킬과 치명타 허용 스킬에 적용한다.
- DOT, 고정 피해, 환경 피해에는 기본적으로 적용하지 않는다.
- 모든 스킬은 치명타 허용 여부를 명시한다.
- 치명타 판정은 스킬 실행 또는 타격 단위 정책을 스킬 데이터에 정의한다.

## 14. CRIT_DMG 치명타 피해

`CRIT_DMG`는 치명타 발생 시 최종 피해에 적용하는 배율이다.

| 항목 | 값 |
|---|---:|
| 기본 CRIT_DMG | 175% |
| 최종 하드캡 | 300% |

```text
치명타 피해 =
일반 최종 피해 × (CRIT_DMG / 100)
```

- 기본 치명타는 일반 최종 피해의 1.75배다.
- CRIT_DMG는 스탯 포인트로 투자할 수 없다.
- 피해 감소 계산 전후의 정확한 치명타 처리 순서는 `CORE-001`에서 확정한다.

## 15. PEN 방어 관통

`PEN`은 대상 DEF를 절대 수치로 감소시킨다.

```text
일반 적용 PEN =
min(
  공격자 PEN,
  대상 DEF × 규칙 모드별 관통 상한
)

유효 DEF =
max(0, 대상 DEF - 일반 적용 PEN)
```

- PEN은 스탯 포인트로 투자할 수 없다.
- 일반 PEN은 STANDARD에서 대상 DEF의 최대 90%, CHAOS에서 최대 98%까지만 관통한다.
- `TRUE_PEN` 태그가 있는 특수 공격만 DEF를 0까지 감소시킬 수 있다.
- PEN은 고정 피해와 환경 피해에 의미가 없다.
- 대상 DEF가 0이면 PEN 초과값을 다른 보상으로 변환하지 않는다.

## 16. RES 상태이상 저항

`RES`는 저항 가능한 상태이상의 최종 적용 확률을 퍼센트포인트로 감소시킨다.

| 항목 | 값 |
|---|---:|
| 기본 RES | 0 |
| 최종 하드캡 | 90 |

```text
최종 상태이상 적용 확률 =
기본 적용 확률
+ 적용자의 상태 적중 보정
- 대상 RES
```

- RES 30은 상태이상 적용 확률을 30%p 감소시킨다.
- 일반 저항 가능 상태이상의 최소 적용 확률 10%, 최대 95% 규칙은 유지한다.
- 확정 적용, 스크립트 상태, 면역 정책은 `STATUS-001`을 따른다.

## 17. TENACITY 강한 CC 저항

`TENACITY`는 적용된 제어 효과의 지속시간을 감소시킨다.

| 항목 | 값 |
|---|---:|
| 기본 TENACITY | 0 |
| 최종 하드캡 | 80 |
| 최종 제어 지속시간 감소 상한 | 60% |

```text
TENACITY 기반 제어 지속시간 감소율 =
TENACITY / (100 + TENACITY)
```

예시:

| TENACITY | 지속시간 감소율 |
|---:|---:|
| 20 | 16.67% |
| 50 | 33.33% |
| 80 | 44.44% |

- 장비·증강의 별도 지속시간 감소를 포함한 최종 감소율은 60%를 넘지 않는다.
- 적용 성공한 강한 CC의 최소 지속시간은 `STATUS-001` 규칙을 따른다.
- 보스에게 직접 적용되지 않는 CC에는 TENACITY를 사용하지 않고 보스 정책을 적용한다.

## 18. STAGGER_RES 경직 저항

`STAGGER_RES`는 받는 경직 및 브레이크 피해를 감소시킨다.

| 항목 | 값 |
|---|---:|
| 기본 STAGGER_RES | 0 |
| 최종 하드캡 | 80 |

```text
받는 경직·브레이크 피해 배율 =
100 / (100 + STAGGER_RES)
```

예시:

| STAGGER_RES | 받는 경직·브레이크 피해 |
|---:|---:|
| 0 | 100.00% |
| 20 | 83.33% |
| 50 | 66.67% |
| 80 | 55.56% |

- 일반 경직, 브레이크 피해, 일부 강제 행동 중단에 적용한다.
- 기믹 고정 브레이크와 패턴 강제 중단에는 적용하지 않는다.
- 플레이어 대상 경직 게이지가 추가되면 같은 공식을 사용할 수 있다.
- 세부 브레이크 규칙은 `BREAK` 문서에서 확정한다.

## 20. 몬스터 스탯 구조

몬스터는 플레이어와 같은 전투 스탯 구조를 사용하지만 `EXP` 스탯은 보유하지 않는다.

### 몬스터 보유 스탯

- `HP`
- `AP`
- `ATK`
- `DEF`
- `HIT`
- `EVA`
- `SPD`
- `CRIT`
- `CRIT_DMG`
- `PEN`
- `RES`
- `TENACITY`
- `STAGGER_RES`

### 몬스터 스탯 규칙

- 몬스터 AP는 실제 스킬 사용 자원으로 사용한다.
- 몬스터는 스탯 포인트를 투자하지 않는다.
- 기본 스탯은 몬스터 템플릿과 역할에서 결정한다.
- 생성 시 Day Scaling, 등급, 난이도, 인원 스케일링을 적용한다.
- 전투 중에는 상태이상, 패턴, 페이즈 효과로 최종 스탯이 변할 수 있다.
- 몬스터 스탯에도 플레이어와 같은 DEF, PEN, CRIT, RES, TENACITY, STAGGER_RES 공식을 사용한다.

## 21. 몬스터 Day Scaling

몬스터는 Day가 증가할수록 선택적인 스탯 성장을 받는다.

### 적용 가능 스탯

- HP
- AP
- ATK
- DEF
- HIT
- EVA
- SPD
- CRIT
- PEN
- RES
- TENACITY
- STAGGER_RES

`CRIT_DMG`는 일반 Day Scaling으로 자주 증가시키지 않고 특정 역할과 등급에서 제한적으로 사용한다.

### Day Scaling 원칙

- 모든 스탯을 매일 동일 비율로 증가시키지 않는다.
- Day 구간과 몬스터 역할별 성장표를 사용한다.
- 초반에는 HP·ATK 중심, 중반에는 상태 저항·HIT·AP, 후반에는 역할 특화 스탯을 강화할 수 있다.
- SPD, CRIT, PEN처럼 전투 체감과 즉사 위험이 큰 스탯은 증가량을 작게 제한한다.
- 일반 몬스터, 엘리트, 보스는 서로 다른 Day Scaling 표를 사용한다.
- 최종 수치는 난이도와 인원 스케일링 이후 검증한다.

정확한 Day별 성장식과 배율은 `ENEMY` 및 `BALANCE` 문서에서 확정한다.

## 22. 일반 몬스터 등급

일반 몬스터는 생성 시 하나의 기본 등급을 가진다.

| 등급 | 내부 ID | 강화 방향 | 기본 대가 또는 약점 |
|---|---|---|---|
| normal | `NORMAL` | 템플릿 기본값 | 특화 없음 |
| enhanced | `ENHANCED` | 전체 능력치 소폭 증가 | 명확한 약점 없음 |
| corrupted | `CORRUPTED` | 오염 공격, 상태이상, RES 강화 | 정화 및 특정 대응에 취약 가능 |
| frenzied | `FRENZIED` | ATK·SPD 증가 | DEF 감소 |
| armored | `ARMORED` | HP·DEF·STAGGER_RES 증가 | SPD 감소 |
| swift | `SWIFT` | SPD·EVA·HIT 증가 | HP 감소 |

- 기본 등급은 한 몬스터에 하나만 적용한다.
- 등급은 생성 시 확정하고 일반적으로 전투 중 변경하지 않는다.
- 특수 기믹과 오염 변이는 명시된 경우에만 전투 중 등급 또는 상태를 변경할 수 있다.
- 추후 새로운 등급을 추가할 수 있다.
- 엘리트 특성, 보스 페이즈, 개체별 특수 태그는 기본 등급과 별도 시스템으로 관리한다.
- 정확한 등급별 배율과 출현 확률은 `ENEMY` 문서에서 확정한다.

## 23. 난이도와 스탯 연계

### 회차 난이도 선택

- 파티는 회차 생성 시 난이도를 선택한다.
- 선택된 난이도는 해당 회차가 끝날 때까지 변경할 수 없다.
- 난이도 표시명 `???`의 내부 ID는 `UNKNOWN`을 사용한다.
- 난이도는 저장 데이터, 종료 통계, 추천 스탯 분배안에 기록한다.

### 플레이어 적용

- 난이도별 기본 최대 HP
- 난이도별 오염 피해 DEF 효율
- 난이도별 추천 스탯 분배안

### 몬스터 적용

- 몬스터는 플레이어 HP 난이도 배율을 사용하지 않는다.
- 몬스터 난이도 배율은 별도 템플릿 또는 밸런스 표로 적용한다.
- 몬스터 난이도 배율, Day Scaling, 등급, 인원 스케일링은 서로 독립된 출처로 계산한다.

## 24. 추천 분배안 연계

추천안은 무기·역할뿐 아니라 현재 난이도를 고려한다.

- Easy에서는 HP보다 공격 및 유틸리티 스탯을 더 권장할 수 있다.
- Hard와 Challenge에서는 HP·DEF 권장 비중을 높인다.

# STAT-002 포인트 투자, 최종 스탯 계산 및 보조 전투값

## 1. 시스템 목적

STAT-002는 모든 스탯 출처를 하나의 규칙으로 계산하고, 장비·증강·스킬이 공통으로 사용할 보조 전투값을 정의한다.

- 포인트 투자, 장비, 증강, 상태이상, 오염, 기믹의 적용 순서를 통일한다.
- 같은 효과의 중복과 서로 다른 효과의 중첩을 명확히 처리한다.
- 피해, 회복, 보호막, AP, 속도, 생명력 흡수, 브레이크 관련 보조값을 공통 규격으로 제공한다.
- 플레이어와 몬스터가 같은 계산 구조를 사용하게 한다.
- 서버 성능을 위해 필요한 시점에만 스탯을 다시 계산한다.

## 2. 포인트 투자 규칙 연계

- 포인트 투자와 재분배 절차는 `PROG-002`를 따른다.
- 투자 포인트는 주 스탯의 `투자 증가값`만 생성한다.
- 투자 증가값은 장비·증강 고정값과 합산된 뒤 퍼센트 보정의 영향을 받는다.
- 투자 상한은 포인트 투자에만 적용한다.
- 장비·증강·아이템·상태 효과는 투자 상한을 초과할 수 있지만 최종 하드캡을 따른다.
- 포인트 투자 효율에는 소프트캡을 적용하지 않는다.

## 3. 최종 스탯 계산 파이프라인

```text
고정 합계 =
기본값
+ 투자 증가값
+ 장비·증강·아이템·기타 고정 보너스

일반 보정값 =
고정 합계
× (1 + 퍼센트 증가 합계 - 퍼센트 감소 합계)

임시 최종값 =
일반 보정값
× 개별 상태·오염·기믹 최종 배율

최종 스탯 =
스탯별 최소값과 최종 하드캡을 적용한 임시 최종값
```

### 계산 원칙

- 퍼센트 보너스는 기본값, 투자 증가값, 모든 고정 보너스를 합친 값에 적용한다.
- 같은 계산 단계의 퍼센트 증가와 감소는 각각 합산한다.
- 효과에 `FINAL_MULTIPLIER`가 명시된 경우에만 다른 일반 퍼센트 보정과 곱연산한다.
- 서로 다른 최종 배율은 효과 우선순위에 따라 순차 곱연산한다.
- 최종 하드캡은 모든 보너스와 디버프 계산이 끝난 뒤 마지막에 적용한다.
- 하드캡 초과 원본 수치는 보존한다. 디버프 이후에도 하드캡을 초과하면 최종값은 계속 하드캡에 머문다.

### 최소값

| 스탯 | 최종 최소값 |
|---|---:|
| `ATK` | `-2,147,483,648` |
| `SPD` | 1 |
| 그 외 주·보조 스탯 | 0 |

- ATK 저장 범위는 Java `int` 음수 범위까지 허용한다.
- 실제 ATK 계수와 피해·회복 계산은 `long` 또는 `double`로 처리한다.
- 오버플로 또는 비정상 수치가 감지되면 해당 계산을 취소하고 오류를 기록한다.

## 4. 스탯 출처와 중복 규칙

모든 스탯 효과는 최소한 다음 식별자를 가진다.

| 필드 | 역할 |
|---|---|
| 출처 ID | 장비, 증강, 스킬, 상태이상 등 원본 식별 |
| 효과 ID | 실제 스탯 변경 효과 식별 |
| 중첩 그룹 | 서로 비교하거나 중첩할 효과 묶음 |
| 중첩 정책 | `STRONGEST`, `STACKABLE`, `UNIQUE` 등 |
| 대상 개체 ID | 효과가 실제 적용되는 플레이어 또는 몬스터 |

### 기본 중복 처리

- 같은 `출처 ID + 효과 ID + 중첩 그룹`의 강화 효과는 가장 높은 값만 적용한다.
- 같은 조합의 약화 효과는 가장 낮은 값만 적용한다.
- 강화와 약화는 서로 별도로 계산한다.
- `STACKABLE`로 명시된 효과만 같은 조합끼리 중첩한다.
- 서로 다른 출처 ID는 정상적으로 중첩한다.
- 서로 연산하지 않는 독립 개체 속성은 각각 별도의 값으로 적용한다.
- 같은 효과 ID라도 적용 대상 개체가 다르면 서로 중복 판정하지 않는다.
- 한 대상에게 실제로 모인 효과끼리만 중복 규칙을 비교한다.
- 소환수와 투사체가 소유자 스탯을 복사하면 복사 시점의 출처 중복 규칙을 적용한다.

## 5. 스탯 재계산 시점

전체 스탯을 매 틱 다시 계산하지 않는다. 다음 사건이 발생할 때 변경된 스탯과 파생값만 재계산한다.

- 스탯 포인트 투자, 되돌리기, 재분배
- 장비 장착, 해제, 파괴, 옵션 변경
- 개인·파티 증강 획득 또는 제거
- 버프, 디버프, 상태이상 적용·갱신·해제
- 플레이어 또는 기지 오염 단계 변경
- 난이도 및 Day Scaling 갱신
- 몬스터 생성, 등급 확정, 페이즈 변경
- 스킬이나 기믹의 일시적 스탯 변경
- 부활 및 저장 데이터 복구

전투 중 장비 변경 허용 여부는 `EQUIP-001`에서 확정한다.

## 6. 최대 HP·AP 변경 처리

### 최대치 증가

- 최대 HP·AP가 증가해도 현재 HP·AP는 증가하지 않는다.
- 효과 설명에 현재값 증가가 명시된 경우만 예외로 적용한다.
- 예외 효과도 최대치를 초과하여 현재값을 증가시킬 수 없다.

### 최대치 감소

```text
변경 후 현재 HP = min(변경 전 현재 HP, 변경 후 최대 HP)
변경 후 현재 AP = min(변경 전 현재 AP, 변경 후 최대 AP)
```

- 현재값 비율을 유지하지 않는다.
- 최대 HP 감소 자체로 플레이어를 빈사 상태에 진입시키지 않는다.
- 최대 HP 감소 계산 결과가 현재 HP를 1 미만으로 만들 경우 생존 상태의 현재 HP를 1로 유지한다.
- 최대치 감소는 피해 또는 AP 소비로 처리하지 않으며 관련 발동 효과를 발생시키지 않는다.

## 7. 수치 정밀도와 반올림

| 값 | 내부 처리 | 최종 처리 |
|---|---|---|
| 피해량 | 소수점 유지 | 실제 적용 시 내림 |
| 회복량 | 소수점 유지 | 실제 적용 시 내림 |
| AP 비용 | 소수점 유지 | 실제 소비 시 올림 |
| 최대 HP·AP | 소수점 유지 | 최종 최대치 적용 시 내림 |
| 확률 | 소수점 유지 | 반올림 없이 판정 |
| 시간 | 초 단위 소수점 유지 | 서버 틱 단위로 올림 |

- 실제 피해와 회복이 0 미만이면 음수 ATK 회복 규칙을 제외하고 0으로 처리한다.
- 1틱은 `0.05초`를 기준으로 한다.

## 8. 보조 전투값 목록

보조 전투값은 스탯 포인트로 직접 투자하지 않으며 장비, 증강, 스킬, 상태이상, 기믹으로 획득한다.

| 내부 ID | 한글 표시명 | 역할 |
|---|---|---|
| `DAMAGE_DEALT` | 주는 피해 보정 | 허용된 공격의 최종 피해 증감 |
| `DAMAGE_TAKEN` | 받는 피해 보정 | 대상이 받는 피해 증감 |
| `HEALING_DONE` | 주는 회복량 | 자신이 발생시키는 회복 증가 |
| `HEALING_RECEIVED` | 받는 회복량 | 자신이 받는 회복 증감 |
| `SHIELD_POWER` | 보호막 효율 | 생성하는 보호막 수치 증가 |
| `AP_REGEN` | AP 자연 회복 보정 | 전투·비전투 자연 회복 증감 |
| `AP_COST_REDUCTION` | AP 비용 감소 | 허용 행동의 AP 비용 감소 |
| `SKILL_HASTE` | 스킬 가속 | 액티브 스킬 쿨타임 감소 |
| `ATTACK_SPEED` | 공격속도 | 일반 공격 스킬의 공격 간격 감소 |

| `RELOAD_SPEED` | 장전속도 | 석궁 등 탄창형 장비의 장전 시간 감소 |
| `LIFESTEAL` | 생명력 흡수 | 실제 HP 피해 일부를 일반 HP로 회복 |

기존 `CRIT`, `CRIT_DMG`, `PEN`, `RES`, `TENACITY`, `STAGGER_RES`도 공통 보조 스탯으로 유지한다.

## 9. 피해 보정

### 상한

| 보조값 | 최종 범위 |
|---|---:|
| `DAMAGE_DEALT` | -99% ~ +300% |
| `DAMAGE_TAKEN` | -80% ~ +300% |

- `DAMAGE_DEALT -99%`는 허용 피해를 원래 값의 1%까지 감소시킨다.
- `DAMAGE_TAKEN -80%`는 DEF, 방어, 부분 회피와 별개인 일반 받는 피해 감소 상한이다.
- 고정 피해와 환경 피해는 별도 명시가 없으면 두 보정의 영향을 받지 않는다.
- 속성별, 스킬별, 대상별 피해 보정은 별도 효과 ID로 관리한다.

### 기준 피해 계산 순서

```text
스킬 기본 피해 및 참조 스탯 계수
→ 공격자 DAMAGE_DEALT 및 허용된 공격 보정
→ 치명타
→ 대상 DEF 및 공격자 PEN
→ 대상 DAMAGE_TAKEN
→ 아군 공격 배율 등 대상 관계 보정
→ 방어·부분 회피·기믹 보정
→ 최종 피해
```

정확한 독자 피해 처리와 예외 우선순위는 `CORE-001`에서 확정한다.

## 10. 음수 ATK 회복 변환

최종 ATK는 특수한 디버프와 기믹으로 음수가 될 수 있다.

### 기본 규칙

1. 스킬 기본 피해와 모든 공격 계수 결과를 합산한다.
2. 합산 결과가 0 이상이면 정상 피해 계산을 진행한다.
3. 합산 결과가 음수이고 스킬에 `ALLOW_NEGATIVE_ATK_HEAL` 태그가 있으면 절댓값만큼 회복으로 변환한다.
4. 태그가 없다면 해당 공격의 최종 피해를 0으로 처리한다.

- 개별 계수마다 피해와 회복을 동시에 발생시키지 않는다.
- 회복은 원래 공격 대상에게 적용한다.
- 적을 공격한 경우 적이 회복되며, 아군을 공격한 경우 아군이 회복된다.
- 음수 ATK 회복은 아군 공격 피해 30% 배율의 영향을 받지 않고 100% 적용한다.

### 회복 보정

- `DAMAGE_DEALT`, 치명타, PEN, DEF, `DAMAGE_TAKEN`을 적용하지 않는다.
- `HEALING_DONE`과 대상의 `HEALING_RECEIVED`를 정상 적용한다.
- 회복 불가 상태에는 차단된다.
- 생명력 흡수, 보호막, 브레이크 피해를 발생시키지 않는다.
- 적 회복도 전투 상태, 어그로, 공격 적중 및 허용된 상태이상 판정을 발생시킨다.
- 적 회복은 기여도와 활동 EXP를 지급하지 않는다.

## 11. 아군 공격 공통 규칙

플레이어가 직접 발생시킨 커스텀 공격 피해는 아군 대상에게 최종 피해의 30%만 적용한다.

```text
아군 대상 적용 피해 =
플레이어가 직접 발생시킨 커스텀 공격의 일반 최종 피해
× 0.30
```

- 고정 피해, 환경 피해, 몬스터 공격에는 이 배율을 적용하지 않는다.
- 아군 공격으로 빈사 및 완전 사망할 수 있다.
- 아군 공격 상태이상은 기존 적용 확률을 사용한다.
- 아군 대상 강한 CC 지속시간은 원래 지속시간의 30%다.
- 넉백, 끌어당김, 강제 이동은 원래 세기를 적용한다.
- 아군 대상 브레이크 피해는 원래 값의 50%다.
- 공격자 보상, 생명력 흡수, 처치 효과는 아군 공격으로 발동하지 않는다.
- 회피, 방어, 패링과 성공 보상 제한은 `COMBAT` 규칙을 따른다.

## 12. 회복 보조값

| 보조값 | 최종 범위 |
|---|---:|
| `HEALING_DONE` | 기본 대비 최대 +100% |
| `HEALING_RECEIVED` 증가 | 기본 대비 최대 +100% |
| `HEALING_RECEIVED` 감소 | 기본 대비 최대 -99% |

```text
최종 회복량 =
기본 회복량
× (1 + 주는 회복량 증가)
× (1 + 받는 회복량 증가 - 받는 회복량 감소)
```

- 회복 불가는 감소 상한과 별도의 차단 상태다.
- 일반 회복은 빈사 체력을 회복하지 않는다.
- 빈사 체력 전용 회복은 효과 데이터에 명시해야 한다.
- 음수 ATK 회복도 같은 회복 보조값을 사용한다.

## 13. 보호막 효율

`SHIELD_POWER`는 자신이 생성하는 보호막의 양을 증가시킨다.

| 항목 | 규칙 |
|---|---|
| 보호막 효율 증가 상한 | +300% |
| 영향 대상 | 보호막 생성량 |
| 영향하지 않는 값 | 보호막 지속시간, 보호막 자체 피해 감소율 |

```text
최종 생성 보호막 =
기본 보호막
× (1 + SHIELD_POWER)
```

- 보호막별 최대 보유량은 개별 스킬과 효과 데이터에 설정한다.
- 보호막 중복, 갱신, 우선 소모 규칙은 `SKILL` 및 관련 시스템에서 확정한다.

## 14. AP 보조값 연계

기존 `COMBAT-002` 규칙을 유지한다.

| 항목 | 상한 |
|---|---:|
| 일반 AP 자연 회복 성장 | 기본값 대비 +50% |
| 조건부 효과 포함 최종 자연 회복 | 기본값의 최대 200% |
| 전체 AP 비용 감소 | 최대 15% |
| 회피 AP 비용 감소 | 최대 30% |
| 방어 유지·채널링 비용 감소 | 행동별 최대 30% |

- 행동별 비용 감소가 전체 비용 감소보다 우선 적용될 수 있다.
- 모든 비용 감소 후 실제 AP 소비량은 올림 처리한다.
- AP 비용은 행동별 최소 비용보다 낮아질 수 없다.
- 회복 차단은 AP 회복 감소 상한과 별도 상태로 처리한다.

## 15. 스킬 가속

`SKILL_HASTE`는 액티브 스킬의 재사용 대기시간을 감소시킨다.

```text
쿨타임 감소율 =
SKILL_HASTE / (100 + SKILL_HASTE)

최종 스킬 쿨타임 =
max(
  1틱,
  기본 쿨타임 × (1 - 쿨타임 감소율)
)
```

| 항목 | 규칙 |
|---|---|
| 최종 쿨타임 감소율 하드캡 | 99% |
| 99% 도달에 필요한 스킬 가속 | 9,900 |
| 최종 최소 쿨타임 | 1틱 |

- 회피, 패링, 아이템, 증강 내부 쿨타임, 구조, 시설에는 스킬 가속을 적용하지 않는다.
- 일반 공격에는 스킬 가속을 적용하지 않고 `ATTACK_SPEED` 기반 공격 간격만 사용한다.
- 제외 항목은 기존 개별 재사용 대기시간 감소 규칙을 사용한다.
- 스킬 가속은 이미 진행 중인 쿨타임의 남은 시간을 소급 변경하지 않는 것을 기본으로 한다.

## 16. 공격속도

`ATTACK_SPEED`는 일반 공격 스킬의 기본 공격 간격을 감소시킨다.

```text
최종 공격 간격 =
max(
  1틱,
  기본 공격 간격 × 100 / (100 + ATTACK_SPEED)
)
```

- 공격속도 수치 자체에는 하드캡을 두지 않는다.
- 최종 공격 간격은 마인크래프트 서버 처리 단위인 1틱보다 짧아질 수 없다.
- 플레이어별 한 틱에 일반 공격 스킬을 최대 한 번 실행한다.
- 같은 틱에 들어온 추가 일반 공격 입력은 무시한다.
- 다단 공격의 개별 타격은 일반 공격 실행 제한과 별도로 처리한다.
- 공격속도는 액티브 스킬 쿨타임, 시전 시간, 후딜레이에 영향을 주지 않는다.

## 17. 시전속도

`CAST_SPEED`는 허용된 스킬의 시전 시간을 감소시킨다.

```text
최종 시전 시간 =
기본 시전 시간 × 100 / (100 + CAST_SPEED)
```

| 항목 | 규칙 |
|---|---:|
| 시전속도 하드캡 | 100 |
| 최종 시전 시간 최소 비율 | 기본값의 50% |

- 즉시 시전 스킬에는 적용하지 않는다.
- 후딜레이, 채널링 지속시간, 회피, 패링, 구조 시간에는 적용하지 않는다.
- 공격속도와 시전속도는 서로 독립된 보조 전투값이다.

## 17-1. 장전속도

`RELOAD_SPEED`는 석궁과 향후 탄창형 장비의 장전 시간을 감소시킨다.

```text
최종 장전 시간 =
max(
  기본 장전 시간 × 25%,
  기본 장전 시간 × 100 / (100 + RELOAD_SPEED)
)
```

| 항목 | 규칙 |
|---|---:|
| 기본 RELOAD_SPEED | 0 |
| 포인트 투자 | 불가 |
| 최종 장전 시간 최소 | 기본값의 25% |

- 장비, 증강, 커스텀 인챈트와 상태 효과로 획득할 수 있다.
- `ATTACK_SPEED`는 발사 간격, `RELOAD_SPEED`는 장전 시간에만 적용한다.
- `CAST_SPEED`와 `SKILL_HASTE`는 장전에 적용하지 않는다.
- 진행 중인 장전에는 장전 시작 시 확정한 속도를 기본적으로 유지한다.

## 18. 생명력 흡수

`LIFESTEAL`은 대상의 실제 HP에 가한 피해 일부를 공격자의 일반 HP로 회복한다.

### 기본 규칙

| 항목 | 규칙 |
|---|---:|
| 기본 생명력 흡수율 하드캡 | 100% |
| 단일 공격 효율 | 100% |
| 광역 또는 다단 공격 효율 | 70% |
| 지속 피해 효율 | 40% |

```text
생명력 흡수 회복량 =
대상의 실제 HP에 가한 피해
× min(100%, LIFESTEAL)
× 공격 분류 효율
```

### 분류 우선순위

```text
지속 피해 40%
> 광역 또는 다단 공격 70%
> 단일 공격 100%
```

- 광역 지속 피해는 40%, 광역 다단 공격은 70% 효율을 사용한다.
- 보호막에 준 피해, 초과 피해, 고정 피해, 환경 피해에는 적용하지 않는다.
- 아군 공격에는 적용하지 않는다.
- 빈사 상태에서는 발동하지 않는다.
- 일반 HP만 회복하며 빈사 체력을 회복하지 않는다.
- 생명력 흡수 회복은 회복 불가 상태와 받는 회복량 보정의 영향을 받는다.

## 19. 브레이크 피해 보조값

| 항목 | 규칙 |
|---|---:|
| 주는 브레이크 피해 증가 상한 | +300% |
| 받는 브레이크 피해 감소 | `STAGGER_RES` 공식 |
| 아군 대상 브레이크 피해 | 원래 값의 50% |

```text
최종 일반 브레이크 피해 =
기본 브레이크 피해
× (1 + BREAK_DAMAGE)
× 100 / (100 + 대상 STAGGER_RES)
```

- 브레이크 피해는 음수가 되거나 브레이크 회복으로 변환되지 않는다.
- 고정 기믹 브레이크와 패턴 강제 중단은 두 보정을 모두 무시한다.
- 세부 게이지와 그로기 규칙은 `BREAK` 문서에서 확정한다.

## 20. 확률 판정 규칙

- CRIT와 상태이상 확률은 기본적으로 매 타격마다 독립 난수를 사용한다.
- 다단 스킬은 타격별로 치명타와 허용된 상태이상 판정을 수행한다.
- 지속 스킬은 시전당 치명타를 한 번 판정하고 모든 틱이 결과를 공유한다.
- 지속 스킬의 상태이상은 상태이상 종류별·대상별로 시전당 한 번 판정한다.
- 지속 스킬이 여러 대상을 적중하면 각 대상에 대해 독립 판정한다.
- 재시전 또는 새 실행 ID가 생성되면 다시 판정한다.
- 지속 스킬이 별도 DOT 상태이상을 적용하면 DOT의 판정은 별도로 수행한다.
- 화상, 독, 출혈 같은 DOT는 상태이상별 치명타 허용 여부와 적용 시점 규칙을 가진다.

## 21. 몬스터 적용

- 몬스터도 플레이어와 같은 최종 스탯 계산 순서, 중복 규칙, 하드캡을 사용한다.
- 몬스터는 템플릿, Day Scaling, 등급, 난이도, 인원 스케일링을 각각 독립 출처로 가진다.
- 보스 기믹이 일반 하드캡이나 계산 순서를 무시하면 해당 패턴 데이터에 예외를 명시한다.
- 몬스터 음수 ATK와 `ALLOW_NEGATIVE_ATK_HEAL`도 플레이어와 같은 규칙을 사용한다.
- 몬스터가 적을 회복하더라도 플레이어 기여도와 활동 EXP를 생성하지 않는다.

## 22. UI 표시 모드

플레이어는 설정에서 `간단 표시`와 `상세 표시` 중 하나를 선택할 수 있다. 기본값은 간단 표시다.

### 간단 표시

- 최종 스탯
- 투자 포인트와 투자 증가값
- 주요 파생 효과
- 투자 상한 및 최종 하드캡 경고

```text
ATK 공격력: 280
투자: 50포인트 (+100)
주는 피해: +20%
```

### 상세 표시

- 기본값
- 투자 증가값
- 출처별 고정 보너스
- 퍼센트 증가·감소
- 상태·오염·기믹 최종 배율
- 하드캡 적용 전 수치와 실제 최종값
- 중복으로 제외된 효과
- 주요 파생 공식 결과

```text
SPD 이동속도
기본 100 + 투자 5 + 장비 220 = 325
상태 배율 ×0.95 = 308.75
하드캡 전 308.75 → 최종 300
```

- 플레이어별 표시 모드 선택값을 저장한다.
- 상세 표시는 계산 검증과 빌드 비교에 사용할 수 있게 한다.

## 23. 플러그인 구현 방향

- 모든 스탯 효과를 출처 ID, 효과 ID, 중첩 그룹, 대상 개체 ID와 함께 등록한다.
- 변경된 출처가 영향을 주는 스탯과 파생값만 무효화하고 재계산한다.
- 최종 스탯 캐시는 읽기 성능을 위해 유지하되 원본 출처에서 재구성할 수 있어야 한다.
- 피해, 회복, 보호막, AP, 브레이크 계산은 공통 수치 처리 서비스를 사용한다.
- 확률 판정은 스킬 실행 ID, 타격 ID, 대상 ID를 기록하여 중복 판정을 방지한다.
- 1틱 일반 공격 실행 제한은 플레이어별 마지막 실행 틱으로 검증한다.
- 음수 ATK 절댓값 변환은 `int`가 아닌 `long` 또는 `double`에서 수행한다.
- 비정상 값, NaN, 무한대, 오버플로는 계산을 취소하고 원인 출처를 로그에 기록한다.

## 24. 저장 데이터

```yaml
players:
  "player-uuid":
    preferences:
      stat-display-mode: SIMPLE
    stats:
      formula-version: 2
      dirty-groups: []
      cached-final:
        HP: 1500
        AP: 125
        ATK: 280
        DEF: 140
        SPD: 110.5
      auxiliary:
        DAMAGE_DEALT: 0.20
        HEALING_DONE: 0.10
        SKILL_HASTE: 50
        ATTACK_SPEED: 30
        LIFESTEAL: 0.15
```

- 저장된 최종 캐시는 접속 및 재개 시 원본 출처와 공식 버전으로 검증한다.
- 일시 효과는 원본 시스템의 저장 정책에 따라 남은 시간과 출처를 저장한다.
- UI 표시 모드 선택은 회차가 아닌 플레이어 설정으로 저장할 수 있다.

## 25. 예외 처리

| 상황 | 처리 |
|---|---|
| ATK가 음수이고 허용 태그 없음 | 최종 피해 0 |
| ATK가 음수이고 허용 태그 있음 | 원래 공격 대상을 절댓값만큼 회복 |
| 음수 ATK 절댓값 변환 오버플로 | 안전한 수치형으로 계산, 실패 시 계산 취소 및 기록 |
| 스탯 효과 출처가 제거됨 | 해당 출처만 제거 후 영향 스탯 재계산 |
| 같은 효과가 중복 등록됨 | 중첩 정책에 따라 가장 강한 값 또는 허용 중첩만 적용 |
| 최대 HP 감소 | 현재 HP 절삭, 스탯 감소 자체로 빈사 진입 금지 |
| 스킬 쿨타임 계산이 1틱 미만 | 1틱 적용 |
| 한 틱에 일반 공격 입력 반복 | 최초 한 번만 실행 |
| 아군 공격으로 보상 발동 시도 | 공격자 보상·흡혈·처치 효과 차단 |
| 적을 음수 ATK로 회복 | 전투·어그로·적중 유지, 기여도·활동 EXP 미지급 |
| 계산 결과 NaN·무한대 | 계산 취소, 이전 정상값 유지, 오류 기록 |

## 27. STAT-002 완료 기준

- 포인트 투자와 모든 외부 출처가 확정된 계산 순서로 최종 스탯에 반영된다.
- 같은 효과의 중복과 독립 개체 속성이 정의된 규칙으로 처리된다.
- ATK를 제외한 스탯 최소값과 음수 ATK 회복 변환 규칙이 적용된다.
- 최대 HP·AP 변경이 회복 또는 스탯 감소에 의한 빈사 악용을 만들지 않는다.
- 피해, 회복, 보호막, AP, 스킬 가속, 공격속도, 시전속도, 장전속도, 생명력 흡수, 브레이크 보조값이 정의된다.
- 아군 공격이 피해 30%, 강한 CC 30%, 이동 효과 100%, 브레이크 50% 규칙을 따른다.
- 스킬 가속과 공격속도가 최소 1틱 제한을 지킨다.
- 다단 및 지속 스킬의 확률 판정 단위가 일관되게 처리된다.
- 플레이어와 몬스터가 같은 계산 구조를 사용한다.
- 간단·상세 스탯 표시 모드를 선택하고 저장할 수 있다.
- 서버 재시작과 효과 갱신으로 최종 스탯 및 출처 데이터가 손상되지 않는다.

## 관리 규칙

- 문서 본문에서는 가능한 한 `문서 ID`를 사용해 참조하고, 특정 파일을 직접 열어야 할 때만 상대 경로 링크를 사용한다.
- 파일을 이동하거나 이름을 바꾸면 이 색인과 저장소 전체의 Markdown 링크를 함께 갱신한다.
- 목록·실데이터 문서는 해당 시스템 문서와 같은 카테고리에 두되, 여러 시스템을 가로지르는 원장과 시뮬레이션만 `09 데이터와 밸런스`에 둔다.
- 런타임 스키마·콘텐츠 번들·운영 복구 계약은 `10 기술과 운영`에서 관리한다.

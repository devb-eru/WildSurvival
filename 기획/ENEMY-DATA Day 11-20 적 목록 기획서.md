## 1. 설계 목표

- Day 11~20은 단순 피해 증가가 아니라 상태 인지, 상태 조합 분리, 구조, 침묵·무장해제 대응을 순서대로 시험한다.
- 강한 상태와 제어는 전조·지속시간·연속 CC 보호를 지키며 특정 해제 아이템 하나를 강제하지 않는다.
- 적 증강은 최초 Lv15 달성자가 고정한 회차 등급을 읽고 실제 ID만 적별로 독립 추첨한다.
- 일반 무리의 화면 내 동시 강한 전조는 2개, 정예 포함 무리는 3개를 넘지 않는다.
- 상태 표본 보상은 적 처치 수가 아니라 Day·원천 쿼터에 묶어 반복 파밍으로 경제를 늘리지 않는다.

- Day 15 잠금 증강은 회차에 잠긴 등급에 따라 실버 1·골드 2·프리즘 3의 비용을 사용한다. 표는 프리즘 2개 최악값이며 실제 등급이 낮아도 남은 예산을 다른 적으로 채우지 않는다.

## 9. 상태·보상 원장

| 항목 | 키 | 규칙 |
|---|---|---|
| 상태 원천 | `status-source-id` | 적 실행마다 유일, DOT 재귀 적용 차단 |
| 표본 자격 | `sample-eligibility-id` | 템플릿·Day·상태 계열 조합, 최초 유효 기록 1회 |
| 적 증강 | `enemy-augment-instance` | `source-level`, 잠금 등급, 실제 ID, 시드 저장 |
| 변이 | `mutation-instance` | ID, 비용, 전조 세트, 상충 검사 결과 저장 |
| 전투 보상 | `encounter-reward-id` | 마지막 타격이 아니라 참여·역할·회수 기여로 분배 |
| 소환체 | `summon-parent-id` | 부모 전투 보상에 흡수, 자체 EXP·드롭 없음 |

- 같은 적에게 해제와 재적용을 반복해도 상태 표본 쿼터를 늘리지 않는다.
- 낙사·환경사·청크 언로드로 적이 제거돼도 이미 커밋된 전투 보상을 다시 생성하지 않는다.
- 강화 적·정예의 추가 위험은 해당 전투의 원천 보상 예산 안에서 품질 가중치로만 환산한다.

## 11. 검증 항목

- 프로필·난이도·인원·등급·변이·증강 배율의 중복 적용 방지
- 모든 강한 상태 패턴의 전조, 최소 2개 대응, 지속시간, 내부 재사용
- SILENCE·DISARM이 슬롯 아이템 제거·드롭·권투로 전환을 일으키지 않음
- 처형자 패턴이 즉사·구조 불가·빈사 확정을 만들지 않음
- Lv15 최초 달성 등급 잠금 전·후 생성 적의 비소급 처리
- 대표 무리 예산과 역할·전조·활성 개체 상한
- 정예 변이·증강 상충과 프리즘 허용 개체 제한
- 소환체 EXP·자원·표본·기여품 미생성
- 서버 재시작·청크 언로드 뒤 적 실행·브레이크·보상 원장 멱등성

## 12. 완료 기준

- Day 11~19의 신규 일반·강화·정예 적이 실제 HP·피해·브레이크·패턴을 가진다.
- 상태 학습이 약한 상태에서 구조, 침묵·무장해제, 상태 정예 순으로 상승한다.
- 적 증강이 플레이어 최초 달성 등급 잠금과 정확히 연계되며 기존 적에 소급되지 않는다.
- 2~4인 무리 예산과 역할 상한이 특정 무기·특정 담당자를 강제하지 않는다.
- 모든 적이 바닐라 엔티티 외형, 플러그인 AI·PDC, 리소스 팩 선택 적용으로 구현 가능하다.

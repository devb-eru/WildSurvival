| 구현 | 서버 권위 커스텀 공격, 바닐라 기본 피해·투척·강타 차단 |

## 1. 공통 실행 규칙

- 권투를 제외한 9개 무기군의 일반 공격은 AP 0인 장착 인스턴스 귀속 `BASIC_ATTACK`이며 좌클릭을 서버 권위 스킬 실행으로 변환한다.
- 권투 일반 공격은 장착 인스턴스 스킬이 아니라 `UNARMED_COMBAT` 가상 프로필로 실행한다. 바닐라 피해는 취소하고 아래 실행표와 공통 Combat 파이프라인은 그대로 사용한다.
- WEAPON-001의 초 단위 간격은 표시 기준이고 실제 실행은 서버 틱으로 올림한다.
- 공격 가능 시점 전 3틱의 입력 하나만 버퍼에 저장한다.
- 한 플레이어는 한 틱에 일반 공격을 최대 한 번 시작한다.
- 일반 공격 시작 시 공격자 ATK·장비·증강을 스냅샷하고 적중 시 대상 DEF·상태·보호막을 조회한다.
- 일반 공격과 액티브의 AP, 쿨다운, 상태와 브레이크는 같은 실행 ID에서 한 번만 확정한다.
- 플레이어가 직접 회피로 액티브를 취소하거나 적 공격·CC로 취소되면 AP를 환급하지 않는다.
- 대상·지형 검증 실패로 실행 자체가 시작되지 않으면 AP와 쿨다운을 소비하지 않는다. 시스템 안전 취소는 100% 환급한다.

### 1.1 실행 구간

| 구간 | 의미 | 회피 취소 |
|---|---|---|
| `STARTUP` | 입력 확정부터 판정 생성 전 | 스킬별 허용, 허용 시 AP 환급 없음 |
| `ACTIVE` | 근접 도형·투사체·영역이 생성되는 구간 | 기본 불가, 명시 스킬만 가능 |
| `RECOVERY` | 판정 종료 후 다음 행동까지의 구간 | 표의 `회피 가능 틱`부터 가능 |

`회피 가능 틱 3`은 RECOVERY 시작 후 3틱째부터 회피를 시작할 수 있다는 뜻이다.

### 1.2 기본 브레이크

표의 브레이크 값은 `기본 브레이크 피해`다. 최종값은 BREAK_DAMAGE와 대상 STAGGER_RES 공식을 적용한다. 일반 몬스터가 브레이크 게이지를 가지지 않으면 값을 무시한다.

### 1.3 입력·슬롯 계약

| 실행 | 바인드 | 슬롯 점유 |
|---|---|---|
| 장착 무기 기본 공격 | 슬롯 0 `L` | 무기 액티브 미점유 |
| 권투 기본 공격 | 슬롯 0이 비어 있는 상태의 `L` | 가상 프로필, 미점유 |
| 무기 액티브 1 | `Shift+L` | `W1` |
| 무기 액티브 2 | `Shift+R` | `W2` |
| 무기 액티브 3 | `F` | `W3` |

- 각 장착 무기 기본 공격 실행은 `equipmentInstanceId`, `basicSkillId`, `weaponClass`, `dataRevision`을 스냅샷한다.
- 바닐라 근접 피해, 활·석궁 발사, 철퇴 강타와 삼지창 투척 피해는 모두 취소하고 같은 실행 ID로 재생성한다.
- `SILENCE`는 기본 공격을 막지 않지만 `W1~W3`는 막는다.
- 무기 액티브는 `SKILL-LIST-001`의 후보 중 최대 3개를 장착하며 본 문서의 기본 추천 2개는 시작 로드아웃이지 장착 상한이 아니다.

### 2.1 콤보

- 다음 공격은 현재 단계 적중 여부와 무관하게 입력하면 진행하지만, 단계별 적중 조건 효과는 빗나가면 발생하지 않는다.
- 검·도끼·단검·곡괭이·삼지창·권투는 마지막 공격 시작 후 1.25초 동안 다음 1타가 없으면 1단계로 초기화한다.
- 무기 변경, GUI 진입, 강한 CC, 빈사, 사망과 서버 재시작은 콤보를 초기화한다.
- 한 단계가 여러 대상을 적중해도 콤보는 한 번만 진행한다.

### 2.2 상태 적중

표의 확률은 상태 기본 확률이다. 최종 확률은 STATUS의 HIT·RES 공식을 사용한다. 보스의 약화와 DOT는 강도·지속시간 50% 및 개별 DPS 상한을 적용한다.

| 45초 미회수 | 자동 RETURNING, AP 0, 피해 없음 |
| 귀환 경로 차단 3초 | 소유자 앞 안전 위치로 복구, 피해 없음 |
| 무기 변경 시도 | 전투 중 거부, 비전투는 먼저 무피해 자동 회수 |

- 바닐라 삼지창 투척, 급류 이동과 충성 귀환은 모두 취소한다.
- RETURNING 경로 적중은 한 대상당 한 번만 가능하다.

### 12.1 자동 활성화

```text
MAIN_WEAPON == empty
AND actual slot 0 == empty
AND no pending equip transaction
→ UNARMED_COMBAT 활성
```

- 아이템을 슬롯 0에 직접 옮기면 GUI 장착이 아니므로 원래 위치로 되돌리고 권투를 유지한다.
- 전투 중 주무기 장착·해제는 금지한다.
- 권투는 장비 내구도와 탄약이 없지만 주무기 옵션 슬롯도 얻지 못한다.

## 15. 저장·복구

- 일반 공격, 입력 버퍼와 콤보는 서버 재시작 시 초기화한다.
- 액티브 쿨다운, 석궁 탄창, 선택 탄약, 삼지창 상태·위치와 장비 인스턴스는 저장한다.
- 재시작 중 진행 중이던 투사체와 장판은 제거한다. 소비가 확정된 액티브는 재발사하지 않는다.
- 삼지창 소유 인스턴스가 있는데 투척체 기록이 없으면 RECOVERABLE로 전환한다.
- 같은 실행 ID의 피해·브레이크·상태·AP 환급을 두 번 처리하지 않는다.

## 16. 검증 항목

- 표시 초 단위 간격과 실제 틱 올림 간격
- 일반 공격 AP 0과 3틱 입력 버퍼
- 9개 장착 무기 기본 공격의 바닐라 피해 0회·커스텀 실행 1회
- 권투 가상 기본 공격이 장착 인스턴스 스킬로 저장되지 않음
- `W1/W2/W3` 최대 3개와 기본 공격 미점유
- 10개 무기 콤보·판정 도형·대상 상한
- 액티브 AP·쿨다운·시전 구간과 회피 취소 무환급
- 상태 적중 HIT·RES 및 보스 REDUCED·BREAK_CONVERT
- 다단 공격 발동 감쇠와 실행당 AP 환급 상한
- 곡괭이 전투 우선·채굴 분리
- 삼지창 HELD~RECOVERABLE 저장·자동 회수
- 권투 빈 슬롯 자동 활성과 GUI 외 장착 차단
- 낮은 TPS에서 실제 경과시간 기준 중복 실행 차단

## 17. 완료 기준

- 10개 무기군의 일반 공격 틱, 도형, 계수, 브레이크와 상태가 실행 가능한 수치로 정의된다.
- 무기마다 기본 추천 액티브 2개의 AP, 쿨다운, 타이밍, 상태와 회피 취소 창이 있으며 해금 후보 중 최대 3개를 장착할 수 있다.
- 곡괭이·삼지창·권투의 특수 판정과 저장 상태가 구체화된다.
- 활·석궁 탄약과 석궁 탄창이 자원·저장 계약에 연결된다.
- 모든 무기가 회피·패링·브레이크·상태 계약을 우회하지 않는다.

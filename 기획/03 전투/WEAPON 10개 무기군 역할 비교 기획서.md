# WildSurvival WEAPON 10개 무기군 역할 비교 기획서

## 문서 정보

| 항목 | 내용 |
|---|---|
| 문서 ID | WEAPON-001 |
| 상태 | `BASELINE_LOCKED` |
| 최종 수정일 | 2026-08-21 |
| 상위 기준 | `EQUIP-001`, `CORE-002`, `COMBAT`, `BREAK`, `STATUS`, `RULES` |
| 목적 | 10개 무기군의 역할·조작·성장 축을 같은 기준으로 비교 |
| 수치 상태 | 첫 밸런스 검증용 기준안, 실제 구현 전 시뮬레이션으로 조정 |
| 구현 | 바닐라 아이템 + PDC + 서버 권위 커스텀 공격 |

## 1. 공통 설계 원칙

- 무기별 강점은 명확하게 만들되 특정 무기나 역할을 필수로 만들지 않는다.
- 모든 무기는 AP가 없어도 일반 공격을 사용할 수 있다.
- 권투를 제외한 9개 무기군은 바닐라 기본 공격을 사용하지 않는다. 슬롯 0 좌클릭이 장착 인스턴스의 `BASIC_ATTACK` 스킬을 실행하며 무기 액티브 3칸에는 포함되지 않는다.
- 권투는 아이템 귀속 기본 공격 스킬 대신 `UNARMED_COMBAT` 가상 콤보 프로필을 유지하고, 최종 피해만 공통 Combat 파이프라인에서 확정한다.
- AP는 액티브 스킬, 방어, 회피와 특수 공격의 선택 비용이다.
- 브레이크, 원거리 대응, 군중 대응과 상태 대응은 각각 최소 세 무기와 공용 수단 하나 이상으로 제공한다.
- 주무기는 커스텀 GUI의 `MAIN_WEAPON`에 장착하고 실제 슬롯 `0`에 동기화한다.
- 방패와 보조 도구는 `OFF_WEAPON`, 실제 오프핸드 `-106`을 사용하며 10개 주무기군에 포함하지 않는다.
- 리소스 팩이 없어도 Material, 이름, 로어, 무기군 접두어와 GUI 아이콘으로 구분할 수 있어야 한다.

## 2. 공통 수치 정의

| 수치 | 의미 |
|---|---|
| 기본 간격 | ATTACK_SPEED 0일 때 일반 공격 시작 간격 |
| 사거리 | 서버 레이 트레이스 또는 공격 도형의 기본 거리 |
| 대상 수 | 일반 공격 한 단계의 기본 최대 대상 |

| AP 성향 | 액티브 스킬의 비용·환급 구조 |

아래 수치는 무기 간 상대 역할을 고정하기 위한 시작점이다. 장비 등급이 일반 공격의 판정 구조를 바꾸기보다 ATK, 보조 옵션과 스킬 선택을 확장하게 한다.

### 수치 해석

- 피해 계수 합계는 콤보 완주 시간과 위험 노출을 함께 비교해야 한다.
- 원거리 일반 공격은 탄약·시야·발사체 이동이라는 비용이 있어 근접과 같은 계수만으로 평가하지 않는다.
- 둔기·곡괭이의 높은 브레이크는 느린 간격, 좁은 기동 또는 낮은 상태 활용과 교환한다.
- 단검·권투의 빠른 타격은 타격별 발동 확률 감쇠와 초당 발동 상한을 적용한다.
- 공격속도가 증가해도 일반 공격 간격은 최소 1틱이며 플레이어당 틱당 한 번만 시작한다.

# 6. 무기별 역할

## 6.1 검 — 균형형 전투 조율

| 항목 | 기준 |
|---|---|
| 핵심 태그 | `BALANCED`, `COMBO`, `GUARD_LINK` |
| 강점 | 안정적인 콤보, 방어·패링 후 반격, 단일·소수 광역 균형 |
| 약점 | 어느 한 축에서도 최고 효율이 아님 |
| AP 성향 | 중간 비용, 패링·콤보 완주 조건부 환급 |
| 브레이크 | 보통, 패링과 정확한 3타로 보완 |
| 상태 | 표식·취약·짧은 출혈 |
| 회피 연계 | 회피 후 콤보 2단 진입 또는 짧은 전진 베기 후보 |

검은 초보자가 규칙을 배우기 쉬운 기준 무기다. 검만 있으면 모든 상황을 최고 효율로 해결할 수는 없지만 어떤 파티에서도 무효가 되지 않는다.

## 6.2 도끼 — 고위험 단일 압박

| 항목 | 기준 |
|---|---|
| 핵심 태그 | `HEAVY`, `EXECUTION`, `ARMOR_PRESSURE` |
| 강점 | 높은 단일 피해, 방어 대상 압박, 준수한 브레이크 |
| 약점 | 느린 후딜, 빗나감 손실, 다수 대응 제한 |
| AP 성향 | 높은 단일 비용, 적중·처치보다 차지 성공에 보상 |
| 브레이크 | 높음 |
| 상태 | 방어력 감소·상처 표식 |
| 회피 연계 | 회피로 준비 취소 가능, 회피 직후 공격은 피해보다 준비시간 감소 |

도끼의 처형은 즉사 판정이 아니라 낮은 HP 대상 추가 계수와 긴 내부 재사용 대기시간으로 처리한다.

## 6.3 활 — 지속 원거리와 상태 운용

| 항목 | 기준 |
|---|---|

| 강점 | 장거리 안전 공격, 약점 조준, 특수 화살 상태 활용 |
| 약점 | 탄약, 시야선, 근접 압박, 이동 중 명중 안정성 |

바닐라 활 당기기는 시각 입력으로 활용할 수 있으나 피해·속도·탄약 소비는 서버가 확정한다.

탄창은 서버 데이터이며 바닐라 석궁 장전 상태만 표시 보조로 사용한다.

## 6.5 단검 — 근접 기동과 상태 누적

단검은 리소스 팩 전까지 검 계열 아이템을 쓰며 이름·로어·공격속도 UI로 명확히 구분한다.

## 6.6 둔기 — 광역 충격과 브레이크

| 약점 | 느린 공격, 높은 AP, 빠른 적 추적 취약 |

| 상태 | 짧은 둔화·취약·공중 띄움 후보 |

바닐라 철퇴 낙하 강타는 차단한다. 낙하·고도 연계가 필요하면 전조와 상한이 있는 커스텀 스킬로 별도 제공한다.

## 6.7 지팡이 — 범위·지원·원소 변환

| 항목 | 기준 |
|---|---|
| 핵심 태그 | `MAGIC`, `AREA`, `SUPPORT`, `ELEMENT` |
| 강점 | 넓은 범위, 상태 조합, 파티 지원과 지형 통제 |
| 약점 | AP 의존, 시전 중 취약, 단일 기본 공격 낮음 |
| AP 성향 | 높은 스킬 의존, 회복·지원 성공으로 자원 흐름 변경 |
| 브레이크 | 낮음, 상태이상 변환으로 보완 |
| 상태 | 화상·빙결·약화·보호·정화 |
| 회피 연계 | 회피가 채널링을 취소, 특정 증강만 잔류 영역 유지 |

MagicSpells는 투사체·빔·연출 후보로 사용할 수 있지만 최종 피해와 상태 적용은 WildSurvival이 처리한다.

## 6.8 곡괭이 — 전투·채집 전환과 구조 파쇄

| 항목 | 기준 |
|---|---|
| 핵심 태그 | `PICKAXE`, `PENETRATION`, `BREAK`, `UTILITY` |
| 강점 | 높은 브레이크, 방어 관통, 채집과 장비 슬롯 통합 |
| 약점 | 공격 범위 좁음, 상태·기동 선택 제한 |
| AP 성향 | 중간 비용, 약점·장갑 대상 적중 보상 |
| 브레이크 | 매우 높음 |
| 상태 | 방어력 감소·균열 표식 |
| 회피 연계 | 회피 후 짧은 전진 찌르기 또는 채굴 자세 해제 |

### 곡괭이 판정

1. 열린 GUI·시설·구조 상호작용을 검사한다.
2. 공격 가능한 개체 레이 트레이스를 수행한다.
3. 유효 개체가 있으면 블록 파괴를 취소하고 커스텀 공격을 실행한다.
4. 유효 개체가 없고 파괴 가능한 블록을 조준하면 바닐라 채굴을 허용한다.
5. 공격과 채굴이 같은 틱에 모두 처리되지 않도록 입력 sequence를 소비한다.

## 6.9 삼지창 — 중거리 전환과 회수 관리

| 상태 | 관통 표식·젖음 연계·끌어오기 후보 |
| 회피 연계 | 회피 방향과 투척 상태에 따라 회수 이동 또는 거리 조절 |

### 삼지창 커스텀 실행

- 바닐라 투척, 충성, 급류와 채널링 결과를 차단한다.
- `HELD`, `THROWN`, `RETURNING`, `RECOVERABLE` 상태를 서버에 저장한다.
- 투척체는 실행 ID와 장비 instance ID를 가진다.
- 청크 언로드·서버 종료 시 실제 투사체를 제거하고 저장 상태로 복구한다.
- 삼지창 분실을 장비 영구 소실로 사용하지 않으며 회수 실패는 AP·쿨타임·위치 손해로 처리한다.

## 6.10 권투 — 빈손 반응형 전투

| 항목 | 기준 |
|---|---|
| 핵심 태그 | `UNARMED`, `AGILE`, `COUNTER`, `COMBO` |
| 강점 | 아이템 불필요, 최고 반응성, 회피·패링·반격 연계 |
| 약점 | 최단 사거리, 낮은 기본 계수, 장비 옵션 슬롯 손해 |
| AP 성향 | 낮은 비용, 정확한 회피·반격 조건부 환급 |
| 브레이크 | 낮음~보통, 반격 또는 특수 자세로 보완 |
| 상태 | 짧은 경직·표식·도발 후보 |
| 회피 연계 | 핵심 성장 축, 연속 회피 무한화 상한 적용 |

### 권투 활성화

- `MAIN_WEAPON` 원장과 실제 슬롯 `0`이 모두 비어 있으면 자동 활성화한다.
- 권투용 가상 프로필만 사용하며 실제 아이템을 생성하지 않는다.
- 비무기 아이템을 손에 들게 허용하는 별도 시스템이 생기더라도 장비 원장 우선 정책을 유지한다.
- 장비 데이터가 손상돼 슬롯이 비어 보이는 경우 권투로 우회하지 않고 장비를 격리한다.

## 9. 필수 역할 방지 매트릭스

| 콘텐츠 요구 | 무기 대응 | 공용 대안 |
|---|---|---|
| 높은 브레이크 | 둔기, 곡괭이, 도끼 | 패링, 강한 CC 변환, 브레이크 소모품 |
| 장거리 약점 | 활, 석궁, 지팡이, 삼지창 | 동적 엄폐 접근, 공용 투척 도구 |
| 다수 적 제어 | 둔기, 지팡이, 검 | 환경 장치, 함정, 파티 증강 |
| 빠른 적 추적 | 단검, 권투, 삼지창 | 회피 접근 스킬, 둔화 소모품 |
| 방어력 높은 적 | 곡괭이, 도끼, 석궁 | 방어력 감소 상태, 패턴 약점 |
| 상태이상 적용 | 단검, 활, 지팡이 등 | 탄약·소모품·증강 |
| 정화·지원 | 지팡이 | 소모품, 시설, 파티 증강 |
| 패턴 중단 | 둔기, 곡괭이, 도끼 | 패링, 협동 누적, 기믹 상호작용 |

- 보스 필수 패턴은 무기 대응 하나와 공용 대안 하나 이상을 가진다.
- 파티 구성 검사로 보스 입장을 막지 않는다.
- 추천 무기는 표시할 수 있지만 `필수`로 표기하지 않는다.

## 10. 장비 등급과 무기 정체성

| 희귀도 | 무기 변화 방향 |
|---|---|
| 일반 | 핵심 일반 공격과 기본 액티브 |
| 고급 | 무기 핵심 태그 하나 강화 |
| 희귀 | 상태·AP·회피 중 보조 축 선택 |
| 영웅 | 빌드 분기와 증강 연계 옵션 |
| 전설 | 플레이 방식 변형, 명확한 조건·ICD |
| 심연 | 강한 대가와 오염·위험 연계, 하드캡 준수 |

희귀도가 올라가도 공격 사거리·대상 수·무적을 무제한 확대하지 않는다. 고등급은 수치 상승보다 조건과 빌드 구조를 변화시킨다.

## 13. 테스트 항목

- 10개 무기 동일 장비 점수에서 60초 단일·다수·브레이크 성능 비교
- AP 0 상태에서도 일반 공격으로 전투 지속

## 15. 완료 기준

- 10개 무기군의 강점·약점·일반 공격 기준과 AP 성향이 분리된다.
- 곡괭이·삼지창·권투의 특수 입력·상태가 구체적으로 정의된다.
- 단검과 둔기의 리소스 팩 전후 아이템 정책이 정의된다.
- 방패가 보조 슬롯 장비이며 주무기군이 아님이 명확하다.
- 모든 필수 전투 요구에 복수 무기와 공용 대안이 있다.
- 다음 실제 스킬·장비 목록을 작성할 공통 비교축이 마련된다.

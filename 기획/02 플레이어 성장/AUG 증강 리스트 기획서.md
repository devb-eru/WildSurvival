## 1. 공통 규칙

- 개인 증강 일정, 등급 잠금, 후보 3개, 리롤과 교체는 `AUG 시스템 상세 기획서`를 따른다.
- 개인 증강은 레벨 3·6·10·15·20·25·30·35·40·45에 총 10회 선택한다.
- 레벨 3은 실버, 6은 골드, 10은 프리즘이며 이후 등급은 마일스톤별 최초 도달자가 잠근다.
- 모든 효과는 선택 즉시 서버 데이터에 저장하고 재접속 시 복원한다.
- 아군 공격, 훈련용 대상, 운영자 소환물과 보상 비적용 개체로 발동 조건을 충족할 수 없다.
- 동일 실행에서 같은 증강은 한 번만 발동한다.
- 다단 공격은 별도 명시가 없으면 `시전당 1회` 또는 `초당 상한`을 사용한다.
- AP 환급 총량은 장비·증강 합산 초당 최대 25, 단일 행동에서 실제 소비 AP의 100%를 넘지 않는다.
- 강한 CC는 항상 3초 체인·감쇠·면역을 적용한다.
- 수치가 하드캡을 넘으면 원본을 보존하되 최종 효과는 시스템 하드캡을 따른다.

## 2. 태그와 후보 역할

| 후보 역할 | 설명 | 후보 3개 구성 목표 |
|---|---|---|
| `ANCHOR` | 현재 무기·최근 행동·보유 증강과 직접 연결 | 최소 1개 |
| `EXTENSION` | 보유 빌드 확장·진화·상태 소비 | 최소 1개 또는 진화 보장 |
| `BRIDGE` | 방어·AP·정화·범용 생존 | 무효 후보 방지용 최소 1개 |

후보 풀에 적합한 `ANCHOR`가 부족하면 무기 공명 템플릿을 사용한다. 모든 후보가 같은 태그에 과도하게 편향되면 세 번째 슬롯은 `BRIDGE`에서 뽑는다.

후보 생성 시 레벨 달성 스냅샷 또는 최근 2분 최다 사용 무기군에 맞춰 실제 ID를 생성한다. 한 플레이어는 같은 무기 공명을 한 번만 선택할 수 있다.

# 6. 진화 계열

진화는 기존 증강을 교체하며 선택 횟수 하나를 소비한다. 모든 핵심 계열은 등급 잠금에 대응할 수 있도록 실버·골드·프리즘 변형을 가진다.

| 계열 | 선행·증거 | 실버 변형 | 골드 변형 | 프리즘 변형 |
|---|---|---|---|---|
| F01 약점 해석 | `약점 기록`, 브레이크 5회 | 약점 기록+ | 파열 계산 | 붕괴 설계 |
| F02 회피 반격 | `짧은 반격`, 정확 회피 8회 | 반격 각인 | 완벽한 간격 | 불가침 궤도 또는 영점 회피 |
| F03 상태 촉매 | DOT 2종 조합 10회 | 반응 관찰 | 상태 촉매 | 원소 융합 |
| F04 탄약 순환 | 탄약 80발 유효 사용 | 예비 탄약+ | 탄약 조율 | 무한 탄창의 역설 |
| F05 삼지창 회수 | 투척·회수 적중 12회 | 삼지창의 공명+ | 관통 궤도-창 | 회귀하는 창 |
| F06 권투 반격 | 권투 정확 회피 반격 12회 | 권투의 공명+ | 맨손의 흐름 | 맨손의 증명 |
| F07 오염 적응 | 오염 단계 3 이상 생존 3회 | 정화 호흡+ | 정화 전환 | 오염 공생 |
| F08 구조 전문 | 구조 성공 5회 | 구조 본능+ | 구조 파동 | 마지막 구조선 |

### 등급별 대체 규칙

- 대기 진화의 잠긴 등급 변형이 있으면 후보 한 칸을 보장한다.
- 프리즘 계열에 두 갈래가 있으면 형제 진화 중 하나만 선택할 수 있다.
- 진화가 선행을 교체하므로 두 효과를 동시에 계산하지 않는다.
- 진화하지 않은 선행도 계속 유효하며 실패 빌드로 취급하지 않는다.

## 7. 중복·배타 그룹

| 그룹 | 정책 | 포함 예시 |
|---|---|---|
| `DODGE_REWARD_MAJOR` | 강한 배타 | 완벽한 간격, 연속 기동 |

| `AP_REFUND` | 초당 25 상한 | 독성 순환, 마력 환류, 패링 환급 |
| `BREAK_VULNERABILITY` | 보스 +10% 상한 | 파열 계산, 붕괴 설계, 파티 증강 |

### 파티 인원 감소 처리

- 증강은 회차 시작 등록 인원이 아니라 현재 생존 가능 인원에 맞춰 판정한다.
- `서로 다른 플레이어` 조건은 1인만 남으면 약화된 단독 효과를 명시한 경우만 유지한다.
- 인원 감소로 증강이 완전히 무효가 되면 기본적으로 절반 이하의 단독 보정을 제공한다.
- 정확한 파티 시너지별 생존 인원 보정은 후속 `PARTY-SYNERGY` 문서에서 최종 확정한다.

## 9. 파티 증강 후보 제한

- 현재 파티에 탄약 무기가 없으면 `탄약 공방` 가중치를 0으로 내린다.
- 시설이 없어도 `방어선 없는 방어`, `정화 순환망`은 유목 효과가 있으므로 유효하다.
- Day 30 이전에는 `재건의 합의`를 후보에서 제외한다.
- 완전 사망자가 있어도 `마지막 대형`을 강제로 후보에 넣지 않는다.
- 후보 3개 중 최소 2개는 현재 파티 구성에서 즉시 기능해야 한다.
- 생존자 투표가 동률일 때만 동률 후보에 사망자 표를 더하고, 여전히 동률이면 시드 난수로 결정한다.

## 10. 후보 가중치 예시

```text
최종 후보 가중치 =
기본 가중치
× 현재 무기 태그 가중치
× 최근 행동 태그 가중치
× 보유 증강 연결 가중치
× 중복 역할 감쇠
× 유효성 보정
```

| 조건 | 배율 기준 |
|---|---:|
| 현재·최근 주무기 태그 일치 | 1.50 |
| 보유 증강 2개 이상과 연결 | 1.35 |
| 진화 조건 충족 | 보장 슬롯 또는 2.00 |
| 같은 역할 증강 3개 이상 보유 | 0.65 |
| 약한 충돌 | 0.35~0.60 |
| 효과 일부만 유효 | 0.50 |
| 완전 무효 | 0, 후보 제외 |

가중치는 후보 다양성을 위한 것이며 원하는 증강을 확정 제공하지 않는다. 진화 최초 보장만 예외다.

## 11. 리롤·교체 비용 연결

| 기능 | 비용 기준 | 제한 |
|---|---|---|
| 개인 후보 리롤 | 증강 안정화 코어 1개 | 마일스톤당 1회, 등급 유지 |
| 일반 증강 교체 | 안정화 코어 2개 + 오염 촉매 1개 | 플레이어당 회차 1회 |
| 프리즘 교체 | 일반 비용 2배 | 해당 증강 데이터가 허용할 때만 |
| 진화 증강 교체 | 일반 비용 2배 | 선행 복원 여부를 GUI에 명시 |

- 비용은 파티 공용 원장에서 원자적으로 소비한다.
- 리롤 후 직전 후보 3개는 제외하고 진화 보장 슬롯은 유지한다.
- 교체 후보는 원래 선택 마일스톤의 잠긴 등급을 사용한다.

## 13. 밸런스 안전선

- 개인 증강 하나의 상시 피해 증가 권장 상한: 실버 8%, 골드 12%, 프리즘 22% 또는 명확한 대가
- 파티 전체 상시 피해 증가 권장 상한: 단일 증강 8%
- 보스 받는 피해 증가 전체 상한: +25%
- 보스 받는 브레이크 증가 전체 상한: +30%
- 탄약 미소비 최종 상한: 75%
- 회피 AP 환급은 회피 실제 비용을 초과하지 않음
- 구조·정화·시설 증강으로 고유 재료를 생성하지 않음
- 증강으로 Day·발견·보스·최종 진행 잠금을 건너뛰지 않음

## 14. 테스트 항목

- 모든 티어에서 유효 후보 3개 생성 가능
- 10개 무기군별 `ANCHOR` 후보 존재
- 무기 교체로 이미 생성된 후보 변경 불가
- 진화 보장 슬롯과 마일스톤 등급 일치
- 중복·강한 배타·약한 충돌 필터
- 다단 공격 AP·흡혈·상태 발동 상한
- 기본 아군 공격·훈련 대상으로 증강 발동 차단
- 1인 잔존 시 파티 증강 무효·대체 보정
- 시설 없는 파티의 파티 증강 유효성
- 리롤·교체 비용 중복 소비 방지
- 서버 재시작 후 후보·선택·ICD·진화 대기 복원
- Day 10·20·30·40 파티 투표와 사망자 후순위 동률 처리

## 15. 완료 기준

- 실버·골드·프리즘 개인 증강과 파티 증강의 1차 후보 풀이 존재한다.
- 10개 무기군과 범용 생존·지원·자원 태그가 모두 후보를 가진다.
- 진화, 배타, AP·다단 상한과 보상 악용 방지가 개별 효과에 연결된다.
- 시설 없는 파티와 인원 감소 상황에서도 후보 무효를 방지할 수 있다.
- 플러그인 이벤트와 스탯 modifier로 구현 가능한 효과만 사용한다.

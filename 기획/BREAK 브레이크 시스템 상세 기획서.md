# BREAK-001 브레이크 게이지 및 피해

## 1. 시스템 목적

브레이크 시스템은 보스와 엘리트에게 무한 CC를 직접 적용하지 않으면서도 플레이어의 제어, 패링, 집중 공격, 협동 대응이 의미 있게 쌓이도록 만든다.

- 상태이상 빌드가 보스전에서 완전히 무효화되지 않게 한다.
- 패링, 도끼, 강한 단일기, 기믹 성공이 보스 압박 수단이 되게 한다.
- 파티가 위험 패턴에 대응할 수 있는 공통 목표를 제공한다.
- 피해량만 높은 빌드와 브레이크 효율이 높은 빌드의 역할을 분리한다.
- 2~4인 인원 변화에 따라 브레이크 부담을 조정한다.

## 2. 적용 대상

| 대상 | 브레이크 게이지 | 기본 표시 | 비고 |
|---|---|---|---|
| 보스 | 사용 | 머리 위 상시 표시 | 페이즈와 기믹에 직접 연결 |
| 엘리트 | 사용 | 조준 중 또는 피해 직후 표시 | 일부 패턴 중단 가능 |
| 일부 일반 몬스터 | 선택 사용 | 기본 비표시 | 튜토리얼, 특수 적, 방어형 적에 사용 |
| 일반 몬스터 전체 | 기본 미사용 | 없음 | 필요 시 개별 적 데이터로 활성화 |
| 플레이어 | 미사용 | 없음 | 상태이상과 `STAGGER_RES`만 사용 |
| 구조물·기지 시설·소환물 | 구조만 지원 | 기본 비표시 | 추후 기믹용으로 열어둠 |

플레이어는 브레이크 게이지를 가지지 않는다. 플레이어에게는 상태이상, 넉백, `TENACITY`, `STAGGER_RES`를 사용한다.

## 3. 게이지 기본 구조

브레이크 게이지는 다음 구조를 사용한다.

```text
브레이크 게이지 = 현재 브레이크 누적치 / 최대 브레이크 게이지
```

- 현재 브레이크 누적치가 최대 브레이크 게이지 이상이 되면 `BREAK_SUCCESS` 이벤트가 발생한다.
- `BREAK_SUCCESS` 발생 후 실제 그로기, 패턴 중단, 게이지 초기화 방식은 `BREAK-002`에서 확정한다.
- 브레이크 게이지는 음수가 될 수 없다.
- 브레이크 피해는 음수가 되거나 브레이크 회복으로 변환되지 않는다.
- 같은 실행 ID의 브레이크 피해는 중복 적용 방지 규칙을 가진다.

## 4. 게이지 데이터

브레이크 가능 대상은 다음 데이터를 가진다.

| 필드 | 설명 |
|---|---|
| `break-enabled` | 브레이크 게이지 사용 여부 |
| `break-max-base` | 기본 최대 브레이크 게이지 |
| `break-current` | 현재 누적 브레이크 값 |
| `break-scale-group` | 보스, 엘리트, 일반 특수 적 등 스케일링 그룹 |
| `break-decay-policy` | 자연 감소 정책 |
| `break-save-policy` | 저장 및 복원 방식 |
| `break-on-phase-change` | 페이즈 전환 시 유지, 비율 유지, 초기화 여부 |
| `break-success-policy` | 성공 이벤트 후 처리 정책 |
| `break-resistance-profile` | `STAGGER_RES`, 패턴별 내성, 반복 패링 내성 |
| `break-ui-policy` | 표시 위치와 표시 조건 |

## 5. 최대 브레이크 게이지 산정

최대 브레이크 게이지는 적 데이터에 직접 입력한다.

```text
최대 브레이크 게이지 =
기본 최대 브레이크 게이지
× 인원 배율
× Day 스케일 배율
× 모드 배율
× 페이즈 보정
× 개체 변형 보정
```

### 인원 배율

인원 배율은 전투 시작 시점의 `전투 스케일 인원`을 기준으로 한다.

| 전투 스케일 인원 | 브레이크 게이지 배율 |
|---:|---:|
| 1인 | 0.75 |
| 2인 | 1.00 |
| 3인 | 1.25 |
| 4인 | 1.50 |

- 콘텐츠 기준 인원은 2~4인이다.
- 1인 배율은 진행 중 인원 손실이나 테스트를 위한 예외값이다.
- 전투 중 새 플레이어가 합류해 스케일 인원이 증가하면 최대 브레이크 게이지와 현재 브레이크 누적치를 같은 비율로 증가시킨다.
- 접속 종료, 빈사, 완전 사망으로 인원이 줄어도 현재 전투의 최대 브레이크 게이지는 낮아지지 않는다.

### Day 스케일 배율

브레이크 게이지에도 Day Scaling을 적용한다.

```text
일반 Day 브레이크 배율 =
1 + 일반 Day 브레이크 성장률 × (현재 Day - 1)

보스 Day 브레이크 배율 =
1 + 보스 Day 브레이크 성장률 × (현재 Day - 1)
```

| 대상 | 기본 성장률 |
|---|---:|
| 일부 일반 몬스터 | Day당 +1.5% |
| 엘리트 | Day당 +2.0% |
| 보스 | Day당 +2.5% |

- 실제 Day 1~10 수직 완성본에서는 적 데이터별로 성장률을 오버라이드할 수 있다.
- Day Scaling은 브레이크 게이지를 높이지만, 브레이크 피해 자체를 자동으로 높이지 않는다.

### STANDARD와 CHAOS

난이도별 Easy, Normal, Hard, Challenge, ??? 배율은 브레이크 게이지에 직접 적용하지 않는다. 대신 STANDARD 모드와 CHAOS 모드는 별도의 규칙 모드를 가진다.

| 모드 | 처리 |
|---|---|
| STANDARD | 일반 숫자 범위와 기본 성장률 사용 |
| CHAOS | BigNumber 브레이크 게이지와 별도 성장률 사용 |

CHAOS 모드의 브레이크 게이지와 브레이크 피해는 BigNumber 수 저장 방식을 사용한다. CHAOS 모드의 실제 성장률은 CHAOS 전용 밸런스 문서에서 확정하되, 데이터 구조는 `mode-values.chaos`에 별도로 둔다.

## 6. 게이지 자연 감소

브레이크 게이지는 대상 등급에 따라 자연 감소 정책을 다르게 사용한다.

| 대상 | 기본 자연 감소 |
|---|---|
| 일부 일반 몬스터 | 사용 |
| 엘리트 | 사용 |
| 보스 | 기본 미사용, 보스별로 매우 느린 감소 선택 가능 |

공통으로 마지막 브레이크 피해를 받은 뒤 7초가 지나야 자연 감소가 시작된다.

### 기본 감소값

| 대상 | 감소 시작 | 감소량 |
|---|---:|---:|
| 일부 일반 몬스터 | 7초 후 | 최대 게이지의 초당 20% |
| 엘리트 | 7초 후 | 최대 게이지의 초당 12% |
| 보스 선택 감소 | 7초 후 | 최대 게이지의 초당 0.5% |

- 보스는 기본적으로 전투 중 브레이크 게이지가 자연 감소하지 않는다.
- 보스별 패턴 설계상 장기 누적을 막아야 할 때만 선택 감소를 활성화한다.
- 자연 감소는 `BREAK_SUCCESS` 직전 누적치를 0 미만으로 만들 수 없다.
- 세션에 아무도 없어 Day가 정지하면 자연 감소도 정지한다.

## 7. 저장과 페이즈 처리

- 보스와 엘리트의 현재 브레이크 게이지는 저장한다.
- 세션 중단 후 이어하기에서는 현재 브레이크 게이지를 복원한다.
- 보스전 재시도 정책이 별도로 존재하면 해당 보스의 전투 상태 저장 정책을 따른다.
- 페이즈 전환 시 브레이크 게이지는 유지한다.
- 페이즈 전환으로 최대 브레이크 게이지가 바뀌면 현재 브레이크 비율을 유지한다.

```text
페이즈 전환 후 현재 브레이크 =
새 최대 브레이크 게이지 × 이전 현재 브레이크 비율
```

페이즈 전환 연출 중 브레이크 성공 처리가 겹치면 페이즈 전환을 우선하고, 브레이크 성공 이벤트는 보스 데이터의 `phase-break-carry-policy`에 따라 보류 또는 무효화한다.

## 8. 브레이크 피해 종류

| 종류 | 설명 | 보정 적용 |
|---|---|---|
| 일반 브레이크 피해 | 스킬, 일반 공격, 패링, 장비 효과로 발생 | `BREAK_DAMAGE`, `STAGGER_RES` 적용 |
| 상태 변환 브레이크 피해 | 보스에게 직접 적용되지 않는 강한 CC가 변환됨 | 기본적으로 일반 브레이크 피해로 처리 |
| 고정 기믹 브레이크 | 기믹 성공, 특정 오브젝트 상호작용 | 보정 무시 |
| 패턴 강제 중단 | 특정 패턴을 끊는 스크립트 효과 | 보정 무시 |
| 아군 브레이크 피해 | 아군 대상 공격으로 발생 | 50%, 보상 미반영 |

## 9. 일반 브레이크 피해 공식

기존 STAT 문서의 공식을 확정한다.

```text
최종 일반 브레이크 피해 =
기본 브레이크 피해
× (1 + BREAK_DAMAGE)
× 100 / (100 + 대상 STAGGER_RES)
```

| 항목 | 규칙 |
|---|---:|
| `BREAK_DAMAGE` 증가 상한 | +300% |
| `STAGGER_RES` 하드캡 | 80 |
| `STAGGER_RES 80`의 받는 브레이크 피해 | 55.56% |
| 아군 대상 브레이크 피해 | 최종값의 50% |

- `BREAK_DAMAGE`는 장비, 증강, 스킬 효과, 버프로 증가할 수 있다.
- `STAGGER_RES`는 몬스터와 일부 소환물의 받는 브레이크 피해를 줄인다.
- 고정 기믹 브레이크와 패턴 강제 중단은 `BREAK_DAMAGE`, `STAGGER_RES`를 모두 무시한다.
- 브레이크 피해는 음수로 내려가지 않으며, 회복으로 변환되지 않는다.
- BigNumber 대상에게도 같은 연산 순서를 사용한다.

## 10. 상태이상 변환 브레이크 피해

보스에게 직접 적용되지 않는 `HARD_CC`, 강한 `ROOT`, 강한 `FORCED_MOVE`는 브레이크 피해로 변환된다.

침묵과 무장 해제 같은 `SOFT_CC`는 브레이크 피해로 변환하지 않는다. 보스에게는 `REDUCED`, `SCRIPTED`, `IMMUNE` 중 하나로 처리한다.

### 변환 공식

```text
상태 변환 기본 브레이크 피해 =
대상 최대 브레이크 게이지
× 모드별 변환 계수
× 저항 전 지속시간
× 강도 계수
× 상태별 변환 보정
```

이후 일반 브레이크 피해와 동일하게 `BREAK_DAMAGE`, `STAGGER_RES`를 적용한다.

```text
최종 상태 변환 브레이크 피해 =
상태 변환 기본 브레이크 피해
× (1 + BREAK_DAMAGE)
× 100 / (100 + 대상 STAGGER_RES)
```

### 기본 계수

| 모드 | 변환 계수 |
|---|---:|
| STANDARD | 최대 브레이크 게이지의 초당 1.5% |
| CHAOS | 최대 브레이크 게이지의 초당 1.0% |

`저항 전 지속시간`은 상태이상이 보스 정책으로 변환되기 전, 스킬 데이터와 상태별 최대 지속시간 제한을 적용한 값을 사용한다. RES와 TENACITY는 직접 적용하지 않는다.

### 강도 계수

```text
강도 계수 =
clamp(상태 강도 / 상태 기준 강도, 0.50, 2.00)
```

- 상태 강도가 명시되지 않은 기절, 수면 같은 상태는 강도 계수 1.00을 사용한다.
- 공중 띄움, 끌어당김, 밀쳐내기처럼 이동 벡터 강도가 있는 상태는 상태 기준 강도를 데이터에 명시한다.
- 강한 속박은 이동 차단 강도를 1.00으로 본다.
- 상태별 변환 보정은 기본 1.00이며, 특정 보스나 상태가 더 강하거나 약하게 환산되어야 할 때만 오버라이드한다.

### 변환 예시

```text
보스 최대 브레이크 게이지: 10,000
STANDARD 변환 계수: 1.5%
저항 전 지속시간: 2초
강도 계수: 1.00
STAGGER_RES: 20
BREAK_DAMAGE: +50%

상태 변환 기본 브레이크 피해 =
10,000 × 0.015 × 2 × 1.00 = 300

최종 상태 변환 브레이크 피해 =
300 × 1.5 × 100 / 120 = 375
```

## 11. 패링 브레이크 피해

패링 성공 시 브레이크 피해는 COMBAT 문서의 권장 배율을 확정한다.

| 공격 유형 | 패링 성공 시 브레이크 처리 |
|---|---|
| 일반 적 약한 공격 | 즉시 경직 또는 소량 브레이크 |
| 일반 적 강한 공격 | 높은 경직 또는 높은 브레이크 |
| 엘리트 일반 공격 | 해당 공격 기본 브레이크 피해의 150% |
| 엘리트 강한 공격 | 해당 공격 기본 브레이크 피해의 200% |
| 보스 일반 공격 | 해당 공격 기본 브레이크 피해의 100% |
| 보스 패링 유도 패턴 | 고정된 높은 브레이크 피해 또는 패턴 중단 |

- 같은 공격 실행 ID를 여러 플레이어가 동시에 패링해도 공격자 브레이크 피해는 최초 유효 패링만 전체 적용한다.
- 아군 공격을 패링하면 피해와 부가 효과는 무효화하지만 AP 환급, 브레이크, 반격 강화는 발동하지 않는다.
- 보스의 모든 공격을 패링 브레이크 대상으로 만들지는 않는다.

### 반복 패링 내성

같은 보스 패턴을 반복 패링하면 패턴별 브레이크 내성이 증가한다.

| 같은 패턴 반복 패링 | 브레이크 피해 배율 |
|---:|---:|
| 1회 | 100% |
| 2회 | 70% |
| 3회 | 40% |
| 4회 이상 | 20% |

- 반복 패링 내성은 패턴 ID별로 관리한다.
- 마지막 해당 패턴 패링 후 30초가 지나면 1단계씩 회복한다.
- 페이즈 전환 시 패턴별 내성은 보스 데이터에 따라 유지 또는 초기화한다. 기본값은 유지다.
- 패링 유도 패턴은 내성 적용 여부를 패턴별로 지정할 수 있다.

## 12. 아군 브레이크와 보상 악용 방지

| 항목 | 처리 |
|---|---|
| 아군 대상 브레이크 피해 | 최종값의 50% |
| 아군 대상 고정 기믹 브레이크 | 기본 미적용 |
| 아군에게 준 브레이크 피해 | 기여도, 활동 EXP, 보상 자격 미반영 |
| 아군 패링 | 피해와 부가 효과만 무효, 브레이크 보상 없음 |

아군 브레이크 피해는 협동 이동, 연출, 특수 기믹에 활용할 수 있지만 보상 체계에는 반영하지 않는다.

## 13. 기여도와 보상

적에게 준 유효 브레이크 피해는 기여도에 반영한다. 단, HP 피해와 같은 가중치를 사용하지 않는다.

```text
브레이크 기여도 =
유효 브레이크 피해
× 대상 브레이크 중요도
× 브레이크 기여 가중치
```

| 대상 | 대상 브레이크 중요도 |
|---|---:|
| 일부 일반 몬스터 | 0.25 |
| 엘리트 | 0.60 |
| 보스 | 1.00 |

| 항목 | 기본값 |
|---|---:|
| 브레이크 기여 가중치 | HP 피해 기여도의 40% |
| 고정 기믹 브레이크 기여 | 보스별 기믹 기여도로 별도 계산 |
| 아군 브레이크 기여 | 0 |

브레이크 성공 막타 보너스는 기본적으로 두지 않는다. 파티 협동 목표이므로 누적 기여를 더 중요하게 계산한다.

## 14. 브레이크 성공 보상

브레이크 성공 시 생존 파티원 전원에게 AP를 회복시킨다.

```text
브레이크 성공 기본 AP 회복 =
각 플레이어 최대 AP × 20%
```

- 회복 대상은 브레이크 성공 시점의 생존 파티원 전원이다.
- 빈사, 완전 사망, 관전 상태 플레이어는 기본 회복 대상이 아니다.
- AP 회복은 각 플레이어의 현재 최대 AP를 기준으로 계산한다.
- 파티 증강, 장비 효과, 버프의 브레이크 성공 AP 회복은 기본 회복과 별도로 중첩된다.
- 예시 증강 `브레이크 성공 시 생존 파티원 AP 15 회복`은 기본 20% 회복 후 별도로 적용한다.
- AP 최대값을 초과해 회복할 수 없다.

## 15. 브레이크 성공 이벤트

`BREAK-001`에서는 성공 이벤트까지만 정의한다.

```text
BREAK_SUCCESS 이벤트 발생 조건 =
현재 브레이크 누적치 >= 최대 브레이크 게이지
```

이벤트는 다음 정보를 포함한다.

| 필드 | 설명 |
|---|---|
| `target-id` | 브레이크된 대상 |
| `target-type` | 보스, 엘리트, 일반 특수 적 |
| `break-current` | 성공 시점 누적치 |
| `break-max` | 성공 시점 최대 게이지 |
| `trigger-source` | 마지막 브레이크 피해 출처 |
| `contributors` | 브레이크 기여자 목록 |
| `mode` | STANDARD 또는 CHAOS |
| `phase-id` | 보스 페이즈 |
| `script-flags` | 패턴 중단, 그로기 가능 여부 등 |

`BREAK_SUCCESS` 이후의 그로기 지속시간, 패턴 중단, 보스 다운 연출, 게이지 초기화와 내성 증가는 `BREAK-002`에서 확정한다.

## 16. UI 표시

| 대상 | 표시 방식 |
|---|---|
| 보스 | 몹 머리 위에 브레이크 게이지 상시 표시 |
| 엘리트 | 조준 중이거나 피해를 준 직후 일정 시간 표시 |
| 일부 일반 몬스터 | 기본 비표시, 설정 또는 기믹으로 표시 가능 |
| 구조물·시설·소환물 | 기본 비표시 |

### 보스 표시

- 보스 머리 위에 현재 브레이크 비율을 표시한다.
- 표시 색상은 낮음, 중간, 임박, 성공 가능 상태를 구분한다.
- 패링 유도 패턴이나 브레이크 취약 패턴 중에는 게이지 색상 또는 테두리를 강조한다.
- 보스 바는 HP, 페이즈, 위험 전조에 우선 사용하고, 브레이크는 머리 위 표시를 기본으로 한다.

### 엘리트 표시

- 조준 중이거나 최근 5초 안에 피해 또는 브레이크 피해를 준 경우 표시한다.
- 게이지가 80% 이상이면 파티원에게도 짧게 강조할 수 있다.
- 일반 몬스터의 브레이크 게이지는 기본 비표시로 한다.

## 18. 예외 처리

| 상황 | 처리 |
|---|---|
| 대상이 브레이크 게이지를 가지지 않음 | 브레이크 피해 무시 |
| 브레이크 피해가 0 이하 | 적용하지 않음 |
| 대상이 무적 페이즈 | 브레이크 피해도 무효 또는 저장, 보스 데이터에 따름 |
| 페이즈 전환 중 브레이크 성공 | 페이즈 전환 우선, 성공 이벤트는 보류 또는 무효 |
| 같은 실행 ID 중복 적중 | 스킬의 다단 규칙과 브레이크 ICD를 따른다 |
| 서버 중단 | 저장 정책에 따라 현재 게이지 복원 |
| BigNumber 게이지 | 같은 공식, BigNumber 연산 서비스 사용 |
| 아군 브레이크 | 50% 적용, 보상과 기여도 미반영 |

|---|---|

| 전투 중 인원 증가 | 최대치와 현재치 같은 비율 증가 검증 |

| 고정 기믹 브레이크 | 보정 무시 검증 |
| 상태 변환 브레이크 | 지속시간과 강도 계수 환산 검증 |
| 패링 브레이크 | 공격 유형별 배율 검증 |

| 브레이크 성공 AP 회복 | 생존 파티원 전원 최대 AP 20% 회복 검증 |
| UI 표시 | 보스 머리 위 상시 표시, 엘리트 조건부 표시 검증 |

## 20. BREAK-001 완료 기준

- 브레이크 적용 대상과 비적용 대상이 구분되어 있다.
- 브레이크 게이지 구조, 최대치 산정, 인원 배율, Day Scaling이 정의되어 있다.
- STANDARD와 CHAOS의 브레이크 수치 구조가 분리되어 있다.
- 자연 감소, 저장, 페이즈 전환 시 유지 규칙이 정의되어 있다.
- 일반 브레이크 피해 공식과 `BREAK_DAMAGE`, `STAGGER_RES` 적용 여부가 확정되어 있다.
- 상태이상 변환 브레이크 피해 공식이 정의되어 있다.
- 패링 브레이크 배율과 반복 패링 내성이 정의되어 있다.
- 브레이크 기여도, AP 회복 보상, UI 표시 정책이 정의되어 있다.
- 실제 그로기와 패턴 중단은 `BREAK-002`로 분리되어 있다.

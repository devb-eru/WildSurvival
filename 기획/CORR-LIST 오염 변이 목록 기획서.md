# WildSurvival CORR-LIST 오염 변이 목록 기획서

## 문서 정보

- 문서 ID: `CORR-LIST-001`
- 상태: 1차 목록 확정안
- 선행 문서: `CORR`, `STATUS`, `BREAK`, `CONTENT`, `EVENT`, `AUG`
- 구현 전제: Minecraft Java Edition 바닐라 클라이언트 + Paper 플러그인, 모드 미사용

## 1. 목적

오염 변이는 적의 체력과 공격력을 일괄 증폭하는 수단이 아니라, 이미 알고 있는 적의 행동을 다른 방식으로 읽고 대응하게 만드는 전투 규칙이다. 변이는 반드시 눈에 보이는 전조, 둘 이상의 대응 방법, 제한된 효과 예산을 가진다.

- 특정 무기, 특정 증강 또는 고정 시설을 요구하지 않는다.
- 적 증강과 오염 변이는 서로 다른 슬롯으로 관리한다.
- 같은 전투 축을 중복 강화하는 조합은 배제하거나 예산을 크게 올린다.
- 보스 핵심 전조, 위험 범위와 구조 가능 여부를 가리지 않는다.
- 플레이어에게 적용하는 제어는 `STATUS`의 연속 CC 방지 규칙을 그대로 따른다.

## 2. 변이와 적 증강의 구분

| 구분 | 오염 변이 | 적 증강 |
|---|---|---|
| 발생 근거 | Day, 세계·지역 오염, 사건 | 최초 달성자가 잠근 개인 증강 등급 |
| 주요 역할 | 행동 패턴·공간·대응 방식 변화 | 전투 빌드 축의 제한적 강화 |
| 등급 | 경미·위험·극성 | 실버·골드·프리즘 |
| 슬롯 | 변이 슬롯 | 적 증강 슬롯 |
| 공개 | 외형 단서 후 조우 시 이름 공개 | 생성 시 등급과 핵심 효과 표시 |
| 중복 제한 | 상충표와 위협 예산 사용 | `AUG`의 적 증강 상한 사용 |

하나의 적이 두 체계를 동시에 가질 수는 있으나, 동일 효과 축을 겹치지 않는다. 예를 들어 `적응 갑피` 변이와 방어형 적 증강을 동시에 부여하거나, `침묵 포효`와 스킬 봉쇄형 증강을 함께 부여하지 않는다.

## 3. 변이 등급과 위협 예산

| 등급 | 비용 | 설계 범위 | 기본 대상 |
|---|---:|---|---|
| 경미 `MINOR` | 1 | 한 행동의 변형, 약한 상태 또는 짧은 공간 압박 | 일반·정예 |
| 위험 `MAJOR` | 2 | 새로운 패턴 하나와 명확한 대응 창 | 정예·보스 소환체 |
| 극성 `POLAR` | 3 | 전투 흐름을 바꾸는 복합 기믹 | 희귀 정예·보스 전용 |

### Day별 일반 예산

| Day | 일반 적 | 정예 | 보스·특수 개체 |
|---|---:|---:|---:|
| 1~7 | 0 | 0~1 | 패턴에 명시된 변이만 |
| 8~10 | 0~1, 매우 낮은 확률 | 1 | 최대 1 |
| 11~20 | 0~1 | 1~2 | 최대 2 |
| 21~30 | 0~1 | 2~3 | 최대 3 |
| 31~40 | 0~2 | 3~4 | 최대 4 |
| 41~50 | 1~2 | 4~5 | 최대 5 |

- 세계·지역 오염은 후보 가중치와 예산 사용 확률을 높일 뿐, 표의 최대치를 넘기지 않는다.
- 일반 적에게 `POLAR`를 부여하지 않는다.
- 같은 종류의 일반 적 무리가 모두 같은 변이를 갖지 않도록 군집 내 동일 조합 비율을 60% 이하로 제한한다.
- 적 증강 1개가 추가될 때 변이 가용 예산을 1 줄인다. 프리즘 적 증강은 2 줄인다.
- 보스는 무작위 변이보다 보스 문서에 고정된 변이 슬롯을 우선한다.

## 4. 공통 판독 규칙

변이 개체는 리소스 팩 없이도 다음 세 채널 중 최소 두 개로 구분해야 한다.

1. 장비 또는 블록 표현: 염색 가죽, 머리 장비, 들고 있는 바닐라 아이템
2. 파티클·소리: 변이별 고유 조합, 초당 출력 상한 적용
3. 이름표·HUD: 조우 전 현상 단서, 조우 후 변이명과 핵심 대응 태그

- 즉사 가능 패턴은 최소 1.2초, 강한 CC는 최소 0.8초, 일반 위험 패턴은 최소 0.5초의 전조를 둔다.
- 전조 도중 대상이 보이지 않으면 소리와 지면 표시를 함께 제공한다.
- `BLIND`나 화면 방해 변이는 보스 전조, 구조 대상, 탈출 경로 표식을 숨길 수 없다.
- 색상만으로 구분하지 않고 아이콘·입자 모양·소리를 함께 사용한다.

## 11. 상충과 중복 제한

### 강한 배타

다음 조합은 같은 개체에 부여하지 않는다.

- `MUT_CARAPACE` + 방어형 적 증강
- `MUT_BREAK_SHELL` + 브레이크 게이지 증가형 적 증강
- `MUT_SILENCE_CRY` + 스킬 봉쇄형 적 증강
- `MUT_DISARM_TENDRIL` + 무기 봉쇄형 적 증강
- `MUT_HEAL_BLIGHT` + 추가 회복 감소형 적 증강
- `MUT_PHASE_STEP` + 투사체 완전 무효형 효과
- `MUT_VOLATILE_CORPSE` + `MUT_LARVAL_RELEASE`
- `MUT_PURIFIER_JAMMER` + `MUT_FACILITY_CORRODER`
- `MUT_SIGNAL_SCRAMBLER` + 전조·표식 은폐 효과
- `MUT_RESCUE_HUNTER` + 구조 행동 자체를 봉쇄하는 패턴

### 군집 제한

- 같은 전투 무리에 `HEAL_BLIGHT`, `AP_STATIC`, `MIST` 오라는 각각 최대 1체만 둔다.
- 사망 반응 변이는 한 무리의 35% 이하만 보유한다.
- `PURIFIER_JAMMER`, `FACILITY_CORRODER`, `RESOURCE_LEECH`는 목표물 하나당 동시에 1체만 활성화한다.
- 강한 CC를 직접 부여하는 변이가 추가되면 그 적의 다른 상태 변이는 약화·DOT 중 하나만 허용한다.

## 12. 적 역할별 허용 규칙

| 적 역할 | 선호 변이 | 금지 또는 제한 |
|---|---|---|
| 추적자 | 측면 질주, 열상 발톱, 군체 연결 | 잠복과 균열 걸음 동시 금지 |
| 원거리 | 적응 갑피, 시야 균사, 오염 표식 | 투사체 완전 무효 효과 금지 |
| 방어자 | 충격 외피, 반격 가시, 공생 보호핵 | 방어 축 2개 동시 금지 |
| 제어자 | 침묵 포효, 탈진 흡수, 잔류 포자 | 직접 강한 CC는 별도 예산 2 사용 |
| 지원자 | 재생 안개, 회복 침식, 군체 연결 | 지원 오라 2개 동시 금지 |
| 시설 공격자 | 정화 방해파, 시설 부식자 | 플레이어를 무시하는 상시 시설 공격 금지 |
| 소환체 | 불안정 사체, 잔류 포자 | 보상·경험치·추가 소환 연쇄 금지 |

어떤 역할도 특정 무기군만으로 대응하도록 만들지 않는다. 근접, 원거리, 상태, 브레이크, 이동, 시설·소모품 중 최소 두 축이 유효해야 한다.

## 13. 정예와 보스 적용

### 정예

- 변이 이름을 체력 표시 옆에 공개한다.
- `MAJOR` 이상 변이마다 최소 한 번의 독립된 대응 창을 보장한다.
- 무작위 변이로 얻은 스킬은 정예 기본 패턴의 최소 간격을 침범하지 않는다.
- 드랍 표본은 실제 보유 변이 ID와 묶어 중복 지급을 방지한다.

### 보스

- 보스의 변이는 페이즈 설계에 고정하고 회차마다 전면 무작위화하지 않는다.
- 무작위 슬롯이 있다면 후보 3개를 전투 시작 전에 공개하고 위협 예산 2 이내에서만 선택한다.
- 변이는 `UNINTERRUPTIBLE`, 페이즈 전환, 즉사 패턴 같은 보스 핵심 규칙보다 우선하지 않는다.
- `HARD_CC`, 강한 `ROOT`, 강제 이동은 `BREAK`의 변환 또는 보스별 정책을 따른다.
- 그로기 시간 감소, 그로기 피해 보너스 무효, 브레이크 게이지 초기화 같은 변이는 사용하지 않는다.

## 14. 변이 선택 파이프라인

1. 적 템플릿과 역할로 허용 후보를 만든다.
2. Day와 세계 오염으로 해금되지 않은 후보를 제거한다.
3. 현재 사건, 시설·균열·자원 노드 문맥에 맞지 않는 후보를 제거한다.
4. 이미 부여된 적 증강 및 고정 패턴과 강한 배타를 검사한다.
5. 무리 전체의 오라·사망 반응·시설 교란 상한을 검사한다.
6. 남은 위협 예산 안에서 가중 추첨한다.
7. 동일 조합 반복 방지를 위해 최근 5개 정예 조합에 등장한 후보 가중치를 50% 낮춘다.
8. 판독 표현을 구성할 수 없는 조합이면 해당 후보를 버리고 다시 선택한다.
9. 결과와 난수 문맥을 생성 원장에 기록한다.

후보가 부족하면 예산을 억지로 채우지 않는다. 변이 없음은 정상 결과다.

## 16. Paper 플러그인 구현 범위

- 커스텀 속성, 재사용 대기시간, 상태 부여와 브레이크 처리는 서버 플러그인이 최종 권한을 가진다.
- 변이 메타데이터는 엔티티 PDC와 회차 DB에 저장하되, 재시작 후 템플릿에서 다시 구성한다.
- 이동 변이는 Paper 경로 탐색과 제한된 속도·벡터 제어를 사용한다. 블록을 통과하는 장시간 무적 이동은 사용하지 않는다.
- 시각 표현은 바닐라 파티클, 사운드, 장비, 글로잉, 이름표와 보스바로 구성한다.
- 반경 검사는 공간 인덱스와 활성 청크만 사용하고, 매 틱 전 월드 엔티티 탐색을 금지한다.
- 오라는 5틱, 시설·자원 문맥 검사는 20틱 이상의 주기로 분산 처리한다.
- 서버 TPS가 저하되면 장식 파티클과 비핵심 오라 갱신 빈도를 낮추되 전조 판정과 피해 판정은 유지한다.

## 17. 밸런스 안전장치

- 변이만으로 적의 최대 HP를 올리지 않는다.
- 피해 증가가 필요한 패턴은 개별 공격 계수로만 정의하며 변이 총 기대 DPS 증가는 기본 템플릿 대비 25% 이내로 둔다.
- 이동 불가 또는 행동 불가를 만드는 단일 변이의 저항 전 지속시간은 2초 이하로 둔다.
- AP 직접 감소는 1회 최대 12, AP 비용 증가는 스킬당 최대 5로 제한한다.
- 회복 감소는 단일 변이 최대 25%, 오염·상태 시스템 전체 상한은 `STATUS`를 따른다.
- 시설 출력 저하는 단일 변이 최대 20%, 중첩 불가이며 파괴 대신 수리·유인·처치 대안을 둔다.
- 사망 반응은 다른 사망 반응을 연쇄 발동하지 않는다.
- 변이 적이 디스폰되거나 사건이 종료되면 예약 공격, 오라, 시설 저하와 표식을 정리한다.

## 18. 테스트 항목

### 규칙

- Day 이전 후보가 등장하지 않는가
- 예산, 역할 허용, 강한 배타와 군집 제한이 항상 지켜지는가
- 최초 달성자 등급 잠금에 따른 적 증강과 변이가 별도 슬롯으로 처리되는가
- 적 증강 추가 시 변이 예산이 올바르게 줄어드는가
- 후보 부족 시 무한 재추첨 없이 변이 없음으로 종료되는가

### 전투

- 모든 `MAJOR`·`POLAR` 변이에 둘 이상의 실전 대응 방법이 있는가
- 10개 무기군 중 어느 하나도 필수 대응 수단이 되지 않는가
- 강한 CC와 침묵·무장 해제가 `STATUS`의 체인 면역을 우회하지 않는가
- 브레이크 변이가 그로기 보상을 삭제하거나 게이지를 임의 초기화하지 않는가
- 빈사자 구조를 압박하되 구조 입력 자체를 잠그지 않는가

### 판독과 성능

- 리소스 팩 없이 변이 전조와 핵심 대응 태그를 구분할 수 있는가
- 색각 이상 환경에서도 소리·모양·텍스트로 구분 가능한가
- 시야 방해 중 보스 전조와 구조 표식이 유지되는가
- 변이 다수 전투에서 오라·반경 검사가 TPS 예산을 지키는가
- 재시작 후 예약 패턴과 오라가 중복 복원되지 않는가

## 19. 완료 기준

- Day 8~50에 사용할 실제 변이 후보가 ID, 예산, 해금 Day와 함께 정의되어 있다.
- 변이와 적 증강의 책임, 슬롯, 예산과 중복 제한이 분리되어 있다.
- 각 변이에 판독 표현과 복수 대응 수단이 있다.
- 상태이상, 브레이크, 시설, 사건과의 상충 규칙이 있다.
- 바닐라 클라이언트와 Paper 플러그인만으로 구현할 수 있다.

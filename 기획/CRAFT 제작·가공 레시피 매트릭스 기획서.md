### 2.1 인원 보정

표는 GAME-003의 공용 재료 보상 배율을 3인 기준으로 정규화한 값이다.

| 전투 스케일 인원 | 표 적용 배율 | 개인 소비량 기준 |
|---:|---:|---:|
| 2인 | 0.80 | 0.67 |
| 3인 | 1.00 | 1.00 |
| 4인 | 1.20 | 1.33 |

- 최종 기대값은 항목별로 내림하되, 핵심 호출 재료는 발견 보상으로 최소 1개를 보장할 수 있다.
- 난이도는 직접 드롭량을 깎지 않는다. 높은 난이도는 획득 과정의 위험과 소모품 지출을 증가시킨다.
- 4인 파티는 소비 증가가 보상 증가보다 크므로 역할 분담과 장비 우선순위가 필요하다.

### 2.3 적응형 대체 보급

Day 4와 Day 8 정산 직전에 아래 예측을 수행한다.

```text
생존 재료 충족률 =
(현재 섬유 + 가죽 + 식량 배급 + 확정 대기열 출력)
/ (다음 정산까지의 필수 소비 + 복구 예비량)
```

- 충족률이 115% 미만이면 다음 Day의 자연 활동 후보에 `생존자 채집 흔적`을 강제 1회 포함한다.
- 완료 보상은 섬유 8, 가죽 4, 식량 배급 6이며 3인 기준이다. 2·4인은 공용 재료 배율을 적용한다.
- 이 보상은 세 항목 합계 18을 배율 적용 후 내림하고, 섬유→식량→가죽 순 최대잔여법으로 정수 배분한다. 따라서 4인은 총 21단위를 받는다.
- 한 회차 Day 1~10에서 최대 2회만 발생한다.
- 이 사건은 활동 EXP, 고유 장비, 변이·증강 표본을 지급하지 않는다.
- 완료하지 않아도 핵심 발견이 잠기지는 않지만 GUI에 예상 부족량을 표시한다.
- 일반 자원 충족률이 회복되면 후보 강제와 경고를 즉시 해제한다.

이 경로는 자원을 잃은 파티를 보정하기 위한 것이 아니라 4인·고난도에서 보장 하한과 필수 소비가 지나치게 가까워지는 상황을 완화한다.

| `WSRCP-G02` | 보스 신호 코어 | 철 4, 구리 8, 금 2, 회로 8, 마력 결정 1, 오염 조직 2 | 휴대 분석기 | 120초 | C07 | 파티 |

- 호출 세트는 Day 10 이전에 조립할 수 있지만 활성화할 수 없다.
- 보스 전장 후보 검증이 끝나기 전에는 호출 세트를 소비하지 않는다.
- 신호 말뚝은 회수 전 재사용할 수 없으며 활성 전장 원장에 귀속한다.

## 8. 공용 제작 대기열

### 8.1 작업 상태

```text
VALIDATING
→ RESERVED
→ QUEUED
→ RUNNING
→ OUTPUT_READY
→ CLAIMED
```

예외 상태는 `PAUSED_FACILITY`, `PAUSED_SESSION`, `CANCEL_PENDING`, `ROLLBACK_PENDING`, `FAILED_VALIDATION`이다.

| 상태 | 자원 | 시간 | 출력 |
|---|---|---|---|
| VALIDATING | 미예약 | 미진행 | 없음 |
| RESERVED | 원장 예약, 사용 불가 | 미진행 | 없음 |
| QUEUED | 예약 유지 | 미진행 | 없음 |
| RUNNING | 소모 단계별 확정 | 경과시간 저장 | 중간품 가능 |
| OUTPUT_READY | 입력 소모 확정 | 완료 | 가상 보상함 보관 |
| CLAIMED | 트랜잭션 종료 | 완료 | 소유자·파티에 지급 |

### 8.2 슬롯과 순서

| 설비 | 동시 작업 | 대기열 상한 | 기본 순서 |
|---|---:|---:|---|
| 휴대 제작 꾸러미 | 요청자별 1 | 요청자별 4 | 개인 FIFO |
| 간이 작업대·야영 시설 | 시설별 1 | 시설별 12 | 파티 FIFO |
| 정착 제작 시설 | 시설별 2 | 시설별 24 | 파티 FIFO |
| 보스·재건 전용 작업 | 전용 1 | 4 | 우선순위 고정 |

우선순위는 `운영 복구 > 진행 잠금 해제 > 파티 승인 긴급 복구 > 일반 FIFO`다. 개인 장비라는 이유만으로 먼저 처리하지 않는다.

### 8.3 소유와 승인

| 자원 출처 | 결과 소유 | 승인 |
|---|---|---|
| 개인 인벤토리만 사용 | 요청자 | 불필요 |
| 공용 일반 재료 사용, 예비량 유지 | 레시피 정책 | 불필요, 로그 공개 |
| 공용 재료 사용 후 복구 예비량 미달 | 레시피 정책 | 생존·접속 파티 과반 |
| 보스·고유·재건 재료 사용 | 파티 또는 자동 귀속 | 생존·접속 파티 과반 |
| 최초 고유 장비 | EQUIP 투표 결과 | 별도 후보·필요/양보 절차 |

Day 1~10 복구 예비량은 `배급 9, 야전 수리 키트 4, 붕대 6, 정화 앰풀 4`다. 이 수량을 완제품 또는 즉시 제작 가능한 예약 재료로 유지한다.

## 9. 취소·실패·환불 규칙

### 9.1 플레이어 취소

| 취소 시점 | 원재료 | 연료·촉매 | 결과 |
|---|---|---|---|
| VALIDATING | 변화 없음 | 변화 없음 | 즉시 종료 |
| RESERVED·QUEUED | 100% 예약 해제 | 100% 예약 해제 | 수수료 없음 |
| RUNNING 0~25% | 조립품 100% 반환 | 이미 점화한 연료 미반환 | 가공품 정책 적용 |
| RUNNING 25~75% | 내구 부품 100%, 일반 소모재 50% 반환 | 미반환 | 중간품으로 반환 가능 |
| RUNNING 75% 초과 | 직접 환불 없음 | 미반환 | `미완성 조립품`으로 보관 후 재개 |
| OUTPUT_READY | 취소 불가 | 확정 | 수령 대상 변경만 허용 |

- 반환 수량의 소수점은 플레이어에게 유리하게 올림하지 않고 작업별 단계 산출물로 판정한다.
- 개인 취소로 공용 원장 재료를 개인 인벤토리로 옮길 수 없다. 반환 위치는 원래 출처다.
- 반복 취소로 중간품을 복제하지 못하도록 작업 ID와 소비 단계 해시를 저장한다.

### 9.2 시스템 실패

| 실패 원인 | 처리 |
|---|---|
| 서버 정상 종료 | 경과시간·단계 저장, 재개 전까지 정지 |
| 서버 충돌 | 마지막 확정 단계에서 재개, 중복 출력 차단 |
| 시설 파괴 | `PAUSED_FACILITY`, 입력과 중간품을 가상 원장에 보호 |
| 시설망 분리 | 유효 대체 시설 선택 전 정지 |
| 설정·레시피 리비전 불일치 | 작업 동결 후 구 리비전으로 완료하거나 100% 원장 복구 |
| 출력 지급 중 인벤토리 부족 | OUTPUT_READY 유지, 보상함 수령 |
| 서명·PDC 생성 실패 | 출력 폐기 후 입력·연료·촉매 100% 원장 복구와 오류 기록 |

시스템 실패는 플레이어 취소 페널티를 적용하지 않는다. 운영자가 수동 복구할 때도 기존 작업 ID를 승계한다.

## 10. 경제 안전선

- 필수 진행 레시피의 보장 하한 소비량은 해당 자원의 Day 1~10 보장 하한 80%를 넘지 않는다.
- 장비·시설을 포함한 3인 기준 권장 제작안은 철 86, 가죽 26, 금 7, 조직 12 이하를 목표로 한다.
- 고급 장비 한 개 때문에 보스 호출 재료나 복구 예비량이 사라지면 GUI에서 제작을 차단하고 승인 화면을 연다.
- 제작은 기본적으로 확정 성공이며, 희귀성은 재료·발견·시설·처리시간으로 만든다.
- 분해 회수율은 일반 재료 50%, 가공 부품 70%를 시작값으로 사용하고 보스 고유 재료는 회수하지 않는다.
- 시설이 없어도 휴대 경로로 C01~C07과 Day 10 호출 세트를 완성할 수 있다. 설치 시설은 속도와 병렬 처리만 개선한다.

## 13. 완료 기준

- Day 1~10 자원 단위, 기대 유입량, 보장 하한과 인원 보정이 수치로 정의된다.
- 가공·생존·무기·장비·시설·보스 호출 레시피가 발견 및 시설 조건과 연결된다.
- 공용 대기열의 예약, 진행, 출력, 소유와 승인 규칙이 구현 가능한 상태로 정의된다.
- 플레이어 취소와 시스템 실패의 반환 책임이 분리된다.
- 서버 재시작, 시설 파괴와 출력 실패로 자원이 중복되거나 사라지지 않는다.
- 시설 없이도 핵심 진행이 가능하고 시설은 처리량 이점을 제공한다.

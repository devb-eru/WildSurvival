# WildSurvival ECONOMY 장비·제작 경제 기준 기획서

## 문서 정보

| 항목 | 내용 |
|---|---|
| 카테고리 | 자원 공급·소비, 제작, 강화, 재련, 시설 경제 |
| 목적 | 50 Day 회차에서 성장 선택과 자원 압박을 동시에 유지 |
| 최종 수정일 | 2026-08-16 |

## 1. 경제 목표

- 탐험과 관찰이 자원·단서·장비 성장으로 연결된다.
- 하나의 반복 활동이 모든 자원을 공급하지 않는다.
- 장비 성장, 시설 성장, 정화와 생존 물자 사이에 실제 선택을 만든다.
- 무작위 실패로 장시간 성과가 삭제되지 않게 한다.
- 자유 야생과 복수 거점을 허용하면서 시설 이전·분산에 비용과 이익을 부여한다.
- 파티 인원수에 따라 자원 요구가 지나치게 선형 증가하지 않게 한다.

## 2. 자원 계층

| 계층 | 예시 역할 | 주요 획득 | 주요 소비 |
|---|---|---|---|
| 생존 자원 | 목재, 석재, 식량 | 바닐라 채집·농사 | 야영, 건축, 기본 도구 |
| 가공 자원 | 금속, 섬유, 정제 재료 | 채굴·가공 | 장비, 시설, 수리 |
| 오염 자원 | 오염 표본, 잔류물 | 위험 지역·변이 적 | 정화, 심연 장비, 연구 |
| 전투 부품 | 코어, 장갑판, 촉매 | 정예·공세·보스 | 강화, 재련, 고급 시설 |
| 발견 자원 | 기록, 설계 단서, 표본 | 관찰·분석·보스 | 제작식·대응책 해금 |
| 재건 자원 | 붕괴 핵 조각, 안정화 부품 | 세션 보스·후반 발견 | Day 50+ 최종 설비 |

- 핵심 진행 자원은 바닐라 자동 농장으로 획득할 수 없다.
- 재건 자원은 파티 공용이며 버리기·개인 귀속·외부 반출을 차단한다.
- 일반 생존 자원을 과도하게 모았을 때 가공 자원으로 낮은 효율 전환할 수 있지만 역전환은 제한한다.

## 3. 공급·소비 원장

모든 자원은 다음 표를 가져야 한다.

| 필드 | 설명 |
|---|---|
| `source-id` | 획득 출처 |
| `source-repeatability` | 일회성·Day 제한·무한 반복 |
| `expected-yield-per-day` | 기준 파티의 Day당 예상량 |
| `variance` | 무작위 편차 |
| `sink-id` | 소비처 |
| `mandatory` | 핵심 진행 필수 여부 |
| `expected-cost-per-session` | 세션당 예상 소비량 |
| `overflow-conversion` | 초과 자원 처리 |
| `recovery-source` | 소프트락 방지 최소 획득 경로 |
| `anti-farm-policy` | 반복 감쇠·상한·출처 차단 |

CONTENT와 BALANCE는 세션별 공급 합계가 필수 소비와 선택 소비를 어떻게 충족하는지 검증한다.

## 4. 세션 자원 예산

각 Day 10 세션은 다음 비중을 목표로 한다.

| 용도 | 기준 방향 |
|---|---|
| 필수 생존·정화 | 평균 파티가 안정적으로 충족 가능 |
| 핵심 진행 제작 | 일반 플레이로 세션 내 완료 가능 |
| 장비 성장 | 모든 장비를 최대화할 수 없고 2~3개 우선 선택 |
| 거점 성장 | 장비와 경쟁하는 중장기 선택 |
| 예비·복구 | 한 번의 시설 파괴나 잘못된 소비를 복구할 여유 |

- 필수 진행 비용은 기대 획득량의 100%를 요구하지 않는다.
- Easy 기준 필수 비용은 보장 공급량의 70~80% 이내를 목표로 한다.
- 나머지는 선택 성장과 다음 세션 비축에 사용한다.
- 난이도 상승은 모든 비용을 일괄 증가시키기보다 위험 지역 접근, 정화 소비와 복구 비용을 조정한다.

## 5. 제작

- 핵심 제작은 확정 결과를 제공한다.
- 제작식은 재료 ID뿐 아니라 요구 발견, 시설 계층, Day 하한과 회차 진행을 검증한다.
- 제작 시작 시 재료를 예약하고 완료 시 소비한다.
- 중단 정책은 작업별로 `전액 반환`, `가공 재료 반환`, `일부 손실` 중 하나를 명시한다.
- 서버 종료 후 작업 ID와 예약 재료를 복원한다.
- 같은 제작 완료 사건을 두 번 지급하지 않는다.
- 휴대 설비는 기본 생존·복구 제작을, 거점 시설은 고급 장비·강화·재련을 담당한다.

## 6. 강화

### 기본 정책

- 강화 성공 확률은 100%다.
- 실패, 장비 파괴, 강화 단계 하락을 사용하지 않는다.
- 강화 단계가 높아질수록 재료와 고급 부품 요구량이 증가한다.
- 세션별 강화 상한 또는 요구 발견으로 조기 과성장을 제한한다.
- 강화는 기본 스탯 예산을 증가시키되 고유 효과와 증강 역할을 대체하지 않는다.

### 비용 구조

```text
최종 강화 비용 =
장비 등급 기본 비용
× 강화 단계 배율
× 장비 아이템 레벨 배율
× 시설 상태·오염 보정
```

- 비용 결과는 정수로 확정하기 전에 전체 재료 묶음으로 검증한다.
- 기지·시설 오염 비용 증가는 상한을 가진다.
- 시설 손상으로 비용이 증가해도 휴대 복구 제작이 완전히 막히지 않는다.

## 7. 재련

- 재련은 장비 옵션 예산 안에서 옵션 후보를 다시 생성한다.
- 한 번의 재련은 현재 옵션 전체 또는 선택한 옵션 하나를 대상으로 한다.
- 옵션 잠금 수가 늘수록 비용이 크게 증가한다.
- 같은 옵션이 연속해서 나오는 것을 막기 위해 직전 결과 제외 또는 누적 보정을 사용한다.
- 장비 역할과 완전히 무관한 옵션을 무효 후보로 제거한다.
- 재련으로 희귀도 고유 옵션 수와 하드캡을 초과할 수 없다.

### 권장 잠금 비용

| 잠금 수 | 비용 배율 |
|---:|---:|
| 0 | 1.0 |
| 1 | 1.8 |
| 2 | 3.2 |
| 3 이상 | 기본 금지 또는 전설·심연 전용 |

### 천장

- 같은 옵션군을 목표로 연속 재련할 때 유효 후보 가중치를 점진적으로 높인다.
- 누적 보정은 장비 인스턴스에 저장하고 원하는 옵션군 획득 시 초기화한다.
- 최고 수치 천장과 옵션 종류 천장을 분리한다.

## 8. 장비 내구와 수리

- 콘텐츠 장비는 바닐라 내구 표시를 사용할 수 있으나 실제 손상 정책은 서버 데이터가 관리한다.
- 일반 전투 사용만으로 고유 장비가 영구 파괴되지 않는다.
- 내구 0은 `BROKEN` 상태와 효과 비활성화로 처리하고 수리 가능하게 한다.
- 기본 수리 키트는 휴대 설비로 제작 가능해야 한다.
- 고급 수리와 최대 내구 증가에는 거점 시설과 부품을 요구할 수 있다.
- 사망 유품 상태에서 오프라인 시간으로 내구가 감소하지 않는다.

## 9. 적 드롭과 제작의 관계

- 일반 적: 생존 자원과 낮은 전투 부품
- 변이·정예: 태그 부품, 장비 옵션 재료, 발견 표본
- 공세: 파티 공용 자원과 시설 대응 부품
- 보스: 재건 자원, 고유 장비 후보, 제작식 해금

직접 완제품 드롭은 보조 성장 경로이며 제작 시스템을 대체하지 않는다. 미해금 고등급 완제품은 손상 장비·설계 단서·분해 재료 중 하나로 변환한다.

## 10. 거점과 시설 경제

- 시설은 고정 기지에 미리 존재하지 않고 플레이어가 제작·배치한다.
- 휴대 설비는 안전망, 거점 시설은 효율과 고급 기능을 제공한다.
- 시설 이전 시 모든 재료를 100% 반환하지 않는다. 핵심 모듈은 보존하고 구조 재료 일부를 소비한다.
- 공세가 시작되거나 시설이 공격받는 동안 즉시 회수할 수 없다.
- 복수 거점은 허용하지만 동력·정화·저장 네트워크 유지비가 발생한다.
- 모든 시설을 잃어도 기본 수리 키트와 야영 작업대를 다시 만들 수 있는 회복 레시피를 보장한다.

## 11. 파티 공용과 개인 소유

| 자원 | 기본 소유권 |
|---|---|
| 핵심 진행·재건 자원 | 파티 공용 |
| 시설·정화·공세 보상 | 파티 공용 |
| 일반 채집 재료 | 개인 소지 가능, 공용 저장 가능 |
| 개인 소모품 | 개인 |
| 장비 인스턴스 | 미귀속 또는 개인 귀속 |
| 증강 안정화 코어 | 파티 공용 |

- 공용 핵심 자원 소비는 제작·시설·증강 트랜잭션 로그에 기록한다.
- 최종 재건 자원과 보스 고유 보상은 일반 드롭·버리기·호퍼 이동을 차단한다.
- 공용 보관은 특정 고정 기지 상자에 의존하지 않고 회차 가상 원장 또는 등록 시설 보관함을 사용할 수 있다.

## 12. 악용 방지

- 블록 설치·파괴 반복 보상 없음
- 같은 제작의 제작·분해 순환 이익 금지
- 스포너·사육·플레이어 생성 개체의 핵심 보상 차단
- 아이템 UUID 복제와 PDC 제거 감지
- 저장 실패 중 재료 소비·결과 지급 원자성
- 시설 철거·재설치로 손상·오염 초기화 금지
- 차원 이동과 엔더 저장을 이용한 회차 외 반출 차단
- 무인 서버 동안 시설 생산·연구·정화·작업 정지

## 13. 검증 지표

- Day별 자원 획득 중앙값과 하위 10% 파티 값
- 필수 진행 비용 충족률
- 장비·시설·정화 소비 비중
- 사용되지 않고 누적되는 자원 비율
- 강화 단계 분포와 재련 횟수
- 시설 파괴 후 복구 소요 Day
- 특정 활동 하나가 전체 핵심 자원의 과반을 공급하는지
- 2·3·4인에서 개인 장비 성장 속도와 공용 시설 성장 속도

## 14. 완료 기준

- 모든 자원의 공급·소비·복구 경로를 추적할 수 있다.
- 강화는 무작위 파괴 없이 누적 성장한다.
- 재련 잠금, 후보 유효성, 비용 증가와 천장이 정의되어 있다.
- 직접 드롭이 제작·발견 진행을 우회하지 않는다.
- 거점을 잃어도 최소 제작·수리 경로가 남는다.
- 자유 야생과 복수 거점에서 공용 경제를 저장할 수 있다.

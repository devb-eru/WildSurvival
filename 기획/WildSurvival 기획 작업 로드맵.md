# WildSurvival 기획 작업 로드맵

## 문서 목적

이 문서는 WildSurvival 상세 기획의 진행 순서와 문서 분리 기준을 관리한다.

- 서로 다른 카테고리는 별도의 Markdown 문서에 기록한다.
- 같은 카테고리의 후속 작업은 기존 카테고리 문서에 이어서 기록한다.
- 기반 규칙을 먼저 확정하고, 해당 규칙에 의존하는 시스템을 이후에 기획한다.
- 시스템 규칙 문서와 실제 콘텐츠 목록 문서를 구분한다.
- 완료된 작업은 상태를 갱신하고 다음 작업을 명시한다.

## 신규 개별 시스템 요구 범위

### 커스텀 레벨 시스템

- 마인크래프트 경험치 레벨과 별도로 콘텐츠 전용 레벨과 EXP를 관리한다.
- 콘텐츠 전용 경험치 요구 공식을 사용한다.
- 레벨 상승마다 스탯 포인트 `3`을 지급한다.
- 최대 레벨, 도중 참여 보정, 사망·부활·세션 저장 시 처리 규칙을 확정한다.
- EXP 스탯과 장비·증강·보상에 의한 경험치 획득량 변화를 정의한다.

### 커스텀 스탯 시스템

- 플레이어는 획득한 스탯 포인트를 사용하여 개별 스탯을 성장시킨다.
- 포인트 투자 대상은 `HP`, `AP`, `ATK`, `DEF`, `HIT`, `EVA`, `SPD`, `EXP`다.
- 각 스탯의 포인트당 증가량, 투자 상한, 최종 하드캡, 최종 계산 순서를 정의한다.
- 장비·증강·상태이상·오염으로 발생하는 보너스와 페널티를 함께 계산한다.
- 상태이상 저항, 제어 저항, 브레이크 관련 값처럼 포인트 투자 대상이 아닌 보조 전투값은 별도로 정의한다.

### 독자 전투 및 능력치 시스템

- 마인크래프트의 기본 체력, 방어력, 공격 피해를 실제 전투 계산에 사용하지 않는다.
- 플러그인이 독자적인 HP, ATK, DEF 및 피해 공식을 관리한다.
- 일반적인 마인크래프트 공격은 직접 피해를 주지 않는다.
- 일반 공격 입력 시 장착 무기에 등록된 `일반 공격 스킬`을 실행한다.
- 무기 스킬과 다른 전투 스킬도 동일한 커스텀 스킬 실행 시스템을 사용한다.
- 바닐라 피해, 커스텀 피해, 환경 피해, 아군 공격, 빈사 판정의 연결 순서를 정의한다.

### 커스텀 스킬 시스템

모든 스킬은 최소한 다음 데이터를 가져야 한다.

- 스킬 ID, 이름, 설명, 태그, 사용 입력
- 피해 및 회복 계수와 참조 능력치
- 기본 피해 또는 고정 수치
- 재사용 대기시간과 내부 재사용 대기시간
- AP 및 기타 소모값
- 사거리, 폭, 반경, 각도, 높이 등 판정 범위
- 최대 적중 개체 수와 대상 선정 우선순위
- 시전 시간, 동작 시간, 후딜레이, 취소 규칙
- 단일·광역·다단 공격 여부와 적중 간격
- 상태이상, 브레이크, 넉백 등 부가 효과
- 아군 공격, 구조물 공격, 보스 적용 규칙
- 시각·사운드 연출과 플러그인 구현 메모
- 서버 구동 중 원자적 스킬 핫 리로드와 롤백
- 보스의 허용된 플레이어 스킬 복제 및 오버라이드
- STANDARD·CHAOS 규칙 모드별 수치와 처리 간격
- 카오스 BigNumber 기반 HP·피해·DEF·브레이크·기여도

### 증강 시스템과 증강 리스트

- `AUG 증강 시스템 상세 기획서`는 선택, 드로우, 리롤, 티어, 중복 등 시스템 규칙을 정의한다.
- `AUG 증강 리스트 기획서`는 실제 개인 및 파티 증강의 이름, 효과, 수치, 태그, 등장 조건을 기록한다.
- 시스템 규칙과 실제 증강 목록을 별도 문서로 관리한다.

### 커스텀 인챈트 시스템

- 바닐라 인챈트, 인챈트된 책, 모루의 바닐라 인챈트 기능을 사용하지 않는다.
- 인챈트 테이블 상호작용 시 플러그인 커스텀 인챈트 GUI를 연다.
- 바닐라 경험치와 청금석 대신 커스텀 재료 및 설정된 자원을 사용한다.
- 기존 바닐라 인챈트가 남은 아이템은 콘텐츠 장비 및 유틸리티 슬롯에 장착할 수 없다.
- 주무기, 보조무기, 방어구 4부위, 장신구 2부위에 인챈트를 적용할 수 있다.
- 곡괭이, 삽, 괭이 등 유틸리티 도구에도 전용 인챈트를 적용할 수 있다.
- 부적은 기본적으로 인챈트 대상에서 제외한다.
- 인챈트는 장비 개체에 귀속되며 장비를 해제하거나 잃으면 효과도 비활성화된다.
- 인챈트 효과는 STAT의 출처 ID, 중첩 그룹과 최종 하드캡을 따른다.
- 시스템 규칙과 실제 인챈트 목록을 별도 문서로 관리한다.

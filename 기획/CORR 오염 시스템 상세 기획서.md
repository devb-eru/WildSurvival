- 오염은 시간이 흐를수록 세계와 기지를 압박하는 장기 난이도 축이다.
- 오염도 최대가 즉시 패배로 이어지지는 않는다.
- 오염을 관리하지 않으면 전투, 이동, 회복, 시설 효율이 흔들려 전원 사망 가능성이 높아진다.

- 오염 시스템은 세계 진행도, 기지 상태, 플레이어 개인 상태, 지역 노출을 분리해서 계산한다.

# CORR-001 세계·기지·플레이어 오염도

## 1. 시스템 목적

`CORR-001`은 WildSurvival에서 사용되는 오염도의 종류, 저장 방식, 증가·감소 흐름, 노출 계산 기준을 정의한다.

- 세계 오염도가 콘텐츠 전체의 시간 압박을 만든다.
- 기지 오염도가 시설 효율과 안전 구역의 안정성을 흔든다.
- 플레이어 오염도가 개인 생존과 전투 효율을 압박한다.
- 지역 오염도는 플레이어가 현재 위치에서 얼마나 위험한 오염에 노출되는지 계산한다.
- 오염 단계별 구체적인 페널티는 `CORR-002`에서 상세화한다.
- 정화탑, 정화 범위, 정화 자원은 `CORR-003`에서 상세화한다.

## 2. 오염도 구조

오염도는 `수치`와 `강도`를 함께 가진다.

| 항목 | 범위 | 설명 |
|---|---:|---|
| 오염도 수치 | 0~100% | 해당 대상이 얼마나 오염되었는지 나타내는 기본 값 |
| 오염 강도 | 난이도별 최소값~150% | 100% 이후에도 오염 압박이 더 강해지는 초과 압력 |
| 유효 오염 압력 | 0~150 | 오염도 수치와 강도를 조합한 효과 계산용 값 |

오염도 수치는 100%를 넘지 않는다. 대신 100% 상태에서 추가 오염을 받으면 `오염 강도`가 최대 150%까지 상승한다.

```text
유효 오염 압력 =
오염도 수치 × (오염 강도 / 100)
```

예시:

| 오염도 수치 | 오염 강도 | 유효 오염 압력 |
|---:|---:|---:|
| 30% | 100% | 30 |
| 75% | 100% | 75 |
| 100% | 100% | 100 |
| 100% | 125% | 125 |
| 100% | 150% | 150 |

`CORR-002`의 단계별 효과는 기본적으로 오염도 수치를 기준으로 하되, 고오염 구간에서는 유효 오염 압력을 추가 배율로 참조할 수 있다.

## 3. 난이도별 오염 강도 최소값

오염 강도는 오염도 수치가 100% 이하인 상태에서 서서히 감소한다. 단, 난이도별 최소값 아래로 내려가지 않는다.

| 난이도 | 오염 강도 최소값 | 설명 |
|---|---:|---|
| Easy | 80% | 오염 압박이 빠르게 안정됨 |
| Normal | 100% | 기준 난이도 |
| Hard | 110% | 오염이 기본적으로 더 거칠게 유지됨 |
| Challenge | 125% | 정화 후에도 압박이 강하게 남음 |
| ??? | 140% | 오염 강도가 거의 항상 위험 수준으로 유지됨 |

오염 강도의 최대값은 모든 난이도에서 150%다.

### 오염 강도 상승

오염도 수치가 100%인 상태에서 추가 오염을 받으면 초과량을 강도로 전환한다.

```text
초과 오염량 =
max(0, 현재 오염도 수치 + 오염 증가량 - 100)

새 오염 강도 =
min(150, max(현재 오염 강도, 100) + 초과 오염량)

새 오염도 수치 =
min(100, 현재 오염도 수치 + 오염 증가량)
```

Day 진행으로 세계 오염도가 100%에 도달한 이후에도 강도가 150%까지 상승할 수 있다. 이 구조 덕분에 Day 41~50 구간은 단순히 100%에서 멈추지 않고, 세계가 더 위험해지는 느낌을 유지한다.

### 오염 강도 감소

오염도 수치가 100% 이하이고, 해당 대상이 추가 오염을 받고 있지 않으면 강도는 난이도별 최소값까지 감소한다.

| 대상 | 기본 감소 기준 |
|---|---|
| 세계 오염 강도 | 세계 정화 이벤트 또는 최종 정화 진행 중 감소 |
| 기지 오염 강도 | 정화탑 또는 정화 시설이 작동 중일 때 감소 |
| 플레이어 오염 강도 | 정화 소모품, 치료 시설, 정화 영역 효과를 받을 때 감소 |

기본 감소량은 세부 정화 시스템에서 확정한다. CORR-001에서는 다음 기준만 둔다.

```text
오염도 수치 < 100
그리고 추가 오염 증가 없음
그리고 정화 또는 안정화 조건 충족
→ 오염 강도는 난이도별 최소값까지 점진 감소
```

## 4. 오염도 종류

| 종류 | 저장 여부 | 내부 ID | 역할 |
|---|---|---|---|
| 세계 오염도 | 저장 | `worldCorruption` | 콘텐츠 전체 진행 압박 |
| 기지 오염도 | 저장 | `baseCorruption` | 기지 시설과 안전 구역 압박 |
| 플레이어 오염도 | 저장 | `playerCorruption` | 개인 전투·회복·이동 압박 |
| 지역 오염도 | 파생값 | `localCorruption` | 현재 위치의 노출 위험 계산 |

세계, 기지, 플레이어 오염도는 저장 데이터에 기록한다. 지역 오염도는 구역, 이벤트, 주변 기믹, 세계·기지 오염도를 바탕으로 계산하는 파생값이다.

## 5. 세계 오염도

세계 오염도는 콘텐츠 전체의 시간 압박이다.

- Day가 진행될수록 증가한다.
- 기본적으로 자연 감소하지 않는다.
- 세계 정화 이벤트, 최종 목표, 특수한 스토리 진행만 예외적으로 감소시킬 수 있다.
- 세계 오염도는 일반 몬스터의 변이, 오염 지역 위험도, 기지 오염 압력, 이벤트 강도에 영향을 준다.

### Day 시작 세계 오염 증가

기존 GAME 문서의 Day 구간별 증가안을 유지한다.

| Day 구간 | Day당 세계 오염도 증가 |
|---|---:|
| Day 1~10 | +1 |
| Day 11~20 | +2 |
| Day 21~30 | +3 |
| Day 31~40 | +4 |
| Day 41~50 | +5 |

보스 Day도 Day가 시작될 때 세계 오염도는 증가한다. 단, 보스전 중에는 Day 타이머가 멈추므로 추가 Day 증가가 발생하지 않는다.

### 세계 오염도 처리 순서

Day 시작 시 다음 순서로 처리한다.

1. 현재 Day 구간의 세계 오염 증가량을 계산한다.
2. 세계 오염도 수치에 증가량을 적용한다.
3. 100%를 초과한 증가량은 세계 오염 강도로 전환한다.
4. 세계 오염도에 따른 Day 이벤트, 몬스터 변이, 기지 오염 압력을 갱신한다.
5. 변경된 값을 저장한다.

## 6. 기지 오염도

기지 오염도는 기지 영역이 얼마나 오염 압박을 받고 있는지 나타낸다.

- 세계 오염도가 높을수록 기지 오염도 상승 압력이 증가한다.
- 잔존 공세가 길어질수록 기지 오염도가 증가한다.
- 보스전이 길어질수록 기지 오염도가 증가한다.
- 정화탑과 정화 시설은 기지 오염 상승을 억제하고, 기지 오염을 감소시킬 수 있다.
- 정화 시설 업그레이드를 통해 정화 범위 확장과 정화 단계 상승이 가능하다.

### Day 시작 기지 오염 증가

```text
Day 시작 기지 오염 증가 =
세계 유효 오염 압력
× 0.02
× 정화 상태 보정
× 이벤트 보정
```

| 정화 상태 | 보정 |
|---|---:|
| 정화탑 정상 | 0.5 |
| 정화탑 손상 | 0.75 |
| 정화탑 중파 | 1.1 |
| 정화탑 정지 | 1.6 |
| 정화탑 없음 | 1.8 |

이 값은 CORR-001의 기준식이다. 실제 정화탑 레벨, 정화 단계, 정화 자원, 업그레이드에 따른 세부 조정은 `CORR-003`에서 확정한다.

### 잔존 공세 기지 오염 증가

BASE-002의 잔존 공세 규칙을 사용한다.

```text
잔존 공세 기지 오염 증가량/분 =
(
  잔존 주요 적 수 × 0.15
  + 잔존 일반 적 예산 비율 × 0.05
)
× Day 구간 보정
```

| Day 구간 | Day 구간 보정 |
|---|---:|
| Day 1~10 | 1.0 |
| Day 11~20 | 1.2 |
| Day 21~30 | 1.45 |
| Day 31~40 | 1.75 |
| Day 41~50 | 2.1 |

잔존 공세는 다음 Day 진행을 막지 않지만, 방치하면 기지 오염을 계속 밀어 올린다.

### 보스전 기지 오염 증가

보스전에는 제한 시간이 없지만, 무한 대치와 안전 파밍을 막기 위해 기지 오염 압박이 누적된다.

```text
보스전 기지 오염 증가량/분 =
0.25
× 보스 페이즈 보정
× 세계 오염 강도 / 100
```

| 보스 상태 | 페이즈 보정 |
|---|---:|
| 기본 페이즈 | 1.0 |
| 강화 페이즈 | 1.25 |
| 최종 페이즈 | 1.5 |
| 특수 오염 기믹 진행 중 | 보스 데이터에서 지정 |

보스전 기지 오염 증가량은 보스전 실패 조건이 아니라 장기 압박이다.

## 7. 플레이어 오염도

플레이어 오염도는 각 플레이어가 개인적으로 축적한 오염이다.

- 플레이어별로 따로 저장한다.
- 주변 지역 오염도에 노출된 시간에 비례해 증가한다.
- 접속 종료 중에는 증가하지 않는다.
- 완전 사망 중에는 증가하거나 감소하지 않는다.
- 예외 부활 시 사망 당시 플레이어 오염도를 유지한다.
- 오염도 100%가 되어도 즉시 빈사, 완전 사망, 패배가 발생하지 않는다.

### 플레이어 오염 축적 주기

플레이어 오염도는 기본 5초마다 계산한다.

```text
플레이어 오염 증가량/5초 =
기본 노출량
× 지역 오염도 / 100
× 지역 오염 강도 / 100
× 단계 보정
× 상태 보정
× 이벤트 보정
× 장비·증강 보정
```

| 항목 | 기본값 |
|---|---:|
| 기본 노출량 | 0.20 |
| 계산 주기 | 5초 |
| 생존 플레이어 상태 보정 | 1.0 |
| 빈사 상태 보정 | 1.5 |
| 완전 사망 상태 보정 | 0 |
| 접속 종료 상태 보정 | 0 |
| 관전 상태 보정 | 0 |

빈사 상태 오염 축적 150% 규칙은 DEATH 문서와 동일하게 유지한다.

### Day 단계 보정

| Day 단계 | 보정 |
|---|---:|
| 활동 단계 | 1.0 |
| 경고 단계 | 1.15 |
| 공세 단계 | 1.25 |
| 잔존 공세 교전 중 | 1.25 |
| 보스전 | 1.35 |

정화된 기지 중심부 또는 내부 안전 구역에 있으면 지역 오염도 자체가 낮거나 0이 될 수 있으므로, 단계 보정이 있어도 실제 증가량은 없을 수 있다.

## 8. 지역 오염도

지역 오염도는 저장값이 아니라 현재 위치에서 계산하는 노출 위험이다.

청크별 영구 저장 방식은 사용하지 않는다. 플러그인 성능과 기획 관리 편의를 위해 구역·이벤트·기믹 기반으로 계산한다.

| 지역 | 지역 오염도 기준 |
|---|---|
| 정화된 중심부 | 0 |
| 정화된 내부 안전 구역 | 0 |
| 손상된 정화 영역 | 기지 오염도의 일부 |
| 외곽 방어선 | 기지 오염도 기준 |
| 야생 일반 구역 | 세계 오염도 기준 |
| 위험 야생 구역 | 세계 오염도 + 지역 보정 |
| 오염 균열 | 지정 고정값 또는 세계 오염도 중 높은 값 |
| 잔존 공세 영역 | 기지 오염도 + 잔존 공세 보정 |
| 보스전 영역 | 보스 데이터의 오염도 기준 |

### 기지 구역별 지역 오염도

정화탑 상태에 따라 중심부와 내부 안전 구역의 지역 오염도가 달라진다.

| 정화탑 상태 | 중심부 | 내부 안전 구역 | 외곽 방어선 |
|---|---:|---:|---:|
| 정상 | 0 | 0 | 기지 오염도 |
| 손상 | 기지 오염도 × 0.1 | 기지 오염도 × 0.25 | 기지 오염도 |
| 중파 | 기지 오염도 × 0.3 | 기지 오염도 × 0.6 | 기지 오염도 |
| 정지 | 기지 오염도 | 기지 오염도 | 기지 오염도 |

정화 시설을 통해 정화 범위가 확장되면 보호 대상 구역이 늘어난다. 정화 단계가 상승하면 같은 구역에서도 지역 오염도 환산율이 낮아질 수 있다.

### 야생 지역 오염도

```text
야생 지역 오염도 =
clamp(세계 오염도 + 지역 보정 + 이벤트 보정, 0, 100)
```

| 지역 유형 | 지역 보정 |
|---|---:|
| 일반 야생 | 0 |
| 자원 밀집 지역 | +5 |
| 위험 자원 지역 | +10 |
| 오염 생물 군락 | +15 |
| 오염 균열 주변 | +25 |
| 보스 영향 지역 | 보스 데이터 지정 |

높은 보상을 주는 지역은 더 높은 오염 노출을 제공할 수 있다.

## 9. 오염 감소와 정화

세계 오염도는 일반적으로 감소하지 않는다. 기지와 플레이어 오염도는 정화 시스템을 통해 감소할 수 있다.

| 대상 | 자연 감소 | 정화 감소 | 비고 |
|---|---|---|---|
| 세계 오염도 | 없음 | 특수 이벤트만 가능 | 최종 목표와 연결 |
| 기지 오염도 | 없음 | 정화탑, 정화 시설 | `CORR-003` 상세화 |
| 플레이어 오염도 | 없음 | 정화 소모품, 치료 시설, 정화 영역 | `CORR-003` 상세화 |
| 지역 오염도 | 파생값 | 정화 범위와 기믹으로 변화 | 저장하지 않음 |

정화는 두 가지 방향을 가진다.

| 정화 방향 | 설명 |
|---|---|
| 정화 범위 확장 | 오염 영향을 받지 않는 기지 구역을 넓힘 |
| 정화 단계 상승 | 같은 구역의 오염 환산율을 낮추거나 정화 효율을 높임 |

정화 범위와 정화 단계는 기지 내 정화 시설을 통해 확장할 수 있다.

## 10. 오염도 적용 우선순위

오염 관련 계산은 다음 순서를 따른다.

1. Day 시작 또는 이벤트로 세계 오염도 갱신
2. 세계 오염도에 따른 기지 오염 압력 갱신
3. 잔존 공세, 보스전, 정화탑 상태로 기지 오염도 갱신
4. 지역·구역·기믹 기반 지역 오염도 계산
5. 플레이어별 노출 주기마다 플레이어 오염도 갱신
6. 오염 단계 변화 이벤트 발생
7. `STAT`, `COMBAT`, `CORE`, `BASE`에 오염 배율 전달

오염 효과가 실제 스탯과 피해에 적용되는 방식은 `CORR-002`, `STAT`, `CORE`, `COMBAT` 규칙을 따른다.

## 11. 오염도와 기존 시스템 연결

| 시스템 | 연결 |
|---|---|
| GAME | Day 시작 시 세계·기지 오염도 갱신 |
| BASE | 기지 구역, 정화탑, 시설 효율, 잔존 공세 오염 증가 |
| BASE-003 | `CORRUPTION_DECAY` 시설 피해 타입 |
| STAT | 오염으로 인한 상태·기믹 배율과 오염 피해 DEF 효율 |
| CORE | `POLLUTION` 피해 분류와 커스텀 HP 피해 처리 |
| COMBAT | AP 회복 감소, 이동·전투 효율 감소 |
| DEATH | 빈사 상태 오염 축적 150%, 최대 오염도 즉사 없음 |
| STATUS | 정화, 해제, 오염 변이 상태와 연결 |
| ACT/RES/CRAFT/RESEARCH | 정화 자원, 오염 연구, 위험 지역 보상 |


## 17. CORR-001 완료 기준

- 오염도 수치와 오염 강도의 범위가 정의되어 있다.
- 100% 이후 오염 강도 150% 상승 규칙이 정의되어 있다.
- 난이도별 오염 강도 최소값이 정의되어 있다.
- 세계, 기지, 플레이어, 지역 오염도의 역할이 분리되어 있다.
- 세계 오염도 증가 규칙이 Day 구간과 연결되어 있다.
- 기지 오염도 증가 규칙이 세계 오염, 잔존 공세, 보스전, 정화 상태와 연결되어 있다.
- 플레이어 오염도 축적 규칙이 주변 지역 오염도와 노출 시간에 연결되어 있다.
- 지역 오염도가 저장값이 아니라 구역 기반 파생값으로 정의되어 있다.
- 정화 범위 확장과 정화 단계 상승이 후속 작업으로 연결되어 있다.
- UI, 저장 데이터, 예외 처리, 테스트 항목이 정의되어 있다.

# CORR-002 오염 단계별 효과

## 1. 시스템 목적

`CORR-002`는 세계·기지·플레이어·지역 오염도가 실제 게임플레이에 적용하는 단계별 효과를 정의한다.

- 오염 단계가 상승할수록 플레이어가 체감할 수 있는 압박을 만든다.
- 오염도 100%가 즉시 패배나 즉사로 이어지지 않게 한다.
- 오염 효과를 전투, 회복, 구조, 기지 운영, 시설 피해와 연결한다.
- 오염 강도 100~150% 구간에서도 효과가 과도하게 폭주하지 않도록 개별 상한을 둔다.
- 실제 정화 수단과 정화 효율은 `CORR-003`에서 정의한다.

## 2. 오염 단계

오염 단계는 `오염도 수치`를 기준으로 판정한다.

| 단계 | 수치 범위 | 내부 ID | 의미 |
|---|---:|---|---|
| 안정 | 0~19 | `STABLE` | 체감 페널티 없음 |
| 경미 | 20~39 | `MINOR` | 경고와 약한 운영 압박 |
| 위험 | 40~59 | `DANGER` | 전투·회복 효율 저하 시작 |
| 심각 | 60~79 | `SEVERE` | 오염 피해와 구조 방해 시작 |
| 임계 | 80~99 | `CRITICAL` | 전투 지속력과 기지 운영 급감 |
| 붕괴 | 100 | `COLLAPSE` | 최대 오염 단계, 강도에 따라 추가 강화 |

단계 이름은 수치 기준으로 고정한다. `오염 강도`는 단계 이름을 바꾸지 않고, 단계 효과의 실제 적용량을 키우거나 줄인다.

### 효과 강도 배율

단계별 표의 수치는 `오염 강도 100%` 기준이다.

```text
오염 효과 강도 배율 =
오염 강도 / 100

최종 단계 효과 =
단계 기본 효과 × 오염 효과 강도 배율
```

예시:

| 오염도 | 강도 | 단계 | 기본 받는 피해 증가 | 최종 받는 피해 증가 |
|---:|---:|---|---:|---:|
| 80% | 100% | 임계 | +10% | +10% |
| 80% | 125% | 임계 | +10% | +12.5% |
| 100% | 150% | 붕괴 | +15% | +20% 상한 적용 |

각 효과는 개별 상한을 먼저 적용한 뒤 `STAT`, `COMBAT`, `CORE`, `DEATH`의 전체 상한 규칙을 따른다.

## 3. 세계 오염 단계 효과

세계 오염도는 플레이어에게 직접 디버프를 주기보다 몬스터, 지역, 이벤트, 기지 오염 압력을 강화한다.

| 단계 | 몬스터 변이 가중치 | 오염 지역 보정 | 특수 이벤트 강도 | 기지 오염 압력 |
|---|---:|---:|---:|---:|
| 안정 | +0% | +0 | ×1.00 | ×1.00 |
| 경미 | +5% | +0 | ×1.00 | ×1.00 |
| 위험 | +10% | +3 | ×1.05 | ×1.05 |
| 심각 | +18% | +6 | ×1.10 | ×1.10 |
| 임계 | +28% | +10 | ×1.20 | ×1.15 |
| 붕괴 | +40% | +15 | ×1.35 | ×1.30 |

- `몬스터 변이 가중치`는 corrupted, frenzied, enhanced 등급 등장 확률 계산에 사용한다.
- 실제 몬스터 등급별 출현 확률과 상한은 `ENEMY` 문서에서 확정한다.
- `오염 지역 보정`은 야생 지역 오염도 계산에 추가되는 값이다.
- 세계 오염 단계가 높아져도 플레이어 개인 오염도가 낮다면 즉시 개인 디버프를 받지는 않는다.

### 세계 붕괴+

세계 오염도 100%에서 오염 강도가 100%를 넘으면 UI에 `붕괴+` 또는 `초과 오염`으로 표시할 수 있다.

| 강도 | 표시 | 처리 |
|---:|---|---|
| 100~119% | 붕괴 | 기본 붕괴 단계 |
| 120~139% | 붕괴+ | 이벤트와 지역 위험도 강화 |
| 140~150% | 초과 오염 | 최종 구간 압박, 강한 오염 이벤트 가능 |

표시 이름만 달라지며 단계 ID는 `COLLAPSE`를 유지한다.

## 4. 기지 오염 단계 효과

기지 오염도는 시설 효율, 비전투 AP 회복 보너스, 기지 운영, 시설 부식에 영향을 준다.

| 단계 | 정화 효율 | 치료 비용 | 치료 시간 | 제작·강화 비용 | 비전투 AP 회복 보너스 효율 |
|---|---:|---:|---:|---:|---:|
| 안정 | 100% | +0% | +0% | +0% | 100% |
| 경미 | 95% | +5% | +0% | +0% | 100% |
| 위험 | 85% | +10% | +5% | +5% | 80% |
| 심각 | 70% | +20% | +10% | +10% | 60% |
| 임계 | 50% | +35% | +20% | +20% | 40% |
| 붕괴 | 30% | +50% | +35% | +35% | 20% |

- 기지 오염 100%가 되어도 모든 시설이 즉시 정지하지 않는다.
- 정화 효율 감소는 정화탑과 정화 시설의 오염 감소량에 적용한다.
- 치료 비용과 치료 시간 증가는 치료 시설 손상 효과와 별도로 중첩된다.
- 제작·강화 비용 증가는 일반 제작보다 강화, 재련, 고급 제작에 우선 적용한다.
- 비전투 AP 회복 보너스 효율은 기지 내부의 안전 정비 보너스에만 적용한다.

### 기지 시설 부식

기지 오염이 `임계` 이상이면 시설에 `CORRUPTION_DECAY`가 발생할 수 있다.

```text
시설 부식 피해/분 =
시설 최대 HP
× 단계별 부식 비율
× 기지 오염 강도 / 100
× 정화탑 상태 보정
```

| 단계 | 부식 비율 | 기본 주기 | 적용 대상 |
|---|---:|---:|---|
| 안정 | 없음 | 없음 | 없음 |
| 경미 | 없음 | 없음 | 없음 |
| 위험 | 없음 | 없음 | 없음 |
| 심각 | 없음 | 없음 | 없음 |
| 임계 | 0.05%/분 | 60초 | 핵심 시설, 정화 시설 |
| 붕괴 | 0.12%/분 | 60초 | 핵심 시설, 정비 시설, 정화 시설 |

| 정화탑 상태 | 부식 보정 |
|---|---:|
| 정상 | 0.5 |
| 손상 | 0.8 |
| 중파 | 1.2 |
| 정지 | 1.6 |

- 부식 피해는 `BASE-003`의 시설 피해 타입 `CORRUPTION_DECAY`를 사용한다.
- 부식만으로도 시설이 0%가 될 수 있지만, 이는 즉시 패배가 아니다.
- 방어벽, 문, 함정 같은 방어 구조물은 기본 부식 대상이 아니다. 특수 오염 이벤트가 명시한 경우에만 적용한다.
- 잔존 공세와 정화탑 정지가 겹치면 부식 압박이 커진다.

## 5. 플레이어 오염 단계 효과

플레이어 오염도는 개인 전투 지속력, 회복, 구조, 이동, 피해량, 받는 피해에 영향을 준다.

| 단계 | AP 자연 회복 | 받는 회복량 | 구조 속도 | 이동속도 | 주는 피해 | 받는 피해 |
|---|---:|---:|---:|---:|---:|---:|
| 안정 | 0% | 0% | 0% | 0% | 0% | 0% |
| 경미 | -5% | 0% | 0% | 0% | 0% | 0% |
| 위험 | -10% | -5% | -10% | -3% | -3% | +3% |
| 심각 | -20% | -10% | -15% | -6% | -7% | +6% |
| 임계 | -30% | -20% | -20% | -10% | -10% | +10% |
| 붕괴 | -40% | -30% | -30% | -15% | -15% | +15% |

### 플레이어 오염 효과 상한

| 효과 | 오염 단독 상한 | 전체 시스템 상한 |
|---|---:|---:|
| AP 자연 회복 감소 | -40% | 다른 효과 포함 -50% |
| 받는 회복량 감소 | -30% | 다른 효과 포함 -99% |
| 구조 속도 감소 | -30% | 다른 효과 포함 -50% |
| 이동속도 감소 | -15% | 최종 SPD 최소 1% |
| 주는 피해 감소 | -15% | Damage Dealt 하한 -99% |
| 받는 피해 증가 | +20% | Damage Taken 증가 상한 +300% |

`받는 피해 증가`는 일반 커스텀 피해와 오염 피해에 적용한다. 고정 피해, 시스템 피해, 별도 명시된 환경 피해에는 기본적으로 적용하지 않는다.

오염 단계 효과는 `STAT-002`의 출처 ID와 중첩 그룹을 따른다.

```text
source-id: corr.player.stage
stack-group: corruption.player.stage
```

같은 플레이어 오염 단계 효과는 중첩되지 않고 현재 단계의 값만 적용한다.

## 6. 오염 피해

오염 피해는 `POLLUTION` 피해 분류를 사용한다.

- `심각` 단계부터 발생한다.
- 플레이어 오염도가 높고 고오염 지역에 계속 노출될 때 주기적으로 발생한다.
- CORE의 `POLLUTION` 피해 처리, STAT의 난이도별 오염 피해 DEF 효율을 따른다.
- 오염 단계의 `받는 피해 증가`는 오염 피해에도 적용한다.
- 치명타는 발생하지 않는다.
- 생명력 흡수와 반사 피해의 원천이 되지 않는다.

### 오염 피해 발생 조건

오염 피해는 다음 조건을 모두 만족할 때 발생한다.

1. 플레이어 오염 단계가 `심각` 이상이다.
2. 현재 지역 오염도가 40 이상이다.
3. 플레이어가 정화 보호를 받는 중심부 또는 내부 안전 구역에 있지 않다.
4. 플레이어가 생존 또는 빈사 상태다.

### 오염 피해량

```text
오염 피해 =
최대 HP
× 단계별 피해 비율
× 플레이어 오염 강도 / 100
× 지역 오염도 / 100
× 지역 오염 강도 / 100
```

| 플레이어 단계 | 피해 비율 | 기본 주기 |
|---|---:|---:|
| 안정 | 없음 | 없음 |
| 경미 | 없음 | 없음 |
| 위험 | 없음 | 없음 |
| 심각 | 최대 HP의 0.40% | 5초 |
| 임계 | 최대 HP의 0.75% | 4초 |
| 붕괴 | 최대 HP의 1.00% | 3초 |

### 빈사 상태 오염 피해

빈사 상태에도 오염 피해는 적용한다.

- 빈사 상태의 플레이어도 주변 오염에 노출된다.
- 오염 피해는 빈사 체력 피해로 전환된다.
- 빈사 상태에서 오염 피해만으로 즉시 완전 사망하지 않도록 `DEATH`의 빈사 피해 상한을 따른다.
- 오염도 최대 상태 자체가 완전 사망 조건은 아니다.

## 7. 지역 오염 단계 효과

지역 오염도는 주로 플레이어 오염 축적과 오염 피해 조건에 사용한다.

| 지역 단계 | 지역 오염도 | 표시 | 즉시 효과 |
|---|---:|---|---|
| 안정 | 0~19 | 없음 또는 낮음 | 없음 |
| 경미 | 20~39 | 약한 파티클 | 오염 축적 시작 |
| 위험 | 40~59 | 파티클, 낮은 경고음 | 오염 피해 조건 충족 가능 |
| 심각 | 60~79 | 시야 가장자리 효과 | 오염 축적 증가 |
| 임계 | 80~99 | 강한 파티클, 심장박동음 | 오염 피해 위험 경고 |
| 붕괴 | 100 | 화면 경고, 강한 사운드 | 강한 오염 피해 조건 |

지역 오염 단계는 독립 디버프를 많이 직접 적용하지 않는다. 대부분은 플레이어 오염 축적과 오염 피해 발생 조건으로 처리한다.

## 8. 단계 변화 알림

| 대상 | 상승 알림 | 하락 알림 |
|---|---|---|
| 세계 오염 | 파티 전체 타이틀, 사운드 | 특수 정화 이벤트 때만 표시 |
| 기지 오염 | 파티 전체 채팅, 기지 경보음 | 정화 시설 효과로 하락 시 표시 |
| 플레이어 오염 | 개인 액션바, 경고음 | 개인 액션바 |
| 지역 오염 | 위험 지역 진입 경고 | 안전 구역 진입 안내 |

플레이어 개인 오염 단계가 `심각` 이상으로 상승하면 개인 경고를 강화한다. 기지 오염이 `임계` 이상이면 기지 GUI와 공세 관측 장치에 상시 경고를 표시한다.

## 9. 효과 적용 순서

플레이어에게 오염 효과를 적용할 때는 다음 순서를 따른다.

1. 플레이어 오염도 수치로 단계 판정
2. 플레이어 오염 강도로 효과 강도 배율 계산
3. 단계별 효과 기본값 선택
4. 오염 단독 상한 적용
5. `STAT` 보조 전투값에 출처 ID로 반영
6. 전체 시스템 상한 적용
7. 실제 전투, 회복, 구조, 이동 계산에 반영

오염 피해는 별도 피해 이벤트로 처리한다.

1. 오염 피해 발생 조건 확인
2. 최대 HP 기반 기본 피해 계산
3. 지역 오염도와 강도 반영
4. CORE의 `POLLUTION` 피해 처리
5. STAT의 난이도별 오염 피해 DEF 효율 적용
6. Damage Taken과 기타 대상 피해 보정 적용
7. HP 또는 빈사 체력에 적용

## 11. 예외 처리

| 상황 | 처리 |
|---|---|

| 오염 단계 효과가 다른 디버프와 겹침 | 출처별 합산 후 전체 상한 적용 |

| 지역 오염 100% | 즉시 피해가 아니라 오염 피해 조건 강화 |

## 13. CORR-002 완료 기준

- 오염 단계 기준과 내부 ID가 정의되어 있다.
- 오염 강도가 단계 효과 배율로 적용되는 방식이 정의되어 있다.
- 세계 오염 단계가 몬스터, 지역, 이벤트, 기지 압력에 미치는 효과가 정의되어 있다.
- 기지 오염 단계가 정화, 치료, 제작, AP 회복 보너스, 시설 부식에 미치는 효과가 정의되어 있다.
- 플레이어 오염 단계가 AP 회복, 회복량, 구조 속도, 이동속도, 주는 피해, 받는 피해에 미치는 효과가 정의되어 있다.
- 오염 피해 발생 조건, 피해량, 주기, 빈사 상태 처리가 정의되어 있다.
- 지역 오염 단계의 표시와 즉시 효과 범위가 정의되어 있다.
- 단계 변화 알림, 효과 적용 순서, 예외 처리, 테스트 항목이 정의되어 있다.

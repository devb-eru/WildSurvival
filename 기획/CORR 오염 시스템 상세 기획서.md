- 오염은 시간이 흐를수록 세계와 기지를 압박하는 장기 난이도 축이다.
- 오염도 최대가 즉시 패배로 이어지지는 않는다.
- 오염을 관리하지 않으면 전투, 이동, 회복, 시설 효율이 흔들려 전원 사망 가능성이 높아진다.

- 오염 시스템은 세계 진행도, 기지 상태, 플레이어 개인 상태, 지역 노출을 분리해서 계산한다.

# CORR-001 세계·기지·플레이어 오염도

## 1. 시스템 목적

`CORR-001`은 WildSurvival에서 사용되는 오염도의 종류, 저장 방식, 증가·감소 흐름, 노출 계산 기준을 정의한다.

- 세계 오염도가 콘텐츠 전체의 시간 압박을 만든다.
- 기지 오염도가 시설 효율과 안전 구역의 안정성을 흔든다.
- 플레이어 오염도가 개인 생존과 전투 효율을 압박한다.
- 지역 오염도는 플레이어가 현재 위치에서 얼마나 위험한 오염에 노출되는지 계산한다.
- 오염 단계별 구체적인 페널티는 `CORR-002`에서 상세화한다.
- 정화탑, 정화 범위, 정화 자원은 `CORR-003`에서 상세화한다.

## 2. 오염도 구조

오염도는 `수치`와 `강도`를 함께 가진다.

| 항목 | 범위 | 설명 |
|---|---:|---|
| 오염도 수치 | 0~100% | 해당 대상이 얼마나 오염되었는지 나타내는 기본 값 |
| 오염 강도 | 난이도별 최소값~150% | 100% 이후에도 오염 압박이 더 강해지는 초과 압력 |
| 유효 오염 압력 | 0~150 | 오염도 수치와 강도를 조합한 효과 계산용 값 |

오염도 수치는 100%를 넘지 않는다. 대신 100% 상태에서 추가 오염을 받으면 `오염 강도`가 최대 150%까지 상승한다.

```text
유효 오염 압력 =
오염도 수치 × (오염 강도 / 100)
```

예시:

| 오염도 수치 | 오염 강도 | 유효 오염 압력 |
|---:|---:|---:|
| 30% | 100% | 30 |
| 75% | 100% | 75 |
| 100% | 100% | 100 |
| 100% | 125% | 125 |
| 100% | 150% | 150 |

`CORR-002`의 단계별 효과는 기본적으로 오염도 수치를 기준으로 하되, 고오염 구간에서는 유효 오염 압력을 추가 배율로 참조할 수 있다.

## 3. 난이도별 오염 강도 최소값

오염 강도는 오염도 수치가 100% 이하인 상태에서 서서히 감소한다. 단, 난이도별 최소값 아래로 내려가지 않는다.

| 난이도 | 오염 강도 최소값 | 설명 |
|---|---:|---|
| Easy | 80% | 오염 압박이 빠르게 안정됨 |
| Normal | 100% | 기준 난이도 |
| Hard | 110% | 오염이 기본적으로 더 거칠게 유지됨 |
| Challenge | 125% | 정화 후에도 압박이 강하게 남음 |
| ??? | 140% | 오염 강도가 거의 항상 위험 수준으로 유지됨 |

오염 강도의 최대값은 모든 난이도에서 150%다.

### 오염 강도 상승

오염도 수치가 100%인 상태에서 추가 오염을 받으면 초과량을 강도로 전환한다.

```text
초과 오염량 =
max(0, 현재 오염도 수치 + 오염 증가량 - 100)

새 오염 강도 =
min(150, max(현재 오염 강도, 100) + 초과 오염량)

새 오염도 수치 =
min(100, 현재 오염도 수치 + 오염 증가량)
```

Day 진행으로 세계 오염도가 100%에 도달한 이후에도 강도가 150%까지 상승할 수 있다. 이 구조 덕분에 Day 41~50 구간은 단순히 100%에서 멈추지 않고, 세계가 더 위험해지는 느낌을 유지한다.

### 오염 강도 감소

오염도 수치가 100% 이하이고, 해당 대상이 추가 오염을 받고 있지 않으면 강도는 난이도별 최소값까지 감소한다.

| 대상 | 기본 감소 기준 |
|---|---|
| 세계 오염 강도 | 세계 정화 이벤트 또는 최종 정화 진행 중 감소 |
| 기지 오염 강도 | 정화탑 또는 정화 시설이 작동 중일 때 감소 |
| 플레이어 오염 강도 | 정화 소모품, 치료 시설, 정화 영역 효과를 받을 때 감소 |

기본 감소량은 세부 정화 시스템에서 확정한다. CORR-001에서는 다음 기준만 둔다.

```text
오염도 수치 < 100
그리고 추가 오염 증가 없음
그리고 정화 또는 안정화 조건 충족
→ 오염 강도는 난이도별 최소값까지 점진 감소
```

## 4. 오염도 종류

| 종류 | 저장 여부 | 내부 ID | 역할 |
|---|---|---|---|
| 세계 오염도 | 저장 | `worldCorruption` | 콘텐츠 전체 진행 압박 |
| 기지 오염도 | 저장 | `baseCorruption` | 기지 시설과 안전 구역 압박 |
| 플레이어 오염도 | 저장 | `playerCorruption` | 개인 전투·회복·이동 압박 |
| 지역 오염도 | 파생값 | `localCorruption` | 현재 위치의 노출 위험 계산 |

세계, 기지, 플레이어 오염도는 저장 데이터에 기록한다. 지역 오염도는 구역, 이벤트, 주변 기믹, 세계·기지 오염도를 바탕으로 계산하는 파생값이다.

## 5. 세계 오염도

세계 오염도는 콘텐츠 전체의 시간 압박이다.

- Day가 진행될수록 증가한다.
- 기본적으로 자연 감소하지 않는다.
- 세계 정화 이벤트, 최종 목표, 특수한 스토리 진행만 예외적으로 감소시킬 수 있다.
- 세계 오염도는 일반 몬스터의 변이, 오염 지역 위험도, 기지 오염 압력, 이벤트 강도에 영향을 준다.

### Day 시작 세계 오염 증가

기존 GAME 문서의 Day 구간별 증가안을 유지한다.

| Day 구간 | Day당 세계 오염도 증가 |
|---|---:|
| Day 1~10 | +1 |
| Day 11~20 | +2 |
| Day 21~30 | +3 |
| Day 31~40 | +4 |
| Day 41~50 | +5 |

보스 Day도 Day가 시작될 때 세계 오염도는 증가한다. 단, 보스전 중에는 Day 타이머가 멈추므로 추가 Day 증가가 발생하지 않는다.

### 세계 오염도 처리 순서

Day 시작 시 다음 순서로 처리한다.

1. 현재 Day 구간의 세계 오염 증가량을 계산한다.
2. 세계 오염도 수치에 증가량을 적용한다.
3. 100%를 초과한 증가량은 세계 오염 강도로 전환한다.
4. 세계 오염도에 따른 Day 이벤트, 몬스터 변이, 기지 오염 압력을 갱신한다.
5. 변경된 값을 저장한다.

## 6. 기지 오염도

기지 오염도는 기지 영역이 얼마나 오염 압박을 받고 있는지 나타낸다.

- 세계 오염도가 높을수록 기지 오염도 상승 압력이 증가한다.
- 잔존 공세가 길어질수록 기지 오염도가 증가한다.
- 보스전이 길어질수록 기지 오염도가 증가한다.
- 정화탑과 정화 시설은 기지 오염 상승을 억제하고, 기지 오염을 감소시킬 수 있다.
- 정화 시설 업그레이드를 통해 정화 범위 확장과 정화 단계 상승이 가능하다.

### Day 시작 기지 오염 증가

```text
Day 시작 기지 오염 증가 =
세계 유효 오염 압력
× 0.02
× 정화 상태 보정
× 이벤트 보정
```

| 정화 상태 | 보정 |
|---|---:|
| 정화탑 정상 | 0.5 |
| 정화탑 손상 | 0.75 |
| 정화탑 중파 | 1.1 |
| 정화탑 정지 | 1.6 |
| 정화탑 없음 | 1.8 |

이 값은 CORR-001의 기준식이다. 실제 정화탑 레벨, 정화 단계, 정화 자원, 업그레이드에 따른 세부 조정은 `CORR-003`에서 확정한다.

### 잔존 공세 기지 오염 증가

BASE-002의 잔존 공세 규칙을 사용한다.

```text
잔존 공세 기지 오염 증가량/분 =
(
  잔존 주요 적 수 × 0.15
  + 잔존 일반 적 예산 비율 × 0.05
)
× Day 구간 보정
```

| Day 구간 | Day 구간 보정 |
|---|---:|
| Day 1~10 | 1.0 |
| Day 11~20 | 1.2 |
| Day 21~30 | 1.45 |
| Day 31~40 | 1.75 |
| Day 41~50 | 2.1 |

잔존 공세는 다음 Day 진행을 막지 않지만, 방치하면 기지 오염을 계속 밀어 올린다.

### 보스전 기지 오염 증가

보스전에는 제한 시간이 없지만, 무한 대치와 안전 파밍을 막기 위해 기지 오염 압박이 누적된다.

```text
보스전 기지 오염 증가량/분 =
0.25
× 보스 페이즈 보정
× 세계 오염 강도 / 100
```

| 보스 상태 | 페이즈 보정 |
|---|---:|
| 기본 페이즈 | 1.0 |
| 강화 페이즈 | 1.25 |
| 최종 페이즈 | 1.5 |
| 특수 오염 기믹 진행 중 | 보스 데이터에서 지정 |

보스전 기지 오염 증가량은 보스전 실패 조건이 아니라 장기 압박이다.

## 7. 플레이어 오염도

플레이어 오염도는 각 플레이어가 개인적으로 축적한 오염이다.

- 플레이어별로 따로 저장한다.
- 주변 지역 오염도에 노출된 시간에 비례해 증가한다.
- 접속 종료 중에는 증가하지 않는다.
- 완전 사망 중에는 증가하거나 감소하지 않는다.
- 예외 부활 시 사망 당시 플레이어 오염도를 유지한다.
- 오염도 100%가 되어도 즉시 빈사, 완전 사망, 패배가 발생하지 않는다.

### 플레이어 오염 축적 주기

플레이어 오염도는 기본 5초마다 계산한다.

```text
플레이어 오염 증가량/5초 =
기본 노출량
× 지역 오염도 / 100
× 지역 오염 강도 / 100
× 단계 보정
× 상태 보정
× 이벤트 보정
× 장비·증강 보정
```

| 항목 | 기본값 |
|---|---:|
| 기본 노출량 | 0.20 |
| 계산 주기 | 5초 |
| 생존 플레이어 상태 보정 | 1.0 |
| 빈사 상태 보정 | 1.5 |
| 완전 사망 상태 보정 | 0 |
| 접속 종료 상태 보정 | 0 |
| 관전 상태 보정 | 0 |

빈사 상태 오염 축적 150% 규칙은 DEATH 문서와 동일하게 유지한다.

### Day 단계 보정

| Day 단계 | 보정 |
|---|---:|
| 활동 단계 | 1.0 |
| 경고 단계 | 1.15 |
| 공세 단계 | 1.25 |
| 잔존 공세 교전 중 | 1.25 |
| 보스전 | 1.35 |

정화된 기지 중심부 또는 내부 안전 구역에 있으면 지역 오염도 자체가 낮거나 0이 될 수 있으므로, 단계 보정이 있어도 실제 증가량은 없을 수 있다.

## 8. 지역 오염도

지역 오염도는 저장값이 아니라 현재 위치에서 계산하는 노출 위험이다.

청크별 영구 저장 방식은 사용하지 않는다. 플러그인 성능과 기획 관리 편의를 위해 구역·이벤트·기믹 기반으로 계산한다.

| 지역 | 지역 오염도 기준 |
|---|---|
| 정화된 중심부 | 0 |
| 정화된 내부 안전 구역 | 0 |
| 손상된 정화 영역 | 기지 오염도의 일부 |
| 외곽 방어선 | 기지 오염도 기준 |
| 야생 일반 구역 | 세계 오염도 기준 |
| 위험 야생 구역 | 세계 오염도 + 지역 보정 |
| 오염 균열 | 지정 고정값 또는 세계 오염도 중 높은 값 |
| 잔존 공세 영역 | 기지 오염도 + 잔존 공세 보정 |
| 보스전 영역 | 보스 데이터의 오염도 기준 |

### 기지 구역별 지역 오염도

정화탑이 보호하는 구역과 시설 손상 상태에 따라 기지 구역의 지역 오염도가 달라진다.

| 정화탑 상태 | 중심부 | 내부 안전 구역 | 외곽 방어선 |
|---|---:|---:|---:|
| 정상 | 보호 범위 안이면 0 | 보호 범위 안이면 0 | 보호 범위 안이면 0 |
| 손상 | 기지 오염도 × 0.1 | 기지 오염도 × 0.25 | 기지 오염도 × 0.4 |
| 중파 | 기지 오염도 × 0.3 | 기지 오염도 × 0.6 | 기지 오염도 × 0.85 |
| 정지 | 기지 오염도 | 기지 오염도 | 기지 오염도 |

- 손상 및 중파 환산율은 현재 정화 범위에 포함된 구역에만 적용한다.
- 현재 정화 범위 밖의 구역은 정화 단계의 외곽 완화 효과가 없다면 기지 오염도를 그대로 사용한다.
- 정화탑의 연료 고갈은 시설 HP가 0인 정지와 별도 상태지만, 지역 오염도 계산에서는 정지와 동일하게 처리한다.
- 정화 범위와 정화 단계의 상세 수치는 `CORR-003`을 따른다.

### 야생 지역 오염도

```text
야생 지역 오염도 =
clamp(세계 오염도 + 지역 보정 + 이벤트 보정, 0, 100)
```

| 지역 유형 | 지역 보정 |
|---|---:|
| 일반 야생 | 0 |
| 자원 밀집 지역 | +5 |
| 위험 자원 지역 | +10 |
| 오염 생물 군락 | +15 |
| 오염 균열 주변 | +25 |
| 보스 영향 지역 | 보스 데이터 지정 |

높은 보상을 주는 지역은 더 높은 오염 노출을 제공할 수 있다.

## 9. 오염 감소와 정화

세계 오염도는 일반적으로 감소하지 않는다. 기지와 플레이어 오염도는 정화 시스템을 통해 감소할 수 있다.

| 대상 | 자연 감소 | 정화 감소 | 비고 |
|---|---|---|---|
| 세계 오염도 | 없음 | 특수 이벤트만 가능 | 최종 목표와 연결 |
| 기지 오염도 | 없음 | 정화탑, 정화 시설 | `CORR-003` 상세화 |
| 플레이어 오염도 | 없음 | 정화 소모품, 치료 시설, 정화 영역 | `CORR-003` 상세화 |
| 지역 오염도 | 파생값 | 정화 범위와 기믹으로 변화 | 저장하지 않음 |

정화는 두 가지 방향을 가진다.

| 정화 방향 | 설명 |
|---|---|
| 정화 범위 확장 | 오염 영향을 받지 않는 기지 구역을 넓힘 |
| 정화 단계 상승 | 같은 구역의 오염 환산율을 낮추거나 정화 효율을 높임 |

정화 범위와 정화 단계는 기지 내 정화 시설을 통해 확장할 수 있다.

## 10. 오염도 적용 우선순위

오염 관련 계산은 다음 순서를 따른다.

1. Day 시작 또는 이벤트로 세계 오염도 갱신
2. 세계 오염도에 따른 기지 오염 압력 갱신
3. 잔존 공세, 보스전, 정화탑 상태로 기지 오염도 갱신
4. 지역·구역·기믹 기반 지역 오염도 계산
5. 플레이어별 노출 주기마다 플레이어 오염도 갱신
6. 오염 단계 변화 이벤트 발생
7. `STAT`, `COMBAT`, `CORE`, `BASE`에 오염 배율 전달

오염 효과가 실제 스탯과 피해에 적용되는 방식은 `CORR-002`, `STAT`, `CORE`, `COMBAT` 규칙을 따른다.

## 11. 오염도와 기존 시스템 연결

| 시스템 | 연결 |
|---|---|
| GAME | Day 시작 시 세계·기지 오염도 갱신 |
| BASE | 기지 구역, 정화탑, 시설 효율, 잔존 공세 오염 증가 |
| BASE-003 | `CORRUPTION_DECAY` 시설 피해 타입 |
| STAT | 오염으로 인한 상태·기믹 배율과 오염 피해 DEF 효율 |
| CORE | `POLLUTION` 피해 분류와 커스텀 HP 피해 처리 |
| COMBAT | AP 회복 감소, 이동·전투 효율 감소 |
| DEATH | 빈사 상태 오염 축적 150%, 최대 오염도 즉사 없음 |
| STATUS | 정화, 해제, 오염 변이 상태와 연결 |
| ACT/RES/CRAFT/RESEARCH | 정화 자원, 오염 연구, 위험 지역 보상 |

## 17. CORR-001 완료 기준

- 오염도 수치와 오염 강도의 범위가 정의되어 있다.
- 100% 이후 오염 강도 150% 상승 규칙이 정의되어 있다.
- 난이도별 오염 강도 최소값이 정의되어 있다.
- 세계, 기지, 플레이어, 지역 오염도의 역할이 분리되어 있다.
- 세계 오염도 증가 규칙이 Day 구간과 연결되어 있다.
- 기지 오염도 증가 규칙이 세계 오염, 잔존 공세, 보스전, 정화 상태와 연결되어 있다.
- 플레이어 오염도 축적 규칙이 주변 지역 오염도와 노출 시간에 연결되어 있다.
- 지역 오염도가 저장값이 아니라 구역 기반 파생값으로 정의되어 있다.
- 정화 범위 확장과 정화 단계 상승이 후속 작업으로 연결되어 있다.
- UI, 저장 데이터, 예외 처리, 테스트 항목이 정의되어 있다.

# CORR-002 오염 단계별 효과

## 1. 시스템 목적

`CORR-002`는 세계·기지·플레이어·지역 오염도가 실제 게임플레이에 적용하는 단계별 효과를 정의한다.

- 오염 단계가 상승할수록 플레이어가 체감할 수 있는 압박을 만든다.
- 오염도 100%가 즉시 패배나 즉사로 이어지지 않게 한다.
- 오염 효과를 전투, 회복, 구조, 기지 운영, 시설 피해와 연결한다.
- 오염 강도 100~150% 구간에서도 효과가 과도하게 폭주하지 않도록 개별 상한을 둔다.
- 실제 정화 수단과 정화 효율은 `CORR-003`에서 정의한다.

## 2. 오염 단계

오염 단계는 `오염도 수치`를 기준으로 판정한다.

| 단계 | 수치 범위 | 내부 ID | 의미 |
|---|---:|---|---|
| 안정 | 0~19 | `STABLE` | 체감 페널티 없음 |
| 경미 | 20~39 | `MINOR` | 경고와 약한 운영 압박 |
| 위험 | 40~59 | `DANGER` | 전투·회복 효율 저하 시작 |
| 심각 | 60~79 | `SEVERE` | 오염 피해와 구조 방해 시작 |
| 임계 | 80~99 | `CRITICAL` | 전투 지속력과 기지 운영 급감 |
| 붕괴 | 100 | `COLLAPSE` | 최대 오염 단계, 강도에 따라 추가 강화 |

단계 이름은 수치 기준으로 고정한다. `오염 강도`는 단계 이름을 바꾸지 않고, 단계 효과의 실제 적용량을 키우거나 줄인다.

### 효과 강도 배율

단계별 표의 수치는 `오염 강도 100%` 기준이다.

```text
오염 효과 강도 배율 =
오염 강도 / 100

최종 단계 효과 =
단계 기본 효과 × 오염 효과 강도 배율
```

예시:

| 오염도 | 강도 | 단계 | 기본 받는 피해 증가 | 최종 받는 피해 증가 |
|---:|---:|---|---:|---:|
| 80% | 100% | 임계 | +10% | +10% |
| 80% | 125% | 임계 | +10% | +12.5% |
| 100% | 150% | 붕괴 | +15% | +20% 상한 적용 |

각 효과는 개별 상한을 먼저 적용한 뒤 `STAT`, `COMBAT`, `CORE`, `DEATH`의 전체 상한 규칙을 따른다.

## 3. 세계 오염 단계 효과

세계 오염도는 플레이어에게 직접 디버프를 주기보다 몬스터, 지역, 이벤트, 기지 오염 압력을 강화한다.

| 단계 | 몬스터 변이 가중치 | 오염 지역 보정 | 특수 이벤트 강도 | 기지 오염 압력 |
|---|---:|---:|---:|---:|
| 안정 | +0% | +0 | ×1.00 | ×1.00 |
| 경미 | +5% | +0 | ×1.00 | ×1.00 |
| 위험 | +10% | +3 | ×1.05 | ×1.05 |
| 심각 | +18% | +6 | ×1.10 | ×1.10 |
| 임계 | +28% | +10 | ×1.20 | ×1.15 |
| 붕괴 | +40% | +15 | ×1.35 | ×1.30 |

- `몬스터 변이 가중치`는 corrupted, frenzied, enhanced 등급 등장 확률 계산에 사용한다.
- 실제 몬스터 등급별 출현 확률과 상한은 `ENEMY` 문서에서 확정한다.
- `오염 지역 보정`은 야생 지역 오염도 계산에 추가되는 값이다.
- 세계 오염 단계가 높아져도 플레이어 개인 오염도가 낮다면 즉시 개인 디버프를 받지는 않는다.

### 세계 붕괴+

세계 오염도 100%에서 오염 강도가 100%를 넘으면 UI에 `붕괴+` 또는 `초과 오염`으로 표시할 수 있다.

| 강도 | 표시 | 처리 |
|---:|---|---|
| 100~119% | 붕괴 | 기본 붕괴 단계 |
| 120~139% | 붕괴+ | 이벤트와 지역 위험도 강화 |
| 140~150% | 초과 오염 | 최종 구간 압박, 강한 오염 이벤트 가능 |

표시 이름만 달라지며 단계 ID는 `COLLAPSE`를 유지한다.

## 4. 기지 오염 단계 효과

기지 오염도는 시설 효율, 비전투 AP 회복 보너스, 기지 운영, 시설 부식에 영향을 준다.

| 단계 | 정화 효율 | 치료 비용 | 치료 시간 | 제작·강화 비용 | 비전투 AP 회복 보너스 효율 |
|---|---:|---:|---:|---:|---:|
| 안정 | 100% | +0% | +0% | +0% | 100% |
| 경미 | 95% | +5% | +0% | +0% | 100% |
| 위험 | 85% | +10% | +5% | +5% | 80% |
| 심각 | 70% | +20% | +10% | +10% | 60% |
| 임계 | 50% | +35% | +20% | +20% | 40% |
| 붕괴 | 30% | +50% | +35% | +35% | 20% |

- 기지 오염 100%가 되어도 모든 시설이 즉시 정지하지 않는다.
- 정화 효율 감소는 정화탑과 정화 시설의 오염 감소량에 적용한다.
- 치료 비용과 치료 시간 증가는 치료 시설 손상 효과와 별도로 중첩된다.
- 제작·강화 비용 증가는 일반 제작보다 강화, 재련, 고급 제작에 우선 적용한다.
- 비전투 AP 회복 보너스 효율은 기지 내부의 안전 정비 보너스에만 적용한다.

### 기지 시설 부식

기지 오염이 `임계` 이상이면 시설에 `CORRUPTION_DECAY`가 발생할 수 있다.

```text
시설 부식 피해/분 =
시설 최대 HP
× 단계별 부식 비율
× 기지 오염 강도 / 100
× 정화탑 상태 보정
```

| 단계 | 부식 비율 | 기본 주기 | 적용 대상 |
|---|---:|---:|---|
| 안정 | 없음 | 없음 | 없음 |
| 경미 | 없음 | 없음 | 없음 |
| 위험 | 없음 | 없음 | 없음 |
| 심각 | 없음 | 없음 | 없음 |
| 임계 | 0.05%/분 | 60초 | 핵심 시설, 정화 시설 |
| 붕괴 | 0.12%/분 | 60초 | 핵심 시설, 정비 시설, 정화 시설 |

| 정화탑 상태 | 부식 보정 |
|---|---:|
| 정상 | 0.5 |
| 손상 | 0.8 |
| 중파 | 1.2 |
| 정지 | 1.6 |

- 부식 피해는 `BASE-003`의 시설 피해 타입 `CORRUPTION_DECAY`를 사용한다.
- 부식만으로도 시설이 0%가 될 수 있지만, 이는 즉시 패배가 아니다.
- 방어벽, 문, 함정 같은 방어 구조물은 기본 부식 대상이 아니다. 특수 오염 이벤트가 명시한 경우에만 적용한다.
- 잔존 공세와 정화탑 정지가 겹치면 부식 압박이 커진다.

## 5. 플레이어 오염 단계 효과

플레이어 오염도는 개인 전투 지속력, 회복, 구조, 이동, 피해량, 받는 피해에 영향을 준다.

| 단계 | AP 자연 회복 | 받는 회복량 | 구조 속도 | 이동속도 | 주는 피해 | 받는 피해 |
|---|---:|---:|---:|---:|---:|---:|
| 안정 | 0% | 0% | 0% | 0% | 0% | 0% |
| 경미 | -5% | 0% | 0% | 0% | 0% | 0% |
| 위험 | -10% | -5% | -10% | -3% | -3% | +3% |
| 심각 | -20% | -10% | -15% | -6% | -7% | +6% |
| 임계 | -30% | -20% | -20% | -10% | -10% | +10% |
| 붕괴 | -40% | -30% | -30% | -15% | -15% | +15% |

### 플레이어 오염 효과 상한

| 효과 | 오염 단독 상한 | 전체 시스템 상한 |
|---|---:|---:|
| AP 자연 회복 감소 | -40% | 다른 효과 포함 -50% |
| 받는 회복량 감소 | -30% | 다른 효과 포함 -99% |
| 구조 속도 감소 | -30% | 다른 효과 포함 -50% |
| 이동속도 감소 | -15% | 최종 SPD 최소 1% |
| 주는 피해 감소 | -15% | Damage Dealt 하한 -99% |
| 받는 피해 증가 | +20% | Damage Taken 증가 상한 +300% |

`받는 피해 증가`는 일반 커스텀 피해와 오염 피해에 적용한다. 고정 피해, 시스템 피해, 별도 명시된 환경 피해에는 기본적으로 적용하지 않는다.

오염 단계 효과는 `STAT-002`의 출처 ID와 중첩 그룹을 따른다.

```text
source-id: corr.player.stage
stack-group: corruption.player.stage
```

같은 플레이어 오염 단계 효과는 중첩되지 않고 현재 단계의 값만 적용한다.

## 6. 오염 피해

오염 피해는 `POLLUTION` 피해 분류를 사용한다.

- `심각` 단계부터 발생한다.
- 플레이어 오염도가 높고 고오염 지역에 계속 노출될 때 주기적으로 발생한다.
- CORE의 `POLLUTION` 피해 처리, STAT의 난이도별 오염 피해 DEF 효율을 따른다.
- 오염 단계의 `받는 피해 증가`는 오염 피해에도 적용한다.
- 치명타는 발생하지 않는다.
- 생명력 흡수와 반사 피해의 원천이 되지 않는다.

### 오염 피해 발생 조건

오염 피해는 다음 조건을 모두 만족할 때 발생한다.

1. 플레이어 오염 단계가 `심각` 이상이다.
2. 현재 지역 오염도가 40 이상이다.
3. 플레이어가 정화 보호를 받는 중심부 또는 내부 안전 구역에 있지 않다.
4. 플레이어가 생존 또는 빈사 상태다.

### 오염 피해량

```text
오염 피해 =
최대 HP
× 단계별 피해 비율
× 플레이어 오염 강도 / 100
× 지역 오염도 / 100
× 지역 오염 강도 / 100
```

| 플레이어 단계 | 피해 비율 | 기본 주기 |
|---|---:|---:|
| 안정 | 없음 | 없음 |
| 경미 | 없음 | 없음 |
| 위험 | 없음 | 없음 |
| 심각 | 최대 HP의 0.40% | 5초 |
| 임계 | 최대 HP의 0.75% | 4초 |
| 붕괴 | 최대 HP의 1.00% | 3초 |

### 빈사 상태 오염 피해

빈사 상태에도 오염 피해는 적용한다.

- 빈사 상태의 플레이어도 주변 오염에 노출된다.
- 오염 피해는 빈사 체력 피해로 전환된다.
- 빈사 상태에서 오염 피해만으로 즉시 완전 사망하지 않도록 `DEATH`의 빈사 피해 상한을 따른다.
- 오염도 최대 상태 자체가 완전 사망 조건은 아니다.

## 7. 지역 오염 단계 효과

지역 오염도는 주로 플레이어 오염 축적과 오염 피해 조건에 사용한다.

| 지역 단계 | 지역 오염도 | 표시 | 즉시 효과 |
|---|---:|---|---|
| 안정 | 0~19 | 없음 또는 낮음 | 없음 |
| 경미 | 20~39 | 약한 파티클 | 오염 축적 시작 |
| 위험 | 40~59 | 파티클, 낮은 경고음 | 오염 피해 조건 충족 가능 |
| 심각 | 60~79 | 시야 가장자리 효과 | 오염 축적 증가 |
| 임계 | 80~99 | 강한 파티클, 심장박동음 | 오염 피해 위험 경고 |
| 붕괴 | 100 | 화면 경고, 강한 사운드 | 강한 오염 피해 조건 |

지역 오염 단계는 독립 디버프를 많이 직접 적용하지 않는다. 대부분은 플레이어 오염 축적과 오염 피해 발생 조건으로 처리한다.

## 8. 단계 변화 알림

| 대상 | 상승 알림 | 하락 알림 |
|---|---|---|
| 세계 오염 | 파티 전체 타이틀, 사운드 | 특수 정화 이벤트 때만 표시 |
| 기지 오염 | 파티 전체 채팅, 기지 경보음 | 정화 시설 효과로 하락 시 표시 |
| 플레이어 오염 | 개인 액션바, 경고음 | 개인 액션바 |
| 지역 오염 | 위험 지역 진입 경고 | 안전 구역 진입 안내 |

플레이어 개인 오염 단계가 `심각` 이상으로 상승하면 개인 경고를 강화한다. 기지 오염이 `임계` 이상이면 기지 GUI와 공세 관측 장치에 상시 경고를 표시한다.

## 9. 효과 적용 순서

플레이어에게 오염 효과를 적용할 때는 다음 순서를 따른다.

1. 플레이어 오염도 수치로 단계 판정
2. 플레이어 오염 강도로 효과 강도 배율 계산
3. 단계별 효과 기본값 선택
4. 오염 단독 상한 적용
5. `STAT` 보조 전투값에 출처 ID로 반영
6. 전체 시스템 상한 적용
7. 실제 전투, 회복, 구조, 이동 계산에 반영

오염 피해는 별도 피해 이벤트로 처리한다.

1. 오염 피해 발생 조건 확인
2. 최대 HP 기반 기본 피해 계산
3. 지역 오염도와 강도 반영
4. CORE의 `POLLUTION` 피해 처리
5. STAT의 난이도별 오염 피해 DEF 효율 적용
6. Damage Taken과 기타 대상 피해 보정 적용
7. HP 또는 빈사 체력에 적용

## 13. CORR-002 완료 기준

- 오염 피해 발생 조건, 피해량, 주기, 빈사 상태 처리가 정의되어 있다.
- 지역 오염 단계의 표시와 즉시 효과 범위가 정의되어 있다.
- 단계 변화 알림, 효과 적용 순서, 예외 처리, 테스트 항목이 정의되어 있다.

# CORR-003 정화탑 및 정화 자원

## 1. 목적

정화탑은 기지의 오염 방어를 담당하는 단일 핵심 시설이자, 탐사·수집·제작·연구를 디펜스 준비와 연결하는 공용 자원 소비처다.

- 기지의 지정 구역을 지역 오염도 0으로 유지한다.
- 기지 오염도와 오염 강도를 지속적으로 낮춘다.
- 보호 범위 안의 플레이어 오염도를 지속적으로 정화한다.
- 정화 자원의 생산과 소비를 파티의 Day 전략 선택으로 만든다.
- 시설 손상, 연료 부족, 보스전 장기화가 정화 운영에 실질적인 압박을 주게 한다.
- 한 기지에 주 정화탑은 하나만 존재하며 추가 정화탑을 설치하지 않는다.

## 2. 초기 상태와 해금

정화탑은 세션 시작 시 기지에 이미 설치되어 있으나 즉시 작동하지 않는다.

| 항목 | 초기값 |
|---|---|
| 설치 상태 | 설치 완료 |
| 시설 레벨 | 1 |
| 정화 범위 | 1단계, 중심부 12블록 |
| 정화 단계 | 1 |
| 운전 모드 | 표준 |
| 시설 HP | 6000/6000 |
| 작동 상태 | `LOCKED` |
| 초기 정화력 | 140 |

- Day 1의 초기 목표를 완료하면 `LOCKED`가 해제되고 자동 운전을 시작한다.
- 초기 정화력 140은 시설 손상과 오염 효율 감소가 없는 표준 운전 기준 14분, 즉 2 Day 동안 사용할 수 있다.
- 초기 목표 완료 전에 기지 중심부가 지나치게 오염되지 않도록 Day 1 초기 목표 진행 구간에는 임시 보호를 적용할 수 있다.
- 초기 목표 완료 이후에는 정화 자원 부족도 정상적인 운영 위험으로 취급한다.

## 3. 정화탑 성장 구조

정화탑은 세 개의 독립 성장축을 가진다.

| 성장축 | 상한 | 주요 효과 |
|---|---:|---|
| 시설 레벨 | 5 | 최대 HP, 정화 출력, 연료 효율, 기능 슬롯 |
| 정화 범위 | 3 | 보호 구역 확장 |
| 정화 단계 | 5 | 기지·플레이어 정화량, 외곽 완화율 |

- 시설 레벨이 올라도 정화 범위와 정화 단계가 자동으로 오르지 않는다.
- 정화 범위와 정화 단계는 요구 시설 레벨, 연구, 공용 자원을 모두 충족해야 강화할 수 있다.
- 모든 업그레이드는 비공세 상태에서만 가능하다.
- 업그레이드 도중 세션이 중단되면 진행도와 투입 자원을 저장한다.
- 구체적인 연구 비용과 제작식은 `RES-001`, `CRAFT-001`, `RESEARCH-001`에서 확정한다.

## 4. 시설 레벨

### 레벨별 성능

| 시설 레벨 | 최대 HP | 정화 출력 배율 | 연료 소비 배율 | 기능 슬롯 | 해금 |
|---:|---:|---:|---:|---:|---|
| 1 | 6000 | 1.00 | 1.00 | 0 | 기본 운전 |
| 2 | 6900 | 1.10 | 0.95 | 1 | 정화 중계기 |
| 3 | 7800 | 1.25 | 0.90 | 1 | 정화 증폭기, 집중 운전 |
| 4 | 9000 | 1.45 | 0.85 | 2 | 고급 정화 개조 |
| 5 | 10500 | 1.70 | 0.80 | 3 | 최종 정화 개조 |

```text
정화탑 최대 HP =
레벨 기본 HP
× 시설 강화 배율
+ 보강 부품 고정 HP
+ 연구 보너스 HP
```

- 시설 레벨 상승 시 현재 HP는 최대 HP 증가량만큼 함께 증가한다.
- 기능 슬롯에는 연구로 해금한 정화 개조를 장착한다.
- 기능 슬롯 교체는 비공세 상태에서만 가능하다.
- 기능 개조의 실제 목록은 후속 연구 및 시설 콘텐츠 기획에서 확장한다.

## 5. 정화 범위

### 범위 단계

| 범위 단계 | 반경 | 기본 보호 구역 | 요구 조건 |
|---:|---:|---|---|
| 1 | 12블록 | 기지 중심부 | 초기 |
| 2 | 24블록 | 내부 안전 구역 | 시설 레벨 2, 중계기 해금 |
| 3 | 48블록 | 외곽 방어선 | 시설 레벨 4, 고급 중계 연구 |

- 범위는 정화탑을 중심으로 하는 수평 원기둥이다.
- Y축은 BASE에 등록된 기지 영역 전체 높이를 사용한다.
- 기지 영역 밖으로 반경이 겹치더라도 기지 외부 야생을 영구 안전 지대로 만들지 않는다.
- 정상 작동 중인 정화탑의 현재 범위 안에서는 지역 오염도를 0으로 유지한다.
- 범위 확장은 기지 영역 자체를 확장하지 않는다.

### 정화 중계기

정화 중계기는 주 정화탑의 범위를 전달하는 보조 시설이다.

- 주 정화탑과 연결된 중계기만 작동한다.
- 범위 2단계와 3단계는 각각 대응 중계기 모듈이 정상이어야 유지된다.
- 중계기가 파괴되거나 정지하면 담당 구역의 보호가 즉시 해제된다.
- 주 정화탑과 다른 중계기가 정상이라면 나머지 보호 구역은 유지된다.
- 중계기 상태와 연결 정보는 저장한다.
- 중계기는 독립적인 연료를 소비하지 않고 주 정화탑의 정화력을 사용한다.

## 6. 정화 단계

### 단계별 기본 성능

| 정화 단계 | 기지 오염 감소/분 | 플레이어 오염 감소/분 | 외곽 지역 오염 환산율 | 기지 강도 감소/분 | 플레이어 강도 감소/분 |
|---:|---:|---:|---:|---:|---:|
| 1 | 0.50%p | 0.50%p | 100% | 1.00%p | 1.00%p |
| 2 | 0.75%p | 0.75%p | 85% | 1.25%p | 1.25%p |
| 3 | 1.00%p | 1.00%p | 70% | 1.50%p | 1.50%p |
| 4 | 1.30%p | 1.30%p | 55% | 1.80%p | 1.80%p |
| 5 | 1.65%p | 1.65%p | 40% | 2.20%p | 2.20%p |

- 외곽 지역 오염 환산율은 현재 정화 범위 바로 바깥의 다음 기지 구역 하나에만 적용한다.
- 예를 들어 범위 1단계라면 내부 안전 구역, 범위 2단계라면 외곽 방어선이 외곽 완화 대상이다.
- 범위 3단계에서는 기지 영역 밖 야생에 외곽 완화를 적용하지 않는다.
- 정상 작동 중인 보호 범위 안은 정화 단계와 무관하게 지역 오염도 0이다.
- 정화 단계는 정화 속도와 보호 범위 밖 완화 능력을 높이며, 범위 단계를 대체하지 않는다.

- 빈사 및 완전 사망 플레이어는 정화 자원을 투입하거나 회수할 수 없다.

## 8. 정화력 소비

### 기본 소비 공식

```text
분당 정화력 소비 =
10
× 시설 레벨 연료 소비 배율
× 시설 손상 소비 배율
× 운전 모드 소비 배율
× 과부하 소비 배율
```

- 소비는 내부적으로 틱당 누적하되 UI에는 분당 값과 예상 운전 시간을 표시한다.
- 플레이어 수에 따른 소비량 보정은 적용하지 않는다.
- 정화 대상 플레이어 수가 늘어나도 기본 소비량은 증가하지 않는다.
- 시설 레벨, 개조, 연구 외의 요소가 소비량을 변경하면 출처를 UI에 표시한다.

### 작동 시간 규칙

| 상황 | 정화 작동 | 정화력 소비 |
|---|---|---|
| 생존 플레이어 접속 중 | 진행 | 진행 |
| 공세 진행 중 | 진행 | 진행 |
| 보스전 진행 중 | 진행 | 진행 |
| Day 타이머 정지 보스전 | 진행 | 진행 |
| 서버에 생존 플레이어 없음 | 일시 정지 | 일시 정지 |
| 정상 세션 중단 | 저장 후 정지 | 정지 |
| 시설 정지 | 정지 | 정지 |
| 연료 고갈 | 비상 전력 후 정지 | 잔여량까지만 소비 |

- 관전 중인 완전 사망자만 접속해 있는 상태는 생존 플레이어가 없는 것으로 판정한다.
- 접속자가 한 명이라도 생존 상태라면 다른 플레이어의 접속 여부와 무관하게 작동한다.

## 9. 운전 모드

| 운전 모드 | 출력 배율 | 소비 배율 | 사용 조건 |
|---|---:|---:|---|
| 절약 `ECONOMY` | 0.60 | 0.40 | 정화탑 작동 가능 |
| 표준 `STANDARD` | 1.00 | 1.00 | 기본 모드 |
| 집중 `FOCUS` | 1.50 | 1.80 | 시설 레벨 3 이상 |

- 출력 배율은 기지 오염, 기지 강도, 플레이어 오염, 플레이어 강도 감소량에 모두 적용한다.
- 보호 범위 안의 지역 오염도 0 유지 여부는 출력 배율에 영향을 받지 않는다.
- 운전 모드는 공세와 보스전 중에도 변경할 수 있다.
- 모드 변경 후 실제 전환까지 10초가 필요하다.
- 전환 대기 중 기존 모드를 유지하며, 새 요청이 들어오면 기존 요청을 취소하고 다시 10초를 계산한다.
- 변경 요청은 파티 전체에 알리고 5초 동안 다른 생존 플레이어가 취소할 수 있다.

## 10. 시설 손상과 작동 상태

### 시설 손상 보정

| 시설 상태 | HP 기준 | 출력 배율 | 소비 배율 | 보호 범위 |
|---|---:|---:|---:|---|
| 정상 `NORMAL` | 70% 초과 | 1.00 | 1.00 | 정상 |
| 손상 `DAMAGED` | 40% 초과~70% 이하 | 0.75 | 1.10 | 오염 일부 누출 |
| 중파 `HEAVY_DAMAGED` | 0% 초과~40% 이하 | 0.40 | 1.30 | 오염 크게 누출 |
| 정지 `DISABLED` | 0% | 0 | 0 | 보호 해제 |

- 손상 상태의 지역 오염 누출 환산율은 CORR-001의 기지 구역별 표를 사용한다.
- 기지 오염 단계에 따른 정화 효율과 시설 손상 출력 배율은 곱연산한다.
- 중파 상태에서는 과부하 운전을 시작할 수 없다.
- 과부하 도중 중파 상태가 되면 과부하를 즉시 종료한다.
- 시설 수리 규칙과 수리 자원은 `BASE-003`을 따른다.

### 작동 상태

시설 손상 상태와 운전 상태는 별도로 저장한다.

| 운전 상태 | 의미 |
|---|---|
| `LOCKED` | 초기 목표 미완료 |
| `ACTIVE` | 정상 운전 |
| `MODE_SWITCHING` | 운전 모드 전환 대기 |
| `EMERGENCY_POWER` | 연료 고갈 직전 비상 전력 |
| `FUEL_EMPTY` | 정화력 고갈 |
| `PAUSED_EMPTY_SERVER` | 생존 플레이어 부재로 일시 정지 |
| `DISABLED` | 시설 HP 0 또는 기믹 정지 |

`FUEL_EMPTY`와 `DISABLED`는 모두 정화 기능을 멈추지만 원인, 복구 방법, UI 경고를 분리한다.

## 11. 연료 고갈과 비상 전력

정화력이 0에 도달하면 즉시 모든 보호를 해제하지 않고 60초 비상 전력으로 전환한다.

| 항목 | 비상 전력 규칙 |
|---|---|
| 지속시간 | 60초 |
| 지역 보호 | 기존 범위 유지 |
| 정화 출력 | 기본 출력의 50% |
| 정화력 소비 | 없음 |
| 운전 모드 변경 | 불가 |
| 과부하 | 불가 |
| 자원 충전 | 가능 |

- 60초 안에 정화력을 충전하면 기존 운전 모드로 복귀한다.
- 비상 전력이 종료될 때 정화력이 없다면 `FUEL_EMPTY`가 된다.
- `FUEL_EMPTY`에서는 지역 보호, 기지 정화, 플레이어 정화를 모두 중지한다.
- 정화력을 투입하면 3초 재가동 후 `ACTIVE`로 전환한다.
- 서버에 생존 플레이어가 없으면 비상 전력 남은 시간도 정지한다.

## 12. 기지 오염 정화

### 기지 오염도 감소

```text
분당 기지 오염 감소 =
정화 단계 기본 감소량
× 시설 레벨 출력 배율
× 시설 손상 출력 배율
× 운전 모드 출력 배율
× 과부하 출력 배율
× 기지 오염 단계 정화 효율
× 연구·개조 배율
```

- Normal, 시설 레벨 1, 정화 단계 1, 정상 상태, 표준 운전 기준 분당 0.5%p 감소한다.
- 같은 갱신 주기에 오염 증가와 정화가 함께 발생하면 오염 증가를 먼저 적용한 뒤 정화를 적용한다.
- 최종 기지 오염도는 0% 미만으로 내려가지 않는다.
- 기지 오염 정화는 세계 오염도를 낮추지 않는다.

### 기지 오염 강도 감소

기지 오염 강도는 다음 조건을 모두 만족할 때 감소한다.

1. 기지 오염도 수치가 100% 미만이다.
2. 현재 갱신 주기에 기지 오염 증가가 발생하지 않았다.
3. 정화탑이 실제 정화 출력을 내고 있다.

```text
분당 기지 오염 강도 감소 =
정화 단계 강도 감소량
× 시설 레벨 출력 배율
× 시설 손상 출력 배율
× 운전 모드 출력 배율
× 과부하 출력 배율
× 기지 오염 단계 정화 효율
```

- 강도는 현재 난이도의 최소 오염 강도 아래로 내려가지 않는다.
- 오염도 감소와 강도 감소 조건을 동시에 만족하면 둘 다 같은 주기에 처리한다.

## 13. 플레이어 오염 정화

### 범위 내 지속 정화

현재 정화 범위 안에 있는 플레이어는 다음 효과를 받는다.

- 지역 오염도가 시설 상태와 범위 규칙에 따라 억제된다.
- 플레이어 오염도가 정화 단계에 따라 지속 감소한다.
- 플레이어 오염 강도가 조건을 만족하면 난이도 최소값까지 감소한다.
- 전투 상태에서도 플레이어 오염도와 오염 강도 감소는 중지되지 않는다.
- 플레이어 수에 따라 개인 정화량을 나누지 않는다.

```text
분당 플레이어 오염 감소 =
정화 단계 기본 감소량
× 시설 레벨 출력 배율
× 시설 손상 출력 배율
× 운전 모드 출력 배율
× 과부하 출력 배율
× 기지 오염 단계 정화 효율
× 개인 정화 효율
```

- 완전 사망, 관전, 접속 종료 상태에서는 정화하지 않는다.
- 빈사 플레이어는 지역 보호는 받지만 플레이어 오염도와 강도 감소는 받지 않는다.
- 범위에서 벗어나면 즉시 지속 정화를 중지하고 일반 노출 계산으로 복귀한다.
- 플레이어 오염도는 0% 미만으로 내려가지 않는다.

### 플레이어 오염 강도 감소

플레이어 오염도 수치가 100% 미만이고 실제 정화 효과를 받고 있을 때 강도를 감소시킨다.

- 감소 공식은 플레이어 오염도 감소 공식의 기본 감소량 대신 단계별 강도 감소량을 사용한다.
- 난이도별 최소 오염 강도를 하한으로 사용한다.
- 해당 갱신 주기에 플레이어 오염이 증가했다면 강도 감소는 적용하지 않는다.
- 오염도 감소는 해당 주기에 노출 증가가 없거나 정화량이 증가량을 상쇄한 경우 정상 적용한다.

### 수동 개인 정화

생존 플레이어는 정화탑 GUI에서 공용 정화력을 소비해 개인 오염을 빠르게 정화할 수 있다.

| 항목 | 기본값 |
|---|---:|
| 채널링 시간 | 5초 |
| 정화력 비용 | 30 |
| 플레이어 오염도 감소 | 15%p |
| 플레이어 오염 강도 감소 | 5%p |
| 개인 재사용 대기시간 | 60초 |

- 이동, 피격, 다른 행동, 빈사, 접속 종료 시 채널링을 취소한다.
- 자원은 채널링 완료 시 소비한다.
- 전투 상태에서도 시도할 수 있지만 피격에 의해 중단될 수 있다.
- 빈사 및 완전 사망 플레이어는 사용할 수 없다.
- 강도 감소는 난이도별 최소값 아래로 내려가지 않는다.
- 오염도만 감소한 경우에도 재사용 대기시간을 적용한다.

## 14. 과부하 운전

과부하는 위기 상황에서 자원을 더 소비해 정화 출력을 일시적으로 높이는 공용 기능이다.

| 항목 | 규칙 |
|---|---|
| 비용 | 고순도 정화 촉매 1개 |
| 지속시간 | 3분 |
| 출력 배율 | 2.00 |
| 정화력 소비 배율 | 2.50 |
| 종료 후 재사용 대기 | 1분 |
| 시작 가능 상태 | 정상 또는 손상 |
| 중파·정지 | 시작 불가 |

- 과부하 배율은 현재 운전 모드 배율과 곱연산한다.
- 과부하 자체는 정화탑에 시설 피해를 주지 않는다.
- 과부하 중 중파, 정지, 연료 고갈이 발생하면 과부하를 즉시 종료한다.
- 중도 종료되어도 촉매와 사용된 정화력은 반환하지 않는다.
- 세션이 정상 중단되면 남은 지속시간과 재사용 대기시간을 저장한다.
- 서버에 생존 플레이어가 없으면 지속시간과 재사용 대기시간을 정지한다.

## 16. 정화 보조 시설과 개조

### 정화 증폭기

- 정화 단계의 실제 출력을 강화하는 보조 시설이다.
- 시설 레벨 3과 관련 연구가 필요하다.
- 별도 연료를 사용하지 않고 주 정화탑 소비량에 개조 배율을 더한다.
- 파괴되면 증폭 효과만 사라지며 주 정화탑은 계속 작동한다.

### 정화 중계기

- 정화 범위를 확장하는 보조 시설이다.
- 범위 단계별 담당 구역을 가진다.
- 담당 중계기가 정지하면 해당 구역의 보호만 해제한다.
- 중계기 복구 시 3초 연결 확인 후 보호를 다시 적용한다.

### 기능 개조

기능 개조는 시설 레벨로 확보한 슬롯에 장착한다. 다음 방향을 지원하되 구체적인 목록과 비용은 연구 기획에서 확정한다.

| 개조 방향 | 예시 |
|---|---|
| 연료 효율 | 분당 정화력 소비 감소 |
| 정화 출력 | 기지·플레이어 오염 감소 증가 |
| 안정화 | 오염 강도 감소 증가 |
| 비상 운전 | 비상 전력 지속시간 증가 |
| 방호 | 시설 HP 또는 오염 부식 저항 증가 |
| 중계 강화 | 외곽 완화율 또는 중계기 내구 증가 |

## 18. 계산 및 갱신 순서

정화와 오염은 다음 순서로 처리한다.

1. 생존 플레이어 접속 여부와 세션 진행 상태 확인
2. 시설 HP 상태와 보조 시설 연결 상태 갱신
3. 정화력, 비상 전력, 운전 상태 확인
4. Day·공세·보스·이벤트의 오염 증가량 계산
5. 세계 오염도 갱신
6. 기지 오염 증가 적용
7. 정화탑 기지 오염 감소 적용
8. 기지 오염 강도 감소 조건 판정 및 적용
9. 정화 범위와 지역 오염도 재계산
10. 플레이어 노출 오염 증가 적용
11. 범위 내 플레이어 지속 정화 적용
12. 플레이어 오염 강도 감소 조건 판정 및 적용
13. 단계 변화와 시설 효율 재계산
14. 정화력 소비와 UI 예상 시간 갱신
15. 변경 데이터 저장 예약

- 오염 증가와 정화 감소가 같은 틱에 발생하면 증가를 먼저 적용한다.
- 단계 효과는 최종 오염도와 강도가 확정된 뒤 재계산한다.
- 시설 정지와 범위 이탈은 다음 노출 주기를 기다리지 않고 즉시 지역 오염도 계산에 반영한다.

## 19. 모드별 규칙

Standard와 Chaos는 동일한 정화탑 구조와 레벨 상한을 사용한다.

| 항목 | Standard | Chaos |
|---|---|---|
| 시설 레벨 상한 | 5 | 5 |
| 범위 단계 상한 | 3 | 3 |
| 정화 단계 상한 | 5 | 5 |
| 기본 소비 공식 | 동일 | 동일 |
| 오염 압력 | Standard 데이터 | Chaos 데이터 |
| 자원 획득량 | Standard 데이터 | Chaos 데이터 |
| 연구·개조 배율 | Standard 데이터 | Chaos 전용 데이터 가능 |

- Chaos 전용으로 상한을 늘리지 않는다.
- Chaos의 높은 오염 압력은 자원 획득량, 연구, 개조와 함께 별도 밸런스한다.
- 모드 차이는 데이터 설정으로 관리하고 정화 처리 코드는 공유한다.

## 22. 플러그인 구현 기준

- 정화탑과 중계기는 바닐라 블록 조합을 좌표 기반 시설 오브젝트로 등록한다.
- 실제 성능, HP, 연료, 범위, 단계는 플러그인의 저장 데이터로 관리한다.
- 범위 판정은 플레이어 이동 또는 5틱 주기의 공간 검사로 갱신한다.
- 오염 감소와 연료 소비는 누적 소수값을 지원하며 1초 단위로 정산한다.
- 지역 오염도는 청크에 영구 저장하지 않고 CORR-001의 구역 기반 파생값으로 계산한다.
- GUI는 인벤토리 인터페이스로 구현하고, 수치 경고는 액션바·타이틀·사운드로 보조한다.
- 시설 HP와 수리는 `BASE-003` 시설 API를 사용한다.
- 정화 효과는 상태이상 해제가 아니라 CORR 저장값을 직접 감소시키는 독립 처리다.
- 정화 자원 아이템은 `PersistentDataContainer` 또는 프로젝트의 커스텀 아이템 식별자를 사용한다.
- 정화탑 로직은 MagicSpells에 의존하지 않는다. 연출이 필요하면 파티클·사운드 실행만 외부 플러그인과 연동할 수 있다.

## 25. CORR-003 완료 기준

- 정화탑의 초기 해금, 성장축, 레벨 상한이 정의되어 있다.
- 정화 범위 1~3단계와 정화 단계 1~5단계가 분리되어 있다.
- 정화 결정, 고순도 정화 촉매, 정화 코어 조각의 용도가 정의되어 있다.
- 정화력 소비, 무인 서버, 공세, 보스전 규칙이 정의되어 있다.
- 절약·표준·집중 운전과 과부하 운전이 정의되어 있다.
- 시설 손상, 연료 고갈, 비상 전력, 중계기 파괴 처리가 정의되어 있다.
- 기지 오염도·강도와 플레이어 오염도·강도 감소 공식이 정의되어 있다.
- 전투 중 지속 정화, 빈사, 수동 정화 규칙이 정의되어 있다.
- 조작 권한, 공세 중 제한, UI, 저장, 예외, 테스트 기준이 정의되어 있다.
- 바닐라와 플러그인으로 구현 가능한 데이터 구조가 정의되어 있다.
